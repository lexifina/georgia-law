# მუხლი 53. დამკვირვებლის უფლებები
1. დამკვირვებელს უფლება აქვს :
ა ) დაესწროს და დააკვირდეს საარჩევნო კომისიის სხდომებს ;
ბ ) კენჭისყრის დღეს ნებისმიერ დროს იმყოფებოდეს კენჭისყრის შენობაში , შეუზღუდავად გადაადგილდეს საარჩევნო უბნის ტერიტორიაზე და თავისუფლად , დაუბრკოლებლად დააკვირდეს კენჭისყრის პროცესის ყველა ეტაპს ნებისმიერი ადგილიდან ;
გ ) კენჭისყრის დღეს ნებისმიერ დროს შეენაცვლოს მისი წარმდგენი დამკვირვებელი ორგანიზაციის სხვა რეგისტრირებულ წარმომადგენელს ( არსებობის შემთხვევაში );
დ ) მონაწილეობა მიიღოს საარჩევნო ყუთების შემოწმებაში მათ დალუქვამდე და მათი გახსნის შემდეგ ;
ე ) დააკვირდეს ამომრჩეველთა სიებში ამომრჩეველთა რეგისტრაციას , საარჩევნო ბიულეტენებისა და სპეციალური კონვერტების გაცემასა და დამოწმებას კენჭისყრის პროცესისთვის ხელის შეუშლელად ;
ვ ) დააკვირდეს კენჭისყრის დღეს საჩივრების რეგისტრაციის პროცესს ;
ზ ) დაესწროს ამომრჩეველთა ხმების დათვლისა და შედეგების შეჯამების პროცედურებს ;
თ ) დააკვირდეს გადასატანი საარჩევნო ყუთის მეშვეობით ხმის მიცემის პროცესს ;
ი ) დააკვირდეს ამომრჩეველთა ხმების დათვლას ისეთ პირობებში , რომლებიც უზრუნველყოფს საარჩევნო ბიულეტენის დანახვას ;
კ ) დააკვირდეს საარჩევნო კომისიის მიერ კენჭისყრის შედეგების შემაჯამებელი ოქმისა და სხვა დოკუმენტების შედგენას ;
ლ ) საუბნო საარჩევნო კომისიის თავმჯდომარეს მიმართოს ხმის მიცემისა და კენჭისყრის პროცედურებთან დაკავშირებულ საკითხებზე განცხადებით / საჩივრით , რომლითაც კონკრეტული დარღვევის დაფიქსირების შემთხვევაში მოითხოვს რეაგირებას ;
მ ) მოსთხოვოს ამომრჩეველს , უჩვენოს , რამდენი საარჩევნო ბიულეტენი და სპეციალური კონვერტი აქვს ხელში ;
ნ ) საქართველოს კანონმდებლობით დადგენილი წესით გაასაჩივროს საარჩევნო კომისიის ქმედება ;
ო ) დააკვირდეს საარჩევნო ყუთს , საარჩევნო ყუთში სპეციალური კონვერტების ჩაყრას , საარჩევნო ყუთების გახსნას , საარჩევნო ბიულეტენების დათვლას და ოქმების შედგენას ;
პ ) გაეცნოს საარჩევნო კომისიების მიერ შედგენილ კენჭისყრისა და არჩევნების შედეგების შემაჯამებელ ოქმებს , შესაბამისი საარჩევნო კომისიისგან მოითხოვოს და მიიღოს ამ ოქმების ასლები .
2. დამკვირვებელს უფლება არა აქვს :
ა ) ჩაერიოს საარჩევნო კომისიის ფუნქციებსა და საქმიანობაში ;
ბ ) გავლენა მოახდინოს ამომრჩეველთა მიერ ნების თავისუფალ გამოვლენაზე ;
გ ) აგიტაცია გაუწიოს ამომრჩეველს რომელიმე საარჩევნო სუბიექტის სასარგებლოდ ან საწინააღმდეგოდ ;
დ ) ატაროს რომელიმე საარჩევნო სუბიექტის სიმბოლიკა და ნიშანი ;
ე ) კენჭისყრის დღეს კენჭისყრის შენობაში იმყოფებოდეს სამკერდე ნიშნის გარეშე ;
ვ ) დაარღვიოს ამ კანონის სხვა მოთხოვნები .
3. ადგილობრივი / საერთაშორისო დამკვირვებლის , საარჩევნო სუბიექტისა და მედიის წარმომადგენლების ამ კანონით მინიჭებული უფლებების დარღვევისთვის ან მათ საქმიანობაში ჩარევისთვის პასუხისმგებლობა განისაზღვრება საქართველოს საარჩევნო , ადმინისტრაციული ან / და სისხლის სამართლის კანონმდებლობით დადგენილი წესით .
4. დამკვირვებლის , საარჩევნო სუბიექტისა და მედიის წარმომადგენლების მიერ ამ მუხლის მე -2 პუნქტის " ა "-" დ " ქვეპუნქტების მოთხოვნების დარღვევა გამოიწვევს მათთვის საქართველოს საარჩევნო კანონმდებლობით დადგენილი წესით პასუხისმგებლობის დაკისრებას .
5. საარჩევნო კომისია ვალდებულია შექმნას ყველა პირობა იმისთვის , რომ დამკვირვებელს შეეძლოს საკუთარი უფლებამოსილების განხორციელება საარჩევნო კომისიაში მიმდინარე ყველა პროცედურასთან დაკავშირებით , მათ შორის , საარჩევნო ბიულეტენების დათვლისა და შედეგების შეჯამების მსვლელობის დროს .
