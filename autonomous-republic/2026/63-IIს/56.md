# მუხლი 56. ადგილობრივი დამკვირვებელი ორგანიზაციის ადგილობრივი დამკვირვებლისთვის , პრესის ან მასობრივი ინფორმაციის სხვა საშუალების წარმომადგენლისა და საარჩევნო სუბიექტის წარმომადგენლისთვის დადგენილი მოთხოვნები
1. ამ კანონით განსაზღვრული ადგილობრივი დამკვირვებელი ორგანიზაციის ადგილობრივი დამკვირვებელი / პრესის ან მასობრივი ინფორმაციის სხვა საშუალების წარმომადგენელი არ შეიძლება იმავდროულად იყოს :
ა ) " საჯარო სამსახურის შესახებ " საქართველოს კანონით გათვალისწინებული სახელმწიფო - პოლიტიკური თანამდებობის პირი ;
ბ ) მუნიციპალიტეტის წარმომადგენლობითი ორგანოს - საკრებულოს წევრი ;
გ ) მუნიციპალიტეტის აღმასრულებელი ორგანო - მერი , მუნიციპალიტეტის მერის მოადგილე ;
დ ) მოსამართლე ;
ე ) საქართველოს შინაგან საქმეთა სამინისტროს , საქართველოს თავდაცვის სამინისტროს , საქართველოს იუსტიციის სამინისტროს გენერალური ინსპექციის , ამავე სამინისტროს სისტემაში შემავალი სახელმწიფო საქვეუწყებო დაწესებულების − სპეციალური პენიტენციური სამსახურის , საქართველოს სახელმწიფო უსაფრთხოების სამსახურის , სახელმწიფო დაცვის სპეციალური სამსახურის თანამშრომელი ;
ვ ) პროკურატურის თანამდებობის პირი ;
ზ ) პირი , რომელიც არჩევნების დანიშვნიდან იყო / არის საარჩევნო სუბიექტი / საარჩევნო სუბიექტობის კანდიდატი ან / და მისი წარმომადგენელი ;
თ ) საარჩევნო კომისიის წევრი ;
ი ) სხვა დამკვირვებელი ორგანიზაციის დამკვირვებელი / პრესის ან მასობრივი ინფორმაციის სხვა საშუალების წარმომადგენელი ( ადგილობრივი დამკვირვებელი ორგანიზაციის ადგილობრივი დამკვირვებლის შემთხვევაში );
კ ) პრესის ან მასობრივი ინფორმაციის სხვა საშუალების წარმომადგენელი / დამკვირვებელი ორგანიზაციის ხელმძღვანელი პირი , დამკვირვებელი ( პრესის ან მასობრივი ინფორმაციის სხვა საშუალების წარმომადგენლის შემთხვევაში );
ლ ) პირი , რომელიც არჩევნების დანიშვნიდან იყო / არის პარტიის ხელმძღვანელი პირი ;
მ ) პირი , რომელიც საქართველოს საარჩევნო კანონმდებლობის დარღვევის გამო საარჩევნო კომისიამ ან სასამართლომ გაათავისუფლა საარჩევნო ადმინისტრაციაში დაკავებული თანამდებობიდან , - თანამდებობიდან გათავისუფლების დღიდან 4 წლის განმავლობაში ;
ნ ) პირი , რომელიც საქართველოს საარჩევნო კანონმდებლობის დარღვევის გამო სასამართლომ ცნო ადმინისტრაციულ სამართალდამრღვევად , - სასამართლოს გადაწყვეტილების კანონიერ ძალაში შესვლიდან 4 წლის განმავლობაში .
2. ადგილობრივი დამკვირვებელი ორგანიზაციის ადგილობრივი დამკვირვებელი ასევე არ შეიძლება იყოს პირი , რომელიც :
ა ) ბოლოს ჩატარებული ორი საერთო არჩევნებიდან ან ბოლოს ჩატარებული ორი შუალედური არჩევნებიდან რომელიმეს დანიშვნის შემდეგ იყო პარტიის მიერ დანიშნული საარჩევნო კომისიის წევრი , საარჩევნო სუბიექტი ან საარჩევნო სუბიექტის წარმომადგენელი ;
ბ ) ბოლოს ჩატარებული საერთო არჩევნების წლის დასაწყისიდან ან ბოლოს ჩატარებული შუალედური არჩევნების წლის დასაწყისიდან იყო რომელიმე პარტიის შემომწირველი .
3. საარჩევნო სუბიექტის წარმომადგენლად არ შეიძლება დაინიშნოს :
ა ) პირი , რომელიც არჩევნების დანიშვნიდან იყო / არის საარჩევნო სუბიექტი ან საარჩევნო სუბიექტობის კანდიდატი ;
ბ ) სხვა საარჩევნო სუბიექტის წარმომადგენელი ;

დ ) ადგილობრივი დამკვირვებელი , საერთაშორისო დამკვირვებელი ;
ე ) პრესის ან მასობრივი ინფორმაციის სხვა საშუალების წარმომადგენელი ;
ვ ) დამკვირვებელი ორგანიზაციის ხელმძღვანელი პირი ;
ზ ) პირი , რომელიც საქართველოს საარჩევნო კანონმდებლობის დარღვევის გამო საარჩევნო კომისიამ ან სასამართლომ გაათავისუფლა საარჩევნო ადმინისტრაციაში დაკავებული თანამდებობიდან , - თანამდებობიდან გათავისუფლების დღიდან 4 წლის განმავლობაში ;
