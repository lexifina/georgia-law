# მუხლი 6. მართვის ორგანოს მიერ გაწეული მომსახურების სახეები
1. მართვის ორგანოს მიერ გაწეული მომსახურების სახეებია:
ა) ხე-ტყის დამზადების ბილეთის გაცემა;
ბ ) ხე-ტყის დამზადება;
გ ) ნადირობის ბი ლეთის გაცემა;
დ ) ტყის რესურსით სარგებლობის ბილეთის გაცემა;
ე ) სალიცენზიო ობიექტის მომზადება;
ვ ) ტყის ფონდის სარგებლობის უფლებით გაცემა;
ზ ) ტყის ფონდში მიწის ნაკვეთის შესახებ ინფორმაციის მომზადება:
თ ) ტყეკაფის მონიშვნა;
ი ) ხე-ტყის წარმოშობის დოკუმენტის გაცემა ან/და სპეციალური ფირნიშებით მარკირება.
2. აჭარის ავტონომიური რესპუბლიკის მთავრობის დადგენილებით შეიძლება განისაზღვროს მართვის ორგანოს მიერ გაწეული მომსახურების სხვა სახეებიც.
