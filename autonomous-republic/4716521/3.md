# მუხლი 3
საბჭოთა სახელმწიფოს ორგანიზაციასა და საქმიანობას საფუძვლად უდევს დემოკრატიული ცენტრალიზმის პრინციპი - ქვემოდან ზემოთ სახელმწიფო ხელისუფლების ყველა ორგანოს არჩევითობა, მათი ანგარიშვალდებულება ხალხის წინაშე, ქვემდგომი ორგანოებისათვის ზემდგომი ორგანოების გადაწყვეტილებათა სავალდებულოობა. დემოკრატიული ცენტრალიზმი ერთიან ხელმძღვანელობას უხამებს ადგილობრივ ინიციატივასა და შემოქმედებითს აქტიურობას, თითოეული სახელმწიფო ორგანოსა და თანამდებობის პირის პასუხისმგებლობას დაკისრებული საქმისათვის.
