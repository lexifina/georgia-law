# მუხლი 21. პარტიის მიერ უსკოს დროებითი წევრის დანიშვნისა და მისთვის უფლებამოსილების შეწყვეტის წესი
1. პარტიას უფლება აქვს, დანიშნოს უსკოს 1 წევრი, თუ პარტია ცესკოს თავმჯდომარის მიერ რეგისტრირებული იყო საქართველოს პარლამენტის არჩევნებში მონაწილეობის მიზნით და მას საქართველოს ორგანული კანონის "საქართველოს საარჩევნო კოდექსი" 135-ე მუხლის მე-3-მე-5 ნაწილების შესაბამისად მიეკუთვნა საქართველოს პარლამენტის წევრის მანდატი.
2. თუ ამ მუხლის პირველი პუნქტით გათვალისწინებული პარტიების რაოდენობა 9-ზე მეტია, უსკოს წევრის დანიშვნისას უპირატესობა ენიჭება იმ პარტიას, რომელმაც საქართველოს პარლამენტის არჩევნებში უფრო მეტი ხმა მიიღო.
3. თუ პარტიებმა საქართველოს პარლამენტის არჩევნებში ხმების თანაბარი რაოდენობა მიიღეს, უსკოს წევრის დანიშვნისას უპირატესობა ენიჭება იმ პარტიას, რომელმაც საარჩევნო რეგისტრაცია უფრო ადრე გაიარა.
4. პარტიის მიერ დანიშნული უსკოს წევრი უნდა აკმაყოფილებდეს ამ კანონის მე-19 მუხლის მე-5 პუნქტის მოთხოვნებს.
5. უსკოს წევრის დანიშვნის შესახებ პოლიტიკური პარტიის უფლებამოსილი პირის მიერ ხელმოწერილი განცხადება უსკოს უნდა წარედგინოს უმაღლესი საბჭოს არჩევნების დანიშვნიდან არაუგვიანეს 3 კალენდარული დღის განმავლობაში. აღნიშნულ განცხადებაში მითითებული უნდა იყოს დანიშნული პირის სახელი, გვარი; განათლება (უმაღლესი); სპეციალობა, სამეცნიერო ხარისხი (თუ აქვს). მისამართი საქართველოს მოქალაქის პირადობის (რეგისტრაციის) მოწმობის შესაბამისად; სამუშაო ადგილი და თანამდებობა; საკონტაქტო მისამართი, ტელეფონის ნომერი (თუ აქვს) და მას უნდა დაერთოს:
ა) პირის 2 ფოტოსურათი;
ბ) საქართველოს მოქალაქის პირადობის მოწმობის ან საქართველოს მოქალაქის პასპორტის ფოტოასლი;
გ) უმაღლესი განათლების (სამეცნიერო ხარისხის - თუ აქვს) დამადასტურებელი დოკუმენტის ფოტოასლი;
დ) საარჩევნო ადმინისტრაციის მოხელის სერტიფიკატის ფოტოასლი.
6. პარტიას უფლება არა აქვს, გამოიწვიოს და დანიშნოს უსკოს ახალი წევრი კენჭისყრის დღემდე ბოლო 3 კვირის განმავლობაში. პარტიას უფლება აქვს, კენჭისყრის დღემდე ბოლო 3 კვირის განმავლობაში უსკოს ახალი წევრი დანიშნოს მხოლოდ დანიშნული წევრის გადადგომის ან გარდაცვალების შემთხვევაში, აგრეთვე იმ შემთხვევაში, თუ სასამართლოს გადაწყვეტილებით შეუძლებელია პირის მიერ უსკოს წევრის საქმიანობის განხორციელება.
