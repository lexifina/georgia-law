# მუხლი 3. კანონის ძირითადი მიზნებია
1.აჭარის ავტონომიურ რესპუბლიკაში განათლების სფეროში უზრუნველყოს:
ა) სამეცნიერო-კვლევითი საქმიანობისა და ინფრასტრუქტურის განვითარების ხელშეწყობა;
ბ) სკოლამდელი, ზოგადი, პროფესიული და უმაღლესი განათლების ხელშეწყობა;
გ) სახელოვნებო და არაფორმალური განათლების ხელშეწყობა;
დ) სკოლისგარეშე სასპორტო განათლების მხარდაჭერა;
ე) ინკლუზიური განათლების მხარდაჭერა;
ვ) განათლების ხელმისაწვდომობის გაზრდა.
2. განათლების სფეროში საქართველოს ერთიანი სამთავრობო პოლიტიკის გატარებისა და საკუთარი კომპეტენციის ფარგლებში სამინისტროს სისტემაში შემავალი ყველა რგოლის საქმიანობის კოორდინაცია და კონტროლის განხორციელება.
