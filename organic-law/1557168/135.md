# მუხლი 135. ადგილობრივი თვითმმართველობის წარმომადგენლობითი ორგანოს - საკრებულოს, თვითმმართველი ქალაქის მერის და თვითმმართველი თემის გამგებლის უფლებამოსილებათა ვადები
[მუხლი 135. მუნიციპალიტეტის წარმომადგენლობითი ორგანოს - საკრებულოს და თვითმმართველი ქალაქის/თვითმმართველი თემის მერის უფლებამოსილებათა ვადები ( ამოქმედდეს 2017 წლის ადგილობრივი თვითმმართველობის ორგანოების მორიგი არჩევნების შედეგების ოფიციალურად გამოცხადების დღიდან ) ]
1. მორიგ არჩევნებში არჩეული ადგილობრივი თვითმმართველობის წარმომადგენლობითი ორგანოს - საკრებულოს, აგრეთვე თვითმმართველი ქალაქის/თემის მერის/გამგებლის უფლებამოსილების ვადაა 4 წელი.
[ 1. მორიგ არჩევნებში არჩეული მუნიციპალიტეტის წარმომადგენლობითი ორგანოს - საკრებულოს და თვითმმართველი ქალაქის/თვითმმართველი თემის მერის უფლებამოსილების ვადაა 4 წელი. ( ამოქმედდეს 2017 წლის ადგილობრივი თვითმმართველობის ორგანოების მორიგი არჩევნების შედეგების ოფიციალურად გამოცხადების დღიდან ) ]
2. საკრებულოს ახალი შემადგენლობის უფლებამოსილება იწყება, ხოლო ძველისა წყდება ახალარჩეული საკრებულოს პირველი შეკრებისთანავე.
3. საკრებულოს უფლებამოსილების ვადამდე შეწყვეტის შემთხვევაში ახალარჩეული საკრებულოს უფლებამოსილება იწყება მისი პირველი შეკრებისთანავე.
4. თვითმმართველი ქალაქის/თემის ახალარჩეული მერის/გამგებლის უფლებამოსილება იწყება, ხოლო ძველისა წყდება შესაბამისი საარჩევნო კომისიის მიერ არჩევნების შედეგების შემაჯამებელი ოქმის შედგენიდან (მერის/გამგებლის არჩეულად გამოცხადებიდან) მე-11 დღეს.
5. თვითმმართველი ქალაქის/თემის მერის/გამგებლის უფლებამოსილების ვადამდე შეწყვეტის შემთხვევაში ახალარჩეული მერის/გამგებლის უფლებამოსილება იწყება შესაბამისი საარჩევნო კომისიის მიერ არჩევნების შედეგების შემაჯამებელი ოქმის შედგენიდან (მერის/გამგებლის არჩეულად გამოცხადებიდან) მე-11 დღეს.
[ 4. თვითმმართველი ქალაქის/თვითმმართველი თემის ახალარჩეული მერის უფლებამოსილება იწყება, ხოლო ძველი მერის უფლებამოსილება წყდება შესაბამისი საარჩევნო კომისიის მიერ არჩევნების შედეგების შემაჯამებელი ოქმის შედგენიდან (მერის არჩეულად გამოცხადებიდან) მე-11 დღეს.
5. თვითმმართველი ქალაქის/თვითმმართველი თემის მერის უფლებამოსილების ვადამდე შეწყვეტის შემთხვევაში ახალარჩეული მერის უფლებამოსილება იწყება შესაბამისი საარჩევნო კომისიის მიერ არჩევნების შედეგების შემაჯამებელი ოქმის შედგენიდან (მერის არჩეულად გამოცხადებიდან) მე-11 დღეს. ( ამოქმედდეს 2017 წლის ადგილობრივი თვითმმართველობის ორგანოების მორიგი არჩევნების შედეგების ოფიციალურად გამოცხადების დღიდან ) ]
