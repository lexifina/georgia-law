# მუხლი 3. ეროვნული უშიშროების საბჭოს შემადგენლობა
1. ეროვნული უშიშროების საბჭოს სხდომებს თავმჯდომარეობს საქართველოს პრეზიდენტი.
2. ეროვნული უშიშროების საბჭოს მუდმივი წევრები არიან: საქართველოს პრემიერ-მინისტრი, საქართველოს საგარეო საქმეთა მინისტრი, საქართველოს თავდაცვის მინისტრი, საქართველოს შინაგან საქმეთა მინისტრი, საქართველოს ფინანსთა მინისტრი და საქართველოს პრეზიდენტის თანაშემწე ეროვნული უშიშროების საკითხებში - ეროვნული უშიშროების საბჭოს მდივანი.
3. ეროვნული უშიშროების საბჭოს სხდომების მუშაობაში უშუალოდ მონაწილეობს საქართველოს პარლამენტის თავმჯდომარე.
4. საჭიროების შემთხვევაში, საქართველოს პრეზიდენტის გადაწყვეტილებით, ეროვნული უშიშროების საბჭოს სხდომაზე დასასწრებად შეიძლება მოწვეული იქნენ სხვა პირები.
- საქართველოს 2004 წლის 28 დეკემბერის ორგანული კანონი №824 - სსმ I, №4, 17.01.2005 წ., მუხ.13
