# მუხლი 1
საქართველოს კონსტიტუციის 52-ე მუხლის პირველი პუნქტის "ზ" ქვეპუნქტისა და "საქართველოს სახელმწიფო ჯილდოებისა და პრემიების შესახებ" საქართველოს კანონის მე-4 მუხლის მე-6 პუნქტის შესაბამისად, დამტკიცდეს საქართველოს სახელმწიფო ჯილდოებით დაჯილდოების თანდართული წესი დანართებით (დანართი №1, №2 და №3).
