# მუხლი 5
1. კანონის მე-2 მუხლის "ბ" ქვეპუნქტით გათვალისწინებულ შემთხვევაში, პირის მედლით დაჯილდოების თაობაზე, დაწესებულება, რომელშიც იგი მუშაობს ან ორგანო, რომლის სამოქმედო ტერიტორიაზეც იგი ცხოვრობს, შუამდგომლობით მიმართავს წარდგინების უფლებამოსილების მქონე ამ წესის მე-4 მუხლით გათვალისწინებულ თანამდებობის პირს.
2. პირის დაჯილდოების თაობაზე ამ წესის მე-4 მუხლით განსაზღვრული თანამდებობის პირის წარდგინებაში მითითებული უნდა იყოს აგრეთვე ჯილდოს გადამცემი პირის ვინაობა. წარდგინებას უნდა ერთოდეს შევსებული დაჯილდოების ფურცელი (დანართი №1).
3. საქართველოს პრეზიდენტის ადმინისტრაციის შესაბამისი დეპარტამენტი (შემდეგში - დეპარტამენტი) განიხილავს წარდგინებას თანდართულ დოკუმენტაციასთან ერთად და, მისი კანონმდებლობის მოთხოვნებთან შესაბამისობის შემთხვევაში, საქართველოს პრეზიდენტს წარუდგენს პირის დაჯილდოების თაობაზე შესაბამის წინადადებას, ხოლო საქართველოს პრეზიდენტის მიერ დაჯილდოების საკითხის დადებითად გადაწყვეტის შემთხვევაში ამზადებს სამართლებრივი აქტის პროექტს.
