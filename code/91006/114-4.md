# მუხლი 114⁴. ამ კოდექსით გათვალისწინებული საჯარო სამართლის იურიდიული პირებისა და არასამეწარმეო (არაკომერციული) იურიდიული პირების განსაზღვრა
1. ამ კოდექსის მე-6 მუხლის "ბ¹" და "ბ²" ქვეპუნქტებით გათვალისწინებული საჯარო სამართლის იურიდიული პირებისათვის და არასამეწარმეო (არაკომერციული) იურიდიული პირებისათვის ამ კოდექსით განსაზღვრული დებულებები საჯარო სკოლებსა და საბავშვო ბაღებზე/სკოლამდელი აღზრდის სხვა დაწესებულებებზე გავრცელდეს 2018 საბიუჯეტო წლისათვის.
2. ამ კოდექსის მე-6 მუხლის "ბ¹.ბ" და "ბ².ბ" ქვეპუნქტებით გათვალისწინებული საჯარო სამართლის იურიდიული პირებისათვის და არასამეწარმეო (არაკომერციული) იურიდიული პირებისათვის ამ კოდექსით განსაზღვრული დებულებები მათზე გავრცელდეს 2016 საბიუჯეტო წლისათვის, გარდა იმ იურიდიული პირებისა, რომლებიც დაფუძნებულია თვითმმართველი ქალაქების ან მათი ორგანოების მიერ ან ექვემდებარება მათ კონტროლს.
- საქართველოს 2014 წლის 12 დეკემბრის კანონი №2935 - ვებგვერდი, 24.12.2014წ.
