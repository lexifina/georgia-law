# მუხლი 62. საგანგებო, მათ შორის, საომარი მდგომარეობის, მობილიზაციის დროს და სხვა საგანგებო სიტუაციებში რკინიგზის მუშაობის ორგანიზება
1. საგანგებო, მათ შორის, საომარი მდგომარეობის, მობილიზაციის დროს და სხვა საგანგებო სიტუაციებში სარკინიგზო ტრანსპორტის საწარმოები (ორგანიზაციები და ა.შ.), სახელმწიფო ხელისუფლების ცენტრალურ და ადგილობრივი თვითმმართველობის (მმართველობის) ორგანოებთან ერთად, ახორციელებენ შესაბამის დაუყოვნებლივ ღონისძიებებს საქართველოს კანონმდებლობით დადგენილი წესით.
2. პასუხისმგებლობა რკინიგზის მუშაობის განზრახ შეფერხების, შეწყვეტისა და ტექნიკური საშუალებების დაზიანებისათვის განისაზღვრება საქართველოს კანონმდებლობით დადგენილი წესით.
