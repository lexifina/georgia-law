# მუხლი 107. საქონლის შენახვა საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის საბაჟო საწყობში
1. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის საბაჟო საწყობი ღია სახისაა.
2. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის საბაჟო საწყობში საქონლის შენახვისას საბაჟო ორგანოსა და მომთავსებელს შორის წარმოშობილი ურთიერთობები, მათი უფლება-მოვალეობები და პასუხისმგებლობა რეგულირდება საქართველოს სამოქალაქო კოდექსითა და ამ კოდექსით.
