# მუხლი 28. საბაჟო მოსაკრებლებისა და საბაჟო ტარიფის განაკვეთები
საბაჟო მოსაკრებლების განაკვეთები, მათი შემოღებისა და ადმინისტრირების წესები რეგულირდება "საბაჟო მოსაკრებლების შესახებ" საქართველოს კანონით, ხოლო საბაჟო ტარიფის განაკვეთები, მათი შემოღებისა და ადმინისტრირების წესები - "საბაჟო ტარიფის შესახებ" საქართველოს კანონით.
