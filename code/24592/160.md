# მუხლი 160. თავისუფალი ზონის ან თავისუფალი საწყობის საქმიანობის შეწყვეტა
თავისუფალი ზონის ან თავისუფალი საწყობის საქმიანობა წყდება ამ საქმიანობის ვადის გასვლისთანავე ან საქართველოს მთავრობის განკარგულებით ვადაზე ადრე, თუ თავისუფალი ზონა ან თავისუფალი საწყობი აღარ შეესაბამება საქართველოს საბაჟო კანონმდებლობით გათვალისწინებულ მოთხოვნებს ან აღნიშნული მოთხოვნები არ სრულდება.
