# მუხლი 48. ოპერაციები საბაჟო ორგანოში წარდგენილ საქონელზე
საბაჟო ორგანოში საქონლის წარდგენის შემდგომ საბაჟო დამუშავების ოპერაციის შერჩევის მიზნით საბაჟო ორგანოს თანხმობით შეიძლება განხორციელდეს საქონლის დათვალიერება, სინჯის ან/და ნიმუშის აღება და მისი ანალიზი ან გამოკვლევა. წერილობითი შუამდგომლობის საფუძველზე საბაჟო ორგანოს თანხმობა გაიცემა პირზე, რომელიც უფლებამოსილია განსაზღვროს საქონლის საბაჟო დამუშავების ოპერაციის სახე. ნიმუშის ან/და სინჯის დეკლარირება ხდება ცალკე ან საქონელთან ერთად.
