# მუხლი 252. დროებითი შენახვის საწყობის, საბაჟო საწყობის ან უბაჟო ვაჭრობის პუნქტის საქმიანობის ნებართვის მფლობელის მიერ საქართველოს კანონმდებლობით დადგენილი პირობების შეუსრულებლობა
1. დროებითი შენახვის საწყობის, საბაჟო საწყობის ან უბაჟო ვაჭრობის პუნქტის საქმიანობის ნებართვის მფლობელის მიერ საქართველოს კანონმდებლობით დადგენილი პირობების შეუსრულებლობა, -
იწვევს ნებართვის მფლობელის დაჯარიმებას 3 000 ლარით.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ქმედება, ჩადენილი განმეორებით, -
იწვევს ნებართვის მფლობელის დაჯარიმებას ყოველ შემდგომ განმეორებაზე ამ მუხლის პირველი ნაწილით გათვალისწინებული ჯარიმის გასამმაგებული ოდენობით.
