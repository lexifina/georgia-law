# მუხლი 164. საქონლის საბაჟო სტატუსი
1. თუ საქონელი შეტანილია ან დაბრუნებულია საქართველოს საბაჟო ტერიტორიის სხვა ადგილზე ანდა მოქცეულია საბაჟო რეჟიმში, საქონლის საბაჟო სტატუსის დასამოწმებლად გამოიყენება ამ კოდექსის 153-ე მუხლის მე-4 ნაწილში აღნიშნული წერილობითი შეტყობინება.
2. თუ საბაჟო ორგანოს წერილობითი შეტყობინებით არ მტკიცდება, რომ საქონელს აქვს საქართველოს ან უცხოური საქონლის სტატუსი, საქონელი განიხილება, როგორც:
ა) საქართველოს საქონელი ექსპორტის გადასახდელების გადახდისა და სავაჭრო პოლიტიკის სხვა ღონისძიებების გატარების მიზნებისათვის;
ბ) უცხოური საქონელი, გარდა ამ ნაწილის "ა" ქვეპუნქტში აღნიშნული შემთხვევებისა.
