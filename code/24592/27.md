# მუხლი 27. საქონლის სატარიფო კლასიფიკაცია
1. საქონლის სატარიფო კლასიფიკაციისას დეკლარანტი საქონლის კოდს განსაზღვრავს სესსნ-ის მიხედვით, საქართველოს კანონმდებლობის მოთხოვნათა შესაბამისად.
2. თუ საბაჟო ორგანო არ ეთანხმება დეკლარირებული საქონლის კოდს, იგი ამის შესახებ აცნობებს დეკლარანტს და საქონლის კოდი განისაზღვრება სესსნ-ის საქონლის კლასიფიკაციის ზოგადი წესებით.
3. სესსნ-ის გამოყენების წესი განისაზღვრება საქართველოს მთავრობის დადგენილებით.
