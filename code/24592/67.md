# მუხლი 67. საბაჟო დეკლარაციის წარდგენის საშუალებები
1. საბაჟო დეკლარაციის წარდგენა ხდება წერილობით ან ელექტრონული ფორმით.
2. ზეპირი (მგზავრის შემთხვევაში) ან სხვა საშუალებით დეკლარირება, რომლითაც საქონლის მფლობელი საქართველოს საბაჟო კანონმდებლობის შესაბამისად გამოთქვამს სურვილს, საქონლის მიმართ გამოყენებულ იქნეს საბაჟო რეჟიმი, ითვლება საბაჟო დეკლარაციის წარდგენად.
