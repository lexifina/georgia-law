# მუხლი 210. გადავადების მოქმედების შეწყვეტა
1. გადავადების მოქმედება წყდება შესაბამისი გადაწყვეტილების (ხელშეკრულების) ვადის ამოწურვისას ან შეიძლება შეწყდეს აღნიშნული ვადის ამოწურვამდე ამ კოდექსით გათვალისწინებულ შემთხვევებში.
2. გადავადება წყდება ვადამდე, თუ ვალდებული პირი დადგენილი ვადის ამოწურვამდე სრულად გადაიხდის გადასახდელების კუთვნილ თანხებს და საქართველოს საგადასახადო კოდექსის 129-ე მუხლით გათვალისწინებულ საურავს.
3. შესაბამისი გადაწყვეტილების მიმღები უფლებამოსილი პირი ვადამდე შეწყვეტს გადავადებას, თუ ვალდებული პირი არღვევს გადავადების პირობებს.
4. გადაწყვეტილება გადავადების ვადამდე შეწყვეტის შესახებ უფლებამოსილი პირის მიერ მისი მიღებიდან 5 დღის ვადაში წერილობით გადაეცემა ვალდებულ პირს. გადაწყვეტილების ასლი ამავე ვადაში ეგზავნება შესაბამის საბაჟო ორგანოს.
