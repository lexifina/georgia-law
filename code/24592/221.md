# მუხლი 221. საბაჟო პროცედურების განმახორციელებელი პირის შესაგებელი და წერილობითი შეტყობინება
1. საბაჟო პროცედურების განმახორციელებელი პირის შესაგებელში უნდა აღინიშნოს:
ა) საბაჟო ორგანოს დასახელება და მისამართი;
ბ) საბაჟო პროცედურების განმახორციელებელი პირის ვინაობა (სახელი და გვარი; დასახელება), გადასახადის გადამხდელის საიდენტიფიკაციო ნომერი (მისი არსებობის შემთხვევაში), მისამართი და საკონტაქტო საშუალებები (ტელეფონი, ფაქსი, ელექტრონული ფოსტა);
გ) საბაჟო ორგანოს გადაწყვეტილების მიღების თარიღი და მოთხოვნის საგანი;
დ) საბაჟო ორგანოს გადაწყვეტილების შესრულებაზე უარის სამართლებრივი და ფაქტობრივი საფუძვლები;
ე) შესაგებელზე დართულ მტკიცებულებათა ნუსხა;
ვ) დავის გაგრძელების შემთხვევაში მისი გადაწყვეტის ფორმა (საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტში ან სასამართლოს მიერ).
2. ამ კოდექსის 219-ე მუხლის პირველი ნაწილით განსაზღვრულ წერილობით შეტყობინებაში უნდა აღინიშნოს:
ა) საბაჟო ორგანოს დასახელება და მისამართი;
ბ) საბაჟო პროცედურების განმახორციელებელი პირის ვინაობა (სახელი და გვარი; დასახელება), გადასახადის გადამხდელის საიდენტიფიკაციო ნომერი (მისი არსებობის შემთხვევაში), მისამართი და საკონტაქტო საშუალებები (ტელეფონი, ფაქსი, ელექტრონული ფოსტა);
გ) საბაჟო ორგანოს გადაწყვეტილების მიღების თარიღი და მოთხოვნის საგანი.
3. შესაგებლის ან წერილობითი შეტყობინების წარუდგენლობას უთანაბრდება საბაჟო ვალდებულების უზრუნველყოფის წარუდგენლობა ან/და ისეთი შესაგებლის/შეტყობინების წარდგენა, რომელშიც მითითებული არ არის დავის გადაწყვეტის ფორმა.
