# მუხლი 91. საფოსტო გზავნილის დეკლარაცია
1. თუ საქართველოდან გასაგზავნი საქონელი მოთავსებულია საერთაშორისო საფოსტო გზავნილში, გამგზავნი ავსებს საფოსტო გზავნილის დეკლარაციას, რომელიც უნდა დაერთოს საფოსტო გზავნილს.
2. თუ უცხო ქვეყნიდან მიღებულ საფოსტო გზავნილში საქონლის რაოდენობა და ღირებულება აღემატება "საბაჟო ტარიფის შესახებ" საქართველოს კანონით გათვალისწინებულ დაუბეგრავ რაოდენობასა და ღირებულებას, გზავნილის მიმღები საფოსტო გზავნილის დეკლარაციასთან ერთად წარადგენს საბაჟო დეკლარაციას.
3. საფოსტო გზავნილის დეკლარაციის ფორმა და შევსების წესი განისაზღვრება საქართველოს ფინანსთა მინისტრის ბრძანებით.
