# მუხლი 37. სარეზერვო მეთოდი
1. საქონლის საბაჟო ღირებულება განისაზღვრება საქართველოში არსებული საქონელთა ფასების შესახებ მონაცემთა სისტემის საფუძველზე, საქართველოს საბაჟო კანონმდებლობის შესაბამისად.
2. სარეზერვო მეთოდის დროს საბაჟო ღირებულების განსაზღვრის საფუძვლად არ გამოიყენება:
ა) საქართველოში წარმოშობილი საქონლის შიდა გასაყიდი ფასი;
ბ) საქონლის ფასი ექსპორტიორი ქვეყნის შიდა ბაზარზე;
გ) სხვა ქვეყანაში საექსპორტოდ გასატანი საქონლის ფასი;
დ) საქონლის მინიმალური საბაჟო ღირებულება;
ე) საქონლის თვითნებურად შერჩეული ან ფიქციური ღირებულებები;
ვ) საქონლის ორ ღირებულებას შორის უდიდესი ღირებულების მიღების პრინციპი;
ზ) ამ კოდექსის 36-ე მუხლის "ა" ქვეპუნქტში მითითებული ხარჯები იდენტური ან მსგავსი საქონლის ღირებულების გამოყენების შემთხვევაში.
3. სარეზერვო მეთოდის მიზნებისათვის შეფასების მეთოდებად გამოიყენება ამ კოდექსის 32-ე-36-ე მუხლების დებულებები, მაგრამ მათი მისაღები მოქნილობა უნდა შეესაბამებოდეს ამ მეთოდის მიზნებსა და დებულებებს. შეფასების მეთოდების მოქნილობა გულისხმობს წინა მეთოდების ლიბერალურად გამოყენებას, კერძოდ:
ა) გარიგების ფასის მეთოდის გამოყენება: თუ არ არსებობს დეკლარანტის მიერ გაცხადებული საბაჟო ღირებულების დამადასტურებელი დოკუმენტები, მოცემული საქონლის შეფასება შესაძლებელია მოხდეს იმ კონკრეტული ფასების შესახებ მონაცემების საფუძველზე, რომლებიც აქვს დეკლარანტს ან საბაჟო ორგანოს;
ბ) იდენტური საქონლის გარიგების ფასის ან/და მსგავსი საქონლის გარიგების ფასის მეთოდის გამოყენება: ამ შემთხვევაში მოქნილობა გულისხმობს იდენტური ან მსგავსი საქონლის შემოტანის ვადების თავისუფალ ინტერპრეტაციას. ამასთანავე, იდენტური ან მსგავსი საქონელი შეიძლება წარმოებული იყოს სხვა ქვეყანაში და სხვა მწარმოებლების მიერ, ვიდრე ეს ხდება იმპორტირებული საქონლის დროს;
გ) საქონლის ერთეულის ფასის და შედგენილი ღირებულების მეთოდების გამოყენება: ამ შემთხვევაში მოქნილობა გულისხმობს იმავე კლასის ან ტიპის საქონლის უცვლელ მდგომარეობაში მიწოდების თაობაზე მოთხოვნისა და შიდა ბაზარზე გაყიდვის ვადების თავისუფალ ინტერპრეტაციას და იმპორტირებული საქონლის შესაძლო გადამუშავების დაშვებას განსაკუთრებული პირობების გარეშე. იდენტური ან მსგავსი საქონლის არარსებობისას შეიძლება გამოყენებულ იქნეს იმავე კლასის ან ტიპის საქონელი, რომელიც შეტანილია სხვა ქვეყნებიდანაც. ამასთანავე, არ გაითვალისწინება მყიდველსა და გამყიდველს შორის ურთიერთდაკავშირებულობის ფაქტი, ასეთის არსებობის შემთხვევაში.
4. სარეზერვო მეთოდით განსაზღვრული საქონლის საბაჟო ღირებულება შეძლებისდაგვარად მაქსიმალურად უნდა ეფუძნებოდეს ადრე უკვე განსაზღვრულ საქონლის საბაჟო ღირებულებას.
