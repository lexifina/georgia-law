# მუხლი 236. გასაჩივრების წესი
1. საბაჟო სამართალდარღვევის საქმეზე საბაჟო ორგანოს მიერ გაგზავნილი შეტყობინება შეიძლება გაასაჩივროს პირმა, რომლის მიმართაც გამოტანილია აღნიშნული გადაწყვეტილება, ან მისმა წარმომადგენელმა ამ კოდექსის IX კარით დადგენილი წესით.
2. საბაჟო სამართალდარღვევის ოქმი შეიძლება გასაჩივრდეს საბაჟო სანქციის შეფარდების შესახებ გამოტანილ გადაწყვეტილებასთან ერთად. ამასთანავე, ამ კოდექსის 235-ე მუხლის მე-12 ნაწილით გათვალისწინებული ოქმი არ საჩივრდება, გარდა იმ შემთხვევებისა, თუ იგი შესრულებულია ფიზიკური ან ფსიქიკური ზემოქმედების შედეგად.
