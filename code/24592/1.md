# მუხლი 1. საქართველოს საბაჟო კოდექსით რეგულირებული ურთიერთობები
ეს კოდექსი აწესრიგებს საქართველოს საბაჟო ტერიტორიაზე საქონლის შემოტანასა და საქართველოს საბაჟო ტერიტორიიდან საქონლის გატანასთან დაკავშირებულ სამართლებრივ ურთიერთობებს, განსაზღვრავს საბაჟო ზედამხედველობისას, საბაჟო კონტროლის და საბაჟო პროცედურების განხორციელებისას წარმოშობილ ურთიერთობებში მონაწილე პირებისა და საბაჟო ორგანოების სამართლებრივ მდგომარეობას, პასუხისმგებლობას საქართველოს საბაჟო კანონმდებლობის დარღვევისათვის, აგრეთვე საბაჟო ორგანოებისა და მათი უფლებამოსილი პირების არამართლზომიერ ქმედებათა გასაჩივრების წესსა და პირობებს, საბაჟო დავების გადაწყვეტის წესს.
