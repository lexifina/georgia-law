# მუხლი 245. საბაჟო ორგანოს თანამდებობის პირისათვის წინააღმდეგობის გაწევა
1. საბაჟო ორგანოს თანამდებობის პირისათვის წინააღმდეგობის გაწევა, მათ შორის, დათვალიერების ჩატარებაზე, საბაჟო ორგანოს თანამდებობის პირის კანონიერი გადაწყვეტილებისა და მოთხოვნის უგულებელყოფა, აგრეთვე საბაჟო კანონმდებლობით განსაზღვრულ ადგილზე სატრანსპორტო საშუალების გაჩერების მოთხოვნის შეუსრულებლობა, -
იწვევს დაჯარიმებას 1 000 ლარით.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ქმედებები, ჩადენილი განმეორებით, -
იწვევს დაჯარიმებას ყოველ შემდგომ განმეორებაზე 2 000 ლარის ოდენობით.
