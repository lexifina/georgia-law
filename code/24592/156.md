# მუხლი 156. თავისუფალ ზონაში ან თავისუფალ საწყობში მოთავსებული უცხოური საქონელი
1. თავისუფალ ზონაში ან თავისუფალ საწყობში მოთავსებული უცხოური საქონელი მისი შენახვის პერიოდში შეიძლება:
ა) გაშვებულ იქნეს თავისუფალ მიმოქცევაში საქონლის იმპორტის საბაჟო რეჟიმის ან ამ კოდექსის 162-ე მუხლის შესაბამისად;
ბ) მოექცეს საბაჟო ტერიტორიაზე საქონლის გადამუშავების საბაჟო რეჟიმში ამავე რეჟიმით განსაზღვრული პირობების შესაბამისად;
გ) მოექცეს საქონლის დროებითი შემოტანის საბაჟო რეჟიმში ამავე რეჟიმით განსაზღვრული პირობების შესაბამისად;
დ) გადაეცეს სახელმწიფოს საკუთრებაში ამ კოდექსის 168-ე მუხლის შესაბამისად;
ე) განადგურდეს საბაჟო ზედამხედველობის ქვეშ ამ კოდექსის 167-ე მუხლის შესაბამისად.
2. საბაჟო ორგანოსთან შეთანხმების გარეშე თავისუფალ ზონაში ან თავისუფალ საწყობში შესანახად მოთავსებული უცხოური საქონლის მიმართ მისი შენახვის პერიოდში შესაძლებელია განხორციელდეს მხოლოდ ამ კოდექსის 111-ე მუხლით გათვალისწინებული მოქმედებები.
