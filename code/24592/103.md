# მუხლი 103. საბაჟო საწყობის სახეები, საბაჟო საწყობის მფლობელი და მომთავსებელი
1. საბაჟო საწყობი არის საბაჟო კონტროლის ზონა, სადაც საქართველოს საბაჟო კანონმდებლობით დადგენილი წესების შესაბამისად შეიძლება მოთავსდეს საქონელი და რომლის საქმიანობისათვის სავალდებულოა შესაბამისი ორგანოს მიერ გაცემული საბაჟო საწყობის საქმიანობის ნებართვა.
2. საბაჟო საწყობი შეიძლება იყოს ღია, დროებითი შენახვის ღია, დახურული ან დროებითი შენახვის დახურული; კერძოდ, საბაჟო საწყობი:
ა) ღიაა - სადაც საქმიანობას ახორციელებს ნებისმიერი პირი, საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმში მოქცეული საქონლის შესანახად;
ბ) დროებითი შენახვის ღიაა - სადაც საქმიანობას ახორციელებს ნებისმიერი პირი საბაჟო დამუშავების ოპერაციის სახის განსაზღვრამდე საქონლის ან/და სატრანსპორტო საშუალებების დროებით შესანახად;
გ) დახურულია - სადაც საქმიანობას ახორციელებს მხოლოდ ნებართვის მფლობელი ან მხოლოდ ერთი პირი, საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმში მოქცეული საქონლის შესანახად;
დ) დროებითი შენახვის დახურულია - სადაც საქმიანობას ახორციელებს მხოლოდ ნებართვის მფლობელი ან მხოლოდ ერთი პირი საბაჟო დამუშავების ოპერაციის სახის განსაზღვრამდე საქონლის ან/და სატრანსპორტო საშუალებების დროებით შესანახად.
3. საბაჟო საწყობის მფლობელი შეიძლება იყოს საქართველოს საწარმო ან მეწარმე ფიზიკური პირი ან საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტი.
4. მომთავსებელი არის პირი, რომელიც საქონელს ინახავს საბაჟო საწყობში და რომელსაც დაეკისრა შესაბამისი ვალდებულებები, ან რომელსაც გადაეცა შესაბამისი დეკლარირების განმახორციელებელი პირის უფლებები და ვალდებულებები.
