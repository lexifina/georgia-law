# მუხლი 22. საბაჟო ორგანოები
1. საბაჟო ორგანოების ერთიანი, ცენტრალიზებული სისტემა შედგება საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტისა და მასში შემავალი საბაჟო ორგანოებისაგან.
2. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტი არის სამართალდამცავი ორგანოს სტატუსის მქონე საბაჟო ორგანო, რომელიც სახელმწიფო საქვეუწყებო დაწესებულების სახით შედის საქართველოს ფინანსთა სამინისტროს სისტემაში.
3. საბაჟო ორგანოს სახელმწიფო მოხელეებზე ვრცელდება ფინანსური პოლიციის თანამშრომელთა სოციალური დაცვის გარანტიები, რომლებიც განსაზღვრულია "ფინანსური პოლიციის შესახებ" საქართველოს კანონით.
4. საბაჟო ორგანოს შექმნის წესი, სტრუქტურა და უფლებამოსილებები განისაზღვრება ამ კოდექსით, "მთავრობის სტრუქტურის, უფლებამოსილებისა და საქმიანობის წესის შესახებ" საქართველოს კანონითა და სხვა ნორმატიული აქტებით.
