# მუხლი 244. თავისუფალი ზონისათვის ან თავისუფალი საწყობისათვის დადგენილი მოთხოვნების დარღვევა
1. თავისუფალი ზონისათვის ან თავისუფალი საწყობისათვის დადგენილი მოთხოვნების დარღვევით საქონლის გადაადგილება ან ამ ტერიტორიიდან გატანა, აგრეთვე საქონლის დასაწყობების, შენახვის ან აღრიცხვის წარმოების მოთხოვნების დარღვევა, -
იწვევს თავისუფალი ზონის ან თავისუფალი საწყობის მფლობელის დაჯარიმებას 500 ლარით.
2. თავისუფალ ზონაში ან თავისუფალ საწყობში უკანონო საწარმოო ან სავაჭრო საქმიანობა ან/და მომსახურება, შენობა-ნაგებობების მშენებლობა, საქონლის მოხმარება ან გამოყენება, -
იწვევს თავისუფალი ზონის ან თავისუფალი საწყობის მფლობელის დაჯარიმებას 500 ლარით.
3. ამ მუხლის პირველი და მე-2 ნაწილებით გათვალისწინებული ქმედებები, ჩადენილი განმეორებით, -
