# მუხლი 155. თავისუფალ ზონასა და თავისუფალ საწყობში ნებადართული საქმიანობა
1. საქართველოს საბაჟო კანონმდებლობით გათვალისწინებულ პირობებში თავისუფალ ზონასა და თავისუფალ საწყობში დასაშვებია ნებისმიერი საქონლის წარმოება ან მომსახურების გაწევა, გარდა ამ მუხლის მე-3 ნაწილით გათვალისწინებული შემთხვევისა. ასეთი საქმიანობის განხორციელების შესახებ წინასწარ უნდა ეცნობოს საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტს.
2. ამ მუხლის პირველი ნაწილით განსაზღვრული საქმიანობა უარყოფითად არ უნდა მოქმედებდეს თავისუფალ ზონაში ან თავისუფალ საწყობში ადამიანთა ჯანმრთელობასა და უსაფრთხოების ნორმებზე.
3. საბაჟო ზედამხედველობის განხორციელების მიზნით თავისუფალ ზონასა და თავისუფალ საწყობში ნებადართული საქმიანობის სახეობაზე საქართველოს მთავრობამ შესაბამისი დადგენილებით შეიძლება დააწესოს აკრძალვები ან შეზღუდვები.
