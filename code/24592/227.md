# მუხლი 227. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის გადაწყვეტილების გასაჩივრება
1. საბაჟო პროცედურების განმახორციელებელ პირს უფლება აქვს ამ კოდექსის 226-ე მუხლის მე-3 ნაწილის "ბ" და "გ" ქვეპუნქტებით განსაზღვრულ შემთხვევებში საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის გადაწყვეტილება (ამ გადაწყვეტილებისა და თანდართული დოკუმენტების მიღებიდან 5 დღეში) ან ამ კოდექსის 226-ე მუხლის პირველი ნაწილით განსაზღვრულ ვადაში გადაწყვეტილების მიუღებლობისას დეპარტამენტის უარი (ამ ვადის ამოწურვიდან 5 დღეში) გაასაჩივროს:
ა) საბჭოში, თუ მის საჩივარში ასე იყო მითებული (ამ შემთხვევაში მან წარდგენილ საჩივარს უნდა დაურთოს საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტისათვის წარდგენილი ყველა მასალის ასლები და დამატებითი მტკიცებულებები, მათი არსებობის შემთხვევაში);
ბ) სასამართლოში (ასეთ შემთხვევაში მოპასუხეა ამ კოდექსის 219-ე მუხლში აღნიშნული საბაჟო ორგანო).
2. საბჭოსათვის წარდგენილ საჩივარში უნდა აღინიშნოს, დავის შემდგომი გაგრძელების შემთხვევაში დავის გადაწყვეტის რომელ ფორმას ირჩევს მომჩივანი.
3. თუ საბაჟო პროცედურების განმახორციელებელი პირი ამ მუხლის პირველი ნაწილით დადგენილ ვადაში არ გაასაჩივრებს:
ა) საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის გადაწყვეტილებას, იგი აღიარებულად ჩაითვლება და მიიქცევა აღსასრულებლად;
ბ) საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის უარს (თუ მან დროულად არ მიიღო დეპარტამენტის გადაწყვეტილება), საჩივარი გაუქმებულად ჩაითვლება და გასაჩივრებული გადაწყვეტილება მიიქცევა აღსასრულებლად.
