# მუხლი 99. გარანტიის წარდგენა
1. სატრანზიტო გადაზიდვებთან დაკავშირებული საბაჟო ვალდებულების დაფარვის უზრუნველყოფის მიზნით, დეკლარანტი ან/და საქონლის გადამზიდველი ვალდებულია, გაგზავნის საბაჟო ორგანოს წარუდგინოს გარანტია, რომლის ოდენობა განისაზღვრება საქართველოს ფინანსთა მინისტრის ბრძანებით.
2. გარანტია შეიძლება იყოს:
ა) ინდივიდუალური, ცალკეული სატრანზიტო გადაზიდვისათვის;
ბ) საერთო, რამდენიმე სატრანზიტო გადაზიდვისათვის.
