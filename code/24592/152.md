# მუხლი 152. თავისუფალ ზონაში და თავისუფალ საწყობში საქონლის შეტანა
1. თავისუფალ ზონაში ან თავისუფალ საწყობში დასაშვებია:
ა) ამ კოდექსის 149-ე მუხლის "ბ" ქვეპუნქტით გათვალისწინებული საქართველოს საქონლის შეტანა;
ბ) საქართველოს საქონლის შეტანა, რომელიც გათვალისწინებული არ არის ამ ნაწილის "ა" ქვეპუნქტით და რომელიც არ გაართულებს საბაჟო კონტროლის განხორციელებას;
გ) უცხოური საქონლის შეტანა.
2. თუ თავისუფალ ზონაში ან თავისუფალ საწყობში შეიტანება ისეთი საქონელი, რომელმაც შეიძლება დააზიანოს სხვა საქონელი, საბაჟო ორგანო უფლებამოსილია მოითხოვოს ასეთი საქონლის მოთავსება სპეციალურად მოწყობილ შენობაში.
