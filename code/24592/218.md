# მუხლი 218. საბაჟო დავის გადაწყვეტის ფორმები
1. საბაჟო დავის გადაწყვეტის ფორმებია:
ა) საქართველოს ფინანსთა სამინისტროს სისტემაში განხილვის წესით დავის გადაწყვეტა;
ბ) სასამართლოს მიერ დავის გადაწყვეტა.
2. საქართველოს ფინანსთა სამინისტროს სისტემაში განხილვის წესით დავის გადაწყვეტა შედგება 3 ეტაპისაგან:
ა) დავის გადაწყვეტა წერილობითი გადაწყვეტილების მიმღებ საბაჟო ორგანოში;
ბ) დავის გადაწყვეტა საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტში;
გ) დავის გადაწყვეტა საქართველოს ფინანსთა სამინისტროსთან არსებულ დავების განხილვის საბჭოში (შემდგომში - საბჭო).
3. თუ საბაჟო პროცედურების განმახორციელებელმა პირმა დავის გადაწყვეტის ფორმად აირჩია მისი გადაწყვეტა საქართველოს ფინანსთა სამინისტროს სისტემაში, მას უფლება აქვს დავის გადაწყვეტის ნებისმიერ ეტაპზე მიღებული წერილობითი გადაწყვეტილება კანონით დადგენილი წესით გაასაჩივროს სასამართლოში იმავე ვადაში, რომელშიც მას აქვს წერილობითი გადაწყვეტილების საქართველოს ფინანსთა სამინისტროს სისტემაში გასაჩივრების უფლება.
4. საბაჟო პროცედურების განმახორციელებელი პირი ვალდებულია საბაჟო დავის გადაწყვეტის ფორმის არჩევის შესახებ აცნობოს საბაჟო ორგანოს:
ა) საბაჟო ორგანოს წერილობითი გადაწყვეტილების საპასუხოდ ამ კოდექსის 221-ე მუხლის შესაბამისად წარდგენილ შესაგებელში მითითებით;
ბ) წერილობითი შეტყობინებით, თუ საბაჟო ორგანოს წერილობითი გადაწყვეტილების საპასუხოდ დავის დაწყებას აპირებს უშუალოდ სასამართლოში გასაჩივრებით.
5. საბაჟო პროცედურების განმახორციელებელ პირს უფლება არა აქვს შეცვალოს თავის შესაგებელში ან წერილობით შეტყობინებაში მითითებული დავის გადაწყვეტის ფორმა.
