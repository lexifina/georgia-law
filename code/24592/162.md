# მუხლი 162. საბაჟო ვალდებულებისა და საბაჟო ღირებულების განსაზღვრის სპეციალური დებულებები
1. თუ საბაჟო ვალდებულება წარმოიშობა საბაჟო ტერიტორიის სხვა ადგილზე გადატანილი საქონლის მიმართ და ამ საქონლის საბაჟო ღირებულება გაანგარიშებულია გარიგების ფასის მიხედვით, რომელიც მოიცავს თავისუფალ ზონაში საქონლის ყოფნის დროს საწყობში საქონლის მოთავსების ან შენახვის საზღაურს, ასეთი საზღაური არ უნდა შედიოდეს საბაჟო ღირებულებაში, თუ იგი ნაჩვენებია გარიგების ფასისაგან დამოუკიდებლად.
2. ამ მუხლის პირველ ნაწილში აღნიშნული იმ საქონლის საბაჟო ღირებულების განსაზღვრისას, რომლის მიმართაც განხორციელდა ამ კოდექსის 111-ე მუხლში აღნიშნული მოქმედებები, დეკლარანტის შუამდგომლობის საფუძველზე და იმ შემთხვევაში, თუ ეს მოქმედებები განხორციელდა საბაჟო ორგანოს თანხმობით, საქონლის სახეობა, ღირებულება და რაოდენობა განისაზღვრება ამავე კოდექსის მე-200 მუხლის შესაბამისად და იმ პირობით, რომ მის მიმართ არ განხორციელებულა 111-ე მუხლში აღნიშნული მოქმედებები.
