# მუხლი 173. საზღვაო თევზჭერის პროდუქტებისა და ზღვის სხვა პროდუქტების გათავისუფლება იმპორტის გადასახდელებისაგან
თუ საქართველოს საბაჟო კანონმდებლობის შესაბამისად საქონლის წარმოშობის განსაზღვრის წესებით სხვა რამ არ არის დადგენილი, საქონლის თავისუფალ მიმოქცევაში გაშვების (იმპორტის) საბაჟო რეჟიმში მოქცევად არ ჩაითვლება და, შესაბამისად, მასზე არ გადაიხდევინება იმპორტის გადასახდელები (გარდა საბაჟო მოსაკრებლისა) საქართველოს საბაჟო ტერიტორიაზე შემდეგი საქონლის შემოტანისას:
ა) საქართველოში რეგისტრირებული და საქართველოს ალმით მცურავი გემის მიერ მოპოვებული თევზჭერის პროდუქტები და ზღვის სხვა პროდუქტები;
ბ) პროდუქტები, რომლებიც საქართველოშია რეგისტრირებული და საქართველოს ალმით მცურავი გადამამუშავებელ (მწარმოებელ) გემზე მიიღება ამ მუხლის "ა" ქვეპუნქტში აღნიშნული პროდუქტებისაგან.
