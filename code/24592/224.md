# მუხლი 224. შესაგებლის მიღებისას საბაჟო ორგანოს ვალდებულება
1. საბაჟო ორგანოს ხელმძღვანელი/მისი მოადგილე ვალდებულია საბაჟო პროცედურების განმახორციელებელი პირის შესაგებლის მიღებიდან 10 დღის ვადაში განიხილოს იგი და გამოსცეს მოტივირებული ბრძანება შესაგებლის დაკმაყოფილების ანუ დავის შეწყვეტის შესახებ, შესაგებლის ნაწილობრივ დაკმაყოფილების ან მის დაკმაყოფილებაზე უარის თაობაზე და ბრძანების გამოცემიდან 3 დღეში გაუგზავნოს იგი შესაგებლის წარმდგენს.
2. საბაჟო ორგანოში დავა განიხილება მომჩივნის ან/და მისი წარმომადგენლის (წარმომადგენლების) მონაწილეობით. საბაჟო დავის განხილვისათვის დანიშნულ დროს მომჩივნის ან/და მისი წარმომადგენლის (წარმომადგენლების) გამოუცხადებლობის შემთხვევაში დავა განიხილება მის (მათ) გარეშე.
3. შესაგებლის ნაწილობრივ დაკმაყოფილების ან მის დაკმაყოფილებაზე უარის შესახებ გადაწყვეტილების მიღების შემთხვევაში საბაჟო ორგანო ვალდებულია, ბრძანების გამოცემიდან 3 დღეში საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტს გადასცეს მიღებული გადაწყვეტილება და შესაგებელი თანდართული მტკიცებულებებით, ხოლო საბაჟო პროცედურების განმახორციელებელ პირს ბრძანებასთან ერთად გაუგზავნოს შესწორებული გადაწყვეტილება (თუ მოხდა მისი შესწორება) და დამატებითი მტკიცებულებები (მათი არსებობის შემთხვევაში).
4. საბაჟო ორგანოს ბრძანებაში უნდა აღინიშნოს:
ა) საბაჟო ორგანოს დასახელება და მისამართი;
ბ) ბრძანების გამოცემის დრო და ადგილი, ბრძანების გამომცემ პირთა ვინაობა;
გ) შესაგებლის წარმდგენის ვინაობა (სახელი და გვარი; დასახელება), გადასახადის გადამხდელის საიდენტიფიკაციო ნომერი (მისი არსებობის შემთხვევაში), მისამართი და საკონტაქტო საშუალებები (ტელეფონი, ფაქსი, ელექტრონული ფოსტა) და დავის საგანი;
დ) საბაჟო ორგანოს მიერ დადგენილი გარემოებანი, მტკიცებულებანი, რომელთა საფუძველზედაც მოხდა ამა თუ იმ მტკიცებულების უარყოფა, ნორმატიული აქტები და მათი ნორმები, რომლებითაც იგი ხელმძღვანელობდა;
ე) საბაჟო ორგანოს გადაწყვეტილება შესაგებლის დაკმაყოფილების, ნაწილობრივ დაკმაყოფილების ან დაკმაყოფილებაზე უარის შესახებ;
ვ) საბაჟო ორგანოს ბრძანების გასაჩივრების ვადა და წესი.
5. თუ საბაჟო ორგანო ამ მუხლის პირველი ნაწილით განსაზღვრულ ვადაში არ გამოსცემს ზემოაღნიშნულ ბრძანებას ან საბაჟო პროცედურების განმახორციელებელ პირს არ გაუგზავნის ბრძანებას, ეს ნიშნავს შესაგებლის დაკმაყოფილებაზე უარს.
