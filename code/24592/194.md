# მუხლი 194. საბაჟო ვალდებულების წარმოშობა საქართველოს საბაჟო ტერიტორიიდან გასატანი საქონლის დეკლარირებისას
1. საქართველოს საბაჟო ტერიტორიიდან გასატან საქონელზე საბაჟო ვალდებულება წარმოიშობა საბაჟო დეკლარაციის რეგისტრაციის დღიდან, თუ მისი გატანა ექვემდებარება ექსპორტის გადასახდელების გადახდას.
2. ამ მუხლის პირველი ნაწილით განსაზღვრულ საბაჟო ვალდებულებასთან დაკავშირებით ვალდებული პირები არიან დეკლარანტი და საქონლის მესაკუთრე.
