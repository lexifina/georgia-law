# მუხლი 113. საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმის დასრულება
1. საბაჟო საწყობში საქონლის შენახვის ვადის გასვლამდე ამ კოდექსით დადგენილი მოთხოვნების დაცვით შეირჩევა საქონლის მიმართ განსახორციელებელი საბაჟო დამუშავების ოპერაცია. შენახვის ვადის გასვლის შემდეგ საქონლის განკარგვა ხორციელდება ამ კოდექსის 87-ე მუხლის შესაბამისად.
2. საქონლის დროებითი შემოტანის საბაჟო რეჟიმში მოქცეული საქონლის საქართველოს ტერიტორიაზე ყოფნის ვადის გაანგარიშებისას არ ჩაითვლება დროის ის მონაკვეთი, რომლის განმავლობაშიც ეს საქონელი იმყოფებოდა საბაჟო საწყობში.
საქართველოს 2008 წლის 26 დეკემბრის კანონი №872 - სსმ I, №41, 30.12. 2008წ., მუხ.307
