# მუხლი 113. საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმის დასრულება
1. საბაჟო საწყობში საქონლის შენახვის ვადის გასვლამდე ამ კოდექსით დადგენილი მოთხოვნების დაცვით ხდება საქონლის მიმართ განსახორციელებელი საბაჟო დამუშავების ოპერაციის შერჩევა. შენახვის ვადის გასვლის შემდეგ საქონლის განკარგვა ხორციელდება ამ კოდექსის 167-ე და 168-ე მუხლების შესაბამისად.
2. საქონლის დროებითი შემოტანის საბაჟო რეჟიმში მოქცეული საქონლის საქართველოს ტერიტორიაზე ყოფნის ვადის გაანგარიშებისას არ ჩაითვლება დროის ის მონაკვეთი, რომლის განმავლობაშიც ეს საქონელი იმყოფებოდა საბაჟო საწყობში.
