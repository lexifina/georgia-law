# მუხლი 225. საბაჟო ორგანოს გადაწყვეტილების გასაჩივრება
1. საბაჟო პროცედურების განმახორციელებელ პირს უფლება აქვს ამ კოდექსის 224-ე მუხლის მე-3 ნაწილით განსაზღვრულ შემთხვევებში საბაჟო ორგანოს ხელმძღვანელის/მისი მოადგილის ბრძანება (ამ ბრძანებისა და თანდართული დოკუმენტების მიღებიდან 5 დღეში) ან ამ კოდექსის 224-ე მუხლის პირველი ნაწილით განსაზღვრულ ვადაში ბრძანების მიუღებლობისას საბაჟო ორგანოს უარი (ამ ვადის ამოწურვიდან 5 დღეში) გაასაჩივროს:
ა) საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტში, თუ მის შესაგებელში ასე იყო მითითებული (ამ შემთხვევაში მან წარდგენილ საჩივარს უნდა დაურთოს, შესაბამისად, ამ კოდექსის 224-ე ან 219-ე მუხლში აღნიშნული საბაჟო ორგანოსათვის წარდგენილი ყველა მასალის ასლები და დამატებითი მტკიცებულებები, მათი არსებობის შემთხვევაში);
ბ) სასამართლოში.
2. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტისათვის წარდგენილ საჩივარში უნდა აღინიშნოს, დავის შემდგომი გაგრძელების შემთხვევაში დავის გადაწყვეტის რომელ ფორმას ირჩევს მომჩივანი.
3. თუ საბაჟო პროცედურების განმახორციელებელი პირი ამ მუხლის პირველი ნაწილით დადგენილ ვადაში არ გაასაჩივრებს:
ა) საბაჟო ორგანოს ხელმძღვანელის/მისი მოადგილის ბრძანებას, იგი აღიარებულად ჩაითვლება და მიიქცევა აღსასრულებლად, ხოლო საბაჟო პროცედურების განმახორციელებელი პირის შესაგებელი ჩაითვლება გაუქმებულად;
ბ) საბაჟო ორგანოს უარს (თუ მან დროულად არ მიიღო საბაჟო ორგანოს ბრძანება), საბაჟო ორგანოს გადაწყვეტილება აღიარებულად ჩაითვლება და იგი მიიქცევა აღსასრულებლად, ხოლო საბაჟო პროცედურების განმახორციელებელი პირის შესაგებელი ჩაითვლება გაუქმებულად.
