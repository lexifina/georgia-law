# მუხლი 73. საბაჟო რეჟიმის მარეგულირებელი საქართველოს საბაჟო კანონმდებლობის გამოყენება
საბაჟო რეჟიმში მოსაქცევად გამოიყენება საბაჟო დეკლარაციის რეგისტრაციის დღისათვის მოქმედი შესაბამისი საბაჟო რეჟიმის მარეგულირებელი საქართველოს საბაჟო კანონმდებლობა, გარდა ამ კოდექსის 89-ე მუხლით გათვალისწინებული შემთხვევებისა.
