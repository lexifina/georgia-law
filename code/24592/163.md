# მუხლი 163. ოპერაციები თავისუფალ ზონაში ან თავისუფალ საწყობში მოთავსებული საქართველოს საქონლის მიმართ
1. საქართველოს საბაჟო კანონმდებლობის შესაბამისად ამ კოდექსის 149-ე მუხლის "ბ" ქვეპუნქტით გათვალისწინებული საქართველოს საქონლის მიმართ ტარდება ისეთივე საბაჟო ღონისძიებები, როგორიც გამოიყენება საქონლის ექსპორტის საბაჟო რეჟიმში მოქცეული მსგავსი საქონლის მიმართ.
2. თუ ამ კოდექსის 149-ე მუხლის "ბ" ქვეპუნქტით გათვალისწინებული საქართველოს საქონელი დაბრუნდა საქართველოს საბაჟო ტერიტორიის სხვა ადგილზე ან ამავე კოდექსის 154-ე მუხლის მე-2 ნაწილის შესაბამისად განსაზღვრულ ვადაში არ იქნა წარმოდგენილი შუამდგომლობა საქონლისათვის საბაჟო დამუშავების ოპერაციის სახის განსაზღვრის მოთხოვნით ამ მუხლის პირველი ნაწილის შესაბამისად, იგი ექვემდებარება დაკავებას.
