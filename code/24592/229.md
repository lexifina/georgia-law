# მუხლი 229. საბჭოს გადაწყვეტილება
1. საბაჟო დავის განხილვის საფუძველზე საბჭო უფლებამოსილია:
ა) გააუქმოს საბაჟო ორგანოს ან/და საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის გადაწყვეტილება;
ბ) გააუქმოს საბაჟო ორგანოს ან/და საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის გადაწყვეტილება და მიიღოს ახალი გადაწყვეტილება;
გ) არ დააკმაყოფილოს საჩივარი.
2. საბჭოს გადაწყვეტილებაში უნდა აღინიშნოს:
ა) გადაწყვეტილების მიღების დრო და ადგილი, გადაწყვეტილების მიმღებ პირთა ვინაობა, მომჩივნისა და იმ საბაჟო ორგანოს დასახელება, რომლის გადაწყვეტილებაც გასაჩივრდა, და დავის საგანი;
ბ) საბჭოს მიერ დადგენილი გარემოებანი, მტკიცებულებანი, რომელთა საფუძველზედაც მოხდა ამა თუ იმ მტკიცებულების უარყოფა, ნორმატიული აქტები და მათი ნორმები, რომლებითაც იგი ხელმძღვანელობდა;
გ) საბჭოს დასკვნა საჩივრის დაკმაყოფილების, ნაწილობრივ დაკმაყოფილების ან დაკმაყოფილებაზე უარის შესახებ;
დ) საბჭოს გადაწყვეტილების გასაჩივრების ვადა და წესი.
3. საბჭოს წევრს (როგორც გადაწყვეტილების მომხრეს, ისე მოწინააღმდეგეს) უფლება აქვს გადაწყვეტილებას დაურთოს განსხვავებული მოსაზრება.
4. საბჭო ვალდებულია გადაწყვეტილების დამოწმებული ასლი 5 დღის ვადაში გაუგზავნოს ან პირადად ჩააბაროს მხარეებს (წარმომადგენლებს).
5. თუ საბჭო ამ კოდექსის 228-ე მუხლის პირველი ნაწილით განსაზღვრულ ვადაში არ მიიღებს ზემოაღნიშნულ გადაწყვეტილებას ან საბაჟო პროცედურების განმახორციელებელ პირს არ გაუგზავნის გადაწყვეტილებას, ეს ნიშნავს საჩივრის დაკმაყოფილებაზე უარს.
