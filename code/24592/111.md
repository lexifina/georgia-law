# მუხლი 111. საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმში მოქცეული საქონლის მიმართ დასაშვები ქმედებები
1. საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმში მოქცეული საქონლის მიმართ დასაშვები ქმედებების ნუსხა და განხორციელების წესი განისაზღვრება საქართველოს ფინანსთა მინისტრის ბრძანებით.
