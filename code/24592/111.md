# მუხლი 111. საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმში მოქცეული საქონლის მიმართ დასაშვები ქმედებები
1. საბაჟო საწყობში საქონლის შენახვის საბაჟო რეჟიმში მოქცეული საქონლის მიმართ დასაშვები ქმედებების ნუსხა და განხორციელების წესი განისაზღვრება საქართველოს ფინანსთა მინისტრის ბრძანებით.
2. საბაჟო საწყობში შენახულ საქონელზე, გარდა საბაჟო ტერიტორიაზე საქონლის გადამუშავების რეჟიმში მოქცეული საქონლის გადამუშავების შედეგად მიღებული გადამუშავების პროდუქტისა, ნაშთებისა ან/და ნარჩენებისა, დასაშვებია საკუთრების უფლების გადაცემა.
საქართველოს 2008 წლის 26 დეკემბრის კანონი №872 - სსმ I, №41, 30.12. 2008წ., მუხ.307
