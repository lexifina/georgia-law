# მუხლი 158. საქონლის გამოყენება ან/და მოხმარება
1. ამ კოდექსის 156-ე და 157-ე მუხლებით განსაზღვრული შემთხვევების გარდა, თავისუფალ ზონაში ან თავისუფალ საწყობში მოთავსებული უცხოური საქონლისა და ამავე კოდექსის 149-ე მუხლის "ბ" ქვეპუნქტით გათვალისწინებული საქართველოს საქონლის გამოყენება ან/და მოხმარება აკრძალულია.
2. ამ მუხლის პირველი ნაწილი არ ვრცელდება იმ საქონლის გამოყენებაზე ან/და მოხმარებაზე, რომლის თავისუფალ მიმოქცევაში გაშვება ან დროებით შემოტანა არ ითვალისწინებს იმპორტის გადასახდელების გადახდას ან სავაჭრო პოლიტიკის არასატარიფო ღონისძიებების გატარებას. ასეთ შემთხვევაში საჭირო არ არის საქონლის თავისუფალ მიმოქცევაში გაშვების ან დროებითი შემოტანის საბაჟო დეკლარაციის წარდგენა.
3. თავისუფალ ზონაში ან თავისუფალ საწყობში საქონლის საცალო გაყიდვა აკრძალულია, გარდა ამ ადგილებში მომუშავე დაქირავებულ პირთა საკვებით უზრუნველყოფისა.
