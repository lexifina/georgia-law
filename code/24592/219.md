# მუხლი 219. საბაჟო დავის დაწყების წესი
1. თუ საბაჟო პროცედურების განმახორციელებელი პირი უარს აცხადებს საბაჟო ორგანოს წერილობითი გადაწყვეტილების შესრულებაზე, იგი ვალდებულია, საბაჟო ორგანოს გადაწყვეტილების მიღებიდან 15 კალენდარულ დღეში საბაჟო ორგანოს გაუგზავნოს წერილობითი შესაგებელი, თუ დავის დაწყების ფორმად ირჩევს მის გადაწყვეტას საქართველოს ფინანსთა სამინისტროს სისტემაში, ან წერილობითი შეტყობინება, თუ დავის გადაწყვეტის ფორმად ირჩევს მის გადაწყვეტას სასამართლოს მიერ.
2. შესაგებელს უნდა დაერთოს ყველა მტკიცებულება, რომლებსაც იგი ემყარება.
3. შესაგებლის ყველა გვერდი უნდა დაინომროს და შესაგებლის ბოლოში, ხელის მოწერამდე სიტყვიერად მიეთითოს შევსებული ფურცლების საერთო რაოდენობა.
4. მოდავე მხარე ვალდებულია ხელი მოაწეროს შესაგებლის ყველა გვერდზე.
5. საბაჟო დავის დაწყების თარიღად ითვლება საბაჟო პროცედურების განმახორციელებელი პირის მიერ საბაჟო ორგანოსათვის ამ მუხლის პირველ ნაწილში აღნიშნული წერილობითი შესაგებლის ან წერილობითი შეტყობინების გაგზავნის თარიღი.
6. ამ მუხლის პირველი ნაწილით დადგენილი ვალდებულების შეუსრულებლობა მიიჩნევა საბაჟო პროცედურების განმახორციელებელი პირის მიერ საბაჟო ორგანოს წერილობითი გადაწყვეტილების აღიარებად და იგი მიექცევა აღსასრულებლად.
