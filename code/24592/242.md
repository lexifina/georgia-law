# მუხლი 242. არადეკლარირებული საქონლის მიერ უკანონოდ საქართველოს საბაჟო საზღვრის გადაკვეთა
1. საბაჟო ორგანოს უფლებამოსილი პირის თანხმობის გარეშე ან საბაჟო კონტროლის გვერდის ავლით არადეკლარირებული საქონლის მიერ საქართველოს საბაჟო საზღვრის გადაკვეთა, -
იწვევს ვალდებული პირის დაჯარიმებას ამ საქონელზე გადასახდელი იმპორტის გადასახდელების თანხის 50 პროცენტის ოდენობით, მაგრამ არანაკლებ 1 000 ლარისა ან/და საბაჟო სამართალდარღვევის სატრანსპორტო საშუალებისა და საქონლის უსასყიდლოდ ჩამორთმევას.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ქმედება, ჩადენილი განმეორებით, -
იწვევს ვალდებული პირის დაჯარიმებას ყოველ შემდგომ განმეორებაზე ამ საქონელზე გადასახდელი იმპორტის გადასახდელების თანხის 100 პროცენტის ოდენობით, მაგრამ არანაკლებ 2 000 ლარისა ან/და საბაჟო სამართალდარღვევის სატრანსპორტო საშუალებისა და საქონლის უსასყიდლოდ ჩამორთმევას.
