# მუხლი 226. საბაჟო დავის განხილვა საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტში
1. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტი ვალდებულია ამ კოდექსის 225-ე მუხლის პირველ ნაწილში აღნიშნული საჩივრის მიღებიდან 15 დღის ვადაში განიხილოს იგი და მიიღოს გადაწყვეტილება საჩივრის დაკმაყოფილების ანუ დავის შეწყვეტის შესახებ, საჩივრის ნაწილობრივ დაკმაყოფილების ან მის დაკმაყოფილებაზე უარის თაობაზე და გადაწყვეტილების მიღებიდან 3 დღეში გაუგზავნოს იგი მომჩივანს და იმ საბაჟო ორგანოს, რომლის გადაწყვეტილებაც გასაჩივრდა.
2. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტში დავა განიხილება მომჩივნის ან/და მისი წარმომადგენლის (წარმომადგენლების) მონაწილეობით. საბაჟო დავის განხილვისათვის დანიშნულ დროს მომჩივნის ან/და მისი წარმომადგენლის (წარმომადგენლების) გამოუცხადებლობის შემთხვევაში დავა განიხილება მის (მათ) გარეშე.
3. დავის განხილვის საფუძველზე საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტი უფლებამოსილია:
ა) გააუქმოს საბაჟო ორგანოს გადაწყვეტილება;
ბ) გააუქმოს საბაჟო ორგანოს გადაწყვეტილება და მიიღოს ახალი გადაწყვეტილება;
გ) არ დააკმაყოფილოს საჩივარი.
4. საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის გადაწყვეტილებაში უნდა აღინიშნოს:
ა) გადაწყვეტილების მიღების დრო და ადგილი, გადაწყვეტილების მიმღებ პირთა ვინაობა, მომჩივნისა და იმ საბაჟო ორგანოს დასახელება, რომლის გადაწყვეტილებაც გასაჩივრდა, და დავის საგანი;
ბ) საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის მიერ დადგენილი გარემოებანი, მტკიცებულებანი, რომელთა საფუძველზედაც მოხდა ამა თუ იმ მტკიცებულების უარყოფა, ნორმატიული აქტები და მათი ნორმები, რომლებითაც იგი ხელმძღვანელობდა;
გ) საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის დასკვნა საჩივრის დაკმაყოფილების, ნაწილობრივ დაკმაყოფილების ან დაკმაყოფილებაზე უარის შესახებ;
დ) საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის გადაწყვეტილების გასაჩივრების ვადა და წესი.
5. გადაწყვეტილებას ხელი უნდა მოაწეროს საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის უფლებამოსილმა თანამდებობის პირმა.
6. საჩივრის ნაწილობრივ დაკმაყოფილების ან მის დაკმაყოფილებაზე უარის შესახებ გადაწყვეტილების მიღების შემთხვევაში საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტი ვალდებულია, გადაწყვეტილების მიღებიდან 3 დღეში საბაჟო პროცედურების განმახორციელებელ პირს გადაწყვეტილებასთან ერთად გაუგზავნოს შესწორებული შეტყობინება (თუ მოხდა მისი შესწორება) და დამატებითი მტკიცებულებები (მათი არსებობის შემთხვევაში), ხოლო მომჩივნის მიერ საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტში წარდგენილ საჩივარში დავის გადაწყვეტის ფორმად საბჭოში მისი განხილვის მითითების შემთხვევაში - საბჭოს გადასცეს საქმის ყველა მასალა თავის გადაწყვეტილებასთან ერთად.
7. თუ საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტი ამ მუხლის პირველი ნაწილით განსაზღვრულ ვადაში არ მიიღებს ზემოაღნიშნულ გადაწყვეტილებას ან საბაჟო პროცედურების განმახორციელებელ პირს არ გაუგზავნის გადაწყვეტილებას, ეს ნიშნავს საჩივრის დაკმაყოფილებაზე უარს.
