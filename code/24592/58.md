# მუხლი 58. დებულებები, რომლებიც გამოიყენება საქონლის ტრანზიტის საბაჟო რეჟიმში მოქცეული უცხოური საქონლის მიმართ საქართველოს საბაჟო ტერიტორიიდან გატანისას
საქონლის ტრანზიტის საბაჟო რეჟიმში მოქცეული უცხოური საქონლის მიმართ, რომელიც მიტანილია საქართველოს საბაჟო ტერიტორიაზე დანიშნულების საბაჟო ორგანოში და საბაჟო ორგანოსათვის წარდგენილია საქონლის ტრანზიტის საბაჟო რეჟიმის მარეგულირებელი საქართველოს საბაჟო კანონმდებლობის შესაბამისად, გამოიყენება ამ კოდექსის 46-ე, 49-ე-56-ე და 61-ე მუხლების დებულებები.
