# მუხლი 238. დეკლარირების დადგენილ ვადაში განუხორციელებლობა
1. დეკლარირების დადგენილ ვადაში განუხორციელებლობა, -
იწვევს დეკლარირებაზე ვალდებული პირის დაჯარიმებას 500 ლარით.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ქმედება, ჩადენილი განმეორებით, -
იწვევს დეკლარირებაზე ვალდებული პირის დაჯარიმებას ყოველ შემდგომ განმეორებაზე 1 000 ლარით.
