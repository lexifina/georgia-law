# მუხლი 222. საბაჟო ვალდებულების შესრულების უზრუნველყოფა
1. საბაჟო პროცედურების განმახორციელებელი პირი თავის მიერ საბაჟო ორგანოს წერილობითი გადაწყვეტილების გასაჩივრების შემთხვევაში ვალდებულია საბაჟო ორგანოს წერილობითი გადაწყვეტილების მიღებიდან 15 კალენდარულ დღეში, საბაჟო ვალდებულების შესრულების უზრუნველსაყოფად, საბაჟო ორგანოს წარუდგინოს საბანკო გარანტია, ბანკში სადეპოზიტო ანგარიშზე სათანადო თანხის შეტანის ცნობა (საბაჟო პროცედურების განმახორციელებელ პირს ამ თანხის განკარგვის უფლება არა აქვს ბანკისათვის შესაბამისი საბაჟო ორგანოს მიერ წერილობითი ნებართვის გაცემის გარეშე) ან/და ფინანსური რისკის დაზღვევის პოლისი. წარდგენილი გარანტიების საერთო ღირებულება არ უნდა იყოს სადავო საბაჟო ვალდებულების თანხაზე ნაკლები.
2. თუ საბაჟო პროცედურების განმახორციელებელი პირი ამ მუხლის პირველ ნაწილში მითითებულ ვადაში საბაჟო ორგანოს არ წარუდგენს ამავე ნაწილში აღნიშნულ საბაჟო ვალდებულების შესრულების უზრუნველყოფის გარანტიებს, საბაჟო ორგანოს უფლება აქვს, სასამართლოს გადაწყვეტილების გარეშე გამოიყენოს საბაჟო ვალდებულებების შესრულების უზრუნველყოფის ქვემოთ ჩამოთვლილი ღონისძიებები (სადავო საბაჟო დავალიანების მოცულობის ფარგლებში, ხოლო თუ წარდგენილია ნაწილობრივი უზრუნველყოფის გარანტია, - იმ ფარგლებში, რომლებიც საკმარისია სადავო საბაჟო დავალიანების მოცულობის შესავსებად):
ა) ყადაღა დაადოს მის საბანკო ანგარიშებს;
ბ) ყადაღა დაადოს მის ნებისმიერი სახის ქონებას (მათ შორის, მოძრავ, უძრავ და არამატერიალურ ქონებას).
3. თუ საბაჟო დავა გადაწყდება საბაჟო პროცედურების განმახორციელებელი პირის სასარგებლოდ, მაშინ გაუქმდება მის მიერ წარდგენილი საბაჟო ვალდებულების შესრულების უზრუნველყოფის გარანტიები, საბაჟო ორგანოს მიერ დადებული ყადაღა ჩაითვლება მოხსნილად, ხოლო გირავნობის/იპოთეკის უფლება - გაუქმებულად.
4. თუ საბაჟო დავა არ გადაწყდება საბაჟო პროცედურების განმახორციელებელი პირის სასარგებლოდ, მაშინ მას სადავო საბაჟო ვალდებულების წარმოშობის დღიდან დაეკისრება სადავო თანხისა და საქართველოს საგადასახადო კოდექსის 129-ე მუხლით გათვალისწინებული საურავის გადახდა.
