# მუხლი 228. საბჭოს სხდომა
1. საბჭო საბაჟო დავას განიხილავს საჩივრის მიღებიდან 15 დღეში თავის სხდომაზე.
2. სხდომას თავმჯდომარეობს საქართველოს ფინანსთა მინისტრი ან მის მიერ საბჭოს წევრთაგან დანიშნული პირი.
3. სხდომის რეგლამენტს განსაზღვრავს საბჭო.
4. საბჭოს გადაწყვეტილება მიიღება სხდომაზე დამსწრეთა ხმების უმრავლესობით. აკრძალულია ხმის მიცემისაგან თავის შეკავება.
5. საბჭოს გადაწყვეტილება ფორმდება წერილობით.
6. საბჭოში დავა განიხილება მომჩივნის ან/და მისი წარმომადგენლის (წარმომადგენლების) მონაწილეობით. საბაჟო დავის განხილვისათვის დანიშნულ დროს მომჩივნის ან/და მისი წარმომადგენლის (წარმომადგენლების) გამოუცხადებლობის შემთხვევაში დავა განიხილება მის (მათ) გარეშე.
