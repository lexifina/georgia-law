# მუხლი 192. ნარჩენების საბაჟო სტატუსი
თუ ამ კოდექსის 191-ე მუხლის პირველი ნაწილის გათვალისწინებით იმ საქონლის, რომელიც იმპორტის გადასახდელებზე შეღავათების გამოყენებითა და მიზნობრივი დანიშნულებით გაშვებულია თავისუფალ მიმოქცევაში და საბაჟო ვალდებულება არ ითვლება წარმოშობილად, განადგურების შედეგად წარმოქმნილი ნარჩენები ჩაითვლება უცხოურ საქონლად.
