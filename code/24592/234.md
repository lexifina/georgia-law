# მუხლი 234. საბაჟო სანქცია
1. საბაჟო სანქცია არის პასუხისმგებლობის ზომა ჩადენილი საბაჟო სამართალდარღვევისათვის.
2. საბაჟო სანქცია გამოიყენება საურავის, ფულადი ჯარიმისა და საბაჟო სამართალდარღვევის საქონლის ან/და სატრანსპორტო საშუალების უსასყიდლოდ ჩამორთმევის სახით ამ კოდექსით გათვალისწინებულ შემთხვევებში, საბაჟო ორგანოს გადაწყვეტილებით, თუ ამავე კოდექსით სხვა რამ არ არის დადგენილი.
3. საბაჟო სამართალდარღვევათა ერთობლიობისას საბაჟო სანქცია გამოიყენება თითოეული სამართალდარღვევისათვის ცალ-ცალკე.
4. საბაჟო სამართალდარღვევათა ერთობლიობა ნიშნავს ამ კოდექსის XXXIV თავით გათვალისწინებული ორი ან ორზე მეტი ქმედების (მოქმედება ან უმოქმედობა) ჩადენა, რომელთაგან სუბიექტს არც ერთის გამო არ დაკისრებია პასუხისმგებლობა.
5. საბაჟო სამართალდარღვევათა ერთობლიობად ჩაითვლება აგრეთვე ისეთი ქმედების (მოქმედება ან უმოქმედობა) ჩადენა, რომელიც შეიცავს ამ კოდექსის XXXIV თავით გათვალისწინებული ორი ან ორზე მეტი მუხლით ან მუხლის ნაწილით გათვალისწინებული საბაჟო სამართალდარღვევის ნიშნებს. თუ ქმედება გათვალისწინებულია ზოგადი და სპეციალური ნორმებით, საბაჟო სამართალდარღვევათა ერთობლიობა არ არსებობს და სუბიექტს პასუხისმგებლობა დაეკისრება სპეციალური ნორმით.
6. თუ საბაჟო სამართალდარღვევის სუბიექტი არის ერთზე მეტი პირი, მათ ამ კოდექსით გათვალისწინებული პასუხისმგებლობა დაეკისრებათ სოლიდარულად.
7. უსასყიდლოდ ჩამორთმეული და სახელმწიფოს საკუთრებაში გადაცემული საქონლის ან/და სატრანსპორტო საშუალების რეალიზების წესი განისაზღვრება საქართველოს პრეზიდენტის ბრძანებულებით.
8. საბაჟო სანქციას საურავი არ ერიცხება.
