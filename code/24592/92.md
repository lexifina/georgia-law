# მუხლი 92. საბაჟო კონტროლს დაქვემდებარებული საქმიანობის შემოწმება
1. საბაჟო ორგანო თავისი კომპეტენციის ფარგლებში, საქართველოს საბაჟო კანონმდებლობის შესაბამისად, უფლებამოსილია დანიშნოს და მოახდინოს იმ პირის საქმიანობის შემოწმება, რომელიც ახორციელებს საბაჟო კონტროლს დაქვემდებარებულ საქმიანობას.
2. საბაჟო კონტროლს დაქვემდებარებული საქმიანობის შემოწმებას და საბაჟო გადასახდელების ადმინისტრირებას საბაჟო ორგანო ახორციელებს საქართველოს საგადასახადო კოდექსის IV-VI კარებით დადგენილი წესების შესაბამისად.
3. საბაჟო კონტროლს დაქვემდებარებული საქმიანობის შემოწმებისას საბაჟო ორგანოს უფლებამოსილი პირის მოქმედებამ არამართლზომიერი ზიანი არ უნდა მიაყენოს ამ მუხლის პირველ ნაწილში აღნიშნულ პირს, რომელსაც დაუყოვნებლივ უნდა ეცნობოს შემოწმების შედეგები.
4. ამ მუხლის მიზნებისათვის საბაჟო კონტროლს დაქვემდებარებულ საქმიანობად ითვლება:
ა) საბაჟო პროცედურების განმახორციელებელი დეკლარანტის ან/და ვალდებული პირის საბაჟო კონტროლს დაქვემდებარებული სამეწარმეო საქმიანობა;
ბ) საბაჟო ორგანოს მიერ გაცემული ლიცენზიის/ნებართვის მფლობელის სამეწარმეო საქმიანობა, რომელიც გათვალისწინებულია ამ ლიცენზიით/ნებართვით.
