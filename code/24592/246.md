# მუხლი 246. სატრანსპორტო საშუალებასთან დაკავშირებული საბაჟო კანონმდებლობის დარღვევა
1. საბაჟო პროცედურების განხორციელებისას საბაჟო ორგანოს თანხმობის გარეშე სატრანსპორტო საშუალების გადაადგილება, მოძრაობისათვის დადგენილი საბაჟო მარშრუტიდან გადახვევა, -
იწვევს დაჯარიმებას 1 000 ლარით.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ქმედებები, ჩადენილი განმეორებით, -
იწვევს დაჯარიმებას ყოველ შემდგომ განმეორებაზე 2 000 ლარით.
