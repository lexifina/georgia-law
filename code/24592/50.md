# მუხლი 50. ზოგადი დეკლარირების ფორმები და მისი წარმდგენი პირი
1. ზოგადი დეკლარირება ნიშნავს საქონელზე იმ ზოგადი მონაცემების წარდგენას, რომლებიც აუცილებელია შესაბამისი საბაჟო დამუშავების ოპერაციის შერჩევამდე მისი იდენტიფიკაციისათვის, საბაჟო ზედამხედველობისა და საბაჟო კონტროლის განხორციელებისათვის. ზოგადი დეკლარირების ფორმები განისაზღვრება საქართველოს ფინანსთა მინისტრის ბრძანებით.
2. ზოგადი დეკლარირება უნდა განახორციელოს პირმა:
ა) რომელმაც საქართველოს საბაჟო ტერიტორიაზე შემოიტანა საქონელი ან რომელმაც საქართველოს საბაჟო ტერიტორიაზე საქონლის შემოტანის შემდეგ აიღო პასუხისმგებლობა მის შემდგომ ტრანსპორტირებაზე;
ბ) რომლის სახელითაც მოქმედებენ ამ ნაწილის "ა" ქვეპუნქტში აღნიშნული პირები.
3. საზღვაო და საჰაერო ხომალდებზე ზოგადი დეკლარირება ხდება საქართველოს საბაჟო ტერიტორიაზე დანიშნულების ნავსადგურში ან აეროპორტში ჩასვლისას, ხოლო საქართველოს საბაჟო ტერიტორიიდან გასვლის შემთხვევაში - იმ საბაჟო ტერიტორიის ნავსადგურში ან აეროპორტში, საიდანაც ისინი გადიან.
4. ცარიელ და მგზავრთა გადამყვან სახმელეთო სატრანსპორტო საშუალებებზე ზოგადი დეკლარირება ხდება საქართველოს საბაჟო საზღვრის გადაკვეთისას.
5. ზოგადი დეკლარირების საფუძველზე ხორციელდება საბაჟო ორგანოს მიერ საბაჟო კონტროლის ქვეშ მყოფი საქონლის ან/და სატრანსპორტო საშუალების აღრიცხვის მოწმობის გამოწერა. აღრიცხვის მოწმობის შევსების წესი დგინდება საქართველოს ფინანსთა მინისტრის ბრძანებით.
