# მუხლი 54. საქონლის დროებითი დასაწყობების პირობები
1. დროებით დასაწყობებული საქონელი უნდა ინახებოდეს საბაჟო ორგანოსთან შეთანხმებულ საბაჟო საწყობში ან შენახვის სხვა ადგილზე, რომელიც აკმაყოფილებს საქართველოს საბაჟო კანონმდებლობით დადგენილ პირობებს. საბაჟო ორგანო უფლებამოსილია, საქონლის მფლობელს მოსთხოვოს იმ საბაჟო ვალდებულებების შესრულების უზრუნველყოფის გარანტიის წარდგენა, რომლებიც შეიძლება წარმოიშვას ამ კოდექსის 188-ე და 189-ე მუხლების საფუძველზე.
2. საბაჟო ორგანო უფლებამოსილია, ნებისმიერ დროს განახორციელოს დროებით დასაწყობებული საქონლის კონტროლი ან/და შეამოწმოს მასთან დაკავშირებული დოკუმენტები.
