# მუხლი 177. საერთო გარანტია
ამ კოდექსის 175-ე მუხლის პირველ და მე-3 ნაწილებში აღნიშნული პირების შუამდგომლობის საფუძველზე საბაჟო ორგანო უფლებამოსილია, მისცეს მათ საერთო გარანტიის წარდგენის უფლება ორ ან ორზე მეტ ისეთ საბაჟო დამუშავების ოპერაციაზე, რომელთა მიმართაც უკვე წარმოიშვა ან შესაძლებელია წარმოიშვას საბაჟო ვალდებულება.
