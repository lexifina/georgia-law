# მუხლი 150. თავისუფალი ზონის შექმნა და თავისუფალი საწყობის მოწყობა
1. თავისუფალი ზონის შექმნა და თავისუფალი საწყობის მოწყობა შესაძლებელია საბაჟო ტერიტორიის ფარგლებში ნავსადგურში ან აეროპორტში ანდა იმ სატრანსპორტო კვანძის მიმდებარე ტერიტორიაზე, რომელიც უშუალოდ ესაზღვრება საქართველოს საბაჟო საზღვარს. თავისუფალი ზონის შექმნა და თავისუფალი საწყობის მოწყობა გათვალისწინებულია განსაზღვრული ვადით.
2. დაინტერესებული პირის განცხადების და შესაბამისი გარანტიის წარდგენის საფუძველზე თავისუფალი ზონის შექმნისა და თავისუფალი საწყობის მოწყობის შესახებ გადაწყვეტილებას იღებს საქართველოს მთავრობა.
3. თავისუფალი ზონა ან თავისუფალი საწყობი უნდა იყოს შემოსაზღვრული და შესაბამისად მონიშნული.
4. თავისუფალ ზონაში ან თავისუფალ საწყობში ან/და მის ნაწილში უნდა განისაზღვროს შესასვლელი და გამოსასვლელი, რათა თავიდან იქნეს აცილებული საქონლის სხვა ადგილებიდან შეტანა ან გატანა, და პერიმეტრის ზღუდე.
5. წარსადგენი გარანტიის ოდენობას, თავისუფალი ზონის შექმნისა და თავისუფალი საწყობის მოწყობის პირობებს, მათი ფუნქციონირების, საქონლის შენახვისა და საბაჟო კონტროლის წესებს განსაზღვრავს საქართველოს მთავრობა შესაბამისი დადგენილებით.
