# მუხლი 15. დოკუმენტებისა და ინფორმაციის წარდგენა
1. საქართველოს საბაჟო კანონმდებლობის შესაბამისად დეკლარანტმა უნდა უზრუნველყოს საბაჟო ორგანოში საჭირო დოკუმენტისა და ინფორმაციის წარდგენა და საბაჟო ზედამხედველობის ფუნქციის შესრულებისათვის საბაჟო ორგანოს მოთხოვნის შესაბამისად სათანადო დახმარების გაწევა.
2. საბაჟო კონტროლის ან/და საბაჟო ზედამხედველობის განხორციელებისათვის საჭირო დოკუმენტების ნუსხა განისაზღვრება საქართველოს ფინანსთა მინისტრის ბრძანებით.
