# მუხლი 55. დროებით დასაწყობებული საქონლის მიმართ დასაშვები ოპერაციები
დროებით დასაწყობებული საქონლის მიმართ დასაშვებია მხოლოდ ისეთი ღონისძიებების გამოყენება, რომლებიც უზრუნველყოფს მის დაცულობას და არ ცვლის მის გარეგნულ სახეს ან ტექნიკურ მახასიათებლებს, გარდა ამ კოდექსის 48-ე მუხლით გათვალისწინებული შემთხვევებისა.
