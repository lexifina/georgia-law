# მუხლი 88. გამარტივებული საბაჟო დეკლარაცია
1. საბაჟო პროცედურების გამარტივების მიზნით საბაჟო ორგანო უფლებამოსილია, შესაბამისი წერილობითი განცხადების საფუძველზე ნება დართოს დეკლარანტს, წარადგინოს გამარტივებული საბაჟო დეკლარაცია.
2. გამარტივებული საბაჟო დეკლარაციის სახეებს, წარდგენის შემთხვევებსა და წესებს განსაზღვრავს საქართველოს მთავრობა.
