# მუხლი 14. საბაჟო პროცედურების განხორციელების ენა
1. საბაჟო პროცედურები ხორციელდება ქართულ ენაზე, ხოლო აფხაზეთში - აგრეთვე აფხაზურ ენაზე.
2. საქართველოს საბაჟო კანონმდებლობით დადგენილ შემთხვევებში საბაჟო პროცედურები შეიძლება განხორციელდეს ან/და საბაჟო ორგანოში წარსადგენი დოკუმენტები შეიძლება შედგენილ იქნეს სხვა ენაზედაც.
3. თუ დეკლარანტის მიერ საბაჟო ორგანოში წარდგენილი დოკუმენტები შედგენილია უცხოურ ენაზე, გარდა ამ მუხლის მე-2 ნაწილით განსაზღვრული შემთხვევისა, და გაუგებარია საბაჟო ორგანოს უფლებამოსილი პირისათვის, მას უფლება აქვს მოითხოვოს ამ დოკუმენტების ნოტარიალურად დამოწმებული თარგმანი სახელმწიფო ენაზე.
