# მუხლი 39. საბაჟო ღირებულებაში შესატანი პროცენტები
1. მყიდველის მიერ იმპორტირებული საქონლის ყიდვასთან დაკავშირებით დადებული საფინანსო შეთანხმებით გათვალისწინებული პროცენტები არ შედის საქონლის საბაჟო ღირებულებაში, თუ:
ა) ეს პროცენტები გამოყოფილია საქონლის ფაქტობრივი ფასიდან;
ბ) საფინანსო შეთანხმება შედგენილია წერილობითი ფორმით;
გ) საჭიროების შემთხვევაში მყიდველს შეუძლია დაადასტუროს, რომ საქონელი ფაქტობრივად გაყიდულია დეკლარირებული ფასით და საპროცენტო განაკვეთი არ აღემატება საშუალო საპროცენტო განაკვეთს, რომელიც დაფინანსების მომენტში მოქმედებს მსგავს შეთანხმებებთან მიმართებით იმ ქვეყანაში, რომელშიც იმყოფება დამფინანსებელი პირი.
2. ამ მუხლის პირველი ნაწილის დებულებები გამოიყენება მიუხედავად იმისა, გარიგებას აფინანსებს გამყიდველი, ბანკი თუ მესამე პირი.
