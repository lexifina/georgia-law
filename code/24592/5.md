# მუხლი 5. საქართველოს საბაჟო ტერიტორია და საბაჟო საზღვარი
1. საქართველოს საბაჟო ტერიტორია შედგება საქართველოს სახმელეთო ტერიტორიისაგან, ტერიტორიული და შიდა წყლებისაგან და მათი საჰაერო სივრცისაგან. საქართველოს საბაჟო ტერიტორია აგრეთვე მოიცავს განსაკუთრებულ საზღვაო ეკონომიკურ ზონაში განლაგებული დანადგარების, ნაგებობებისა და ხელოვნური კუნძულების ტერიტორიებს, რომლებზედაც ვრცელდება საქართველოს განსაკუთრებული იურისდიქცია.
2. საქართველოს საბაჟო ტერიტორია შემოიფარგლება საბაჟო საზღვრით, რომელიც ემთხვევა საქართველოს სახელმწიფო საზღვარს.
