# მუხლი 142. საბაჟო ტერიტორიის გარეთ საქონლის გადამუშავების საბაჟო რეჟიმში მოქცეული საქონლის გადამუშავება კომპენსაციის გადახდით
თუ საბაჟო ტერიტორიის გარეთ საქონლის გადამუშავების საბაჟო რეჟიმში მოქცეული საქონლის გადამუშავება ხორციელდება შესაბამისი კომპენსაციის გადახდით, გადამუშავების პროდუქტის საქართველოს საბაჟო ტერიტორიაზე შემოტანისას იგი თავისუფალ მიმოქცევაში გაშვებული უნდა იქნეს იმპორტის გადასახდელების გადახდისაგან ნაწილობრივ გათავისუფლებით. ასეთ შემთხვევაში საბაჟო ვალდებულება განისაზღვრება ამ კოდექსის 140-ე მუხლის შესაბამისად.
