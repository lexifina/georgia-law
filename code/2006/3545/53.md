# მუხლი 53. საქონლის დროებითი დასაწყობების არსი
საბაჟო ორგანოსათვის წარდგენილი საქონელი მისი წარდგენიდან საბაჟო ორგანოს მიერ საქონლის მიმართ საბაჟო დამუშავების ოპერაციის გამოყენების შესახებ გადაწყვეტილების მიღებამდე ან შესაბამისი საბაჟო დამუშავების ოპერაციის გამოყენების შემთხვევაში საქართველოს კანონმდებლობით დადგენილ ვადაში ამ ოპერაციის დასრულებამდე ითვლება დროებით დასაწყობებულად.
