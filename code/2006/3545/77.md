# მუხლი 77. საბაჟო დეკლარაციის შემოწმების შედეგების გამოყენება
1. საბაჟო დეკლარაციის შემოწმების შედეგები გამოიყენება საქონლის შესაბამისი საბაჟო რეჟიმის მარეგულირებელი საქართველოს საბაჟო კანონმდებლობის მიზნებისათვის.
2. თუ არ ხდება საბაჟო დეკლარაციის შემოწმება, საქართველოს საბაჟო კანონმდებლობის მიზნებისათვის გამოიყენება საბაჟო დეკლარაციაში არსებული მონაცემები.
