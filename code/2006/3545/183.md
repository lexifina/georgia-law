# მუხლი 183. გარანტიის შეთანხმება
1. გარანტიის წარმდგენი ვალდებული პირი უფლებამოსილია, ამ კოდექსის 179-ე მუხლში მითითებული გარანტიის სახეებიდან ამოირჩიოს წარსადგენი გარანტია, ხოლო საბაჟო ორგანო უფლებამოსილია, მოითხოვოს არჩეული გარანტიის შესრულება განსაზღვრულ ვადაში.
2. საბაჟო ორგანო უფლებამოსილია უარი თქვას წარდგენილ გარანტიაზე, თუ:
ა) იგი ეწინააღმდეგება საბაჟო რეჟიმის მარეგულირებელ საქართველოს საბაჟო კანონმდებლობას;
ბ) იგი, საგარანტიო თანხის ან/და გარანტიის მოქმედების ვადის გათვალისწინებით, ვერ უზრუნველყოფს წარმოსაშობი საბაჟო ვალდებულების შესრულებას.
