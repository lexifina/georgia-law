# მუხლი 195. საბაჟო ვალდებულების წარმოშობა საქართველოს საბაჟო ტერიტორიიდან არადეკლარირებული საქონლის გატანისას
1. საბაჟო ვალდებულება წარმოიშობა საქართველოს საბაჟო ტერიტორიიდან იმ არადეკლარირებული საქონლის გატანისას, რომელიც ექვემდებარება ექსპორტის გადასახდელების გადახდას.
2. ამ მუხლის პირველი ნაწილით განსაზღვრულ საბაჟო ვალდებულებასთან დაკავშირებით ვალდებული პირები არიან საქონლის მესაკუთრე და საქონლის მფლობელი.
