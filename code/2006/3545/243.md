# მუხლი 243. საბაჟო ორგანოსთან შეუთანხმებლად საბაჟო ზედამხედველობის ქვეშ მყოფი საქონლის გახსნა, ხელმეორედ შეფუთვა, გადატვირთვა ან გადმოტვირთვა
1. საბაჟო ორგანოსთან შეუთანხმებლად საბაჟო ზედამხედველობის ქვეშ მყოფი საქონლის გახსნა, ხელმეორედ შეფუთვა, გადატვირთვა ან გადმოტვირთვა, -

იწვევს ვალდებული პირის დაჯარიმებას ყოველ შემდგომ განმეორებაზე 1 500 ლარით.
