# მუხლი 172. დაბრუნებული გადამუშავების პროდუქტის დაბეგვრა
1. გადამუშავების პროდუქტზე, რომელიც საბაჟო ტერიტორიაზე საქონლის გადამუშავების საბაჟო რეჟიმის გამოყენების შემდეგ გატანილ იქნა საქართველოს საბაჟო ტერიტორიიდან და უცვლელ მდგომარეობაში ბრუნდება, ვრცელდება ამ კოდექსის 171-ე მუხლის დებულებები.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებულ შემთხვევაში იმპორტის გადასახდელების ოდენობა განისაზღვრება საბაჟო ტერიტორიაზე საქონლის გადამუშავების საბაჟო რეჟიმის მარეგულირებელი დებულებების საფუძველზე.
