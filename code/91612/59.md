# მუხლი 59. უშიშროების დამატებითი ღონისძიებების გეგმა
პატიმრობის/თავისუფლების აღკვეთის დაწესებულებაში მასობრივი არეულობისას და ქვეყანაში საგანგებო ან საომარი მდგომარეობის გამოცხადებისას თავდასხმის, დაწესებულებიდან გაქცევის, სხვა დანაშაულისა და სამართალდარღვევათა აღკვეთის მიზნით დეპარტამენტი შეიმუშავებს უშიშროების დამატებითი ღონისძიებების გეგმას, რომელსაც ამტკიცებს მინისტრი საქართველოს შინაგან საქმეთა სამინისტროსთან შეთანხმებით.
