# მუხლი 93. პირველი ინსტანციის სასამართლოს გადაწყვეტილების (განჩინების) გასაჩივრება
1. პირველი ინსტანციის სასამართლოს გადაწყვეტილება (განჩინება) სააპელაციო სასამართლოში შეიძლება გაასაჩივრონ მხარეებმა ან მათმა წარმომადგენლებმა მათთვის საქართველოს სამოქალაქო საპ-როცესო კოდექსით გათვალისწინებული წესით გადაწყვეტილების (განჩინების) ჩაბარებიდან 7 დღის ვადაში. შემოსულ საჩივარს სასამართლო დაუყოვნებლივ უგზავნის სააპელაციო სასამართლოს და მოწინააღმდეგე მხარეს.
2. სააპელაციო სასამართლო სააპელაციო საჩივარს განიხილავს კოლეგიურად - 3 მოსამართლის შემადგენლობით, ღია სასამართლო სხდომაზე. სააპელაციო სასამართლო საქმეს განიხილავს და გადაწყვეტილება (განჩინება) გამოაქვს პირველი ინსტანციის სასამართლოსათვის ამ კოდექსით დადგენილი წესით და დადგენილ ვადებში.
3. სააპელაციო სასამართლოს გადაწყვეტილება (განჩინება) საბოლოოა და არ საჩივრდება.
