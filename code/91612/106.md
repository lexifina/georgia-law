# მუხლი 106. საჩივრის განხილვის შედეგები
1. საჩივრის განხილვის შედეგები ბრალდებულს/მსჯავრდებულს ხელწერილით გაეცნობა გადაწყვეტილების მიღებიდან არა უგვიანეს 5 დღისა და დაერთვის ბრალდებულის/მსჯავრდებულის პირად საქმეს.
2. საჩივარში მითითებულ ყოველ კონკრეტულ მოთხოვნას უნდა გაეცეს დასაბუთებული პასუხი.
3. საჩივარზე უარყოფითი გადაწყვეტილების შემთხვევაში ბრალდებულს/მსჯავრდებულს უნდა ეცნობოს დასაბუთებული პასუხი.
