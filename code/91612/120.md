# მუხლი 120. ბრალდებულის/მსჯავრდებულის ჯანმრთელობის მდგომარეობის კონტროლი
1. პატიმრობის/თავისუფლების აღკვეთის დაწესებულებაში მისვლისთანავე ბრალდებული/მსჯავრდებული გადის სამედიცინო შემოწმებას.
2. ბრალდებულის/მსჯავრდებულის ჯანმრთელობის მდგომარეობა მოწმდება წელიწადში ერთხელ მაინც. დაავადებულ ბრალდებულს/ მსჯავრდებულს უტარდება გადაუდებელი მკურნალობა.
3. საქართველოს შინაგან საქმეთა სამინისტროს დროებითი მოთავსების იზოლატორიდან პენიტენციური დაწესებულებისთვის ბრალდებულთან/მსჯავრდებულთან დაკავშირებული სამედიცინო ხასიათის ინფორმაციის მიწოდება ხდება საქართველოს შინაგან საქმეთა მინისტრისა და მინისტრის ერთობლივი ბრძანებით დადგენილი წესის შესაბამისად.
- საქართველოს 2015 წლის 1 მაისის კანონი №3523 - ვებგვერდი, 18.05.2015წ.
