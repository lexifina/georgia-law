# მუხლი 115. მსჯავრდებულთა პროფესიული განათლება
1. თავისუფლების აღკვეთის დაწესებულებაში მსჯავრდებულთათვის უნდა შეიქმნას პროფესიული განათლების მიღების პირობები.
2. მსჯავრდებულთა პროფესიული განათლების დროს უპირატესობა ეძლევა იმ პროფესიებს, რომელთა შესწავლაც თავისუფლების აღკვეთის დაწესებულების პირობებშია შესაძლებელი.
3. თავისუფლების აღკვეთის დაწესებულებაში პროფესიული განათლების შედეგად მიღებულ კვალიფიკაციას ადასტურებს საატესტაციო ორგანო "პროფესიული განათლების შესახებ" საქართველოს კანონით დადგენილი წესის შესაბამისად.
