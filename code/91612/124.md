# მუხლი 124. ბრალდებულის მიმოწერა და სატელეფონო საუბარი 2014 წლის 1 იანვრამდე
ბრალდებულს 2014 წლის 1 იანვრამდე უფლება აქვს, ადმინისტრაციის კონტროლით, საკუთარი ხარჯით აწარმოოს მიმოწერა და 1 თვის განმავლობაში 3-ჯერ ჰქონდეს სატელეფონო საუბარი, თითოეული - არა უმეტეს 15 წუთისა, მხოლოდ გამომძიებლის, პროკურორის ან სასამართლოს ნებართვით.
