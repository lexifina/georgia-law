# მუხლი 98. საჩივრის ადრესატი
1. ბრალდებულს/მსჯავრდებულს უფლება აქვს, საჩივრით მიმართოს დაწესებულების დირექტორს, ხოლო დირექტორის მიერ ჩადენილი ქმედების შესახებ - დეპარტამენტის თავმჯდომარეს ან სპეციალურ პრევენციულ ჯგუფს.
2. დაუშვებელია საჩივრის განხილვა იმ პირის ან მისდამი უშუალოდ დაქვემდებარებული პირის მიერ, რომლის ქმედებასაც ეხება საჩივარი. ამგვარი საჩივარი უნდა განიხილოს ზემდგომმა პირმა.
