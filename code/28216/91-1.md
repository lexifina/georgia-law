# მუხლი 91¹. საშიში საწარმოო ობიექტების დამზადება, მათზე სამუშაოთა წარმოება ან მომსახურება უსაფრთხოების მოთხოვნათა დარღვევით, აგრეთვე უფლებამოსილი ორგანოების სათანადო ნებართვის გარეშე მუშაობა
