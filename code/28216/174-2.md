# მუხლი 174 ². საქართველოს რესპუბლიკის უზენაესი საბჭოს და მთავრობის შენობების წინ პოლიტიკური ხასიათის აქციების ორგანიზაციისა და ჩატარების წესის დარღვევა
საქართველოს რესპუბლიკის უზენაესი საბჭოს და მთავრობის შენობების წინ პოლიტიკური ხასიათის აქციების ორგანიზაციისა და ჩატარების წესის დარღვევა ჩატარების წესის დარღვევა, -
გამოიწვევს დაჯარიმებას შრომის ანაზღაურების ორიდან ოთხ მინიმალურ ოდენობამდე, ხოლო გამონაკლის შემთხვევაში, თუ საქმის გარემოებათა მიხედვით და დამრღვევის პიროვნების გათვალიწინებით ამ ზომის გამოყენება ჩაითვლება არასაკმარისად, - ადმინისტრაციულ პატიმრობას ვადით ოცდაათ დღემდე.
