# მუხლი 174². შეკრებისათვის ან მანიფესტაციისათვის ხელის შეშლა სამსახურებრივი მდგომარეობის გამოყენებით

გამოიწვევს დაჯარიმებას შრომის ანაზღაურების ორმოცდაათიდან ას მინიმალურ ოდენობამდე.
