# მუხლი 241. ოქმის გაგზავნა
ოქმი დაუყოვნებლივ ეგზავნება იმ ორგანოს (თანამდებობის პირს), რომელიც უფლებამოსილია განიხილოს ადმინისტრაციული სამართალდარღვევის საქმე.
