# მუხლი 141. რადიოდანადგართა მოწყობა და ექსპლუატაცია სათანადო რეგისტრაციის ან ნებართვის გარეშე
რადიოსატრანსლაციო კვანძის მოწყობა და ექსპლუატაცია სათანადო რეგისტრაციის ან ნებართვის გარეშე (როცა ასეთი საჭიროა), მისი სიმძლავრის მიუხედავად, _
გამოიწვევს თანამდებობის პირთა დაჯარიმებას ორმოცდაათ მანეთამდე.
რადიოსატრანსლაციო წერტილის მოწყობა და ექსპლუატაცია სათანადო რეგისტრაციის ან ნებართვის გარეშე (როცა ასეთი საჭიროა) მიუხედავად იმ რადიოსატრანსლაციო კვაძის უწყებრივი კუთვნილებისა, საიდანაც იგი იდგმება, _
გამოიწვევს დაჯარიმებას ხუთ მანეთამდე.
