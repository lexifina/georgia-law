# მუხლი 284. ადმინისტრაციული სახდელის დადების შესახებ დადგენილებათა აღსრულების წესი
1. დადგენილება ადმინისტრაციული სახდელის დადების შესახებ აღსრულდება საამისოდ უფლებამოსილი ორგანოების მიერ, ამ კოდექსით და საქართველოს სხვა კანონმდებლობით დადგენილი წესით.
2. დადგენილება ადმინისტრაციული პატიმრობის შესახებ აღსრულდება შინაგან საქმეთა ორგანოების მიერ, ხოლო სამხედრო მოსამსახურის პატიმრობის შემთხვევაში - საქართველოს თავდაცვის სამინისტროს მიერ საქართველოს კანონმდებლობით დადგენილი წესით.
3. ერთი პირის მიმართ ადმინისტრაციული სახდელის დადების შესახებ რამდენიმე დადგენილების გამოტანის შემთხვევაში თითოეული დადგენილება დამოუკიდებლად აღსრულდება.
საქართველოს რესპუბლიკის სახელმწიფო საბჭოს 1992 წლის 3 აგვისტოს დეკრეტი - საქართველოს რესპუბლიკის სახელმწიფო საბჭოს ნორმატიული აქტების კრებული, ტ.I, 1992 წ., მუხ.128
