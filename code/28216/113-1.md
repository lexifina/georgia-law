# მუხლი 113¹. საქართველოს შიდა საზღვაო წყლებში, ტერიტორიულ ზღვაში და ხმელეთზე განთავსებულ სანავიგაციო ნიშნებზე უნებართვოდ ასვლა ან ამ ნიშნებში უნებართვოდ შეღწევა
