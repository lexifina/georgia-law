# მუხლი 197. სამხედრო აღრიცხვის წესების დარღვევა
სამხედრო ვალდებულთა და ახალწვეულთა მიერ საყოველთაო სამხედრო ვალდებულების შესახებ სსრ კავშირის კანონის 89- 92-ე მუხლებით გათვალისწინებული სამხედრო აღრიცხვის წესების დარღვევა, სამხედრო კომისარიატში გამოძახების შემდეგ არასაპატიო მიზეზით გამოუცხადებლობა ან სააღრიცხვო ორგა ნოსათვის საცხოვრებელი ადგილის მისამართის შეცვლის არადროული შეტყობინება, -
გამოიწვევს გაფრთხილებას ან დაჯარიმებას ათ მანეთამდე.
