# მუხლი 222¹. საქართველოს იუსტიციის სამინისტროს ორგანოები
საქართველოს იუსტიციის სამინისტროს შესაბამის ორგანოებს თავიანთი კომპეტენციის ფარგლებში აქვთ ამ კოდექსის 185-ე, 185¹, 185², 186-ე მუხლებით და 191-ე მუხლის პირველი და 1¹ ნაწილებით (გარდა დამრღვევის სასაზღვრო გამტარ პუნქტში გამოვლენის შემთხვევისა) გათვალისწინებულ ადმინისტრაციულ სამართალდარღვევათა საქმეების განხილვისა და ადმინისტრაციული სახდელების დადების უფლება.
