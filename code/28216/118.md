# მუხლი 118. სატრანსპორტო საშუალებათა მძღოლების მიერ რკინიგზის გადასასვლელების გავლის წესების დარღვევა
სატრანსპორტო საშუალებათა მძღოლების მიერ რკინიგზის გადასასვლელების გავლის წესების დარღვევა, _

წლის განმავლობაში ამ მუხლის პირველ ნაწილში აღნიშნული დარღვევის განმეორებით ჩადენა, _
