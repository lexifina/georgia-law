# მუხლი 42⁶. საქართველოს სოციალური დაზღვევის ერთიან სახელმწიფო ფონდში სავალდებულო სოციალური დაზღვევის შესატანის შემტანად რეგისტრაციის წესის დარღვევა

გამოიწვევს დაჯარიმებას ორასი ლარის ოდენობით.
