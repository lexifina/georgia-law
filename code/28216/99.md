# მუხლი 99. მასალების საკარანტინო შემოწმებისა და სათანადო დამუშავების გარეშე გატანა

გამოიწვევს მოქალაქეთა დაჯარიმებას ათ მანეთამდე, თანამდებობის პირთა _ ორმოცდაათ მანეთამდე.
