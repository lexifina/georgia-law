# მუხლი 277. ადმინისტრაციული სამართალდარღვევის საქმეზე მიღებული დადგენილების გამო საჩივრისა და პროტესტის განხილვა
ორგანო (თანამდებობის პირი) ადმინისტრაციული სამართალდარღვევის საქმეზე მიღებული დადგენილების, აგრეთვე ამ კოდექსის 234¹ მუხლით დადგენილი წესით ადმინისტრაციული სამართალდარღვევის საქმის ადგილზე განხილვისას მიღებული გადაწყვეტილების გამო საჩივრის და პროტესტის განხილვისას შეამოწმებს გამოტანილი დადგენილების კანონიერებას და დასაბუთებულობას.
