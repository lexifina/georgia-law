# მუხლი 43. სანიტარიულ-ჰიგიენური და სანიტარულ-ეპიდსაწინააღმდეგო წესებისა და ნორმების დარღვევა

გამოიწვევს მოქალაქეთა დაჯარიმებას ათ მანეთამდე, თანამდებობის პირთა - ორმოცდაათ მანეთამდე.
