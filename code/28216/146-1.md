# მუხლი 146¹. დასუფთავების წესების დარღვევა
1. სამშენებლო და საყოფაცხოვრებო ნარჩენების, უვარგისი კონსტრუქციების, მასალების, ნივთების, მიწის და კლდოვანი ქანების ისეთ ადგილებში დაყრა, რომლებიც საამისოდ არ არის გამოყოფილი, -
გამოიწვევს დაჯარიმებას ორმოცდაათიდან ორას ლარამდე.
2. იგივე ქმედება, ჩადენილი განმეორებით ერთი წლის განმავლობაში, -
