# მუხლი 82². გარემოსდაცვითი ტექნიკური რეგლამენტების მოთხოვნების დარღვევა
1. გარემოსდაცვითი ტექნიკური რეგლამენტების მოთხოვნების დარღვევა (გარდა ამ მუხლის მე-3 და მე-4 ნაწილებით გათვალისწინებული შემთხვევებისა) -
