# მუხლი 296. კონფისკაციის შესახებ დადგენილების აღსრულების წესი
იმ საგნის კონფისკაციის შესახებ დადგენილების აღსრულება, რომელიც წარმოადგენდა ადმინისტრაციული სამართალდარღვევის ჩადენის იარაღს ან უშუალო ობიექტს, წარმოებს კონფისკაციაქმნილი საგნის ჩამორთმევის და სახელმწიფო საკუთრებად ამ საგნის იძულებით, უსასყიდლოდ გადაქცევით.
ამ კოდექსის 193-ე მუხლის მეორე ნაწილით და 194-ე მუხლით გათვალისწინებულ ადმინისტრაციულ სამართალდარღვევათა საქმეებზე კონფისკაციის შესახებ დადგენილების აღსრულება ხდება საქართველოს რესპუბლიკ ის საბაჟო კოდექსით დადგენილი წესით.
საქართველოს რესპუბლიკის სახელმწიფო საბჭოს 1992 წლის 3 აგვისტოს დეკრეტი - საქართველოს რესპუბლიკის სახელმწიფო საბჭოს ნორმატიული აქტების კრებული, ტ.I, 1992 წ., მუხ.128
