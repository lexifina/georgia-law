# მუხლი 25. ძირითადი და დამატებითი ადმინისტრაციული სახდელები
საგნების სასყიდლით ჩამორთმევა და კონფისკაცია შეიძლება გამოყენებულ იქნეს როგორც ძირითადი, ისე დამატებითი ადმინისტრაციული სახდელის სახით. გაფრთხილება, ჯარიმა, სპეციალური უფლების ჩამორთმევა, გამასწორებელი სამუშაოები, ადმინისტრაციული პატიმრობა შეიძლება გამოყენებულ იქნეს მხოლოდ როგორც ძირითადი ადმინისტრაციული სახდელი.
ერთი ადმინისტრაციული სამართალდარღვევისათვის შეიძლება დადებული იქნეს ძირითადი ან ძირითადი და დამატებითი სახდელი.
- საქართველოს 2000 წლის 28 ივნისის კანონი №432 - სსმ I, №24, 30.06.2000წ., მუხ.66
