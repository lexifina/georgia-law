# მუხლი 212¹. საქართველოს ეკონომიკისა და მდგრადი განვითარების სამინისტროს სისტემაში შემავალი საჯარო სამართლის იურიდიული პირი − საზღვაო ტრანსპორტის სააგენტო
ამ კოდექსის 114⁵ მუხლით გათვალისწინებულ ადმინისტრაციულ სამართალდარღვევათა საქმეების განხილვისა და ადმინისტრაციული სახდელების დადების უფლება აქვთ საქართველოს ეკონომიკისა და მდგრადი განვითარების სამინისტროს სისტემაში შემავალი საჯარო სამართლის იურიდიული პირის − საზღვაო ტრანსპორტის სააგენტოს უფლებამოსილ პირებს.
