# მუხლი 161. უკანონო ოპერაციები უცხოეთის ვალუტით და საგადასახადო დოკუმენტებით

გამოიწვევს დაჯარიმებას ორმოცდაათ მანეთამდე, ვალუტისა და საგადასახადო დოკუმენტების კონფისკაციით.
