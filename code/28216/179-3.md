# მუხლი 179³. ფალსიფიცირებული ან მავნებელი ალკოჰოლიანი სასმელის რეალიზაცია
1. საზოგადოებრივი კვების ან სავაჭრო ობიექტის მიერ ფალსიფიცირებული ან ადამიანის სიცოცხლისა და ჯანმრთელობისათვის მავნებელი არასერტიფიცირებული ალკოჰოლიანი სასმელის რეალიზაცია, -
გამოიწვევს დაჯარიმებას 5 000 ლარის ოდენობით.
2. იგივე ქმედება, ჩადენილი ადმინისტრაციული სახდელის დადებიდან ერთი წლის განმავლობაში, -
გამოიწვევს დაჯარიმებას 20 000 ლარის ოდენობით.
