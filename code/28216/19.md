# მუხლი 19. აუცილებელი მოგერიება
ადმინისტრაციული პასუხი სმგებლობა არ ეკისრება პირს, რომელმაც, თუმცა ჩაიდინა ამ კოდექსით ან ადმინისტრაციული სამართალდარღვევებ ისათვის ადმინისტრაციული პასუხისმგებლობის დამდგენი სხვა ნორმატიული აქტებით გათვალისწინებული მოქმედება, მაგრამ რომელიც მოქმედებდა აუცილებელი მოგერიების მდგომარეობაში, ესე იგი სახელმწიფო ან საზოგადოებრივი წესრიგის, საკუთრების, მოქალაქეთა უფლებებისა და თავისუფლებების, მმართველობის დადგენილი წესის მართლსაწინააღმდეგო ხელყოფისაგან დაცვისას ხელმყოფისათვის ზიანის მიყენების გზით, თუ ამასთან გადაცილებული არ იყო აუცილებელი მოგერიების ფარგლები.
საქართველოს რესპუბლიკის სახელმწიფო საბჭოს 1992 წლის 3 აგვისტოს დეკრეტი - საქართველოს რესპუბლიკის სახელმწიფო საბჭოს ნორმატიული აქტების კრებული, ტ.I, 1992 წ., მუხ.128
