# მუხლი 288⁵. საურავის დარიცხვის შესახებ დადგენილების იძულებითი აღსრულება
ამ კოდექსის 288⁴ მუხლით დადგენილ ვადაში საურავის გადაუხდელობის შემთხვევაში დადგენილების გამომტანი ორგანოს (თანამდებობის პირის) დადგენილების საფუძველზე საურავის დარიცხვის შესახებ დადგენილების იძულებით აღსრულებას ახორციელებს აღმასრულებელი დამრღვევის ხელფასიდან ან სხვა შემოსავლიდან, აგრეთვე დამრღვევის პირად ქონებაზე ან საერთო საკუთრებაში მის წილზე გადახდევინების მიქცევის გზით, თუ საქართველოს კანონმდებლობით სხვა რამ არ არის გათვალისწინებული.
