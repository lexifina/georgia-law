# მუხლი 185¹. პირის გარდაცვალების შესახებ შეტყობინების ვალდებულების შეუსრულებლობა
გამგეობის (მერიის) რწმუნებულის მიერ, აგრეთვე სახელმწიფო, ადგილობრივი თვითმმართველობის ან კერძო სამედიცინო დაწესებულების, პათოლოგანატომიური საქმიანობის (კლინიკური პათოლოგიის) და სასამართლო-სამედიცინო ექსპერტიზის განმახორციელებელი დაწესებულების, პანსიონატის, თავშესაფრის, თავისუფლების აღკვეთის დაწესებულების ხელმძღვანელის ან მის მიერ უფლებამოსილი ადმინისტრაციის წარმომადგენლის, ასევე გარდაცვალების შესახებ სამედიცინო ცნობის გაცემაზე უფლებამოსილი პირის მიერ სამოქალაქო რეესტრის სააგენტოსთვის პირის გარდაცვალების შესახებ კანონით დადგენილი წესით შეტყობინების ვალდებულების შეუსრულებლობა -
