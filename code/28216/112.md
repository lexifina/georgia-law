# მუხლი 112. საზღვაო ტრანსპორტზე მოძრაობის წესების დარღვევა
საზღვაო ტრან სპორტზე დადგენილი გემების პორტში შესვლისა და პორტიდან გამოსვლის, საპორტო წყლებში გემების მოძრაობის, გაჩერებისა და ბუქსირების წესების დარღვევა, _
გამოიწვევს დაჯარიმებას ათ მანეთამდე.
საპორტო წყლებში საყვინთი სამუშაოების წარმოება სათანადო ნებართვის გარეშე, აგრეთვე ამ სამუშაოთა დროს სიგნალების მიცემის წესების დაუცველობა, _
გამოიწვევს დაჯარიმებას ხუთ მანეთამდე.
