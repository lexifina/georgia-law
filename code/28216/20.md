# მუხლი 20. შეურაცხაობა
ადმინისტრაციული პასუხისმგებლობა არ ეკისრება პირს, რომელიც კანონსაწინააღმდეგო მოქმედების ჩადენის ან უმოქმედობის დროს შეურაცხი იყო, ესე იგი, გონებრივი განვითარების შეფერხების, დემენციის ანდა ქრონიკული ან დროებითი ფსიქიკური აშლილობის ან სხვაგვარი ფსიქიკური აშლილობის გამო არ შეეძლო ანგარიში გაეწია ან ეხელმძღვანელა თავისი ქმედებისთვის.
- საქართველოს 2025 წლის 26 ივნისის კანონი №839 - ვებგვერდი, 03.07.2025წ.
