# მუხლი 105². მევენახეობა-მეღვინეობის დარგში სასაქონლო პროდუქციის წარმოებასთან და შენახვასთან დაკავშირებული ტექნოლოგიური პროცესების აღრიცხვისა და შეტყობინების წესების დარღვევა
მევენახეობა-მეღვინეობის დარგში სასაქონლო პროდუქციის წარმოებასთან და შენახვასთან დაკავშირებული ტექნოლოგიური პროცესების აღრიცხვისა და შეტყობინების წესების დარღვევა, -
