# მუხლი 105². მევენახეობა-მეღვინეობის დარგში პროდუქციის წარმოებასა და შენახვასთან დაკავშირებული ტექნოლოგიური პროცესების აღრიცხვისა და შეტყობინების წესების დარღვევა
1. მევენახეობა-მეღვინეობის დარგში პროდუქციის წარმოებასა და შენახვასთან დაკავშირებული ტექნოლოგიური პროცესების აღრიცხვისა და შეტყობინების წესების დარღვევა −
