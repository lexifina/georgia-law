# მუხლი 228. საქართველოს კავშირგაბმულობისა და ფოსტის სფეროში საქმიანობის მარეგულირებელი ეროვნული კომისია
ამ კოდექსის 141-142-ე, 144¹-144⁹ მუხლებით გათვალისწინებულ ადმინისტრაციულ სამართალდარღვევათა საქმეების განხილვისა და ადმინისტრაციული სახდელების დადების უფლება აქვს საქართველოს კავშირგაბმულობისა და ფოსტის სფეროში საქმიანობის მარეგულირებელ ეროვნულ კომისიას.
