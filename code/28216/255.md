# მუხლი 255. ადვოკატი
ადმინისტრაციული სამართალდარღვევის საქმის განხილვაში მონაწილე ადვოკატს უფლება აქვთ გაეცნოს საქმის ყველა მასალას; განაცხადოს შუამდგომლობანი; იმ პირის დავალებით, რომელმაც იგი მიიწვია, და მისი სახელით შეიტანოს საჩივარი საქმის გამო მიღებულ დადგენილებაზე.
ადვოკატის უფლებამოსილება დასტურდება იურიდიული კონსულტაციის მიერ გაცემული ორდერით.
