# მუხლი 203. კოლეგიური ორგანოების სხდომათა უფლებამოსილება
ადმინისტრაციულ კომისიებსა და არასრულწლოვანთა საქმეების კომისიებს უფლება აქვთ ადმინისტრაციულ სამართალდარღვევათა საქმეები განიხილონ მათი შემადგენლობის წევრთა არანაკლებ ნახევრის დასწრებისას, ხოლო სახალხო დეპუტატთა სადაბო, სასოფლო საბჭოების აღმასრულებელ კომიტეტებს _ აღმასრულებელი კომიტეტის მთლიანი შემადგენლობის არანაკლებ ორი მესამედის დასწრებისას.
სხვა კოლეგიური ორგანოების სხდომათა უფლებამოსილება განისაზღვრება სსრ კავშირისა და საქართველოს სსრ კანონმდებლობით.
