# მუხლი 26. მოსამსახურის სახელმწიფო სპეციალური წოდება
1. მოხელეს, აგრეთვე სამსახურის გენერალურ დირექტორს, მის პირველ მოადგილესა და მოადგილეს სახელმწიფო სპეციალური წოდებები ენიჭებათ საქართველოს კანონმდებლობით დადგენილი წესით.
2. სახელმწიფო სპეციალური წოდებების მქონე თანამდებობების შესაბამის ზღვრულ სპეციალურ წოდებებს განსაზღვრავს მინისტრი.
3. სახელმწიფო სპეციალურ წოდებასთან დაკავშირებული საკითხები წესრიგდება "სახელმწიფო სპეციალური წოდებების შესახებ" საქართველოს კანონითა და მინისტრის ბრძანებით.
