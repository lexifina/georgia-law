# მუხლი 8. სამსახურის საქმიანობის ძირითადი პრინციპები
სამსახურის საქმიანობის ძირითადი პრინციპებია:
ა) კანონიერება;
ბ) ადამიანის ძირითად უფლებათა დაცვა და პატივისცემა;
გ) თანაზომიერება;
დ) გამჭვირვალობა;
ე) პოლიტიკური ნეიტრალიტეტი.
