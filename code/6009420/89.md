# მუხლი 89. სასჯელის მოხდისგან პირობით ვადამდე გათავისუფლება, სასჯელის სახით დანიშნული უვადო თავისუფლების აღკვეთის გადასინჯვა, სასჯელის მოუხდელი ნაწილის შეცვლა უფრო მსუბუქი სახის სასჯელით
სასჯელის მოხდისგან პირობით ვადამდე გათავისუფლებასთან, სასჯელის სახით დანიშნული უვადო თავისუფლების აღკვეთის გადასინჯვასა და სასჯელის მოუხდელი ნაწილის უფრო მსუბუქი სახის სასჯელით შეცვლასთან დაკავშირებული საკითხები წესრიგდება საქართველოს სისხლის სამართლის კოდექსის 72-ე, 72¹ და 73-ე მუხლებით.
