# მუხლი 195¹. სახელმწიფო შესყიდვაში მონაწილეობის წესის დარღვევა
1. სახელმწიფო შესყიდვასთან, მათ შორის, ბაზრის კვლევასთან ან/და გამარტივებულ შესყიდვასთან, დაკავშირებით პირების წინასწარი შეთანხმება, გარიგება ან/და სხვა ქმედება თავისთვის ან სხვისთვის მატერიალური გამორჩენის ან უპირატესობის მიღების მიზნით, რამაც შემსყიდველი ორგანიზაციის კანონიერი ინტერესის არსებითი დარღვევა გამოიწვია, −
ისჯება ჯარიმით, შინაპატიმრობით ვადით ორ წლამდე ან თავისუფლების აღკვეთით ვადით ექვს წლამდე.
2. იგივე ქმედება, ჩადენილი არაერთგზის, −
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით ოთხიდან შვიდ წლამდე.
3. იგივე ქმედება, ჩადენილი იმის მიერ, ვინც ორჯერ ან მეტჯერ იყო ნასამართლევი ამ თავით ან/და ამ კოდექსის 180-ე მუხლით ან/და 182-ე მუხლით გათვალისწინებული დანაშაულის ჩადენისთვის, −
ისჯება თავისუფლების აღკვეთით ვადით ხუთიდან რვა წლამდე.
შენიშვნა: ამ მუხლით გათვალისწინებული ქმედებისთვის იურიდიული პირი ისჯება საქმიანობის უფლების ჩამორთმევით ან ლიკვიდაციითა და ჯარიმით.
