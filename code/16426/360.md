# მუხლი 360. თვითნებობა
1. თვითნებობა, ესე იგი ნამდვილად თავისი ან თავისად დაგულვებული უფლების დადგენილი წესის საწინააღმდეგოდ განხორციელება, რამაც გამოიწვია მნიშვნელოვანი ზიანი, -
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ვადით ას ოთხმოციდან ორას საათამდე ან გამასწორებელი სამუშაოთი ვადით ერთიდან ორ წლამდე ანდა ტუსაღობით ვადით ოთხიდან ექვს თვემდე.
2. იგივე ქმედება, ჩადენილი ძალადობით ან ძალადობის მუქარით, -
ისჯება თავისუფლების შეზღუდვით ვადით სამ წლამდე ან ტუსაღობით ვადით ოთხიდან ექვს თვემდე ანდა თავისუფლების აღკვეთით ვადით ოთხ წლამდე.
