# მუხლი 234. საქართველოს ტერიტორიაზე რადიაქტიური, ტოქსიკური სამრეწველო ან საყოფაცხოვრებო ნარჩენის ტრანზიტი ან იმპორტი
1. საქართველოს ტერიტორიაზე რადიაქტიური, ტოქსიკური სამრეწველო ან საყოფაცხოვრებო ნარჩენის ტრანზიტი ან იმპორტი საქართველოში უტილიზაციის, გაუვნებელყოფის, გადამუშავების, დამარხვის ან ნებისმიერი სხვა მიზნით, სხვა სამრეწველო ან საყოფაცხოვრებო ნარჩენების იმპორტი მათი გაუვნებელყოფის, დაწვის ან დამარხვის მიზნით, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით ხუთ წლამდე.
2. იგივე ქმედება, რამაც გამოიწვია მძიმე შედეგი, -
ისჯება თავისუფლების აღკვეთით ვადით რვა წლამდე.
