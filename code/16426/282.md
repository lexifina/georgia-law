# მუხლი 282. მატარებლის თვითნებური გაჩერება
1. მატარებლის გაჩერება საჭიროების გარეშე, რამაც გაუფრთხილებლობით გამოიწვია ადამიანის სიცოცხლის მოსპობა ან სხვა მძიმე შედეგი, -
ისჯება თავისუფლების აღკვეთით ვადით შვიდ წლამდე.
2. იგივე ქმედება, რამაც გაუფრთხილებლობით გამოიწვია ორი ან მეტი ადამიანის სიცოცხლის მოსპობა, -
ისჯება თავისუფლების აღკვეთით ვადით ათ წლამდე.
