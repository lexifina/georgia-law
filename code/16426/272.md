# მუხლი 272. ნარკოტიკული საშუალების, მისი ანალოგის, ფსიქოტროპული ნივთიერების, მისი ანალოგის მოხმარებაზე დაყოლიება
[ნარკოტიკული საშუალების, მისი ანალოგის, ახალი ფსიქოაქტიური ნივთიერების, ფსიქოტროპული ნივთიერების ან მისი ანალოგის მოხმარებაზე დაყოლიება ( ამოქმედდეს 2014 წლის 1 მაისიდან.)]
1. ნარკოტიკული საშუალების, მისი ანალოგის, ფსიქოტროპული ნივთიერების, მისი ანალოგის მოხმარებაზე დაყოლიება, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით სამ წლამდე.
[1. ნარკოტიკული საშუალების, მისი ანალოგის, ახალი ფსიქოაქტიური ნივთიერების, ფსიქოტროპული ნივთიერების ან მისი ანალოგის მოხმარებაზე დაყოლიება, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით სამ წლამდე. ( ამოქმედდეს 2014 წლის 1 მაისიდან.)]
2. იგივე ქმედება, ჩადენილი არაერთგზის, -
ისჯება თავისუფლების აღკვეთით ვადით სამიდან ექვს წლამდე.
3. ამ მუხლის პირველი ნაწილით გათვალისწინებული ქმედება, ჩადენილი ორი ან მეტი პირის ან არასრულწლოვნის მიმართ, -
ისჯება თავისუფლების აღკვეთით ვადით ექვსიდან ათ წლამდე.
