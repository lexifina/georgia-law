# მუხლი 293. ზღვის დაბინძურება
1. ხმელეთიდან, გემიდან, სხვა მცურავი საშუალებიდან, საჰაერო ხომალდიდან, პლატფორმიდან ან ზღვაში ხელოვნურად აგებული სხვა კონსტრუქციიდან ადამიანის ჯანმრთელობისათვის ან ზღვის ცოცხალი ორგანიზმისათვის მავნე ნივთიერების ანდა სხვა ნარჩენის ან მასალის ზღვაში უკანონო ჩაყრა, აგრეთვე მათი ჩამარხვის წესის დარღვევით ზღვის დაბინძურება, რაც საფრთხეს უქმნის ადამიანის ჯანმრთელობას ან ზღვის ცოცხალ ორგანიზმს ან ხელს უშლის ზღვის მართლზომიერ გამოყენებას, -
ისჯება ჯარიმით ან გამასწორებელი სამუშაოთი ვადით ერთ წლამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე ან უამისოდ.
2. იგივე ქმედება, რამაც მნიშვნელოვნად დააზიანა ადამიანის ჯანმრთელობა, მცენარეული სამყარო, თევზის მარაგი ან წყლის სხვა ცოცხალი ორგანიზმი, დასვენების ზონა ან კანონით დაცული სხვა სიკეთე, -
ისჯება ჯარიმით ან გამასწორებელი სამუშაოთი ვადით ორ წლამდე ანდა თავისუფლების აღკვეთით ვადით სამ წლამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
3. ამ მუხლის პირველი ან მე-2 ნაწილით გათვალისწინებული ქმედება, რამაც გამოიწვია ადამიანის სიცოცხლის მოსპობა, -
ისჯება თავისუფლების აღკვეთით ვადით ორიდან ხუთ წლამდე.
