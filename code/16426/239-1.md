# მუხლი 239¹. ძალადობრივი ქმედებისაკენ საჯაროდ მოწოდება
1. რასობრივი, რელიგიური, ეროვნული, კუთხური, ეთნიკური, სოციალური, პოლიტიკური, ენობრივი ან/და სხვა ნიშნის მქონე პირთა ჯგუფებს შორის განხეთქილების ჩამოსაგდებად ძალადობრივი ქმედებისკენ ზეპირად, წერილობით ან გამოხატვის სხვა საშუალებით საჯაროდ მოწოდება, თუ ეს ქმნის ძალადობრივი ქმედების განხორციელების აშკარა, პირდაპირ და არსებით საფრთხეს, -
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ვადით ორასიდან ოთხას საათამდე ანდა თავისუფლების აღკვეთით ვადით სამ წლამდე.
2. იგივე ქმედება, რასაც მოჰყვა ადამიანის ჯანმრთელობის მძიმე დაზიანება, სიცოცხლის მოსპობა ან სხვა მძიმე შედეგი, -
ისჯება თავისუფლების აღკვეთით ვადით ორიდან ხუთ წლამდე.
შენიშვნა: ამ მუხლით გათვალისწინებული ქმედებისათვის იურიდიული პირი ისჯება ლიკვიდაციით ან საქმიანობის უფლების ჩამორთმევით და ჯარიმით.
