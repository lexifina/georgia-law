# მუხლი 326. საერთაშორისო დაცვით მოსარგებლე პირზე ან დაწესებულებაზე თავდასხმა

ისჯება თავისუფლების აღკვეთით ვადით შვიდიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
