# მუხლი 236. ცეცხლსასროლი იარაღის, საბრძოლო მასალის, ფეთქებადი ნივთიერების ან ასაფეთქებელი მოწყობილობის მართლსაწინააღმდეგო შეძენა, შენახვა, ტარება, დამზადება, გადაზიდვა, გადაგზავნა ან გასაღება
1. ცეცხლსასროლი იარაღის, საბრძოლო მასალის, ფეთქებადი ნივთიერების ან ასაფეთქებელი მოწყობილობის მართლსაწინააღმდეგო შეძენა ან შენახვა, -
ისჯება ჯარიმით ან თავისუფლების შეზღუდვით ვადით სამ წლამდე ან ტუსაღობით ვადით ორ თვემდე ანდა თავისუფლების აღკვეთით ვადით სამ წლამდე.
2. ცეცხლსასროლი იარაღის, საბრძოლო მასალის, ფეთქებადი ნივთიერების ან ასაფეთქებელი მოწყობილობის მართლსაწინააღმდეგო ტარება, -
ისჯება ჯარიმით ან ტუსაღობით ვადით ოთხ თვემდე ანდა თავისუფლების აღკვეთით ვადით ხუთ წლამდე.
3. ცეცხლსასროლი იარაღის, საბრძოლო მასალის, ფეთქებადი ნივთიერების ან ასაფეთქებელი მოწყობილობის მართლსაწინააღმდეგო დამზადება, გადაზიდვა, გადაგზავნა ან გასაღება, -
ისჯება თავისუფლების აღკვეთით ვადით ხუთიდან ათ წლამდე.
შენიშვნა: ის, ვინც ნებაყოფლობით ჩააბარებს ამ მუხლში ჩამოთვლილ საგნებს, გათავისუფლდება სისხლისსამართლებრივი პასუხისმგებლობისაგან, თუ მის ქმედებაში არ არის სხვა დანაშაულის ნიშნები.
