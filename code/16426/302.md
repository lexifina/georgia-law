# მუხლი 302. საქართველოს "წითელ ნუსხაში" შეტანილი, საფრთხის წინაშე მყოფი, ველური მცენარის ან გარეული ცხოველის ადგილსამყოფლის მოშლა
1. საქართველოს "წითელ ნუსხაში" შეტანილი, საფრთხის წინაშე მყოფი, ველური მცენარის ან გარეული ცხოველის ბუნებრივი საბინადრო ან გამრავლების არეალის მოშლა ან იმ ადგილის სხვა დანიშნულებით გამოყენება, სადაც საქართველოს "წითელ ნუსხაში" შეტანილი სახეობა ბუნებრივად ხარობს, რამაც ამ ადგილებში ცხოველის ან მცენარის სახეობის გადაშენების საფრთხე შექმნა, -
ისჯება ჯარიმით ან თავისუფლების შეზღუდვით ვადით სამ წლამდე ანდა თავისუფლების აღკვეთით იმავე ვადით, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
2. იგივე ქმედება, რამაც გამოიწვია საქართველოს "წითელ ნუსხაში" შეტანილი, საფრთხის წინაშე მყოფი, ველური მცენარის ან გარეული ცხოველის გადაშენება, -
ისჯება ჯარიმით ან ტუსაღობით ვადით სამიდან ექვს თვემდე ანდა თავისუფლების აღკვეთით ვადით ხუთ წლამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
