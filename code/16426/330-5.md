# მუხლი 330 5 . ყალბი ოფიციალური დოკუმენტის დამზადება ამ თავით გათვალისწინებული ერთ-ერთი დანაშაულის ჩადენის მიზნით
ყალბი ოფიციალური დოკუმენტის დამზადება ამ თავით გათვალისწინებული ერთ-ერთი დანაშაულის ჩადენის მიზნით, −

შენიშვნა: ამ მუხლით გათვალისწინებული ქმედებისათვის იურიდიული პირი ისჯება ლიკვიდაციით ან საქმიანობის უფლების ჩამორთმევით და ჯარიმით. (ამოქმედდეს 2014 წლის 1 4 იანვრ იდან)]
