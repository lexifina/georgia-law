# მუხლი 396. შინაგანი სამსახურის წესდებისა და გარნიზონში პატრულირების წესის დარღვევა
ნაწილის სადღეღამისო განაწესის შემადგენლობაში (ყარაულისა და ვახტის გარდა) შემავალი პირის მიერ შინაგანი სამსახურის წესდების დარღვევა, ანდა გარნიზონში პატრულირების წესის დარღვევა საპატრულო განაწესის შემადგენლობაში შემავალი პირის მიერ, რამაც გაუფრთხილებლობით გამოიწვია მძიმე შედეგი, -
ისჯება სამხედრო პირის სამსახურებრივი შეზღუდვით ვადით ორ წლამდე ან ტუსაღობით ვადით ექვს თვემდე ანდა სადისციპლინო სამხედრო ნაწილში მოთავსებით ვადით ორ წლამდე.
