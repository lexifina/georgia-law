# მუხლი 286. ეგმ-ის, ეგმ-ის სისტემის ან მათი ქსელის ექსპლუატაციის წესის დარღვევა
1. ეგმ-ის, ეგმ-ის სისტემის ან მათი ქსელის ექსპლუატაციის წესის დარღვევა იმის მიერ, ვისაც ხელი მიუწვდებოდა ეგმ-ზე, ეგმ-ის სისტემაზე ან მათ ქსელზე, რამაც გამოიწვია ეგმ-ის კანონით დაცული ინფორმაციის განადგურება, ბლოკირება, მოდიფიცირება ან გადაღება ანდა რამაც მნიშვნელოვანი ზიანი გამოიწვია, -
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ვადით ას ოთხმოციდან ორას საათამდე ანდა თავისუფლების შეზღუდვით ვადით ორ წლამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე ან უამისოდ.
2. იგივე ქმედება, რამაც გამოიწვია მძიმე შედეგი, -
ისჯება თავისუფლების აღკვეთით ვადით ორიდან ოთხ წლამდე.
