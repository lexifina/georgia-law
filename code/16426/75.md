# მუხლი 75. სასჯელის მოხდის გადავადება ორსული ქალისათვის ან ქალისათვის, რომელსაც ჰყავს შვიდ წლამდე შვილი
1. თუ ორსული ქალი ან ქალი, რომელსაც ჰყავს შვიდ წლამდე შვილი, მძიმე ან განსაკუთრებით მძიმე დანაშაულისათვის არ არის მსჯავრდებული ხუთ წელზე მეტი ვადით თავისუფლების აღკვეთით, სასამართლოს შეუძლია გადაუვადოს მას სასჯელის მოხდა, ვიდრე შვილი შვიდი წლის ასაკს მიაღწევდეს.
2. თუ მსჯავრდებული უარს იტყვის შვილზე ან თავს აარიდებს შვილის აღზრდას მას შემდეგ, რაც იგი გააფრთხილა პრობაციის სამსახურმა, სასამართლოს შეუძლია ამ სამსახურის წარდგინებით გააუქმოს სასჯელის მოხდის გადავადება და მსჯავრდებული სასჯელის მოსახდელად გააგზავნოს განაჩენით დანიშნულ ადგილას.
3. როდესაც შვილი შვიდი წლის ასაკს მიაღწევს, სასამართლო გაათავისუფლებს მსჯავრდებულს სასჯელის მოუხდელი ნაწილის მოხდისაგან ან სასჯელის მოუხდელ ნაწილს შეუცვლის უფრო მსუბუქი სახის სასჯელით, ანდა მიიღებს გადაწყვეტილებას სასჯელის მოუხდელი ნაწილის მოსახდელად შესაბამის დაწესებულებაში მსჯავრდებულის უკან დაბრუნების შესახებ.
4. თუ მსჯავრდებული სასჯელის მოხდის გადავადების პერიოდში ჩაიდენს ახალ დანაშაულს, სასამართლო მას დაუნიშნავს სასჯელს ამ კოდექსის 61-ე მუხლით გათვალისწინებული წესით.
