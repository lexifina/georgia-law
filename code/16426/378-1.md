# მუხლი 378¹. სასჯელაღსრულების დაწესებულებაში, დროებითი ყოფნის იზოლატორში და ჰაუპტვახტში მოთავსებული პირებისათვის აკრძალული საგნების გადაცემა
1. სასჯელაღსრულების დაწესებულებაში, დროებითი ყოფნის იზოლატორში და ჰაუპტვახტში მოთავსებული პირებისათვის აკრძალული საგნების გადაცემა, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით ორ წლამდე.
2. იგივე ქმედება, ჩადენილი:
ა) არაერთგზის;
ბ) იმ პირის მიერ, ვისაც ადრე ჩადენილი ჰქონდა ამ კოდექსის 378-ე - 379-ე მუხლებით გათვალისწინებული რომელიმე დანაშაული;
გ) წინასწარი შეთანხმებით პირთა ჯგუფის მიერ;
დ) ნარკოტიკული საშუალების, მისი ანალოგის ან პრეკურსორის გადაცემით;
ე) ფსიქოტროპული ნივთიერების, მისი ანალოგის ან ძლიერმოქმედი ნივთიერების გადაცემით;
ვ) იარაღის გადაცემით;
ზ) რამაც გამოიწვია მძიმე შედეგი, -
ისჯება თავისუფლების აღკვეთით ვადით ორიდან ოთხ წლამდე.
3. იგივე ქმედება, ჩადენილი სამსახურებრივი მდგომარეობის გამოყენებით, -
ისჯება თავისუფლების აღკვეთით ვადით სამიდან ექვს წლამდე.
შენიშვნა: აკრძალულ საგნად ჩაითვლება ყველა საგანი (ნივთი), გარდა იმ საგნებისა (ნივთებისა), რომელიც დასაშვებია თან იქონიოს სასჯელაღსრულების დაწესებულებაში, დროებითი ყოფნის იზოლატორში და ჰაუპტვახტში მოთავსებულმა პირმა.
