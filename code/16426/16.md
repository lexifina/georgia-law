# მუხლი 16. დანაშაულთა ერთობლიობა
1. დანაშაულთა ერთობლიობა ნიშნავს ამ კოდექსის სხვადასხვა მუხლით ან მუხლის ნაწილით გათვალისწინებული ორი ან მეტი ქმედების ჩადენას, რომელთაგან პირი არც ერთისთვის არ ყოფილა მსჯავრდებული. დანაშაულთა ერთობლიობად ითვლება აგრეთვე ისეთი ქმედების ჩადენა, რომელიც შეიცავს ამ კოდექსის ორი ან მეტი მუხლით ან მუხლის ნაწილით გათვალისწინებულ დანაშაულთა ნიშნებს.
2. თუ ქმედება გათვალისწინებულია ზოგადი და სპეციალური ნორმებით, დანაშაულთა ერთობლიობა არ არსებობს და პირს სისხლისსამართლებრივი პასუხისმგებლობა დაეკისრება სპეციალური ნორმით.
