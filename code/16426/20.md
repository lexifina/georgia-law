# მუხლი 20. პასუხისმგებლობისგან გათავისუფლება დაუმთავრებელი დანაშაულისთვის
პირს არ დაეკისრება სისხლისსამართლებრივი პასუხისმგებლობა დანაშაულის მომზადებისთვის ან მცდელობისთვის, თუ მისი უმეცრების ან მის პიროვნებასთან დაკავშირებული სხვა გარემოების გამო დანაშაულის ჩასადენად გამოყენებული საშუალებით არ შეიძლებოდა მიღწეულიყო შესაბამისი მართლსაწინააღმდეგო შედეგი.
