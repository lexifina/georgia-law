# მუხლი 340. კანონით აკრძალული საჩუქრის მიღება
1. მოხელის ან მასთან გათანაბრებული პირის მიერ კანონით აკრძალული საჩუქრის მიღება-,
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ასიდან სამას საათამდე ანდა თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
2. იგივე ქმედება, ჩადენილი არაერთგზის, -
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ორასიდან ოთხას საათამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
