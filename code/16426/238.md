# მუხლი 238. ცეცხლსასროლი იარაღის დაუდევრად შენახვა
ცეცხლსასროლი იარაღის დაუდევრად შენახვა, რითაც შექმნილი იყო პირობა მისი სხვა პირის მიერ გამოყენებისათვის, რამაც გაუფრთხილებლობით გამოიწვია ადამიანის სიცოცხლის მოსპობა ან სხვა მძიმე შედეგი, -
ისჯება ჯარიმით ან გამასწორებელი სამუშაოთი ვადით ერთ წლამდე ან თავისუფლების შეზღუდვით ვადით ორ წლამდე ან ტუსაღობით ვადით სამ თვემდე ანდა თავისუფლების აღკვეთით ვადით ერთ წლამდე.
