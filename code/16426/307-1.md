# მუხლი 307¹. სამშობლოს ღალატი
1. სამშობლოს ღალატად ითვლება საქართველოს მოქალაქის ან საქართველოში სტატუსის მქონე მოქალაქეობის არმქონე პირის მიერ ამ კოდექსის 308-ე, 309-ე, 310-ე, 311-ე, 312-ე, 313-ე, 314-ე, 315-ე, 318-ე ან 319-ე მუხლით გათვალისწინებული რომელიმე დანაშაულის ჩადენა.
2. სამშობლოს ღალატისთვის სისხლისსამართლებრივი პასუხისმგებლობა განისაზღვრება ამ კოდექსის შესაბამისი მუხლით, ამ მუხლზე მითითებით.
