# მუხლი 336. უკანონო განაჩენის ან სხვა სასამართლო გადაწყვეტილების გამოტანა
1. უკანონო განაჩენის ან სხვა სასამართლო გადაწყვეტილების გამოტანა, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით შვიდ წლამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
2. უკანონო განაჩენის გამოტანა, თუ სასჯელის სახით დანიშნულია თავისუფლების აღკვეთა, -
ისჯება თავისუფლების აღკვეთით ვადით სამიდან ათ წლამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
