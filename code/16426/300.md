# მუხლი 300. თევზის ან წყლის სხვა ცოცხალი ორგანიზმის უკანონოდ მოპოვება
1. თევზის ან წყლის სხვა ცოცხალი ორგანიზმის უკანონოდ მოპოვება საქართველოს კონტინენტურ შელფზე, ტერიტორიულ წყლებში, განსაკუთრებულ ეკონომიკურ ზონაში ან შიდა წყალსატევში თევზსარეწი იარაღით ან მექანიკური სატრანსპორტო საშუალებით, ელექტროდენით ან სხვა აკრძალული იარაღით, ასაფეთქებელი ან მომწამლავი ნივთიერებით ანდა თევზის ან წყლის სხვა ცოცხალი ორგანიზმის მასობრივი განადგურების სხვა საშუალებით, -
ისჯება ჯარიმით ან გამასწორებელი სამუშაოთი ვადით ერთ წლამდე ანდა ტუსაღობით ვადით ორ თვემდე.
2. იგივე ქმედება, რამაც გაუფრთხილებლობით გამოიწვია მნიშვნელოვანი ზიანი, ან ჩადენილი სახელმწიფო ნაკრძალში ან აღკვეთილში, ანდა აკრძალულ დროს ან ადგილას, აგრეთვე საგანგებო ეკოლოგიური მდგომარეობის დროს ან ეკოლოგიური უბედურების ზონაში, ან საქართველოს "წითელ ნუსხაში" შეტანილი თევზის ან წყლის სხვა ცოცხალი ორგანიზმის მიმართ, -
ისჯება ჯარიმით ან გამასწორებელი სამუშაოთი ვადით ორ წლამდე ან ტუსაღობით ვადით ოთხ თვემდე ანდა თავისუფლების აღკვეთით ვადით სამ წლამდე.
