# მუხლი 399. სამხედრო ქონების შენახვის წესის დარღვევა
სამსახურებრივი სარგებლობისათვის მინდობილი იარაღის, საბრძოლო მასალის, სატრანსპორტო საშუალების, სამხედრო ტექნიკის ან სხვა სამხედრო ქონების შენახვის წესის დარღვევა, რამაც გაუფრთხილებლობით გამოიწვია მისი დაკარგვა ან გაუვარგისება, -
ისჯება ჯარიმით ან სამხედრო პირის სამსახურებრივი შეზღუდვით ვადით ექვს თვემდე ან ტუსაღობით ვადით სამ თვემდე ან სადისციპლინო სამხედრო ნაწილში მოთავსებით ვადით ორ წლამდე ანდა თავისუფლების აღკვეთით იმავე ვადით.
