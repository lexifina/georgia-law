2. იგივე ქმედება, ჩადენილი:

ბ) წინასწარი შეთანხმებით ჯგუფის მიერ;

დ) არაერთგზის;
ე) იმის მიერ, ვინც ნასამართლევია ამ თავით გათვალისწინებული რომელიმე განზრახი დანაშაულის ჩადენისთვის, -

3. ამ მუხლის პირველი ან მე-2 ნაწილით გათვალისწინებული ქმედება, ჩადენილი:

4. მცენარე კანაფის ან მარიხუანის უკანონო გადაცემა მატერიალური სარგებლის მიღების მიზნის გარეშე −
ისჯება თავისუფლების აღკვეთით ვადით სამიდან რვა წლამდე.

გ) სამსახურებრივი მდგომარეობის გამოყენებით;

7. ნარკოტიკული საშუალების, მისი ანალოგის, პრეკურსორის ან ახალი ფსიქოაქტიური ნივთიერების უკანონო გადაცემა მატერიალური სარგებლის მიღების მიზნის გარეშე -
ისჯება თავისუფლების აღკვეთით ვადით ათიდან თხუთმეტ წლამდე.
