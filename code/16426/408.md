# მუხლი 408. დანაშაული ადამიანურობის წინააღმდეგ
დანაშაული ადამიანურობის წინააღმდეგ, ესე იგი ნებისმიერი ქმედება, ჩადენილი სამოქალაქო მოსახლეობაზე ან პირებზე ფართომასშტაბიანი ან სისტემატური თავდასხმის ფარგლებში, რაც გამოიხატა მკვლელობით, ადამიანთა მასობრივი განადგურებით, დეპორტაციით და სხვა არაჰუმანური ქმედებით, რომელიც სერიოზულ ზიანს აყენებს ადამიანის ფიზიკურ ან ფსიქიკურ მდგომარეობას, -
ისჯება თავისუფლების აღკვეთით ვადით რვიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
