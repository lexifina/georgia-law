# მუხლი 205. უკანონო ქმედება გადახდისუუნარობისას
გადახდისუუნარობისას ქონების იმ ნაწილის განკარგვა ან დამალვა კრედიტორისათვის ხელმიუწვდომლობის მიზნით, რომელიც გაკოტრების საქმის წარმოების გახსნის შემთხვევაში სამეურვეო ქონებაში მოექცეოდა, აგრეთვე მეურნეობის სწორად გაძღოლის მოთხოვნათა საწინააღმდეგოდ მისი დაზიანება, გაუვარგისება ან განადგურება, -
ისჯება ჯარიმით ან შინაპატიმრობით ვადით ექვსი თვიდან ორ წლამდე ანდა თავისუფლების აღკვეთით ვადით სამ წლამდე.
