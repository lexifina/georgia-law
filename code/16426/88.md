# მუხლი 88. ვადიანი თავისუფლების აღკვეთა
1. არასრულწლოვანს თავისუფლების აღკვეთა ენიშნება არა უმეტეს ათი წლის ვადით, რომელსაც ის სრულწლოვანებამდე მოიხდის აღმზრდელობით დაწესებულებაში.
