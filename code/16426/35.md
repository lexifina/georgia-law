# მუხლი 35. შეზღუდული შერაცხადობა
1. სისხლისსამართლებრივი პასუხისმგებლობისგან არ თავისუფლდება სრულწლოვანი, რომელიც დანაშაულის ჩადენის დროს შეზღუდული შერაცხადობის მდგომარეობაში იმყოფებოდა, ესე იგი, ფსიქიკური აშლილობის გამო არ შეეძლო სრულად გაეცნობიერებინა თავისი ქმედების ფაქტობრივი ხასიათი ან მართლწინააღმდეგობა ანდა ეხელმძღვანელა მისთვის.
