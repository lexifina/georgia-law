# მუხლი 319¹. "გრანტების შესახებ" საქართველოს კანონის დარღვევა, უცხოეთის ორგანიზაციასთან ან უცხოელთან არამართლზომიერი თანამშრომლობა
1. "გრანტების შესახებ" საქართველოს კანონის მე-2 მუხლის პირველი პუნქტითა და 5¹ მუხლის პირველი პუნქტით გათვალისწინებული უცხოური გრანტის გრანტის მიმღების მიერ იმავე კანონით განსაზღვრული გრანტის გამცემისგან შესაბამისი თანხმობის გარეშე პირდაპირ ან არაპირდაპირ მიღება ან მისი გამოყენება, აგრეთვე იმავე კანონით გათვალისწინებული თანხმობის გარეშე სათანადო დოკუმენტში მითითებული მიზნისგან განსხვავებული მიზნით საქართველოსთან დაკავშირებულ პოლიტიკურ საკითხზე აქტივობის განსახორციელებლად გრანტის მიმღების მიერ ამ ნაწილით განსაზღვრული უცხოური გრანტის გამოყენება −
ისჯება ჯარიმით, საზოგადოებისათვის სასარგებლო შრომით ვადით სამასიდან ხუთას საათამდე ან თავისუფლების აღკვეთით ვადით ექვს წლამდე.
2. "გრანტების შესახებ" საქართველოს კანონის მე-2 მუხლის 1⁴ პუნქტით ან 1⁵ პუნქტის "ა" ქვეპუნქტით გათვალისწინებული გრანტის იმავე კანონით განსაზღვრული თანხმობის გარეშე მიღება ან მისი გამოყენება, აგრეთვე "გრანტების შესახებ" საქართველოს კანონის მე-2 მუხლის 1⁵ პუნქტის "ბ" ან "გ" ქვეპუნქტით გათვალისწინებული ტექნიკური დახმარების იმავე კანონით განსაზღვრული თანხმობის გარეშე გაწევა ან მიღება −
ისჯება ჯარიმით, საზოგადოებისათვის სასარგებლო შრომით ვადით სამასიდან ხუთას საათამდე ან თავისუფლების აღკვეთით ვადით ექვს წლამდე.
3. "გრანტების შესახებ" საქართველოს კანონის 5² მუხლის მე-2 პუნქტით გათვალისწინებული სხვა სახელმწიფოს იურიდიული პირის მიერ გრანტის იმავე კანონით განსაზღვრული თანხმობის გარეშე პირდაპირ ან არაპირდაპირ მიღება ან მისი გამოყენება −
ისჯება ჯარიმით, საზოგადოებისათვის სასარგებლო შრომით ვადით სამასიდან ხუთას საათამდე ან თავისუფლების აღკვეთით ვადით ექვს წლამდე.
4. "გრანტების შესახებ" საქართველოს კანონის 5¹ მუხლის მე-4 პუნქტით ან 5² მუხლის მე-5 პუნქტით გათვალისწინებული ფულადი ან ნატურალური ფორმით გადაცემული/გაცემული იმ სახსრების მიღება ან გამოყენება, რომლებიც თავისი ბუნებით გრანტია, მაგრამ გადაცემულია/გაცემულია იმავე კანონის მე-5 ან 5² მუხლით განსაზღვრულისგან განსხვავებული, მოჩვენებითი ან თვალთმაქცური გარიგების საფუძვლით, −
ისჯება ჯარიმით, საზოგადოებისათვის სასარგებლო შრომით ვადით სამასიდან ხუთას საათამდე ან თავისუფლების აღკვეთით ვადით ექვს წლამდე.
5. სხვა სახელმწიფოს მოქალაქისთვის ან იურიდიული პირისთვის საქართველოსთან დაკავშირებულ პოლიტიკურ საკითხზე აქტივობის განხორციელების სანაცვლოდ ფულის, ფასიანი ქაღალდის, სხვა ქონების, ქონებრივი სარგებლის ან რაიმე სხვა უპირატესობის პირდაპირ ან არაპირდაპირ გადაცემა/მინიჭება −
ისჯება ჯარიმით, საზოგადოებისათვის სასარგებლო შრომით ვადით სამასიდან ხუთას საათამდე ან თავისუფლების აღკვეთით ვადით ექვს წლამდე.
შენიშვნა:
1. ამ მუხლით გათვალისწინებული ქმედებისთვის იურიდიული პირი (გარდა საქართველოში რეგისტრირებული პოლიტიკური პარტიისა) ისჯება ჯარიმით ან ლიკვიდაციითა და ჯარიმით.
2. ამ მუხლის მიზნებისთვის საქართველოსთან დაკავშირებულ პოლიტიკურ საკითხზე აქტივობად მიიჩნევა საქართველოს ხელისუფლებაზე, სახელმწიფო დაწესებულებებზე ან საზოგადოების ნებისმიერ ნაწილზე რაიმე გავლენის მოსახდენად განხორციელებული ან განსახორციელებელი ისეთი საქმიანობა, რომელიც საქართველოს საშინაო ან საგარეო პოლიტიკის ჩამოყალიბებისკენ, გატარებისკენ ან შეცვლისკენ არის მიმართული, აგრეთვე ისეთი საქმიანობა, რომელიც უცხო ქვეყნის ხელისუფლების ან უცხოური პოლიტიკური პარტიის პოლიტიკური ან საჯარო ინტერესებიდან, მიდგომებიდან ან ურთიერთობებიდან გამომდინარეობს.
3. ამ მუხლის მე-2 ნაწილის მოქმედება არ ვრცელდება ფულადი ან ნატურალური ფორმით გადაცემული სახსრების სანაცვლოდ "გრანტების შესახებ" საქართველოს კანონის მე-3 მუხლის პირველი პუნქტის "ა" ქვეპუნქტით გათვალისწინებულ უცხო ქვეყნის მთავრობაში ან მის წარმომადგენლობაში ან საერთაშორისო ორგანიზაციაში დასაქმებული თანამშრომლის მიერ ამ დამსაქმებლისთვის გაწეულ ტექნიკურ დახმარებაზე.
4. ამ მუხლის მოქმედება არ ვრცელდება სხვა სახელმწიფოს იურიდიული პირის საქართველოში რეგისტრირებულ წარმომადგენლობაზე, ფილიალსა და განყოფილებაზე, გარდა "გრანტების შესახებ" საქართველოს კანონის მე-4 მუხლის "დ¹" ქვეპუნქტით გათვალისწინებული იურიდიული პირის წარმომადგენლობისა, ფილიალისა და განყოფილებისა.
