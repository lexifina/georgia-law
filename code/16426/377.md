## თავი XLIV. დანაშაული სასამართლო აქტების აღსრულების წინააღმდეგ
# მუხლი 377. უკანონო ქმედება აღწერილ, ყადაღადადებულ ან საპროცესო კონფისკაციით განსაზღვრულ ქონებასთან დაკავშირებით
1. აღწერილი ან ყადაღადადებული ქონების გაფლანგვა, გასხვისება, დამალვა ან უკანონოდ გადაცემა იმის მიერ, ვისაც ეს ქონება მინდობილი ჰქონდა, ანდა ყადაღადადებული ფულადი საშუალებით (ანაბრით) საბანკო ოპერაციის განხორციელება საკრედიტო ორგანიზაციის მოსამსახურის მიერ, -
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ვადით ას ოთხმოციდან ორას ორმოც საათამდე ან ტუსაღობით ვადით სამიდან ექვს თვემდე ანდა თავისუფლების აღკვეთით ვადით ორ წლამდე.
2. კანონიერ ძალაში შესული სასამართლოს განაჩენში მითითებული საპროცესო კონფისკაციას დაქვემდებარებული ქონების დამალვა ანდა განაჩენის აღსრულებისათვის სხვაგვარად თავის არიდება, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით სამ წლამდე.
