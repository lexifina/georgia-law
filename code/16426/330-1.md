# მუხლი 330¹. საქვეყნოდ მოწოდება ტერორიზმისაკენ
საქვეყნოდ ინფორმაციის გავრცელება ან სხვაგვარი მიწოდება ტერორისტული საქმიანობის განხორციელებისაკენ მოწოდების მიზნით, თუ ეს ქმედება, მიუხედავად იმისა, შეიცავს თუ არა იგი დანაშაულის ჩადენისაკენ პირდაპირ მოწოდებას, წარმოშობს ასეთი საქმიანობის განხორციელების საფრთხეს, -
ისჯება თავისუფლების აღკვეთით ვადით სამიდან ექვს წლამდე.
შენიშვნა: ამ მუხლით გათვალისწინებული ქმედებისათვის იურიდიული პირი ისჯება ლიკვიდაციით ან საქმიანობის უფლების ჩამორთმევით და ჯარიმით.

- საქართველოს 2014 წლის 4 აპრილის კანონი №2185 - ვებგვერდი, 16.04.2014წ.
