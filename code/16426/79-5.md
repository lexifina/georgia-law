# მუხლი 79⁵. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობის აღსრულება
1. ნარკომანიით დაავადებული პირის სავალდებულო სამედიცინო მკურნალობა ხორციელდება "ნარკოტიკული საშუალებების, ფსიქოტროპული ნივთიერებების, პრეკურსორებისა და ნარკოლოგიური დახმარების შესახებ" საქართველოს კანონით დადგენილი პრინციპების შესაბამისად.
2. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობის აღსრულება დაიწყება, თუ პირის მიმართ კანონიერ ძალაში შევიდა სასამართლოს გამამტყუნებელი განაჩენი. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობის აღსრულების წესი განისაზღვრება საქართველოს მთავრობის დადგენილებით.
3. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობა შეიძლება შეწყვიტოს სავალდებულო მკურნალობის განმახორციელებელი დაწესებულების ადმინისტრაციამ ექიმ-ნარკოლოგთა კომისიის დასკვნის საფუძველზე.
4. პირს, რომელსაც დაენიშნა ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობა, დანიშნული მკურნალობის დაწყების მომენტიდან ყოველ 3 თვეში ერთხელ ამოწმებს ექიმ-ნარკოლოგთა კომისია, რათა დაადგინოს, არსებობს თუ არა აღნიშნული ღონისძიების შეწყვეტის საფუძველი. თუ არსებობს ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობის შეწყვეტის საფუძველი, გადაწყვეტილება მიიღება ამ მუხლის მე-2 ნაწილით დადგენილი წესით.
5. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობის განმახორციელებელი დაწესებულების ადმინისტრაცია ვალდებულია შეწყვიტოს ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობა, თუ ნარკომანიით დაავადების ხასიათი და სიმძიმე ისე შეიცვალა, რომ აღნიშნული ღონისძიების გამოყენება საჭირო აღარ არის.
- საქართველოს 2025 წლის 16 აპრილის კანონი №499 - ვებგვერდი, 17.04.2025წ.
