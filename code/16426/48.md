# მუხლი 48. ტუსაღობა
1. ტუსაღობა ნიშნავს მსჯავრდებულის საზოგადოებისაგან მკაცრ იზოლაციას.
2. ტუსაღობა ინიშნება ერთიდან ექვს თვემდე ვადით.
3. საზოგადოებისათვის სასარგებლო შრომის, გამასწორებელი სამუშაოს ან თავისუფლების შეზღუდვის ტუსაღობით შეცვლის შემთხვევაში იგი შეიძლება დაინიშნოს ერთ თვეზე მცირე ვადით.
4. ტუსაღობა არ დაენიშნება იმას, ვისაც განაჩენის გამოტანის მომენტისათვის არ შესრულებია თვრამეტი წელი, პირველი და მეორე ჯგუფის ინვალიდებს, ორსულ ქალს, აგრეთვე ქალს, რომელსაც ჰყავს შვიდ წლამდე შვილი.
- საქართველოს 2003 წლის 20 ივნისის კანონი №2458 - სსმ I, №21, 15.07.2003 წ., მუხ.149
