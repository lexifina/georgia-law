# მუხლი 380¹. უცხოელის საქართველოდან გაძევების შესახებ სასამართლოს გადაწყვეტილების აღსრულებისთვის ხელის შეშლა
1. იმ პირის მიერ, რომელსაც სასჯელის სახით დანიშნული აქვს უცხოელის საქართველოდან გაძევება და საქართველოში შემოსვლის აკრძალვა ან რომლის მიმართაც არსებობს საქართველოდან გაძევების შესახებ სასამართლოს გადაწყვეტილება, სასამართლოს გადაწყვეტილების აღსრულებისთვის ხელის შეშლა, რაც გამოიხატა უცხოელის მიერ სამგზავრო დოკუმენტის განზრახ განადგურებით, ხოლო ამ დოკუმენტის არქონის შემთხვევაში − აღნიშნული დოკუმენტის მოპოვებისთვის საჭირო პროცედურისთვის თავის არიდებით ან სასამართლოს გადაწყვეტილების აღსრულებისთვის თავის სხვაგვარად არიდებით, -
ისჯება უცხოელის საქართველოდან გაძევებითა და საქართველოში შემოსვლის აკრძალვით ვადით ხუთიდან ოც წლამდე ან უვადოდ ან თავისუფლების აღკვეთით ვადით ერთიდან ექვს წლამდე.
2. იგივე ქმედება, ჩადენილი:
ა) არაერთგზის;
ბ) სიცოცხლისთვის ან ჯანმრთელობისთვის საშიში ძალადობით ანდა ასეთი ძალადობის გამოყენების მუქარით, -
ისჯება უცხოელის საქართველოდან გაძევებითა და საქართველოში შემოსვლის აკრძალვით ვადით ხუთიდან ოც წლამდე ან უვადოდ ან თავისუფლების აღკვეთით ვადით ხუთიდან ცხრა წლამდე.
