# მუხლი 230. ბირთვული მასალის ან მოწყობილობის, რადიაქტიური ნარჩენის, რადიაქტიური ნივთიერების ან მაიონებელი გამოსხივების სხვა წყაროსადმი უკანონო მოპყრობა
1. ბირთვული მასალის ან მოწყობილობის, რადიაქტიური ნარჩენის (გამოყენებული ბირთვული საწვავის ჩათვლით), რადიაქტიური ნივთიერების ან მაიონებელი გამოსხივების სხვა წყაროს, აგრეთვე ნებისმიერი სახისა და დანიშნულების მოწყობილობის, დანადგარის, ხელსაწყოს ან ნაკეთობის, რომელიც შეიცავს რადიაქტიურ ნივთიერებას, ან მაიონებელი გამოსხივების სხვა წყაროს უკანონო შეძენა, შენახვა, ფლობა ან განკარგვა, გამოყენება, გადამუშავება, გამოცდა, გადაცემა, გადაზიდვა, ექსპორტ-იმპორტი, ვაჭრობა ან მათდამი სხვა უკანონო მოპყრობა, აგრეთვე მათთან დაკავშირებული სხვა გარიგება, -
ისჯება თავისუფლების აღკვეთით ვადით ხუთ წლამდე.
2. იგივე ქმედება:
ა) არაერთგზის;
ბ) რამაც გამოიწვია ადამიანის სიცოცხლის მოსპობა ან სხვა მძიმე შედეგი, -
ისჯება თავისუფლების აღკვეთით ვადით რვა წლამდე.
