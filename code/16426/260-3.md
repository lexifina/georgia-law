# მუხლი 260³. ფსიქოტროპული ნივთიერების, მისი ანალოგის ან ძლიერმოქმედი ნივთიერების, მცენარე კანაფის ან მარიხუანის, სხვა ნარკოტიკული საშუალების, მისი ანალოგის, პრეკურსორის ან ახალი ფსიქოაქტიური ნივთიერების უკანონო რეალიზაცია
1. ფსიქოტროპული ნივთიერების, მისი ანალოგის ან ძლიერმოქმედი ნივთიერების, მცენარე კანაფის ან მარიხუანის უკანონო რეალიზაცია -
ისჯება თავისუფლების აღკვეთით ვადით ხუთიდან ათ წლამდე.
2. იგივე ქმედება, ჩადენილი:
ა) დიდი ოდენობით;
ბ) წინასწარი შეთანხმებით ჯგუფის მიერ;
გ) სამსახურებრივი მდგომარეობის გამოყენებით;
დ) არაერთგზის;
ე) იმის მიერ, ვინც ნასამართლევია ამ თავით გათვალისწინებული რომელიმე განზრახი დანაშაულის ჩადენისთვის, -
ისჯება თავისუფლების აღკვეთით ვადით ექვსიდან თორმეტ წლამდე.
3. ამ მუხლის პირველი ან მე-2 ნაწილით გათვალისწინებული ქმედება, ჩადენილი:
ა) განსაკუთრებით დიდი ოდენობით;
ბ) ორგანიზებული ჯგუფის მიერ, -
ისჯება თავისუფლების აღკვეთით ვადით თორმეტიდან ჩვიდმეტ წლამდე.
4. ნარკოტიკული საშუალების, მისი ანალოგის, პრეკურსორის ან ახალი ფსიქოაქტიური ნივთიერების უკანონო რეალიზაცია -
ისჯება თავისუფლების აღკვეთით ვადით თორმეტიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
5. იგივე ქმედება, ჩადენილი:
ა) დიდი ოდენობით;
ბ) წინასწარი შეთანხმებით ჯგუფის მიერ;
გ) სამსახურებრივი მდგომარეობის გამოყენებით;
დ) არაერთგზის;
ე) იმის მიერ, ვინც ნასამართლევია ამ თავით გათვალისწინებული რომელიმე განზრახი დანაშაულის ჩადენისთვის, -
ისჯება თავისუფლების აღკვეთით ვადით თოთხმეტიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
6. ამ მუხლის მე-4 ან მე-5 ნაწილით გათვალისწინებული ქმედება, ჩადენილი:
ა) განსაკუთრებით დიდი ოდენობით;
ბ) ორგანიზებული ჯგუფის მიერ, -
ისჯება თავისუფლების აღკვეთით ვადით თექვსმეტიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
შენიშვნა:
1. ამ მუხლით გათვალისწინებული ქმედების ჩადენისთვის იურიდიული პირი ისჯება ჯარიმით, საქმიანობის უფლების ჩამორთმევით ან ლიკვიდაციითა და ჯარიმით.
2. ამ მუხლის მე-4 ნაწილის მოქმედება ვრცელდება ახალი ფსიქოაქტიური ნივთიერების ნებისმიერ ოდენობაზე.
3. ახალ ფსიქოაქტიურ ნივთიერებაზე არ ვრცელდება ამ მუხლის მე-5 ნაწილის "ა" ქვეპუნქტითა და მე-6 ნაწილის "ა" ქვეპუნქტით გათვალისწინებული დამამძიმებელი გარემოებები.
