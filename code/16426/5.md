# მუხლი 5. სისხლისსამართლებრივი პასუხისმგებლობა საზღვარგარეთ ჩადენილი დანაშაულისათვის
1. საქართველოს მოქალაქეს, აგრეთვე საქართველოში მუდმივად მცხოვრებ მოქალაქეობის არმქონე პირს, რომლებმაც საზღვარგარეთ ჩაიდინეს ამ კოდექსით გათვალისწინებული ისეთი ქმედება, რომელიც დანაშაულად ითვლება იმ სახელმწიფოს კანონმდებლობით, სადაც ის ჩადენილია, სისხლისსამართლებრივი პასუხისმგებლობა დაეკისრებათ ამ კოდექსით, თუ ისინი მსჯავრდებულნი არ ყოფილან სხვა სახელმწიფოში.
2. საქართველოს მოქალაქეს, აგრეთვე საქართველოში მუდმივად მცხოვრებ მოქალაქეობის არმქონე პირს, რომლებმაც საზღვარგარეთ ჩაიდინეს ამ კოდექსით გათვალისწინებული ისეთი ქმედება, რომელიც დანაშაულად არ ითვლება იმ სახელმწიფოს კანონმდებლობით, სადაც ის ჩადენილია, სისხლისსამართლებრივი პასუხისმგებლობა დაეკისრებათ ამ კოდექსით, თუ ეს არის საქართველოს ინტერესების წინააღმდეგ მიმართული მძიმე ან განსაკუთრებით მძიმე დანაშაული ანდა თუ სისხლისსამართლებრივი პასუხისმგებლობა ამ დანაშაულისათვის გათვალისწინებულია საქართველოს საერთაშორისო ხელშეკრულებით.
3. საზღვარგარეთ დანაშაულის ჩამდენ უცხო ქვეყნის მოქალაქეს, აგრეთვე მოქალაქეობის არმქონე პირს, რომლებიც მუდმივად არ ცხოვრობენ საქართველოში, სისხლისსამართლებრივი პასუხისმგებლობა დაეკისრებათ ამ კოდექსით, თუ ეს არის საქართველოს ინტერესების წინააღმდეგ მიმართული მძიმე ან განსაკუთრებით მძიმე დანაშაული ანდა თუ სისხლისსამართლებრივი პასუხისმგებლობა ამ დანაშაულისათვის გათვალისწინებულია საქართველოს საერთაშორისო ხელშეკრულებით, თუკი ისინი მსჯავრდებულნი არ ყოფილან სხვა სახელმწიფოში.
