# მუხლი 257. ისტორიის, კულტურის ან ბუნების ძეგლის დაზიანება ან განადგურება
1. ისტორიის, კულტურის ან ბუნების ძეგლის ანდა ისტორიული ან კულტურული ფასეულობის მქონე საგნის ან დოკუმენტის დაზიანება ან განადგურება, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით ოთხ წლამდე.
2. იგივე ქმედება, რამაც განსაკუთრებული ღირებულების ობიექტის დაზიანება ან განადგურება გამოიწვია, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით შვიდიდან თორმეტ წლამდე.
3. ისტორიის, კულტურის ან ბუნების ძეგლის ანდა ისტორიული ან კულტურული ფასეულობის მქონე საგნის ან დოკუმენტის დაზიანება ან განადგურება გაუფთხილებლობით, -
ისჯება ჯარიმით ან თავისუფლების აღკვეთით ვადით ორ წლამდე.
4. იგივე ქმედება, რამაც გაუფრთხილებლობით გამოიწვია განსაკუთრებული ღირებულების ობიექტის განადგურება ან დაზიანება, -
ისჯება თავისუფლების აღკვეთით ვადით სამ წლამდე.
