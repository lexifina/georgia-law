# მუხლი 21¹²⁵. მოსამართლის ბრძანება საქართველოდან გაძევების მიზნით უცხოელის დროებითი განთავსების ცენტრში მოთავსების შესახებ
1. რაიონული (საქალაქო) სასამართლოს მოსამართლე საქართველოს შინაგან საქმეთა სამინისტროს უფლებამოსილი ორგანოს შუამდგომლობის საფუძველზე გამოსცემს ბრძანებას:
ა) საქართველოდან გაძევების მიზნით უცხოელის დროებითი განთავსების ცენტრში მოთავსების შესახებ;
ბ) შუამდგომლობის დაკმაყოფილებაზე უარის თქმის შესახებ;
გ) უცხოელის დროებითი განთავსების ცენტრში მოთავსების ვადის გაგრძელების შესახებ;
დ) უცხოელის დროებითი განთავსების ცენტრში მოთავსების ალტერნატიული ზომის გამოყენების შესახებ.
2. უცხოელის დროებითი განთავსების ცენტრში მოთავსების შესახებ შუამდგომლობა სასამართლოს წარედგინება უცხოელის დაკავებიდან არაუგვიანეს 48 საათისა.
3. უცხოელის დროებითი განთავსების ცენტრში მოთავსების ვადის გაგრძელების შესახებ შუამდგომლობა სასამართლოს წარედგინება უცხოელის დროებითი განთავსების ცენტრში მოთავსების ვადის გასვლამდე არაუგვიანეს 48 საათისა.
4. მოსამართლე საქართველოდან გაძევების მიზნით უცხოელის დროებითი განთავსების ცენტრში მოთავსების საკითხს ან უცხოელის დროებითი განთავსების ცენტრში მოთავსების ვადის გაგრძელების საკითხს განიხილავს და შესაბამის ბრძანებას გამოსცემს სათანადო შუამდგომლობის წარდგენიდან არაუგვიანეს 24 საათისა.
4¹. რაიონული (საქალაქო) სასამართლო საქართველოდან გაძევების მიზნით უცხოელის დროებითი განთავსების ცენტრში მოთავსების ვადის გაგრძელების საკითხს განიხილავს ზეპირი მოსმენის გარეშე. თუ საქმე ფაქტობრივი ან სამართლებრივი თვალსაზრისით განსაკუთრებული სირთულით ხასიათდება, რის გამოც საკითხის ზეპირი მოსმენის გარეშე გადაწყვეტა შეუძლებელია, რაიონული (საქალაქო) სასამართლო უფლებამოსილია დავა განიხილოს და გადაწყვეტილება მიიღოს ზეპირი მოსმენით. ზეპირი მოსმენის დანიშვნის შემთხვევაში მხარეებს ეცნობებათ სასამართლო სხდომის ჩატარების დრო და ადგილი. სასამართლოში მხარეთა გამოუცხადებლობა მის მიერ აღნიშნული საკითხის ამ მუხლით დადგენილ ვადაში განხილვასა და გადაწყვეტას არ აბრკოლებს.
4². რაიონული (საქალაქო) სასამართლო მისთვის "უცხოელთა და მოქალაქეობის არმქონე პირთა სამართლებრივი მდგომარეობის შესახებ" საქართველოს კანონის 64-ე მუხლის მე-2 პუნქტის "კ" ქვეპუნქტის საფუძველზე წარდგენილ საქართველოს შინაგან საქმეთა სამინისტროს უფლებამოსილი ორგანოს შუამდგომლობას განიხილავს ზეპირი მოსმენის გარეშე. თუ საქმე ფაქტობრივი ან სამართლებრივი თვალსაზრისით განსაკუთრებული სირთულით ხასიათდება, რის გამოც საკითხის ზეპირი მოსმენის გარეშე გადაწყვეტა შეუძლებელია, რაიონული (საქალაქო) სასამართლო უფლებამოსილია დავა განიხილოს და გადაწყვეტილება მიიღოს ზეპირი მოსმენით. ზეპირი მოსმენის დანიშვნის შემთხვევაში მხარეებს ეცნობებათ სასამართლო სხდომის ჩატარების დრო და ადგილი. სასამართლოში მხარეთა გამოუცხადებლობა მის მიერ აღნიშნული საკითხის ამ მუხლით დადგენილ ვადაში განხილვასა და გადაწყვეტას არ აბრკოლებს.
5. მოსამართლეს უფლება აქვს, საკუთარი ინიციატივით ან საქართველოს შინაგან საქმეთა სამინისტროს უფლებამოსილი ორგანოს დასაბუთებული შუამდგომლობის საფუძველზე გამოსცეს ბრძანება უცხოელის "უცხოელთა და მოქალაქეობის არმქონე პირთა სამართლებრივი მდგომარეობის შესახებ" საქართველოს კანონის 65-ე მუხლით განსაზღვრული დროებითი განთავსების ცენტრში მოთავსების ალტერნატიული ზომის გამოყენების შესახებ. აღნიშნულ შუამდგომლობას მოსამართლე ამ მუხლის მე-4 ნაწილით დადგენილ ვადაში განიხილავს.
6. საქართველოდან გაძევების მიზნით უცხოელის დროებითი განთავსების ცენტრში მოთავსების შესახებ, უცხოელის დროებითი განთავსების ცენტრში მოთავსების ვადის გაგრძელების შესახებ ან უცხოელის დროებითი განთავსების ცენტრში მოთავსების ალტერნატიული ზომის გამოყენების შესახებ მოსამართლის ბრძანება შეიძლება ამ თავით დადგენილი წესით გასაჩივრდეს სააპელაციო სასამართლოში. მოსამართლის ბრძანების გასაჩივრება მის მოქმედებას არ აჩერებს.
