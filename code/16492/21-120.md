# მუხლი 21¹²⁰. მოსამართლის ბრძანების გასაჩივრების წესი
1. მოსამართლის ბრძანების გაუქმების თაობაზე სააპელაციო საჩივარი შეიტანება ბრძანების გამომცემ რაიონულ (საქალაქო) სასამართლოში მხარისთვის მისი გადაცემიდან 5 დღის ვადაში. სააპელაციო საჩივარი საქმის მასალებთან ერთად დაუყოვნებლივ ეგზავნება სააპელაციო სასამართლოს.
2. მოსამართლის ბრძანების გაუქმების თაობაზე სააპელაციო საჩივარს სააპელაციო სასამართლო განიხილავს მისი შეტანიდან 14 დღის ვადაში.
3. სააპელაციო სასამართლო საჩივარს განიხილავს ზეპირი მოსმენის გარეშე. თუ საქმე ფაქტობრივი ან სამართლებრივი თვალსაზრისით განსაკუთრებული სირთულით ხასიათდება, რის გამოც საკითხის ზეპირი მოსმენის გარეშე გადაწყვეტა შეუძლებელია, სააპელაციო სასამართლო უფლებამოსილია დავა განიხილოს და გადაწყვეტილება მიიღოს ზეპირი მოსმენით. ზეპირი მოსმენის დანიშვნის შემთხვევაში მხარეებს ეცნობებათ სასამართლო სხდომის ჩატარების დრო და ადგილი. სასამართლოში მხარეთა გამოუცხადებლობა მის მიერ აღნიშნული საკითხის ამ მუხლით დადგენილ ვადაში განხილვასა და გადაწყვეტას არ აბრკოლებს.
4. სააპელაციო სასამართლო გასაჩივრებულ მოსამართლის ბრძანებას აუქმებს ბრძანებით.
5. სააპელაციო სასამართლოს ბრძანება საბოლოოა და არ საჩივრდება.
