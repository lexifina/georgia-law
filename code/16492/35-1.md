# მუხლი 35¹. დაუსწრებელი გადაწყვეტილების გასაჩივრება
თუ ამ კოდექსის VII² თავის შესაბამისად, მხარის მიმართ გამოტანილია სასამართლოს დაუსწრებელი გადაწყვეტილება, მხარეს უფლება აქვს, დაუსწრებელი გადაწყვეტილება გაასაჩივროს სააპელაციო (საკასაციო) ინსტანციაში. ამ დებულების მოქმედება ვრცელდება ამ კოდექსის VII² თავის ამოქმედების მომენტიდან გამოტანილ ყველა სასამართლო გადაწყვეტილებაზე.
