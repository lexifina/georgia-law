# მუხლი 21¹². სასამართლოსათვის მიმართვა
1. ოჯახში ძალადობის შემთხვევაში სასამართლოსათვის მიმართვის უფლება აქვს მსხვერპლს, აგრეთვე მისი ოჯახის წევრს, ხოლო არასრულწლოვნის მიმართ ძალადობის შემთხვევაში - ასევე მეურვეობისა და მზრუნველობის ორგანოს.
2. ოჯახში ძალადობისას სასამართლოსათვის მიმართვის უფლება აქვს მხოლოდ მსხვერპლის თანხმობით პირს, რომელიც მსხვერპლს უწევს სამედიცინო, იურიდიულ, ფსიქოლოგიურ დახმარებას.
