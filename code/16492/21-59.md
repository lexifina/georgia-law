# მუხლი 21⁵⁹. ფულადი კომპენსაციის მიღების შესახებ სარჩელის განხილვა

- საქართველოს 2016 წლის 27 აპრილის კანონი № 5013 - ვებგვერდი, 13.05.2016წ.
