# მუხლი 21¹³⁸. საქართველოს საპენსიო ფონდის შუამდგომლობა
საქართველოს საპენსიო ფონდის შუამდგომლობა დასაბუთებული უნდა იყოს. მასში უნდა მიეთითოს:
ა) იმ პირის დასახელება და საიდენტიფიკაციო მონაცემები, რომლის შესახებ ინფორმაციის/დოკუმენტაციის მიღებასაც ითხოვს საქართველოს საპენსიო ფონდი;
ბ) ის კომერციული ბანკი, დამსაქმებელი (მისი უფლებამონაცვლე), მონაწილე, პენსიის მიმღები, გარდაცვლილი მონაწილის მემკვიდრე, რომლისგანაც საქართველოს საპენსიო ფონდმა უნდა მიიღოს ინფორმაცია/დოკუმენტაცია;
გ) საქართველოს საპენსიო ფონდის მიერ მოთხოვნილი ინფორმაციის/დოკუმენტაციის აღწერა;
დ) საქართველოს საპენსიო ფონდის მიერ ინფორმაციის/დოკუმენტაციის მიღების ფორმა და ვადა.
