# მუხლი 222. ნებაყოფლობითი რეგისტრაცია
1. პირს, რომელიც არ არის ვალდებული გატარდეს რეგისტრაციაში დღგ-ის გადამხდელად, შეუძლია ნებაყოფლობით მიმართოს საგადასახადო ორგანოს დღგ-ის გადამხდელად რეგისტრაციის მოთხოვნით.
2. პირი, რომელიც ნებაყოფლობით ტარდება რეგისტრაციაში, გადასახადის გადამხდელად ითვლება რეგისტრაციის ძალაში შესვლის მომენტიდან. რეგისტრაცია ძალაში შედის საგადასახადო ორგანოს მიერ პირისათვის საგადასახადო სერტიფიკატის გაცემის თვის მომდევნო თვის პირველი რიცხვიდან.
