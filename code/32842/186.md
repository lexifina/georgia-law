# მუხლი 186. საქველმოქმედო ორგანიზაციებზე გაცემული შეწირულობის თანხის გამოქვითვა
ერთობლივი შემოსავლიდან გამოიქვითება საწარმოს მიერ საქველმოქმედო ორგანიზაციებზე გაცემული შეწირულობის თანხა, მაგრამ არა უმეტეს ერთობლივი შემოსავლიდან ამ კოდექსით გათვალისწინებული გამოქვითვების (ამ მუხლით გათვალისწინებული გამოქვითვების გარეშე) შემდეგ დარჩენილი თანხის 8 პროცენტისა.
