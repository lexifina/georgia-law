# მუხლი 134. გადახდის წყაროსთან გადასახადის დაუკავებლობა
1. საგადასახადო აგენტის მიერ გადახდის წყაროსთან გადასახადის გადამხდელისათვის გადასახადის დაუკავებლობა ან/და დაკავებული გადასახადის თანხის ბიუჯეტში არასრულად გადარიცხვა (გადახდა), -
იწვევს დაჯარიმებას დაუკავებელი (გადასარიცხი) თანხის 10 პროცენტის ოდენობით.
2. ხელფასის გაცემაზე პასუხისმგებელი პირის (ასეთ პირებს შორის თანამდებობით (რანგით) ყველაზე მაღლა მდგომის, მეწარმე ფიზიკური პირის გარდა) მიერ ხელფასიდან დასაკავებელი ან/და გადასახდელი საშემოსავლო გადასახადის დაუკავებლობა ან/და ბიუჯეტში გადახდის მოვალეობის შეუსრულებლობა, -
იწვევს დაჯარიმებას მინიმალური ხელფასის ორმოცდაათმაგი ოდენობით.
