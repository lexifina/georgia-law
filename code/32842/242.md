# მუხლი 242. იმპორტის დრო
საქონლის იმპორტი ხორციელდება მაშინ, როდესაც საქონელი საბაჟო კანონმდებლობის მიხედვით იბეგრება საბაჟო გადასახადით. თუ საქონელი გათავისუფლებულია საბაჟო გადასახადისაგან, საქონლის იმპორტი ხორციელდება მაშინ, როცა მასზე უნდა გადახდილიყო საბაჟო გადასახადი, ეს საქონელი გათავისუფლებული რომ არ ყოფილიყო საბაჟო გადასახადისაგან.
