# მუხლი 191. ზარალი ქონების რეალიზაციისას
მეწარმე ფიზიკური პირის მიერ ქონების რეალიზაციით მიღებული ზარალის კომპენსაცია ხდება ასეთი ქონების რეალიზაციით მიღებული ღირებულების ნამეტით. თუ ზარალის კომპენსაცია შეუძლებელია იმავე წელს, მაშინ იგი გადაიტანება 5 წლამდე ვადით და მისი კომპენსაცია მოხდება ასეთი ქონების რეალიზაციით მიღებული ღირებულების ნამეტით.
