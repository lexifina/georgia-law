# მუხლი 123. საგადასახადო სამართალდარღვევის ცნება
საგადასახადო სამართალდარღვევად ითვლება გადასახადის გადამხდელის/ საგადასახადო აგენტის ან სხვა ვალდებული პირის მართლსაწინააღმდეგო ქმედობა (მოქმედება ან უმოქმედობა), რომლისთვისაც ამ კოდექსით გათვალისწინებულია პასუხისმგებლობა.
