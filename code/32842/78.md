# მუხლი 78. გადავადების მოქმედების შეწყვეტა
1. გადავადების მოქმედება წყდება შესაბამისი გადაწყვეტილების (ხელშეკრულების) ვადის ამოწურვისას ან შეიძლება შეწყდეს აღნიშნული ვადის ამოწურვამდე ამ კოდექსით გათვალისწინებულ შემთხვევებში.
2. გადავადება წყდება ვადაზე ადრე, თუ გადასახადის გადამხდელი დადგენილი ვადის ამოწურვამდე სრულად გადაიხდის გადასახადის კუთვნილ თანხებს და შესაბამის საურავს.
3. შესაბამისი გადაწყვეტილების მიმღები უფლებამოსილი პირი გადავადებას ვადამდე შეწყვეტს, თუ გადასახადის გადამხდელი არღვევს გადავადების პირობებს (გრაფიკს).
4. გადაწყვეტილება გადავადების ვადამდე შეწყვეტის შესახებ უფლებამოსილი პირის მიერ მისი მიღებიდან 5 დღის ვადაში წერილობით გადაეცემა გადასახადის გადამხდელს ამ კოდექსით დადგენილი წესით. გადაწყვეტილების ასლი ამავე ვადაში ეგზავნება საგადასახადო ორგანოს მისი საგადასახადო აღრიცხვის ადგილის მიხედვით.
