# მუხლი 49. საქართველოს საგადასახადო ორგანოები
1. საქართველოს საგადასახადო ორგანოების ერთიანი, ცენტრალიზებული სისტემა შედგება საქართველოს ფინანსთა სამინისტროს შემოსავლების სამსახურისაგან, ტერიტორიული ორგანოებისა და განსაკუთრებული ნიშნის მიხედვით შექმნილი სტრუქტურული ქვედანაყოფისაგან (ასეთი ქვედანაყოფის შექმნის შემთხვევაში).
2. საგადასახადო ორგანოები შედიან საქართველოს ფინანსთა სამინისტროს სისტემაში.

4. (ამოღებულია).
5. საქართველოში საგადასახადო კონტროლს ახორციელებენ მხოლოდ საგადასახადო ორგანოები, რომლებიც თავიანთი კომპეტენციის ფარგლებში უფლებამოსილნი არიან, უზრუნველყონ სახელმწიფო კონტროლი გადასახადების სრულად და დროულად გადახდაზე, გარდა იმ შემთხვევებისა, როდესაც ამ კოდექსით ასეთი უფლებამოსილება მინიჭებული აქვს სხვა ორგანოებს.
