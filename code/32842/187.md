# მუხლი 187. სადაზღვევო შენატანების ხარჯების გამოქვითვა
დაზღვევის ხელშეკრულების საფუძველზე დამზღვევთა ან/და დაზღვეულთა მიერ გადახდილი ან/და გადასახდელი (აღრიცხვის მეთოდის გამოყენების მიხედვით) ეკონომიკურ საქმიანობასთან დაკავშირებული სადაზღვევო შენატანები, გარდა მაგროვებადი და დაბრუნებადი ხასიათის ხელშეკრულებათა მიხედვით გადახდილი სადაზღვევო შენატანებისა, ექვემდებარება გამოქვითვას.
