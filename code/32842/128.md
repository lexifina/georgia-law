# მუხლი 128. საგადასახადო სამართალდარღვევის საქმეზე საგადასახადო ორგანოს მიერ მიღებული ბრძანების ან სხვა გადაწყვეტილების გასაჩივრება
საგადასახადო სამართალდარღვევის საქმეზე საგადასახადო ორგანოს მიერ მიღებული ბრძანება ან სხვა გადაწყვეტილება ცალკე გასაჩივრებას არ ექვემდებარება. აღნიშნული აქტები შეიძლება გაასაჩივროს პირმა, რომლის მიმართაც გამოტანილია აღნიშნული ბრძანება ან სხვა გადაწყვეტილება, ან მისმა კანონიერმა ან უფლებამოსილმა წარმომადგენელმა ამ კოდექსის VIII კარით დადგენილი წესით, მხოლოდ მათ საფუძველზე გამოცემულ "საგადასახადო მოთხოვნასთან" ერთად.
