# მუხლი 36. მეწარმე ფიზიკური პირი
1. მეწარმე ფიზიკურ პირად ითვლება:
ა) ინდივიდუალური საწარმო - ფიზიკური პირი, თუ ის "მეწარმეთა შესახებ" საქართველოს კანონის მე-2 მუხლის მიხედვით არის ინდივიდუალური მეწარმე;
ბ) ფიზიკური პირი, თუ ის ახორციელებს "მეწარმეთა შესახებ" საქართველოს კანონის პირველი მუხლის მე-2 პუნქტით განსაზღვრულ საქმიანობას.
2. ფიზიკური პირის მიერ ეკონომიკური საქმიანობის განხორციელება რეგისტრაციის, ლიცენზიის ან ნებართვის აღების დადგენილი წესის დარღვევით არ არის ამ ფიზიკური პირის დაბეგვრის მიზნით მისი მეწარმე ფიზიკურ პირად არცნობის საფუძველი.
