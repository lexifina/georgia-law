# მუხლი 79. ვადაგადაცილებული საგადასახადო დავალიანებების რესტრუქტურიზაცია
ვადაგადაცილებული საგადასახადო დავალიანებების რესტრუქტურიზაცია ხორციელდება საქართველოს მთავრობის გადაწყვეტილებით, "საგადასახადო დავალიანებებისა და სახელმწიფო სესხების რესტრუქტურიზაციის შესახებ" საქართველოს კანონით განსაზღვრული წესით.
