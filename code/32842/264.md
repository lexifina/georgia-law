# მუხლი 264. საგადასახადო ანგარიშ-ფაქტურა
აქციზური საქონლის რეალიზაციისას აქციზის გადამხდელი ვალდებულია საქონლის მიმღებს მოთხოვნის შემთხვევაში გამოუწეროს და გადასცეს ამ კოდექსის 248-ე მუხლით გათვალისწინებული საგადასახადო ანგარიშ-ფაქტურა, რომელზედაც ვრცელდება ამ კოდექსის 251-ე მუხლით გათვალისწინებული დებულებები.
