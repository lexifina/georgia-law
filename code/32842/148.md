# მუხლი 148. სადავო თანხის გადახდის ვალდებულების შეჩერება
სადავო თანხისა და მასზე დარიცხული საურავის, ისევე, როგორც შესაბამისი ჯარიმის, გადახდის ვალდებულება შეჩერებულად ითვლება ამ კოდექსის 145-ე მუხლის მე-2 ნაწილის "ბ" ქვეპუნქტის საფუძველზე საგადასახადო დავის დაწყების დღიდან დავის დასრულებამდე, თუმცა ძირითად თანხაზე საურავის დარიცხვა გრძელდება.
- საქართველოს 2006 წლის 29 დეკემბრის კანონი №4255 - სსმ I, №51, 31.12.2006წ., მუხ.416
