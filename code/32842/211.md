# მუხლი 211. აქტივების ღირებულება
1. აქტივების ღირებულებაში შეიტანება მათი შესყიდვის, წარმოების, მშენებლობის, მონტაჟისა და დადგმის ხარჯები (დანახარჯები), აგრეთვე სხვა ხარჯები (დანახარჯები), რომლებიც ზრდის მათ ღირებულებას, ხოლო აქტივების უსასყიდლოდ მიღებისას - ამ აქტივების საბაზრო ფასი.
2. აქტივების მხოლოდ ნაწილის მიწოდების შემთხვევაში აქტივების ღირებულება მიწოდების მომენტში ნაწილდება დარჩენილ და მიწოდებულ ნაწილებს შორის.
- საქართველოს 2008 წლის 26 დეკემბრის კანონი №871 - სსმ I, №41, 30.12.2008წ., მუხ.306
