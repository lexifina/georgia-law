# მუხლი 211. აქტივების ღირებულება
1. აქტივების ღირებულებაში შეიტანება მათი შეძენის, წარმოების, მშენებლობის, მონტაჟისა და დადგმის ხარჯები (დანახარჯები), აგრეთვე სხვა ხარჯები (დანახარჯები), რომლებიც ზრდის მათ ღირებულებას, გარდა გადახდილი მოსაკრებლისა ან/და საბაჟო გადასახადისა.
2. აქტივების მხოლოდ ნაწილის მიწოდების შემთხვევაში აქტივების ღირებულება მიწოდების მომენტში ნაწილდება დარჩენილ და მიწოდებულ ნაწილებს შორის.
