# მუხლი 164. საარბიტრაჟო განხილვის ხარჯების ანაზღაურება
1. საარბიტრაჟო განხილვის ხარჯების ანაზღაურება ეკისრება მხარეს, რომლის საწინააღმდეგო გადაწყვეტილებაც მიიღო არბიტრაჟმა.
2. სარჩელის ნაწილობრივ დაკმაყოფილების შემთხვევაში საარბიტრაჟო განხილვის ხარჯები ნაწილდება მხარეებს შორის, დაკმაყოფილებული (უარყოფილი) სასარჩელო მოთხოვნის მოცულობის პროპორციულად.
