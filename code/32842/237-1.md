# მუხლი 237¹. უბაჟო ვაჭრობის პუნქტში საქონლის/მომსახურების მიწოდების დაბეგვრა
1. საქართველოს საქონლის მიწოდება უბაჟო ვაჭრობის პუნქტში რეალიზაციისათვის იბეგრება დღგ-ის ნულოვანი განაკვეთით.
2. უბაჟო ვაჭრობის პუნქტში საქონლის მიწოდება, აგრეთვე კვების მომსახურების მიწოდება იბეგრება დღგ-ის ნულოვანი განაკვეთით.
- საქართველოს 2007 წლის 11 ივლისის კანონი №5280 - სსმ I, №30, 30.07.2007წ., მუხ.344
