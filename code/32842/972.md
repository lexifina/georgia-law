# მუხლი 972. მომხმარებელთა უფლებების დაცვა საკონტროლო-სალარო აპარატების გამოყენებისას
საკონტროლო-სალარო აპარატების გამოყენებისას მომხმარებელთა უფლებების დაცვის უზრუნველყოფის მიზნით ეკონომიკური საქმიანობის განმახორციელებელი პირების მიერ გასაყიდი საქონლის/მომსახურების ფასი გამოცხადდება მხოლოდ ეროვნულ ვალუტაში, ხოლო ფასის მაჩვენებლები (პრეისკურანტები) გამოიკვრება მომხმარებელთათვის თვალსაჩინო ადგილას.
- საქართველოს 2005 წლის 27 დეკემბრის კანონი №2546 - სსმ I, №4, 18.01.2006წ., მუხ.28
