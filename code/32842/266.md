# მუხლი 266. გადასახადის გადამხდელი
სოციალური გადასახადის გადამხდელად ითვლებიან:
ა) დამქირავებელი;
ბ) საწარმო/ორგანიზაცია ან მეწარმე ფიზიკური პირი, რომელიც საქართველოში გაწეული მომსახურების ღირებულებას უნაზღაურებს ფიზიკურ პირს, რომელსაც არ გააჩნია გადასახადის გადამხდელის მოწმობა;
გ) მეწარმე ფიზიკური პირები, ამხანაგობის წევრი ფიზიკური პირები (ამ კოდექსის 206-ე მუხლის შესაბამისად), რომლებიც საქართველოში ეწევიან ეკონომიკურ საქმიანობას.
- საქართველოს 2006 წლის 25 მაისის კანონი №3138 - სსმ I, №18, 31.05.2006წ., მუხ.132
