# მუხლი 160. საბჭოს გადაწყვეტილების ძალაში შესვლა და მისი გასაჩივრება
1. საბჭოს გადაწყვეტილება ძალაში შედის:
ა) მომჩივნის მიერ ამ გადაწყვეტილების მიღებიდან მე-10 კალენდარულ დღეს, თუ მან ამ ვადაში არ გაასაჩივრა იგი;
ბ) ამ კოდექსის 158-ე მუხლის მე-2 ნაწილით განსაზღვრული ვადის ამოწურვიდან მე-10 კალენდარულ დღეს, თუ საბჭომ ამ ვადაში არ მიიღო გადაწყვეტილება და მომჩივანმა ამავე ვადაში არ გაასაჩივრა საბჭოს უარი.
2. გადასახადის გადამხდელს/საგადასახადო აგენტს ან სხვა უფლებამოსილ პირს უფლება აქვს გაასაჩივროს საბჭოს გადაწყვეტილება ამ მუხლის პირველ ნაწილში მითითებულ ვადებში. ასეთ შემთხვევაში მოპასუხეა ამ კოდექსის 147-ე მუხლში ან 151-ე მუხლში აღნიშნული საგადასახადო ორგანო.
3. პირს უფლება აქვს, ამ მუხლის პირველ და მე-2 ნაწილებში მითითებული ვადების დაუცველად სასამართლოში შეტანილ სარჩელზე შეწყვიტოს საქმის წარმოება დასაშვებობის მოთხოვნების დარღვევის გამო.
