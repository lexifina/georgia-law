# მუხლი 209. კომპენსირებული გამოქვითვები და რეზერვების შემცირება
1. ადრე გამოქვითული ხარჯების, ზარალისა და უიმედო ვალების ანაზღაურებით მიღებული თანხა იმ წლის შემოსავლად ითვლება, რომელშიც მოხდა მისი ანაზღაურება.
2. თუ ხდება წინასწარ გამოქვითული რეზერვების შემცირება, შემცირებული თანხა შეიტანება ერთობლივ შემოსავალში.
