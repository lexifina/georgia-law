# მუხლი 181. სარეზერვო ფონდებში გადარიცხვების გამოქვითვა
1. იურიდიულ პირს, რომელიც სადაზღვევო საქმიანობას ეწევა, უფლება აქვს სარეზერვო ფონდებში გადარიცხული თანხა გამოქვითოს საქართველოს კანონმდებლობით დადგენილი ნორმებით.
2. ბანკები და საკრედიტო კავშირები სესხების შესაძლო დანაკარგების რეზერვების გამოქვითვას ახორციელებენ საეჭვო ვალების რეზერვების შექმნის შესახებ საქართველოს ეროვნული ბანკის მიერ დადგენილი წესით.
- საქართველოს 2007 წლის 11 ივლისის კანონი №5280 - სსმ I, №30, 30.07.2007წ., მუხ.344
