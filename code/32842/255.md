# მუხლი 255. დასაბეგრი ოპერაცია
აქციზით დასაბეგრი ოპერაციებია:
ა) საქართველოში წარმოებული აქციზური საქონლის მიწოდება;
ბ) საწარმოს საწყობიდან აქციზური საქონლის გატანა;
გ) დამკვეთის ნედლეულით საქართველოში წარმოებული აქციზური საქონლის გადაცემა დამკვეთისათვის;
დ) საკუთარი წარმოების აქციზური საქონლის გამოყენება არააქციზური საქონლის წარმოებისათვის;
ე) აქციზური საქონლის ექსპორტი.
