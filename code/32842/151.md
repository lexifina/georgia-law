# მუხლი 151. საგადასახადო ორგანოს შესაგებელი
1. საგადასახადო ორგანოს შესაგებელში უნდა აღინიშნოს:
ა) გადასახადის გადამხდელის/საგადასახადო აგენტის ან სხვა ვალდებული პირის ვინაობა (სახელი და გვარი, დასახელება), გადასახადის გადამხდელის საიდენტიფიკაციო ნომერი (ასეთის არსებობის შემთხვევაში), მისამართი;
ბ) საგადასახადო ორგანოს დასახელება და ზუსტი მისამართი, საკონტაქტო საშუალებები (ტელეფონი, ფაქსი, ელექტრონული ფოსტა);
გ) "გადასახადის გადამხდელის მოთხოვნის" მიღების თარიღი და მოთხოვნის საგანი;
დ) შესაგებლის გაგზავნის (გადაცემის) თარიღი;
ე) "გადასახადის გადამხდელის მოთხოვნის" შესრულებაზე უარის სამართლებრივი და ფაქტობრივი საფუძვლები;
ვ) შესაგებლისათვის დართულ მტკიცებულებათა ჩამონათვალი.
2. საგადასახადო ორგანოს შესაგებელს ხელს აწერს საგადასახადო ორგანოს ხელმძღვანელი/მისი მოადგილე.
