# მუხლი 171. გადასახადის განაკვეთი
1. საწარმოს დასაბეგრი მოგება იბეგრება 20 პროცენტით, გარდა ამ მუხლის მე-2 ნაწილით გათვალისწინებული შემთხვევისა.
2. "ნავთობისა და გაზის შესახებ" საქართველოს კანონით განსაზღვრული "არსებული ხელშეკრულებების" განხორციელების შედეგად ნავთობისა და გაზის ოპერაციებით მიღებული მოგება იბეგრება 10-პროცენტიანი განაკვეთით, თუ ეს ხელშეკრულებები დადებულია 1998 წლის 1 იანვრამდე.
