# მუხლი 158. საბჭოს სხდომა
1. საბჭო დავას იხილავს საჩივრის მიღებიდან 15 დღის ვადაში თავის სხდომაზე.
2. სხდომას თავმჯდომარეობს საქართველოს ფინანსთა მინისტრი ან მის მიერ საბჭოს წევრთაგან დანიშნული პირი.
3. სხდომის რეგლამენტს განსაზღვრავს საბჭო.
4. საბჭოს გადაწყვეტილება მიიღება სხდომაზე დამსწრეთა ხმების უმრავლესობით. დაუშვებელია ხმის მიცემისაგან თავის შეკავება.
5. საბჭოს გადაწყვეტილება ფორმდება წერილობით.
6. საბჭოში დავა განიხილება მომჩივნის ან/და მისი კანონიერი ან უფლებამოსილი წარმომადგენლის (წარმომადგენლების) მონაწილეობით. განხილვისთვის დანიშნულ დროს მომჩივნის ან/და მისი კანონიერი ან უფლებამოსილი წარმომადგენლის გამოუცხადებლობის შემთხვევაში დავა განიხილება მის გარეშე.
