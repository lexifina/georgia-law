# მუხლი 237. ელექტროენერგიის გადაცემის, დისპეტჩერიზაციის, წარმოებისა და მიწოდების დაბეგვრა
2007 წლის 1 იანვრამდე ელექტროენერგიის გადაცემა, დისპეტჩერიზაცია, წარმოება და მიწოდება, გარდა ელექტროენერგიის მომხმარებლისათვის მიწოდებისა (მათ შორის, სხვა მომხმარებლებისათვის შემდგომი მიწოდების მიზნით), იბეგრება დღგ-ის ნულოვანი განაკვეთით.
