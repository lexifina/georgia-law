# მუხლი 237. ელექტროენერგიის მიწოდების, აგრეთვე გადაცემის ან/და დისპეტჩერიზაციის მომსახურების დაბეგვრა
2009 წლის 1 იანვრამდე ელექტროენერგიის მიწოდება, გარდა ელექტროენერგიის მომხმარებლისათვის მიწოდებისა (მათ შორის, სხვა მომხმარებლებისათვის შემდგომი მიწოდების მიზნით), აგრეთვე გადაცემის ან/და დისპეტჩერიზაციის მომსახურება იბეგრება დღგ-ის ნულოვანი განაკვეთით. ამ მუხლის მიზნებისათვის სიმძლავრის სასისტემო რეზერვის შესყიდვა განიხილება, როგორც ელექტროენერგიის მიწოდების შემადგენელი ნაწილი.
