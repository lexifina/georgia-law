# მუხლი 149. გადასახადის გადამხდელის/საგადასახადო აგენტის ან სხვა ვალდებული პირის შესაგებელი და შეტყობინება
1. გადასახადის გადამხდელის/საგადასახადო აგენტის ან სხვა ვალდებული პირის შესაგებელში უნდა აღინიშნოს:
ა) საგადასახადო ორგანოს დასახელება და მისამართი;
ბ) გადასახადის გადამხდელის/საგადასახადო აგენტის ან სხვა ვალდებული პირის ვინაობა (სახელი და გვარი დასახელება), გადასახადის გადამხდელის საიდენტიფიკაციო ნომერი (ასეთის არსებობის შემთხვევაში), მისამართი და საკონტაქტო საშუალებები (ტელეფონი, ფაქსი, ელექტრონული ფოსტა);
გ) "საგადასახადო მოთხოვნის" მიღების თარიღი და მოთხოვნის საგანი;
დ) "საგადასახადო მოთხოვნის" შესრულებაზე უარის სამართლებრივი და ფაქტობრივი საფუძვლები;
ე) შესაგებლისათვის დართულ მტკიცებულებათა ჩამონათვალი;
ვ) დავის გაგრძელების შემთხვევაში მისი გადაწყვეტის ფორმა (საქართველოს ფინანსთა სამინისტროს საგადასახადო დეპარტამენტის ან სასამართლოს მიერ).
2. (ამოღებულია).
3. შესაგებლის წარუდგენლობას უთანაბრდება ისეთი შესაგებლის წარდგენა, რომელშიც მითითებული არ არის დავის გადაწყვეტის ფორმა.
4. ამ კოდექსის 147-ე მუხლის მე-2 ნაწილით განსაზღვრულ წერილობით შეტყობინებაში უნდა აღინიშნოს:
ა) საგადასახადო ორგანოს დასახელება და მისამართი;
ბ) გადასახადის გადამხდელის/საგადასახადო აგენტის ან სხვა ვალდებული პირის ვინაობა (სახელი და გვარი, დასახელება), გადასახადის გადამხდელის საიდენტიფიკაციო ნომერი (ასეთის არსებობის შემთხვევაში), მისამართი და საკონტაქტო საშუალებები (ტელეფონი, ფაქსი, ელექტრონული ფოსტა);
გ) "საგადასახადო მოთხოვნის" მიღების თარიღი და მოთხოვნის საგანი;
დ) (ამოღებულია).
