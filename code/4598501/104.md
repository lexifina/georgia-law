# მუხლი 104. საქონლის სახელმწიფოსთვის გადაცემა
1. პროცედურის მფლობელმა ან საქონლის მფლობელმა უცხოური საქონელი და მიზნობრივი დანიშნულებით შემოტანილი საქონელი საბაჟო ორგანოსთან წინასწარი შეთანხმებით შეიძლება საკუთრებაში გადასცეს სახელმწიფოს, მათ შორის, თვითმმართველ ერთეულს.
2. საქონლის სახელმწიფოსთვის გადაცემის წესი განისაზღვრება საქართველოს ფინანსთა მინისტრის ბრძანებით.
