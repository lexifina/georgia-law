# მუხლი 5. საქართველოს ტერიტორიაზე სხვა მოკავშირე რესპუბლიკის შრომის კანონმდებლობის გამოყენება
თუ საქართველოს ტერიტორიაზე განიხილება საკითხი მუშათა და მოსამსახურეთა იმ უფლებებისა და მოვალეობების განხორციელების შესახებ, რომლებიც წარმოიშვნენ სხვა მოკავშირე რესპუბლიკის ტერიტორიაზე, გამოყენებულ უნდა იქნეს ამ რესპუბლიკის შრომის კანონმდებლობა.
