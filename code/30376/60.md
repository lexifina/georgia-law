# მუხლი 60. დასვენების დღეები უწყვეტ მოქმედ საწარმოებში, დაწესებულებებსა და ორგანიზაციებში
საწარმოებში, დაწესებულებებსა და ორგანიზაციებში, სადაც საწარმოო-ტექნიკური პირობებისა ან მოსახლეობის მუდმივი, განუწყვეტელი მომსახურების აუცილებლობის მიზეზით, შეუძლებელია მუშაობის შეჩერება, აგრეთვე სხვა საწარმოებში, სადაც შემოღებულია უწყვეტი წარმოება, მუშებისა და მოსამსახურეების ყოველ ჯგუფს დასვენების დღეები ეძლევა რიგრიგობით, კვირის სხვადასხვა დღეს, ცვლიანობის განრიგის შესაბამისად. განრიგს ამტკიცებს ადმინისტრაცია პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივ კომიტეტთან შეთანხმებით.
