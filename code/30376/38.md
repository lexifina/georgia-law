# მუხლი 38. გასასვლელი დახმარება
თუ შრომის ხელშეკრულება შეწყდა ამ კოდექსის 30-ე მუხლის მე-3 და მე-6 პუნქტებში და 34-ე მუხლის 1¹, მე-2 და მე-6 პუნქტებში აღნიშნული საფუძვლებით ან ადმინისტრაციის მიერ შრომის კანონმდებლობის, კოლექტიური ან შრომის ხელშეკრულების დარღვევის შედეგად (მუხლი 33-ე), მუშებსა და მოსამსახურეებს ეძლევათ გასასვლელი დახმარება ორი კვირის საშუალო ხელფასის ოდენობით.
საქართველოს სსრ უმაღლესი საბჭოს პრეზიდიუმის 1988 წლის 24 მარტის ბრძანებულება №1649 -საქართველოს სსრ უმაღლესი საბჭოს უწყებები, №3, მარტი, 1988წ., მუხ.41
