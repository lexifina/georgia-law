# მუხლი 245. ზოგიერთი კატეგორიის მუშებისა და მოსამსახურეების შრომის მოწესრიგების სხვა თავისებურებანი
სსრ კავშირისა და სხვა მოკავშირე რესპუბლიკების შრომის კანონმდებლობის საფუძვლების შესაბამისად ზოგიერთი კატეგორიის მუშებისა და მოსამსახურების შრომის მოწესრიგების სხვა თავისებურებები ცალკეულ საკითხებზე შეიძლება დაწესებულ იქნეს მხოლოდ სსრ კავშირის კანონებითა და სსრ კავშირის მინისტრთა საბჭოს დადგენილებებით.
