# მუხლი 213. შრომის დავის განხილვა ხელქვეითობის წესით ზემდგომი ორგანოების მიერ
დავას იმ მუშაკთა სამუშაოდან დათხოვნისა და სხვა სამუშოზე გადაყვანის, აგრეთვე მათთვის დისციპლინური სასჯელის დადების შესახებ, რომელთაც უკავიათ განსაკუთრებულ ნუსხაში ჩამოთვლილი თანამდებობები, განიხილავენ ხელქვეითობის წესით ზემდგომი ორგანოები, ამავე წესით განიხილავენ დავს იმ მუშაკებისათვის დისციპლინური სასჯელის დადების თაობაზე, რომლებსაც პასუხისმგებლობა ეკისრებათ წესდებით დისციპლინის შესახებ.
