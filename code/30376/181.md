# მუხლი 181. სამუშაოს მიცემა მიღებული კვალიფიკაციის შესაბამისად
წარმოებაში პროფესიული სწავლების დამთავრების შემდეგ მუშას კვალიფიკაცია ენიჭება სატარიფო-საკვალიფიკაციო ცნობარის თანახმად და ეძლევა სამუშაო მიღებული კვალიფიკაციისა და მისთვის მინიჭებული თანრიგის შესაბამისად.
საქართველოს სსრ უმაღლესი საბჭოს პრეზიდიუმის 1986 წლის 29 ნოემბრის ბრძანებულება №83 - საქართველოს სსრ უმაღლესი საბჭოს უწყებები, №12, დანართი, ნოემბერი, 1986წ., მუხ.285
