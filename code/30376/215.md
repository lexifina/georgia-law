# მუხლი 215. შრომის პირობების დაწესების ან შეცვლის გამო დავის განხილვის წესი
საწარმოს, დაწესებულების, ორგანიზაციის ადმინისტრაციასა და მუშაკს შორის შრომის ახალი პირობების დაწესების ან არსებული პირობების შეცვლის გამო წამოჭრილ დავას, რასაც არ აწესრიგებს შრომის კანონმდებლობა ან სხვა ნორმატიული დებულებები შრომის შესახებ, განიხილავს ადმინისტრაცია პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივ კომიტეტთან შეთანხმებით, ხოლო, თუ შეთანხმებას ვერ მიაღწევენ, დავა გადაწყდება ზემდგომ პროფკავშირულ და სამეურნეო ორგანოებს შორის მიღწეული შეთანხმებით.
