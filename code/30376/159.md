# მუხლი 159. შვებულებები ორსულობისა და მშობიარობის გამო
ქალებს ორსულობისა და მშობიარობის გამო ეძლევათ შვებულება, რომლის ხანგრძლივობაა ორმოცდათექვსმეტი კალენდარული დღე მშობიარობამდე და ორმოცდათექვსმეტი კალენდარული დღე მშობიარობის შემდეგ; ამ პერიოდში მათ ეძლევათ დახმარება სახელმწიფო სოციალური დაზღვევის წესით. არანორმალური მშობიარობისა და ორი ან მეტი ბავშვის შობის შემთხვევაში მშობიარობის შემდეგ ქალებს შვებულება ეძლევათ სამოცდაათი კალენდარული დღის ხანგრძლივობით.
