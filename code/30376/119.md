# მუხლი 119. გარანტია საწარმოს, დაწესებულების, ორგანიზაციისათვის მიყენებული ზიანის გამო მუშებისა და მოსამსახურეებისათვის მატერიალური პასუხისმგებლობის დაკისრებისას
შრომითი მოვალეობების შესრულებისას საწარმოს, დაწესებულების, ორგანიზაციისათვის მიყენებული ზიანის გამო მუშებსა და მოსამსახურეებს, რომელთა ბრალით გამოწვეულია ზიანი, ეკისრებათ მატერიალური პასუხისმგებლობა პირდაპირი ნამდვილი ზიანის ოდენობით, მაგრამ არა უმეტეს მათი თვიური სატარიფო განაკვეთის (სარგოს) ერთი მესამედისა.
მატერიალური პასუხისმგებლობა თვიური სატარიფო განაკვეთის (სარგოს) ერთ მესამედზე მეტი ოდენობით, მაგრამ არა უმეტეს მიყენებული ზიანის სრული ოდენობისა, დასაშვებია მხოლოდ სსრ კავშირის კანონმდებლობით მითითებულ შემთხვევებში.
