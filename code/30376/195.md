# მუხლი 195. შრომითი დავის განხილვის წესი
შრომითი დავის კომისიებისა და პროფესიული კავშირების საფაბრიკო, საქარხნო, ადგილობრივი კომიტეტების მიერ შრომითი დავის განხილვის წესს აწესრიგებს დებულება შრომითი დავის განხილვის წესის შესახებ და ეს კოდექსი.
რაიონული (საქალაქო) სახალხო სასამართლოების მიერ შრომითი დავის განხილვის წესს განსაზღვრავს დებულება შრომითი დავის განხილვის წესის შესახებ, ეს კოდექსი და საქართველოს სსრ სამოქალაქო სამართლის საპროცესო კოდექსი.
