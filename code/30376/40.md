# მუხლი 40. სამუშაოდან გადაყენება
მუშის ან მოსამსახურის სამუშაოდან (თანამდებობიდან) გადაყენება დასაშვებია მხოლოდ იმ ორგანოების წინადადებით, რომლებიც საამისოდ არიან უფლებამოსილი, სსრ კავშირისა და საქართველოს სსრ კანონმდებლობით გათვალისწინებულ შემთხვევებში.
მუშაკს, რომელიც სამუშაოზე არაფხიზელ მდგომარეობაში, ნარკოტიკული ან ტოქსიკური სიმთვრალის მდგომარეობაში გამოცხადდება, საწარმოს, დაწესებულების, ორგანიზაციის ადმინისტრაცია იმ დღეს (იმ ცვლაში) არ დაუშვებს სამუშაოდ.
საქართველოს სსრ უმაღლესი საბჭოს პრეზიდიუმის 1988 წლის 24 მარტის ბრძანებულება №1649 -საქართველოს სსრ უმაღლესი საბჭოს უწყებები, №3, მარტი, 1988წ., მუხ.41
