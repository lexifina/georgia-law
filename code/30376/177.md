# მუხლი 177. თვრამეტ წელზე უფრო ახალგაზრდა მუშებისა და მოსამსახურეების დათხოვნის შეზღუდვა
ადმინისტრაციის ინიციატივით თვრამეტ წელზე უფრო ახალგაზრდა მუშაკების დათხოვნა დაიშვება დათხოვნის საერთო წესის დაცვით; ამასთან, დათხოვნა ამ კოდექსის 34-ე მუხლის პირველი ნაწილის "ა", "ბ" და "ე" ქვეპუნქტებში აღნიშნული საფუძვლებით ხდება მხოლოდ გამონაკლის შემთხვევებში და დაუშვებელია შრომითი მოწყობის გარეშე.
