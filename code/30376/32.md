# მუხლი 32. განუსაზღვრელი ვადით დადებული შრომის ხელშეკრულების მოშლა მუშის ან მოსამსახურის ინიციატივით
მუშებსა და მოსამსახურეებს უფლება აქვთ მოშალონ განუსაზღვრელი ვადით დადებული შრომის ხელშეკრულება, მაგრამ ამის შესახებ წერილობით უნდა გააფრთხილონ ადმინისტრაცია ორი კვირით ადრე. ამ ვადის გასვლის შემდეგ მუშას თუ მოსამსახურეს უფლება აქვს შეწყვიტოს მუშაობა, ხოლო საწარმოს, დაწესებულების, ორგანიზაციის ადმინისტრაცია ვალდებულია მისცეს მუშაკს შრომის წიგნაკი და გაუსწოროს მას ანგარიში.
მუშაკისა და ადმინისტრაციის შეთანხმებით შრომის ხელშეკრულება შეიძლება მოიშალოს ორი კვირის ვადის გასვლამდე.
თუ ორი კვირის გასვლის შემდეგ ადმინისტრაციამ არ გამოსცა ბრძანება მუშაკის განთავისუფლების შესახებ, ხოლო იგი განაგრძობს მუშაობას და არ მოითხოვს შრომითი ხელშეკრულების მოშლას, გაფრთხილება ძალას კარგავს.
