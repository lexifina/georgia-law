# მუხლი 122. საწარმოსთვის, დაწესებულებისთვის, ორგანიზაციისათვის მიყენებული ზიანის ანაზღაურების წესი
ზიანის ანაზღაურება იმ ოდენობით, რასაც ითვალისწინებს ამ კოდექსის 119-ე მუხლის პირველი ნაწილი, ხდება მუშაკის წერილობითი თანხმობით, საწარმოს, დაწესებულების, ორგანიზაციის ადმინისტრაციის განკარგულების საფუძველზე, ხელფასიდან დაქვითვის საშუალებით. განკარგულება დაქვითვის შესახებ ადმინისტრაციას შეუძლია გასცეს არა უგვიანეს ორი კვირისა იმ დღიდან, როცა გამოვლინდა მუშაკის მიერ მიყენებული ზიანი. თუ არ არის მუშაკის წერილობითი თანხმობა, დაქვითვა არ ხდება და საკითხს ზიანის ანაზღაურების შესახებ, ადმინისტრაციის განცხადებით, განიხილავს რაიონული (საქალაქო) სახალხო სასამართლო.
დანარჩენ შემთხვევებში ზიანის ანაზღაურება ხდება ადმინისტრაციის მიერ რაიონულ (საქალაქო) სახალხო სასამართლოში სარჩელის წარდგენის საშუალებით.
თუ დადგენილი წესის დარღვევით ადმინისტრაციამ მუშას ან მოსამსახურეს ხელფასიდან დაუქვითა თანხა მისი წერილობითი თანხმობისა და სასამართლოს გადაწყვეტილების გარეშე, მაშინ შრომითი დავის განმხილველი ორგანო მუშაკის საჩივრის შედეგად იღებს გადაწყვეტილებას უკანონოდ დაქვითული თანხის დაბრუნების შესახებ.
