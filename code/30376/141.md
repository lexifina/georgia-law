# მუხლი 141. ისეთ საწარმოთა საექსპლუატაციოდ გადაცემის აკრძალვა, რომლებიც არ შეესაბამება შრომის დაცვის მოთხოვნებს
არც ერთი საწარმო, საამქრო, უბანი, წარმოება არ შეიძლება იქნეს მიღებული და გადაცემული საექსპლუატაციოდ, თუ იქ არ არის უზრუნველყოფილი შრომის ჯანსაღი და უსაფრთხო პირობები.
საწარმოო დანიშნულების ახალი და რეკონსტრუირებული ობიექტის საექსპლუატაციოდ გადაცემა დაუშვებელია, თუ იქ არ არის იმ ორგანოების ნებართვა, რომლებიც ახორციელებენ სახელმწიფო სანიტარიულ და ტექნიკურ ზედამხედველობას, პროფკავშირთა ტექნიკური ინსპექციის და იმ საწარმოს, დაწესებულების, ორგანიზაციის პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივი კომიტეტის ნებართვა, რომლებიც ობიექტებს გადასცემენ საექსპლუატაციოდ.
