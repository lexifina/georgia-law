# მუხლი 128. შრომის დისციპლინის უზრუნველყოფა
საწარმოებში, დაწესებულებებსა და ორგანიზაციებში შრომის დისციპლინას უზრუნველყოფს შრომისადმი შეგნებული დამოკიდებულება, დარწმუნების მეთოდი, აგრეთვე წახალისება კეთილსინდისიერი შრომისათვის. ცალკეული არაკეთილსინდისიერი მუშაკების მიმართ საჭირო შემთხვევებში იყენებენ დისციპლინური და საზოგადოებრივი ზემოქმედების ღონისძიებებს.
