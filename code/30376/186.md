# მუხლი 186. ზეგანაკვეთურ სამუშაოზე ზოგადასაგანმანათლებლო სკოლებისა და პროფესიულ-ტექნიკური სასწავლო დაწესებულებების მოსწავლეთა დასაქმების აკრძალვა
აკრძალულია მეცადინეობის დღეებში იმ მუშა-მოსამსახურეების ზეგანაკვეთურ სამუშაოებზე დასაქმება, რომლებიც წარმოებისაგან მოუწყვეტლად სწავლობენ ზოგადსაგანმანათლებლო სკოლებსა და პროფესიულ-ტექნიკურ სასწავლო დაწესებულებებში.
საქართველოს სსრ უმაღლესი საბჭოს პრეზიდიუმის 1986 წლის 29 ნოემბრის ბრძანებულება №83 - საქართველოს სსრ უმაღლესი საბჭოს უწყებები, №12, დანართი, ნოემბერი, 1986წ., მუხ.285
