# მუხლი 12. კოლექტიურ ხელშეკრულებაში ცვლილებათა და დამატებათა შეტანა
ცვლილებანი და დამატებანი კოლექტიურ ხელშეკრულებაში მისი მოქმედების ვადის განმავლობაში შეაქვს კავშირის საფაბრიკო, საქარხნო, ადგილობრივ კომიტეტს და საწარმოს, ორგანიზაციის ადმინისტრაციას მუშათა და მოსამსახურეთა კრების (კონფერენციის) მიერ მათი მოწონების შემდეგ.
