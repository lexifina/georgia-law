# მუხლი 162. შვებულებანი იმ ქალებისათვის, რომლებმაც ახალშობილი ბავშვი იშვილეს
ქალებს, რომლებმაც ახალშობილი ბავშვი იშვილეს უშუალოდ სამშობიარო სახლიდან, ეძლევათ შვებულება ბავშვის შვილად აყვანის დღიდან, ვიდრე ბავშვის დაბადებიდან გავიდოდეს ორმოცდათექვსმეტი დღე. ამ ხნის განმავლობაში მათ ეძლევათ დახმარება სახელმწიფო სოციალური დაზღვევის წესით.
იმ ქალს, რომელმაც ახალშობილი ბავშვი იშვილა უშუალოდ სამშობიარო სახლიდან, თავისი განცხადების თანახმად ეძლევა დამატებითი უხელფასო შვებულება, ვიდრე ბავშვს შეუსრულდება ერთი წელი (მუხლი 161-ე).
ქალები, რომლებმაც ახალშობილი ბავშვი იშვილეს, სარგებლობენ იმ შეღავათებითა და უპირატესობით, რაც კანონით დადგენილია მეძუძური დედებისა და იმ ქალებისათვის, რომლებსაც ჰყავთ შვილები რვა წლის ასაკამდე.
