# მუხლი 108. გამომუშავების ნორმების (დროის ნორმების), მომსახურების ნორმების დადგენისა და გადასინჯვის დროს წარმოშობილი უთანხმოების გადაწყვეტის წესი
გამომუშავების ნორმების (დროის ნორმების), მომსახურების ნორმების დადგენისა ან გადასინჯვის დროს საწარმოს, დაწესებულების, ორგანიზაციის ადმინისტრაციასა და პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივ კომიტეტს შორის წარმოშობილ უთანხმოებას გადაწყვეტენ ზემდგომი სამეურნეო და პროფკავშირული ორგანოები.
