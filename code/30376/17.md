# მუხლი 17. გარანტიები სამუშაოზე მიღების დროს
აკრძალულია დაუსაბუთებელი უარი სამუშაოდ მიღებაზე.
სსრ კავშირის კონსტიტუციისა და საქართველოს კონსტიტუციის შესაბამისად, დაუშვებელია სამუშაოზე მიღებისას უფლებათა რაიმე პირდაპირი თუ არაპირდაპირი შეზღუდვა ან პირდაპირი თუ არაპირდაპირი უპირატესობის მინიჭება სქესის, რასის, ეროვნული კუთვნილებისა და რელიგიისადმი დამოკიდებულების მიხედვით.
