# მუხლი 219. მუშებისა და მოსამსახურეების უფლება მონაწილეობდნენ წარმოების მართვაში
მუშებსა და მოსამსახურეებს უფლება აქვთ მონაწილეობა მიიღონ წარმოების განვითარების საკითხთა განხილვასა და გადაწყვეტაში, შეიტანონ წინადადებები საწარმოების, დაწესებულებების, ორგანიზაციების მუშაობის გაუმჯობესების შესახებ, აგრეთვე სოციალურ-კულტურული და საყოფაცხოვრებო მომსახურების საკითხებზე.
