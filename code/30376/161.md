# მუხლი 161. დამატებითი უხელფასო შვებულება დედებისათვის, რომლებსაც ჰყავთ სამ წლამდე ასაკის ბავშვები
ორსულობისა და მშობიარობის გამო შვებულების გარდა ქალს, მისი განცხადების თანახმად, ეძლევა დამატებითი უხელფასო შვებულება, ვიდრე ბავშვი მიაღწევდეს ერთი წლის ასაკს, და შვებულების განმავლობაში ენახება სამუშაო ადგილი (თანამდებობა).
ეს შვებულება შეიძლება გამოყენებულ იქნეს მთლიანად ან ნაწილ-ნაწილ ნებისმიერ დროს, ვიდრე ბავშვს შეუსრულდება ერთი წლის ასაკი.
დამატებითი უხელფასო შვებულება ჩაითვლება მუშაობის საერთო და უწყვეტ სტაჟში, აგრეთვე სპეციალობის მიხედვით მუშაობის სტაჟში.
მუშაობის იმ სტაჟში, რომელიც იძლევა მომდევნო ყოველწლიური შვებულების უფლებას, დამატებითი უხელფასო შვებულების დრო არ ჩაითვლება.
