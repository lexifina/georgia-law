# მუხლი 107. მომსახურების ნორმირებული დავალებებისა და ნორმების დაწესება
დროებლივი ანაზღაურებისას მუშებსა და მოსამსახურეებს უწესდებათ ნორმირებული დავალებები. ცალკეული ფუნქციებისა და სამუშაოს მოცულობის შესასრულებლად შეიძლება დაწესდეს მომსახურების ნორმები ან მუშაკთა რაოდენობის ნორმები.
