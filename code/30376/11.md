# მუხლი 11. კოლექტიური ხელშეკრულების დადებისას წარმოშობილი უთანხმოების გადაწყვეტის წესი
კოლექტიური ხელშეკრულების დადებისას საწარმოს, ორგანიზაციის ადმინისტრაციასა და პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივ კომიტეტს შორის წარმოშობილ უთანხმოებას გადაწყვეტენ ზემდგომი სამეურნეო და პროფკავშირული ორგანოები მხარეთა მონაწილეობით.
