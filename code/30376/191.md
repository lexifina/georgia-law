# მუხლი 191. შრომის ხელშეკრულება საპენსიო ასაკს მიღწეულ მუშებსა და მოსამსახურეებთან
საწარმოს, დაწესებულების, ორგანიზაციის ადმინისტრაციას უფლება აქვს პროფკავშირის კომიტეტთან ერთად შრომითი ურთიერთობა შეინარჩუნოს საპენსიო ასაკს მიღწეული მუშებსა და მოსამსახურეებთან, თუ ისინი კეთილსინდისიერად, სრული ძალისხმევით მუშაობენ, აქვთ შრომის მაღალი შედეგები და კოლექტივში დამსახურებული ავტორიტეტით სარგებლობენ. სხვა მუშაკებთან, რომლებმაც მიაღწიეს საპენიო ასაკს და გააჩნიათ სრული პენსიის დასანიშნავად აუცილებელი სტაჟი, შრომითი ურთიერთობა გაგრძელდება მხარეთა შეთანხმებით ვადიანი შრომის ხელშეკრულების დადების (ხელახლა დადების) გზით (ორ წლამდე ვადით) ან შეწყდება ადმინისტრაციის ინიციატივით პროფკავშირის კომიტეტის თანხმობით (ამ კოდექსის 34-ე მუხლის 1¹პუნქტი).
საპენსიო ასაკს მიღწეულ პირთა დათხოვნის ეს წესი არ ვრცელდება თანამდებობაზე შრომითი კოლექტივის მიერ არჩეულ მუშაკებზე, აგრეთვე იმ პირებზე, რომელთა მიმართ კანონმდებლობით დადგენილია ასაკის გამო სამუშაოდან განთავისუფლების სხვა წესი.
საქართველოს სსრ უმაღლესი საბჭოს პრეზიდიუმის 1988 წლის 24 მარტის ბრძანებულება №1649 -საქართველოს სსრ უმაღლესი საბჭოს უწყებები, №3, მარტი, 1988წ., მუხ.41
