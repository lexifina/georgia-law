# მუხლი 78. მუშების შრომის ანაზღაურება სატარიფო განაკვეთების საფუძველზე
მუშების შრომის ანაზღაურება ხდება სატარიფო განაკვეთების (სარგოების) მიხედვით, რომლებიც დამტკიცებულია ცენტრალიზებული წესით.
შესასრულებელი სამუშაოების მიკუთვნებას გარკვეული სატარიფო თანრიგისათვის და მუშაკებისათვის საკვალიფიკაციო თანრიგის მინიჭებას ახდენს საწარმოს, ორგანიზაციის ადმინისტრაცია პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივ კომიტეტთან შეთანხმებით, სატარიფო-საკვალიფიკაციო ცნობარის შესაბამისად.
