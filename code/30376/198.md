# მუხლი 198. შრომის დავის განმხილველ კომისიაში განცხადებათა მიღების წესი და შრომითი დავის განხილვის ვადა
შრომის დავის განმხილველ კომისიაში განცხადებათა მიღებას აწარმოებს პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივი კომიტეტი, ხოლო იქ, სადაც ასეთი არ არის - პროფორგანიზატორი.
კომისია ვალდებულია შრომის დავა განიხილოს ხუთ დღეში განცხადების მიღების დღიდან.
