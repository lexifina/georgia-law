# მუხლი 244. მუშებისა და მოსამსახურეების მატერიალური პასუხისმგებლობა იმ შემთხვევებაში, როდესაც ფაქტობრივი ზიანის ოდენობა აღემატება მის ნომინალურ ოდენობას
სსრ კავშირისა და სხვა მოკავშირე რესპუბლიკების შრომის კანონმდებლობის საფუძვლების შესაბამისად საწარმოს, დაწესებულების, ორგანიზაციისათვის მიყენებული ზიანის გამო მუშათა და მოსამსახურეთა მატერიალური პასუხისმგებლობის ფარგლებს იმ შემთხვევებში, როდესაც ზიანის ფაქტობრივი ოდენობა აღემატება მის ნომინალურ ოდენობას, აწესებენ სსრ კავშირის კანონები და სსრ კავშირის მინისტრთა საბჭოს დადგენილებები.
