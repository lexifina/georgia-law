# მუხლი 233. დახმარება ორსულობისა და მშობიარობის გამო
დახმარებას ორსულობისა და მშობიარობის გამო გასცემენ ორსულობისა და მშობიარობისათვის აღებული მთელი შვებულების განმავლობაში სრული ხელფასის ოდენობით. (საქართველოს სსრ უმაღლესი საბჭოს პრეზიდიუმის 1973 წლის 29 ნოემბრის ბრძანებულება, "საქართველოს სსრ უმაღლესი საბჭოს უწყებები", 1973, №11, მუხ. 202).
