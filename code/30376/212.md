# მუხლი 212. იმ თანხების გადახდევინების შეზღუდვა, რომლებიც გაცემულია შრომის დავის განმხილველი ორგანოს გადაწყვეტილებით
მუშის ან მოსამსახურისათვის იმ თანხის უკანვე გადახდევინება, რომელიც მან მიიღო შრომითი დავის კომისიის გადაწყვეტილებით ან პროფესიული კავშირის საფაბრიკო, საქარხნო, ადგილობრივი კომიტეტის დადგენილებით, თუ შრომითი დავა შემდგომში სხვაგვარად გადაწყდა, აგრეთვე შრომის დავის გამო სასამართლოს გადაწყვეტილებით გაცემული თანხის უკანვე გადახდევინება, თუ გადაწყვეტილება გაუქმებული იყო ზედამხედველობის წესით, დასაშვებია მხოლოდ იმ შემთხვევებში, როდესაც გაუქმებული გადაწყვეტილება ან დადგენილება ემყარებოდა მუშის ან მოსამსახურის მიერ მიწოდებულ ყალბ ცნობებს ან მის მიერ წარმოდგენილ ყალბ საბუთებს.
