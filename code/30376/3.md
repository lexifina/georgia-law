# მუხლი 3. კოლმეურნეობებისა და სხვა კოოპერაციული ორგანიზაციების წევრთა შრომის მოწესრიგება
კოლმეურნეობებისა და სხვა კოოპერაციული ორგანიზაციების წევრთა შრომას აწესრიგებს კოლმეურნეობის სანიმუშო წესდების, კოოპერატივის სანიმუშო წესდების საფუძველზე და შესაბამისად მიღებული მათი წესდებები, აგრეთვე სსრ კავშირისა და საქართველოს კანონმდებლობა, რომელიც კოლმეურნეობებს და სხვა კოოპერაციულ ორგანიზაციებს ეხება.
საქართველოს სსრ უმაღლესი საბჭოს პრეზიდიუმის 1988 წლის 24 მარტის ბრძანებულება №1649 -საქართველოს სსრ უმაღლესი საბჭოს უწყებები, №3, მარტი, 1988წ., მუხ.41
