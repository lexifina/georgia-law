# მუხლი 422. მუშაკის განთავისუფლების საფუძველი და წესი
1. მოსალოდნელი გათავისუფლების შესახებ მუშაკს პერსონალურად უნდა ეცნობოს ერთი თვით ადრე მაინც. აღნიშნული შეტყობინება მუშაკმა უნდა დაადასტუროს ხელმოწერით. იმ შემთხვევაში, როდესაც მუშაკი უარს აცხადებს ხელის მოწერაზე, გაფრთხილებაზე უფლებამოსილი პირი ვალდებულია შეადგინოს ოქმი, რომელშიც მითითებული იქნება, რომ მუშაკი გაფრთხილებულ იქნა მოსალოდნელი გათავისუფლების შესახებ და იგი უარს აცხადებს ხელის მოწერაზე. ამ შემთხვევაში ოქმში აგრეთვე მიეთითება მისი შედგენის თარიღი და მასზე ხელს აწერს მხოლოდ გაფრთხილებაზე უფლებამოსილი პირი.
2. ლიკვიდაციის ან რეორგანიზაციის დროს საწარმოს, დაწესებულებისა და ორგანიზაციის ადმინისტრაცია ან სალიკვიდაციო კომისია ვალდებულია ორი თვით ადრე მაინც აცნობოს შრომითი მოწყობის ორგანოს მუშაკთა მასობრივი განთავისუფლების შესახებ, მათი სპეციალობისა და კვალიფიკაციის მითითებით.
3. მუშაკთა რიცხოვნობის ან შტატების შემცირებისას სამუშაოზე დარჩენის უპირატესი უფლება განისაზღვრება ამ კოდექსის 36-ე მუხლის შესაბამისად.
