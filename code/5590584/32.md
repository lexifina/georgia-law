# მუხლი 32. განქორწინების წესი
განქორწინება ხდება სასამართლო წესით, ხოლო ამ კოდექსის 38-ე და 39-ე მუხლებით გათვალისწინებული შემთხვევისას - მშრომელთა დეპუტატების რაიონული (საქალაქო)საბჭოს აღმასრულებელი კომიტეტის მოქალაქეობრივი მდგომარეობის აქტების ჩამწერ ბიუროში (განყოფილებაში).
ცოლის ორსულობის დროს და ბავშვის დაბადებიდან ერთი წლის განმავლობაში ქმარს უფლება არა აქვს ცოლის თანხმობის გარეშე აღძრას საქმე განქორწინების შესახებ.
