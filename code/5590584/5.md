# მუხლი 5. დედობის დაცვა და წახალისება
საქართველოს საბჭოთა სოციალისტურ რესპუბლიკაში დედობა გარემოცულია საყოველთაო-სახალხო პატივისცემითა და დაფასებით, მას იცავს და ახალისებს სახელმწიფო.
დედისა და ბავშვის ინტერესთა დაცვა უზრუნველყოფილია სამშობიარო სახლების, საბავშვო ბაგებისა და ბაღების, სკოლა-ინტერნატებისა და სხვა საბავშვო დაწესებულებათა ფართო ქსელის შექმნით, ორსულობისა და მშობიარობის გამო ქალისათვის ხელფასიანი შვებულების მიცემით, ორსული ქალებისა და დედებისათვის შეღავათების დაწესებით, წარმოებაში ქალთა შრომის დაცვით, მარტოხელა და მრავალშვილიანი დედებისათვის სახელმწიფო დახმარების მიცემით, აგრეთვე ოჯახისათვის სხვა სახელმწიფო და საზოგადოებრივი დახმარების გაწევით.
