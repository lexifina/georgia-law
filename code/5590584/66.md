# მუხლი 66. მშობლის უფლების ჩამორთმევის შედეგები
მშობლის უფლებაჩამორთმეული მშობელი კარგავს შვილთან ნათესაობაზე დამყარებულ ყველა უფლებას იმ შვილისადმი, რომლის მიმართაც მას ჩამორთმეული აქვს მშობლის უფლება.
თუ მშობელი, რომელსაც ჩამოერთვა მშობლის უფლება, სისტემატურად არღვევს სოციალისტური საერთო ცხოვრების წესებს და ამით შეუძლებელს ხდის ბავშვის მასთან ერთად ცხოვრებას, არ ემორჩილება გაფრთხილებებსა და საზოგადოებრივი ზემოქმედების ღონისძიებებს, საქართველოს სსრ სამოქალაქო სამართლის კოდექსის 326-ე მუხლის შესაბამისად შეიძლება გამოსახლებულ იქნეს ბინიდან სხვა საცხოვრებელი ფართობის მიუცემლად.
