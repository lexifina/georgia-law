# მუხლი 161. მოქალაქეობრივი მდგომარეობის აქტების რეგისტრაციის ორგანოები
მოქალაქეობრივი მდგომარეობის აქტების რეგისტრაცია ქალაქებსა და რაიონულ ცენტრებში ხდება მოქალაქეობრივი მდგომარეობის აქტების ჩამწერ საქალაქო და რაიონულ ბიუროებში (განყოფილებებში), ხოლო სოფლად, მუშათა დაბებში და იმ ქალაქებში, სადაც მოქალაქეობრივი მდგომარეობის აქტების ჩამწერი ბიუროები (განყოფილებები) არ არის,მშრომელთა დეპუტატების სასოფლო, სადაბო, და საქალაქო საბჭოების აღმასრულებელ კომიტეტებში.
