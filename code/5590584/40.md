# მუხლი 40. ქორწინების შეწყვეტის დრო
განქორწინების შესახებ სასამართლოს გადაწყვეტილება, რომელიც კანონიერ ძალაშია შესული, აღსრულდება ერთ-ერთი ან ორივე მეუღლის მოთხოვნით არაუგვიანეს სამი წლისა მშრომელთა დეპუტატთა რაიონული (საქალაქო) საბჭოს აღმასრულებელი კომიტეტის მოქალაქეობრივი მდგომარეობის აქტების ჩამწერ ბიუროში (განყოფილებაში) რეგისტრაციის საშუალებით.
ქორწინება შეწყვეტილად ითვლება მოქალაქეობრივი მდგომარეობის აქტების ჩამწერ ორგანოში განქორწინების რეგისტრაციის დღიდან.
