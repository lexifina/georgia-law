# მუხლი 3. ქალისა და მამაკაცის თანასწორუფლებიანობა საოჯახო ურთიერთობაში
საოჯახო ურთიერთობაში ქალსა და მამაკაცს თანაბარი პირადი და ქონებრივი უფლებები აქვთ.
უფლებათა თანასწორობას ოჯახში საფუძვლად უძევს ქვეყნის სახელმწიფო, საზოგადოებრივ-პოლიტიკური, სამეურნეო და კულტურული ცხოვრების ყველა დარგში ქალისა და მამაკაცის თანაბარი უფლებები, რაც განმტკიცებულია სსრ კავშირის კონსტიტუციით და საქართველოს სსრ კონსტიტუციით.
