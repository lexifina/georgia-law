# მუხლი 80. შვილების მიერ მშობლების რჩენის მოვალეობა
სრულწლოვანი შვილები მოვალენი არიან არჩინონ შრომისუუნარო მშობლები, რომლებსაც დახმარება სჭირდებათ და იზრუნონ მათთვის.
შვილები შეიძლება გათავისუფლდნენ მშობლების რჩენის მოვალეობისაგან, თუ სასამართლო დაადგენს, რომ მშობლები თავს არიდებდნენ მშობლის მოვალეობის შესრულებას.
მშობელი, რომელსაც მშობლის უფლება აქვს ჩამორთმეული, კარგავს შვილებისაგან ალიმენტის მოთხოვნის უფლებას.
