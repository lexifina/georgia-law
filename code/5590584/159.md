# მუხლი 159. მეურვეობისა და მზრუნველობის ორგანოს გადაწყვეტილების გასაჩივრება
მეურვეობისა და მზრუნველობის ორგანოს გადაწყვეტილება მეურვის (მზრუნველის) დანიშვნის, გადაყენებისა და გათავისუფლების შესახებ, აგრეთვე მეურვეობისა და მზრუნველობის ყველა სხვა საკითხზე დაინტერესებულ პირს შეუძლია გაასაჩივროს შესაბამისად თბილისის მშრომელთა დეპუტატების საქალაქო საბჭოს აღმასრულებელ კომიტეტში, სამხრეთ ოსეთის ავტონომიური ოლქის მშრომელთა დეპუტატების საბჭოს აღმასრულებელ კომიტეტში, აფხაზეთის ასსრ მინისტრთა საბჭოში, აჭარის ასსრ მინისტრთა საბჭოში და საქართველოს სსრ მინისტრთა საბჭოში.
