# მუხლი 110. შვილად აყვანაზე უარის გასაჩივრება
მშრომელთა დეპუტატების რაიონული (საქალაქო) საბჭოს აღმასრულებელი კომიტეტის უარი შვილად აყვანაზე შეიძლება გასაჩივრდეს შესაბამისად თბილისის მშრომელთა დეპუტატების საქალაქო საბჭოს აღმასრულებელ კომიტეტში, სამხრეთ ოსეთის ავტონომიური ოლქის მშრომელთა დეპუტატების საბჭოს აღმასრულებელ კომიტეტში, აფხაზეთის ასსრ მინისტრთა საბჭოში, აჭარის ასსრ მინისტრთა საბჭოში და საქართველოს სსრ მინისტრთა საბჭოში.
