# მუხლი 37. სახელმწიფო ბაჟი განქორწინების საქმეებზე
განქორწინების შესახებ გადაწყვეტილების გამოტანისას სასამართლო განსაზღვრავს თანხას 50-დან 200 მანეთამდე, რომელიც უნდა გადახდეს ერთ-ერთ ან ორივე მეუღლეს განქორწინების მოწმობის გაცემისას. თუ სასამართლო საჭიროდ ცნობს, რომ ბაჟი უნდა გადახდეს ორივე მეუღლეს, განსაზღვრავს თითოეული მეუღლის მიერ გადასახდელ თანხას.
