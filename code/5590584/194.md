# მუხლი 194. ბავშვის მოქალაქეობა
ქორწინებისა და ოჯახის შესახებ სსრ კავშირისა და მოკავშირე რესპუბლიკების კანონმდებლობის საფუძვლების შესაბამისად ბავშვი, რომლის ორივე მშობელი მისი დაბადების დროს სსრ კავშირის მოქალაქე იყო, ითვლება სსრ კავშირის მოქალაქედ, მიუხედავად იმისა, თუ სად დაიბადა იგი.
საქართველოს სსრ რესპუბლიკაში მუდმივად მცხოვრები მოქალაქეობის არმქონე პირები სარგებლობენ უფლებებით და მათ ეკისრებათ მოვალეობები საქორწინო და საოჯახო ურთიერთობაში საბჭოთა მოქალაქეების თანაბრად.
