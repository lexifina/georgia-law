# მუხლი 4. საოჯახო ურთიერთობაში მოქალაქეთა თანასწორუფლებიანობა მათი ეროვნების, რასისა და რელიგიასთან დამოკიდებულების მიუხედავად
ყველა მოქალაქეს, მიუხედავად მისი ეროვნებისა, რასისა და რელიგიასთან დამოკიდებულებისა, საოჯახო ურთიერთობაში აქვს თანაბარი უფლებები.
დაქორწინების დროს და საოჯახო ურთიერთობაში არ დაიშვება უფლებათა რაიმე პირდაპირი ან არაპირდაპირი შეზღუდვა, პირდაპირი ან არაპირდაპირი უპირატესობის მინიჭება ეროვნული, რასობრივი კუთვნილების ან რელიგიასთან დამოკიდებულების მიხედვით.
