# მუხლი 108. შვილად აყვანის გაფორმება
განცხადება ბავშვის შვილად აყვანის სურვილის შესახებ შეაქვთ მეურვეობისა და მზრუნველობის ორგანოში შვილად ასაყვანის ან მშვილებლის საცხოვრებელი ადგილის მიხედვით.
რაიონის (ქალაქის) განათლების განყოფილება ჩატარებს სათანადო გამოკვლევას და თავის დასკვნას შვილად აყვანის საკითხის გადასაწყვეტად წარუდგენს მშრომელთა დეპუტატების რაიონული (საქალაქო) საბჭოს აღმასრულებელ კომიტეტს.
