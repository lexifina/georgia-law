# მუხლი 68. პროცესის მონაწილის დაცვის სპეციალური ღონისძიების სახეები
პროცესის მონაწილის დაცვის სპეციალური ღონისძიების სახეებია:
ა) საჯარო რეესტრში ან სხვა საჯარო ხასიათის ჩანაწერში პროცესის მონაწილის ამოცნობისა და იდენტიფიცირების შესაძლებლობის შემცველი მონაცემების, კერძოდ, სახელის, გვარის, მისამართის, სამუშაო ადგილის, პროფესიის ან სხვა შესაბამისი ინფორმაციის, შეცვლა ან ამოღება;
ბ) პროცესის მონაწილის ამოცნობისა და იდენტიფიცირების შესაძლებლობის შემცველი საპროცესო დოკუმენტის და ამ მუხლის "ა" ქვეპუნქტით გათვალისწინებული დოკუმენტის გასაიდუმლოება;
გ) ფსევდონიმის მინიჭება;
დ) უსაფრთხოების ზომების მიღება;
ე) გარეგნობის შეცვლა;
ვ) საცხოვრებელი ადგილის დროებით ან სამუდამოდ შეცვლა.
