# მუხლი 253. ბრალდებულის საბოლოო სიტყვა
1. მხარეთა მიერ დასკვნითი სიტყვების წარდგენისა და რეპლიკით გამოსვლის შემდეგ ბრალდებულს უფლება აქვს, გამოვიდეს საბოლოო სიტყვით.
2. სხდომის თავმჯდომარეს უფლება არა აქვს, დაადგინოს ბრალდებულის საბოლოო სიტყვის ხანგრძლივობა, მაგრამ მას შეუძლია შეაჩეროს ბრალდებული, თუ ის ეხება გარემოებას, რომელსაც კავშირი არა აქვს განსახილველ საქმესთან.
