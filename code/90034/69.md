# მუხლი 69. პროცესის მონაწილის დაცვის სპეციალური ღონისძიების გამოყენება
1. პროკურორი უფლებამოსილია პროცესის მონაწილის, მასთან დაკავშირებული პირის ან/და მისი ახლო ნათესავის მიმართ, მათი თანხმობით, გამოიყენოს ამ თავით გათვალისწინებული დაცვის ნებისმიერი სპეციალური ღონისძიება.
2. პროცესის მონაწილის დაცვის სპეციალური ღონისძიების ხარჯებს სახელმწიფო გაიღებს.
