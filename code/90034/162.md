# მუხლი 162. ზოგიერთი პირის თანამდებობიდან გადაყენება (თანამდებობრივი უფლებამოსილების განხორციელებისაგან ჩამოცილება)
1. საქართველოს პარლამენტის წევრის, აფხაზეთისა და აჭარის ავტონომიური რესპუბლიკების უმაღლესი წარმომადგენლობითი ორგანოების დეპუტატების, საქართველოს სახალხო დამცველის, მოსამართლის, საქართველოს კონტროლის პალატის თავმჯდომარის თანამდებობიდან გადაყენების (თანამდებობრივი უფლებამოსილების განხორციელებისაგან ჩამოცილების) საკითხი წყდება საქართველოს კანონმდებლობით დადგენილი წესით.
2. ამ მუხლის პირველ ნაწილში აღნიშნულ პირთა თანამდებობიდან გადაყენების (თანამდებობრივი უფლებამოსილების განხორციელებისაგან ჩამოცილების) მოთხოვნით მიმართვის უფლება აქვს საქართველოს მთავარ პროკურორს.
