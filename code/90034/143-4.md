# მუხლი 143⁴. ფარული საგამოძიებო მოქმედების განხორციელების უფლებამოსილების მქონე ორგანო
1. ფარულ საგამოძიებო მოქმედებას ახორციელებს შესაბამისი უფლებამოსილების მქონე სახელმწიფო ორგანო ამ კოდექსით დადგენილი წესით.
2. ამ კოდექსის 143¹მუხლის პირველი ნაწილის "ა" ქვეპუნქტით გათვალისწინებულ ფარულ საგამოძიებო მოქმედებას უფლებამოსილი ორგანო ახორციელებს ფარული საგამოძიებო მოქმედებების განხორციელების ორეტაპიანი ელექტრონული სისტემის მეშვეობით.
- საქართველოს 2014 წლის 1 აგვისტოს კანონი №2634- ვებგვერდი, 18.08.2014წ.
- საქართველოს 2014 წლის 30 ნოემბრის კანონი №2870 - ვებგვერდი, 30.11.2014წ.
