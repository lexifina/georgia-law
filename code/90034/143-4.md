# მუხლი 143⁴. ფარული საგამოძიებო მოქმედების ჩატარების უფლებამოსილების მქონე ორგანო
ფარულ საგამოძიებო მოქმედებას ატარებს შესაბამისი უფლებამოსილების მქონე სახელმწიფო ორგანო ამ კოდექსით და "ოპერატიულ-სამძებრო საქმიანობის შესახებ" საქართველოს კანონით დადგენილი წესებით.
- საქართველოს 2014 წლის 1 აგვისტოს კანონი №2634- ვებგვერდი, 18.08.2014წ.
[მუხლი 143 4 . ფარული საგამოძიებო მოქმედების განხორციელების უფლებამოსილების მქონე ორგანო
1. ფარულ საგამოძიებო მოქმედებას ახორციელებს შესაბამისი უფლებამოსილების მქონე სახელმწიფო ორგანო ამ კოდექსით დადგენილი წესით.
2. ამ კოდექსის 143 1 მუხლის პირველი ნაწილის "ა" ქვეპუნქტით გათვალისწინებულ ფარულ საგამოძიებო მოქმედებას უფლებამოსილი ორგანო ახორციელებს ფარული საგამოძიებო მოქმედებების განხორციელების ორეტაპიანი ელექტრონული სისტემის მეშვეობით. (ამოქმედდეს 2015 წლის 31 მარტიდან)]
- საქართველოს 2014 წლის 30 ნოემბრის კანონი №2870 - ვებგვერდი, 30.11.2014წ.
