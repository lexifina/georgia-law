# მუხლი 141. კომუნიკაციის ტექნიკური საშუალებით განხორციელებულ გზავნილზე ყადაღის გაუქმება
სასამართლო მხარის შუამდგომლობის საფუძველზე განჩინებით აუქმებს კომუნიკაციის ტექნიკური საშუალებით განხორციელებულ გზავნილზე ყადაღას, თუ აღარ არსებობს ყადაღის გაგრძელების საფუძველი. ყადაღა ასევე უქმდება სასამართლოს განჩინებაში აღნიშნული ვადის ამოწურვისას, სისხლისსამართლებრივი დევნის ან/და გამოძიების შეწყვეტისთანავე ან განაჩენის გამოტანისთანავე.
