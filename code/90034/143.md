# მუხლი 143. ფარული საგამოძიებო მოქმედების განჩინების რეესტრი
1. სასამართლოში დგება ფარული საგამოძიებო მოქმედების განჩინების რეესტრი. განჩინების გამომტან სასამართლოს რეესტრში შეაქვს ინფორმაცია, ვინ, როდის, ვისი შუამდგომლობით, ვის მიმართ და რა ვადით გამოიტანა განჩინება. რეესტრში ასევე მიეთითება სისხლის სამართლის საქმის ნომერი. ფარული საგამოძიებო მოქმედების შედეგად მიღებული ინფორმაციის განსაიდუმლოების შემდეგ საჯაროა რეესტრის ინფორმაციაც.
2. ფარული საგამოძიებო მოქმედების განჩინების რეესტრის შესაბამისი ნომერი უნდა აღინიშნოს ამ თავით გათვალისწინებულ სასამართლოს განჩინებაში საგამოძიებო მოქმედების ჩატარების შესახებ.
