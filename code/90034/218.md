# მუხლი 218. ბრალდებულის სასჯელისაგან სრულად გათავისუფლება
1. განსაკუთრებულ შემთხვევაში, როდესაც ბრალდებულის საგამოძიებო ორგანოებთან თანამშრომლობის შედეგად გაირკვა თანამდებობის პირის ან/და განსაკუთრებით მძიმე დანაშაულის ჩამდენი პირის ვინაობა და მისი უშუალო ხელშეწყობით შეიქმნა ამ დანაშაულის გახსნისთვის არსებითი პირობები, საქართველოს მთავარ პროკურორს უფლება აქვს, სასამართლოს მიმართოს შუამდგომლობით ბრალდებულის სასჯელისაგან სრულად გათავისუფლების თაობაზე. შუამდგომლობის დაკმაყოფილების შემთხვევაში ბრალდებული სრულად თავისუფლდება სასჯელისაგან, თუმცა იგი ითვლება ნასამართლევად. ბრალდებულის სასჯელისაგან სრულად გათავისუფლება დაუშვებელია საქართველოს სისხლის სამართლის კოდექსის 144¹, 144² და 144³მუხლებით გათვალისწინებულ დანაშაულთა საქმეებზე.
2. სასჯელისაგან სრულად გათავისუფლების შესახებ დგება წერილობითი შეთანხმება, რომელსაც ხელს აწერენ ბრალდებული, მისი ადვოკატი და საქართველოს მთავარი პროკურორი.
3. სასჯელისაგან სრულად გათავისუფლების შესახებ შეთანხმებაში აღინიშნება, რომ თუ ბრალდებული არ ითანამშრომლებს საგამოძიებო ორგანოებთან, შეთანხმება, მისი პირობების შესაბამისად, ბათილად ჩაითვლება.
4. სასჯელისაგან სრულად გათავისუფლების შესახებ შეთანხმებას სასამართლოს დასამტკიცებლად წარუდგენს საქართველოს მთავარი პროკურორი. დაუშვებელია სასჯელისაგან სრულად გათავისუფლება მხოლოდ ჯარიმის ან სხვა თანხის გადახდის სანაცვლოდ.
