# მუხლი 152. ქონებაზე ყადაღის დადებისას უფლებამოსილებათა შეზღუდვა
1. ქონებაზე ყადაღის დადება მესაკუთრეს ან მფლობელს უკრძალავს ქონების განკარგვას, ხოლო აუცილებლობის შემთხვევაში - აგრეთვე ქონებით სარგებლობას.
2. კომერციული ბანკის ლიკვიდაციის მიზნებისათვის კომერციული ბანკის ლიკვიდატორი უფლებამოსილია ყადაღადადებული ანგარიშები "კომერციული ბანკების საქმიანობის შესახებ" საქართველოს კანონის 37-ე მუხლის მე-14 პუნქტის შესაბამისად სხვა კომერციულ ბანკში ან/და საქართველოს ეროვნულ ბანკში გადაიტანოს.
- საქართველოს 2017 წლის 23 დეკემბრის კანონი №1902 - ვებგვერდი, 11.01.2018წ.
