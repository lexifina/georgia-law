# მუხლი 152. ქონებაზე ყადაღის დადებისას უფლებამოსილებათა შეზღუდვა
1. ქონებაზე ყადაღის დადება მესაკუთრეს ან მფლობელს უკრძალავს ქონების განკარგვას, ხოლო აუცილებლობის შემთხვევაში - აგრეთვე ქონებით სარგებლობას.
2. კომერციული ბანკის ლიკვიდატორი ან სპეციალური მმართველი უფლებამოსილია ყადაღადადებული ანგარიშები "კომერციული ბანკების საქმიანობის შესახებ" საქართველოს კანონის შესაბამისად სხვა კომერციულ ბანკში ან/და საქართველოს ეროვნულ ბანკში გადაიტანოს.
- საქართველოს 2017 წლის 23 დეკემბრის კანონი №1902 - ვებგვერდი, 11.01.2018წ.
- საქართველოს 2019 წლის 20 დეკემბრის კანონი №5660 - ვებგვერდი, 31.12.2019წ.
