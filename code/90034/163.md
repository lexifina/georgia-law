# მუხლი 163. ბრალდებულისათვის (მსჯავრდებულისათვის) საქართველოს მოქალაქის პასპორტის მოქმედების შეჩერების საფუძველი
საქართველოს მოქალაქის პასპორტის მოქმედება შეიძლება შეჩერდეს, თუ პირი, რომელზედაც გაცემულია საქართველოს მოქალაქის პასპორტი, ბრალდებულია (მსჯავრდებულია) ამ კოდექსით დადგენილი წესით და არსებობს დასაბუთებული ვარაუდი, რომ აღნიშნული პასპორტის გამოყენებით იგი შეძლებს საქართველოდან გასვლას ან საზღვარგარეთ გადაადგილებას.
