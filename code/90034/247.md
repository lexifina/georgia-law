# მუხლი 247. ბრალდებულის მიერ საქმის არსებით განხილვამდე მიცემული ინფორმაციის მტკიცებულებად გამოყენების დაუშვებლობა
1. თუ ბრალდებული წინააღმდეგია, საქმის არსებით განხილვამდე მის მიერ მოწმის სტატუსით მიცემული ინფორმაციის სასამართლო სხდომაზე საჯაროდ წაკითხვა და ამ ინფორმაციის აუდიო- ან ვიდეოჩანაწერის მოსმენა (დემონსტრირება), ასევე მისი მტკიცებულებად გამოყენება დაუშვებელია. მიცემული ინფორმაციის საჯაროდ წაკითხვაზე ან მისი აუდიო- ან ვიდეოჩანაწერის მოსმენაზე (დემონსტრირებაზე) ბრალდებულის უარი არ შეიძლება შეფასდეს მისი ბრალეულობის დამადასტურებელ მტკიცებულებად.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული შეზღუდვა არ ვრცელდება ოპერატიულ-სამძებრო ღონისძიების შედეგად მიღებულ ინფორმაციაზე.
