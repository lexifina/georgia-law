# მუხლი 140. ფარული საგამოძიებო მოქმედების მინიმუმამდე დაყვანა
1. ფარული საგამოძიებო მოქმედების ჩამტარებელი პირი (ორგანო) ვალდებულია მაქსიმალურად შეზღუდოს იმ კომუნიკაციისა და პირის მონიტორინგი, რომელსაც გამოძიებასთან კავშირი არა აქვს.
2. თუ წინასწარ ცნობილია, რომ ფარული საგამოძიებო მოქმედების ობიექტი სასულიერო პირი, პოლიტიკური ან საზოგადო მოღვაწე, გამომცემელი, მეცნიერი, პედაგოგი, ადვოკატი , ჟურნალისტი ან იმუნიტეტის მქონე პირია, ამ მოქმედების ჩატარება დასაშვებია მხოლოდ იმ შემთხვევაში, როდესაც ეს არ უკავშირდება მის კანონით დაცულ საქმიანობას.
