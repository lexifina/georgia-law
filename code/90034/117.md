# მუხლი 117. ყრუ-მუნჯის და მძიმედ დაავადებულის დაკითხვა
1. ყრუ-მუნჯის დაკითხვა ტარდება შესაბამისი ცოდნის მქონე თარჯიმნის მონაწილეობით. თუ დასაკითხი პირი ყრუა, მისთვის შეკითხვების დასმა შეიძლება წერილობით, ხოლო თუ ის მუნჯია, მას შეუძლია შეკითხვებზე პასუხები წერილობით გასცეს.
2. მძიმედ დაავადებულის დაკითხვა ტარდება ექიმის ნებართვით და საჭიროების შემთხვევაში მისი დასწრებით.
