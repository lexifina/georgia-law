# მუხლი 84. დაცვის მხარის საგამონაკლისო უფლება
დაცვის მხარის მიერ ისეთი მტკიცებულების წარუდგენლობა, რომელიც განსაკუთრებით მნიშვნელოვანია მისი დაცვის უზრუნველსაყოფად, არ იწვევს სასამართლოში საქმის არსებით განხილვაზე ამ მტკიცებულების დაუშვებლობას. ამ შემთხვევაში დაცვის მხარეს ეკისრება ჯარიმა და საპროცესო ხარჯების ანაზღაურება. ჯარიმის ოდენობა უნდა იყოს შემაკავებელი ხასიათის, მიყენებული ზიანის პროპორციული და უნდა შეესაბამებოდეს მხარის ფინანსურ მდგომარეობას.
