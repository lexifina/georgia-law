# მუხლი 284. ავადმყოფობის ან ხანდაზმულობის გამო სასჯელის შემდგომი მოხდისაგან გათავისუფლება
1. საქართველოს სისხლის სამართლის კოდექსის 74-ე მუხლითა და "პატიმრობის შესახებ" საქართველოს კანონის 67-ე მუხლით გათვალისწინებული პირობების არსებობისას, მსჯავრდებულის შუამდგომლობით ან/და სასჯელაღსრულების დაწესებულების დირექტორის წარდგინებით, ხანდაზმული პირის, აგრეთვე სახელმწიფო საექსპერტო დაწესებულების დასკვნის საფუძველზე, სასჯელის მოხდის ადგილის მიხედვით პირველი ინსტანციის სასამართლოს უფლება აქვს, მძიმე ან უკურნებელი სენით დაავადებული მსჯავრდებულის მიმართ ზეპირი მოსმენის გარეშე გამოიტანოს განჩინება სასჯელის შემდგომი მოხდისაგან გათავისუფლების შესახებ.
2. ავადმყოფობის ან ხანდაზმულობის გამო სასჯელის მოხდისაგან მსჯავრდებულის გათავისუფლებისას სასამართლოს უფლება აქვს, იგი დამატებითი სასჯელისგანაც გაათავისუფლოს.
