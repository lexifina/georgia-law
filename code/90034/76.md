# მუხლი 76. ირიბი ჩვენება
1. ირიბია მოწმის ის ჩვენება, რომელიც ეფუძნება სხვა პირის მიერ გავრცელებულ ინფორმაციას.
2. ირიბი ჩვენება დასაშვებია მხოლოდ ინფორმაციის წყაროს მითითებით.
3. სასამართლოში საქმის არსებითი განხილვის დროს ირიბი ჩვენება დასაშვები მტკიცებულებაა, თ უ იგი დასტურდება სხვა მტკიცებულებათა ერთობლიობით.
