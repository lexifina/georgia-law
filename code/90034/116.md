# მუხლი 116. არასრულწლოვნის დაკითხვა
1. არასრულწლოვანი შეიძლება დაიკითხოს იმ შემთხვევაში, თუ მას შეუძლია სიტყვიერად ან სხვა ფორმით გადმოსცეს საქმისათვის მნიშვნელობის მქონე ინფორმაცია.
2. არასრულწლოვნის დაკითხვა ტარდება კანონიერი წარმომადგენლის ან ფსიქოლოგის დასწრებით.
3. 14 წლამდე პირის დაკითხვა შეიძლება მხოლოდ კანონიერი წარმომადგენლის თანხმობითა და დასწრებით; მას უფლება აქვს, გამოთქვას თავისი მოსაზრება და სასამართლოს ნებართვით დააზუსტოს დასმული შეკითხვა. 14 წლამდე მოწმეს განუმარტავენ მის მოვალეობას, თქვას მხოლოდ სიმართლე, მაგრამ არ აფრთხილებენ ჩვენების მიცემაზე უარის თქმისათვის, ცრუ ჩვენების და არსებითად ურთიერთსაწინააღმდეგო ჩვენებების მიცემისათვის სისხლისსამართლებრივი პასუხისმგებლობის თაობაზე.
