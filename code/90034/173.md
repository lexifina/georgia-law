# მუხლი 173. იმუნიტეტი დაკავებისას
არ შეიძლება დაკავებულ იქნენ: დიპლომატიური იმუნიტეტის მქონე პირი და მისი ოჯახის წევრები, საქართველოს პრეზიდენტი, საქართველოს პარლამენტის წევრი, საქართველოს კონტროლის პალატის თავმჯდომარე, საქართველოს სახალხო დამცველი, მოსამართლე. ეს აკრძალვა, საქართველოს პრეზიდენტის, დიპლომატიური იმუნიტეტის მქონე პირისა და მისი ოჯახის წევრების გარდა, არ ვრცელდება ამ კოდექსის 171-ე მუხლის მე-2 ნაწილის "ა" ქვეპუნქტით გათვალისწინებულ შემთხვევაზე.
