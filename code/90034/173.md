# მუხლი 173. იმუნიტეტი დაკავებისას
არ შეიძლება დაკავებულ იქნენ: დიპლომატიური იმუნიტეტის მქონე პირი და მისი ოჯახის წევრები, საქართველოს პრეზიდენტი, საქართველოს პარლამენტის წევრი, გენერალური აუდიტორი, საქართველოს სახალხო დამცველი, პერსონალურ მონაცემთა დაცვის ინსპექტორი, მოსამართლე. ეს აკრძალვა, საქართველოს პრეზიდენტის, დიპლომატიური იმუნიტეტის მქონე პირისა და მისი ოჯახის წევრების გარდა, არ ვრცელდება ამ კოდექსის 171-ე მუხლის მე-2 ნაწილის "ა" ქვეპუნქტით გათვალისწინებულ შემთხვევაზე.
საქართველოს 2012 წლის 2 2 ივნისის კანონი №6 550 - ვებგვერდი, 29 .0 6 .2012წ.
- საქართველოს 2014 წლის 1 აგვისტოს კანონი №2634- ვებგვერდი, 18.08.2014წ.
