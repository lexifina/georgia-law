# მუხლი 333. კოდექსის ამოქმედება
1. ეს კოდექსი, გარდა 310-ე მუხლის "ე" ქვეპუნქტისა, ამოქმედდეს 2010 წლის 1 ოქტომბრიდან.
2. ამ კოდექსის 310-ე მუხლის "ე" ქვეპუნქტი ამოქმედდეს 2012 წლის 1 ოქტომბრიდან.
3. ამ კოდექსის 254-ე და 331-ე მუხლები ძალადაკარგულად იქნეს ცნობილი 2012 წლის 1 ოქტომბრიდან.
4. ამ კოდექსის დებულებები ფარული საგამოძიებო მოქმედებების შესახებ ამოქმედდეს 2011 წლის 1 აპრილიდან. ეთხოვოს საქართველოს მთავრობას, 2011 წლის 1 იანვრამდე საქართველოს პარლამენტს განსახილველად წარუდგინოს "ფარული საგამოძიებო მოქმედებების შესახებ" საქართველოს კანონისა და "ოპერატიულ-სამძებრო საქმიანობის შესახებ" საქართველოს კანონის ძალადაკარგულად ცნობის თაობაზე საქართველოს კანონის პროექტები. "ფარული საგამოძიებო მოქმედებების შესახებ" საქართველოს კანონის ამოქმედებისთანავე ძალადაკარგულად იქნეს ცნობილი ამ კოდექსის დებულებები ფარული საგამოძიებო მოქმედებების შესახებ.
5. ამ კოდექსის ამოქმედებამდე საქართველოს იუსტიციის მინისტრმა განსაზღვროს ამ კოდექსის 35-ე-36-ე მუხლებით გათვალისწინებული საგამოძიებო და ტერიტორიული საგამოძიებო ქვემდებარეობა.
6. დაცვის მხარის უფლება ამ კოდექსის 180-ე მუხლის პირველი ნაწილით გათვალისწინებული შუამდგომლობის დაყენების თაობაზე ამოქმედდეს 2012 წლის 1 ოქტომბრიდან.
