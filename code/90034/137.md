# მუხლი 137. ფარული საგამოძიებო მოქმედების ჩატარების შესახებ გადაწყვეტილება
1. ფარული საგამოძიებო მოქმედების ჩატარების შესახებ გადაწყვეტილებას, გარდა ამ მუხლის მე-2 ნაწილით გათვალისწინებული შემთხვევებისა, იღებს პროკურორი.
2. ამ კოდექსის 136-ე მუხლის პირველი ნაწილის "ა" და "დ" ქვეპუნქტებით გათვალისწინებული საფუძვლების არსებობისას ან/და იმავე მუხლის მე-3 ნაწილით გათვალისწინებულ შემთხვევებში ფარული საგამოძიებო მოქმედება ტარდება პროკურორის შუამდგომლობის საფუძველზე სასამართლოს განჩინებით. სასამართლოს განჩინება შესაძლოა გაასაჩივროს პროკურორმა ამ კოდექსის 207-ე მუხლით გათვალისწინებული წესით. ვიზუალური კონტროლის განხორციელებისას ამ ნაწილით გათვალისწინებული განჩინება აუცილებელია მხოლოდ მაშინ, როდესაც ირღვევა პირადი ცხოვრების ხელშეუხებლობა, ვიზუალურ კონტროლს ახორციელებს ისეთი პირი, რომელსაც ამ ადგილას ყოფნის უფლება არა აქვს, და ის ხორციელდება ისეთ ადგილას, სადაც ვიზუალური კონტროლის ობიექტს პირადი ცხოვრების პატივისცემის გონივრული მოლოდინი აქვს.
3. შუამდგომლობაში დასაბუთებული უნდა იყოს, რომ მოთხოვნილი ფარული საგამოძიებო მოქმედებით მოპოვებული იქნება ის ინფორმაცია, რომლის სხვა საგამოძიებო მოქმედებით მოპოვება შეუძლებელია.
4. საქართველოს მთავარი პროკურორი უფლებამოსილია მოსამართლის მიმართ ამ კოდექსით გათვალისწინებული ფარული საგამოძიებო მოქმედების ჩატარების შესახებ განჩინების გამოტანის თაობაზე მოტივირებული შუამდგომლობით მიმართოს საქართველოს უზენაესი სასამართლოს თავმჯდომარეს. დაუშვებელია მოსამართლის მიმართ ფარული საგამოძიებო მოქმედების ჩატარება სასამართლოს სათათბირო ოთახში.
