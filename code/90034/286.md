# მუხლი 286. განაჩენის აღსრულება სხვა აღუსრულებელი განაჩენის არსებობის დროს
თუ მსჯავრდებულის მიმართ არსებობს რამდენიმე აღუსრულებელი განაჩენი, სასჯელაღსრულების დეპარტამენტის თავმჯდომარის შუამდგომლობით სასჯელის მოხდის ადგილის მიხედვით პირველი ინსტანციის სასამართლოს ზეპირი მოსმენის გარეშე გამოაქვს განჩინება მსჯავრდებულისათვის სასჯელის ყველა აღნიშნული განაჩენის მიხედვით განსაზღვრის შესახებ.
