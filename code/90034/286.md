# მუხლი 286. განაჩენის აღსრულება სხვა აღუსრულებელი განაჩენის არსებობის დროს
თუ მსჯავრდებულის მიმართ არსებობს რამდენიმე აღუსრულებელი განაჩენი, საქართველოს სასჯელაღსრულებისა და პრობაციის სამინისტროს პენიტენციური დეპარტამენტის დირექტორის შუამდგომლობით სასჯელის მოხდის ადგილის მიხედვით პირველი ინსტანციის სასამართლოს ზეპირი მოსმენის გარეშე გამოაქვს განჩინება მსჯავრდებულისათვის სასჯელის ყველა აღნიშნული განაჩენის მიხედვით განსაზღვრის შესახებ.
- საქართველოს 2015 წლის 1 მაისის კანონი №3528 - ვებგვერდი, 18.05.2015წ.
