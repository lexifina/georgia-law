# მუხლი 118². პირის იდენტიფიცირების შეზღუდვის გამოყენების ვადა
1. ოპერატიულ-სამძებრო ღონისძიებაში ან ფარულ საგამოძიებო მოქმედებაში მონაწილე პირის იდენტიფიცირების შეზღუდვა შეიძლება გამოყენებულ იქნეს უვადოდ.
2. პროკურორი უფლებამოსილია სისხლის სამართლის საქმის განხილვის ნებისმიერ ეტაპზე საქართველოს გენერალური პროკურორის ან მისი მოადგილის თანხმობით, დასაბუთებული გადაწყვეტილებით გააუქმოს პირის იდენტიფიცირების შეზღუდვა.
- საქართველოს 2025 წლის 2 ივლისის კანონი №923 - ვებგვერდი, 03.07.2025წ.
