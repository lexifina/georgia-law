# მუხლი 71. ინფორმაციის დაცვა
დაცვის სპეციალური ღონისძიების გამოყენების შესახებ გადაწყვეტილება საჯარო არ არის. იგი ხელმისაწვდომია მხოლოდ გადაწყვეტილების მიმღები მოსამართლის, შუამდგომლობის განხილვაში მონაწილე პირებისა და იმ უფლებამოსილი თანამდებობის პირისათვის, რომელმაც უნდა აღასრულოს სასამართლოს გადაწყვეტილება.
