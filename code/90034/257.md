# მუხლი 257. დამატებითი განმარტებების მიღება
თუ სასამართლო განხილვის მიმდინარეობისას ან თათბირის პროცესში ნაფიცი მსაჯული მიიჩნევს, რომ სჭირდება დამატებითი განმარტებები კანონის, ფაქტობრივი გარემოებების, დასკვნითი სიტყვის შესახებ, იგი სხდომის თავმჯდომარეს ერთჯერადად წერილობით წარუდგენს დამატებითი განმარტებების თაობაზე მოთხოვნას შესაბამისი კითხვების მითითებით. სხდომის თავმჯდომარე ამ კოდექსით დადგენილი წესით, მხარეთა პოზიციების გათვალისწინებით იღებს გადაწყვეტილებას აღნიშნულ მოთხოვნასთან დაკავშირებით.
