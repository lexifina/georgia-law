# მუხლი 28². კეიპტაუნის კონვენციით გათვალისწინებული საავიაციო ობიექტის საქართველოს სამოქალაქო საჰაერო ხომალდების სახელმწიფო რეესტრიდან ამოღება და საქართველოს საბაჟო ტერიტორიიდან გატანა
1. კეიპტაუნის კონვენციის მე-11 მუხლით გათვალისწინებული დეფოლტის არსებობისას სააგენტო უზრუნველყოფს საავიაციო ობიექტის საქართველოს სამოქალაქო საჰაერო ხომალდების სახელმწიფო რეესტრიდან ამოღებას IDERA-ს დოკუმენტის საფუძველზე ან საავიაციო ობიექტის საქართველოს სამოქალაქო საჰაერო ხომალდების სახელმწიფო რეესტრიდან ამოღების, როგორც კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენების, შესახებ სასამართლოს ბრძანების საფუძველზე, იმავე კონვენციით განსაზღვრული კრედიტორის მიერ ამ ბრძანების წარდგენიდან 5 სამუშაო დღის ვადაში.
2. IDERA-ს დოკუმენტი საავიაციო ობიექტის საქართველოს სამოქალაქო საჰაერო ხომალდების სახელმწიფო რეესტრიდან ამოღების საფუძველია, თუ:
ა) იგი რეგისტრირებულია სააგენტოში სააგენტოს მიერ დადგენილი წესის შესაბამისად;
ბ) კეიპტაუნის კონვენციით განსაზღვრული კრედიტორი, რომლის მიმართაც გაცემულია ეს დოკუმენტი, წარადგენს მტკიცებულებას − იმის დამადასტურებელ დოკუმენტს, რომ მას საავიაციო ობიექტთან დაკავშირებით აქვს უპირატესი საერთაშორისო ინტერესი ან ასეთი უპირატესი საერთაშორისო ინტერესის მქონე პირს გაცემული აქვს თანხმობა საავიაციო ობიექტის საქართველოს სამოქალაქო საჰაერო ხომალდების სახელმწიფო რეესტრიდან ამოღებასა და საქართველოს საბაჟო ტერიტორიიდან გატანაზე.
შენიშვნა: ამ ქვეპუნქტის მიზნებისთვის კრედიტორის მიერ უპირატესი საერთაშორისო ინტერესის ქონის დამადასტურებელი დოკუმენტია კეიპტაუნის კონვენციით გათვალისწინებული საერთაშორისო რეესტრის მიერ გაცემული პრიორიტეტის ძიების სერტიფიკატი.
3. დაუშვებელია საავიაციო ობიექტის საქართველოს საბაჟო ტერიტორიიდან გატანისთვის ხელის შეშლა იმ საფუძვლით, რომ კეიპტაუნის კონვენციით განსაზღვრულ კრედიტორს მესამე პირების წინაშე ვადამოსული ვალდებულებები აკისრია.
