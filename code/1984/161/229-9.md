# მუხლი 229⁹. საქართველოს განათლების, მეცნიერებისა და ახალგაზრდობის სამინისტროს მიერ განსახილველი ადმინისტრაციული სამართალდარღვევის საქმე
1. ამ კოდექსის 172¹⁰ მუხლის მე-3 ნაწილით გათვალისწინებული ადმინისტრაციული სამართალდარღვევის საქმეს განიხილავს და სამართალდამრღვევს შესაბამის ადმინისტრაციულ სახდელს შეუფარდებს საქართველოს განათლების, მეცნიერებისა და ახალგაზრდობის სამინისტროს მიერ უფლებამოსილი პირი.
2. ამ კოდექსის 172¹⁰ მუხლის მე-3 ნაწილით გათვალისწინებული ადმინისტრაციული სამართალდარღვევის ჩადენისას, თუ ეს ადმინისტრაციული სამართალდარღვევა ადმინისტრაციულ გამოკვლევას არ საჭიროებს, საქართველოს განათლების, მეცნიერებისა და ახალგაზრდობის სამინისტროს მიერ უფლებამოსილი პირი აღნიშნული ადმინისტრაციული სამართალდარღვევის საქმეს ადგილზე განიხილავს და სამართალდამრღვევს ადგილზევე შეუფარდებს ადმინისტრაციულ სახდელს.
