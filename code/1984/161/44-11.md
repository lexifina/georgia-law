# მუხლი 44¹¹. "წამლისა და ფარმაცევტული საქმიანობის შესახებ" საქართველოს კანონით პირველი ჯგუფისთვის მიკუთვნებული ფარმაცევტული პროდუქტის დანიშვნის წესისა და გამოწერისა და გაფორმების წესის დარღვევა
1. "წამლისა და ფარმაცევტული საქმიანობის შესახებ" საქართველოს კანონით პირველი ჯგუფისთვის მიკუთვნებული ფარმაცევტული პროდუქტის დანიშვნის წესის დარღვევა −
