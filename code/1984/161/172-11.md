# მუხლი 172¹¹. უმაღლესი ან პროფესიული საგანმანათლებლო დაწესებულების მიერ ინფორმაციის აღრიცხვასთან დაკავშირებული ვალდებულების შეუსრულებლობა
1. უმაღლესი ან პროფესიული საგანმანათლებლო დაწესებულების მიერ უცხოელი სტუდენტის/პროფესიული სტუდენტის შესახებ საქართველოს კანონმდებლობით განსაზღვრული ინფორმაციის უმაღლესი ან პროფესიული განათლების მართვის საინფორმაციო სისტემაში აღურიცხველობა ან/და აღრიცხვის წესის დარღვევა −
გამოიწვევს უმაღლესი ან პროფესიული საგანმანათლებლო დაწესებულების გაფრთხილებას ან დაჯარიმებას შესაბამის სისტემაში აღურიცხავი ან არასრულად აღრიცხული უცხოელი სტუდენტის/ პროფესიული სტუდენტის წლიური სწავლის საფასურის ორმაგი ოდენობიდან ხუთმაგ ოდენობამდე (გამოვლენილი დარღვევის რაოდენობის პროპორციულად).
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ადმინისტრაციული სამართალდარღვევის ჩადენისთვის ადმინისტრაციულსახდელდადებული პირის მიერ იმავე ნაწილით განსაზღვრული ადმინისტრაციული სამართალდარღვევის ჩადენა −
გამოიწვევს უმაღლესი ან პროფესიული საგანმანათლებლო დაწესებულების დაჯარიმებას შესაბამის სისტემაში აღურიცხავი ან არასრულად აღრიცხული უცხოელი სტუდენტის/პროფესიული სტუდენტის წლიური სწავლის საფასურის ორმაგი ოდენობიდან ხუთმაგ ოდენობამდე (გამოვლენილი დარღვევის რაოდენობის პროპორციულად).
3. ამ ნაწილით ან ამ მუხლის მე-2 ნაწილით გათვალისწინებული ადმინისტრაციული სამართალდარღვევის ჩადენისთვის ადმინისტრაციულსახდელდადებული პირის მიერ ამავე მუხლის პირველი ნაწილით განსაზღვრული ადმინისტრაციული სამართალდარღვევის ჩადენა −
გამოიწვევს უმაღლესი ან პროფესიული საგანმანათლებლო დაწესებულების დაჯარიმებას შესაბამის სისტემაში აღურიცხავი ან არასრულად აღრიცხული უცხოელი სტუდენტის/პროფესიული სტუდენტის წლიური სწავლის საფასურის ორმაგი ოდენობიდან ექვსმაგ ოდენობამდე (გამოვლენილი დარღვევის რაოდენობის პროპორციულად) ან უმაღლესი ან პროფესიული საგანმანათლებლო დაწესებულებისთვის უცხოელი სტუდენტის/პროფესიული სტუდენტის მიღების უფლების ერთიდან სამ სასწავლო წლამდე ვადით შეზღუდვას.
შენიშვნა: ამ მუხლით გათვალისწინებული პასუხისმგებლობის დაკისრება უმაღლეს ან პროფესიულ საგანმანათლებლო დაწესებულებას არ ათავისუფლებს უცხოელი სტუდენტის/პროფესიული სტუდენტის შესახებ საქართველოს კანონმდებლობით განსაზღვრული ინფორმაციის უმაღლესი ან პროფესიული განათლების მართვის საინფორმაციო სისტემაში აღრიცხვის ვალდებულებისგან.
