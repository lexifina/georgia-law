# მუხლი 290¹¹. საქართველოს რეგიონული განვითარებისა და ინფრასტრუქტურის სამინისტროს სისტემაში შემავალი შესაბამისი ორგანოსთვის სათანადო ინფორმაციის ხელმისაწვდომობის უზრუნველყოფა
ამ კოდექსის 194² მუხლით გათვალისწინებული ადმინისტრაციული სამართალდარღვევის საქმის წარმოების საქართველოს რეგიონული განვითარებისა და ინფრასტრუქტურის სამინისტროს სისტემაში შემავალი შესაბამისი ორგანოს მიერ განსახორციელებლად საქართველოს იუსტიციის სამინისტროს მმართველობის სფეროში მოქმედი საჯარო სამართლის იურიდიული პირი − სახელმწიფო სერვისების განვითარების სააგენტო უფლებამოსილია აღნიშნულ ორგანოს ამ სააგენტოს მონაცემთა ბაზიდან მიაწოდოს სამართალდამრღვევის იდენტიფიცირებისთვის აუცილებელი პერსონალური მონაცემები. დაუშვებელია, ეს ინფორმაცია საქართველოს რეგიონული განვითარებისა და ინფრასტრუქტურის სამინისტროს სისტემაში შემავალმა შესაბამისმა ორგანომ სხვას გადასცეს ან სხვა ფორმით გაუზიაროს.
