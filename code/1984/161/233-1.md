# მუხლი 233¹. შეჯიბრებითობა და სასამართლოს მიერ ადმინისტრაციული სამართალდარღვევის საქმის გარემოებების გამოკვლევა
1. სასამართლოში ადმინისტრაციული სამართალდარღვევის საქმის წარმოება ხორციელდება მხარეთა თანასწორობისა და შეჯიბრებითობის საფუძველზე. მხარეს უფლება აქვს, დააყენოს შუამდგომლობა, მოიპოვოს, სასამართლოს მეშვეობით გამოითხოვოს, წარადგინოს და გამოიკვლიოს ყველა შესაბამისი მტკიცებულება.
2. სასამართლო უფლებამოსილია თავისი ინიციატივით მიიღოს გადაწყვეტილება დამატებითი ინფორმაციის ან მტკიცებულების წარმოსადგენად.
- საქართველოს 2025 წლის 6 თებერვლის კანონი №273 - ვებგვერდი, 06.02.2025წ.
