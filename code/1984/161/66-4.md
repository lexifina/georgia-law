# მუხლი 66⁴. "გადაშენების საფრთხის წინაშე მყოფი ველური ფლორისა და ფაუნის სახეობებით საერთაშორისო ვაჭრობის შესახებ" კონვენციის (CITES) დანართებში შეტანილი სახეობების, მათი ნაწილებისა და დერივატების ექსპორტის, იმპორტის, რეექსპორტისა და ზღვიდან ინტროდუქციის ნებართვის პირობების დარღვევა
"გადაშენების საფრთხის წინაშე მყოფი ველური ფლორისა და ფაუნის სახეობებით საერთაშორისო ვაჭრობის შესახებ" კონვენციის (CITES) დანართებში შეტანილი სახეობების, მათი ნაწილებისა და დერივატების ექსპორტის, იმპორტის, რეექსპორტისა და ზღვიდან ინტროდუქციის ნებართვის პირობების დარღვევა -
