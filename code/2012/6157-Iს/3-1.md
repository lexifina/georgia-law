# მუხლი 3¹. ბაზარზე ზედამხედველობის ეროვნული სტრატეგია
1. ბაზარზე ზედამხედველობის ეროვნული სტრატეგია განსაზღვრავს რეგულირებული სფეროსთვის მიკუთვნებული პროდუქტების ბაზარზე ზედამხედველობის განხორციელების პოლიტიკის პრიორიტეტებს, მიზნებსა და ამოცანებს, აგრეთვე აყალიბებს მიდგომებს დასახული მიზნებისა და ამოცანების განსახორციელებლად.
2. საქართველოს ეკონომიკისა და მდგრადი განვითარების სამინისტრო უზრუნველყოფს ბაზარზე ზედამხედველობის ეროვნული სტრატეგიის შემუშავებას სულ მცირე 4 წელიწადში ერთხელ.
- საქართველოს 2026 წლის 1 აპრილის კანონი №1447 - ვებგვერდი, 03.04.2026წ.
