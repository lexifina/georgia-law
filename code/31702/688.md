# მუხლი 688. ტვირთის მიტანის ვადის გადაცილება
ტვირთის მიტანის ვადის გადაცილებად ითვლება, როცა ტვირთი არ არის მიტანილი შეთანხმებულ ვადაში, ან, თუ ვადა არ იყო დათქმული, _ გადასაზიდად საჭირო ჩვეულებრივ დროში _ იმ გარემოებათა გათვალისწინებით, რომლებიც დაკავშირებულია ნაწილ-ნაწილ დატვირთვისას ამ ნაწილების შესაკრებად აუცილებელი დროის განსაზღვრასთან, თუ დარღვეულია ვადა, რომელიც წინდახედულ გადამზიდველს უნდა დაეცვა ჩვეულებრივ შემთხვევებში.
