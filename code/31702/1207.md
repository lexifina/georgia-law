# მუხლი 1207. მშობლის უფლებაჩამორთმეული პირის შვილის უფლებები
მშობლის უფლებაჩამორთმეული მშობელი კარგავს ნათესაობაზე დამყარებულ ყველა უფლებას იმ შვილთან ურთიერთობაში, რომლის მიმართაც მას ჩამორთმეული აქვს მშობლის უფლება. შვილი, რომლის მშობელსაც ჩამოერთვა მშობლის უფლება, ინარჩუნებს უფლებას საცხოვრებელ ადგილზე, აგრეთვე ნათესაობით დამყარებულ ქონებრივ უფლებებს, მათ შორის _ მემკვიდრეობის მიღების უფლებას.
