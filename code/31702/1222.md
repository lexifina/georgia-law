# მუხლი 1222. ალიმენტის ოდენობის შეცვლა მატერიალური თუ ოჯახური მდგომარეობის შეცვლის გამო
თუ შეიცვალა მშობლების ან შვილების მატერიალური თუ ოჯახური მდგომარეობა მას შემდეგ, რაც სასამართლო დაადგენს იმ თანხის ოდენობას, რომელიც უნდა გადაიხადონ მშობლებმა სრულწლოვანი შრომისუუნარო შვილების სასარგებლოდ, ან შვილებმა _ შრომისუუნარო მშობლების სასარგებლოდ, რომლებიც დახმარებას საჭიროებენ, სასამართლოს შეუძლია ერთ-ერთი მათგანის სარჩელით შეცვალოს ალიმენტის დადგენილი ოდენობა.
