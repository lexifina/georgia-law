# მუხლი 1138. განქორწინების რეგისტრაცია
1. სასამართლოს გადაწყვეტილების საფუძველზე განქორწინების რეგისტრაციას ახდენს იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელი ტერიტორიული ორგანო ორივე ან ერთ-ერთი მეუღლის განცხადებით.
2. ერთ-ერთი მეუღლის განცხადებით განქორწინების რეგისტრაციის შემთხვევაში იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელი ტერიტორიული ორგანო ამის შესახებ აცნობებს მეორე მეუღლეს, თუ ცნობილია მისი და იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელი ტერიტორიული ორგანოს მისამართი, რომელმაც მოახდინა ქორწინების რეგისტრაცია.
- საქართველოს 2004 წლის 24 ივნისის კანონი №179 - სსმ I, №19, 15.07.2004 წ., მუხ.79
