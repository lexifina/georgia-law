# მუხლი 1138. განქორწინების რეგისტრაცია
1. სასამართლოს გადაწყვეტილების საფუძველზე განქორწინების რეგისტრაციას ახდენს მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანო ორივე ან ერთ-ერთი მეუღლის განცხადებით.
2. ერთ-ერთი მეუღლის განცხადებით განქორწინების რეგისტრაციის შემთხვევაში მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანო აცნობებს ამის შესახებ მეორე მეუღლეს, თუ ცნობილია მისი და აგრეთვე მოქალაქეობრივი მდგომარეობის რეგისტრაციის იმ ორგანოს მისამართი, რომელმაც მოახდინა ქორწინების რეგისტრაცია.
