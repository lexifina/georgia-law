# მუხლი 1044. ავტორის პირადი არაქონებრივი უფლებების განხორციელება
1. 1043-ე მუხლის პირველი ნაწილის "ზ" და "თ" ქვეპუნქტებით გათვალისწინებულ უფლებათა განხორციელება ხდება ავტორის ხარჯზე. ავტორს უფლება აქვს აგრეთვე თავისი ხარჯებით ამოიღოს მიმოქცევიდან ადრე დამზადებული, გავრცელებისათვის გამიზნული ნაწარმოების ეგზემპლარები.
2. პირადი უფლებები ავტორს ეკუთვნის მისი ქონებრივი უფლებებისაგან დამოუკიდებლად და უნარჩუნდება ამ უფლებების დათმობის შემთხვევაშიც.
3. პირად უფლებათა განხორციელება ავტორის გარდაცვალების შემდეგ ხდება კანონით დადგენილი წესით.
