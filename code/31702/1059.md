# მუხლი 1059. საეთერო მაუწყებლობის ორგანიზაციის მიერ ნაწარმოების მოკლევადიანი ჩაწერა
საეთერო მაუწყებლობის ორგანიზაციას შეუძლია ავტორის ან საავტორო უფლების სხვა მფლობელის თანხმობისა და მისთვის დამატებითი ჰონორარის გადახდის გარეშე მოკლევადიანი სარგებლობისათვის ჩაწეროს ის ნაწარმოები, რომლის მიმართაც ამ ორგანიზაციამ მიიღო ეთერში გადაცემის უფლება, შემდეგი პირობების დაცვით:
ა ) საეთერო მაუწყებლობის ორგანიზაციის მიერ ჩანაწერის დამზადება საკუთარი მოწყობილობის მეშვეობით საკუთარი გადაცემისათვის;
ბ ) ასეთი ჩანაწერის განადგურება დამზადებიდან ექვსი თვის გასვლის შემდეგ, თუ უფრო ხანგრძლივი ვადა არ იყო შეთანხმებული ჩაწერილი ნაწარმოების ავტორთან; ასეთი ჩანაწერი ნაწარმოების ავტორის თანხმობის გარეშე შეიძლება შენახულ იქნეს ოფიციალურ არქივში, თუ ჩანაწერი მხოლოდ და მხოლოდ დოკუმენტური ხასიათისაა.
