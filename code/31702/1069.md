# მუხლი 1069. ჩვეულებრივი ლიცენზია
1. ჩვეულებრივ უფლებათა გადაცემის საავტორო ხელშეკრულების მიხედვით (ჩვეულებრივი ლიცენზია) ავტორი ან საავტორო უფლებათა სხვა მფლობელი ნებას რთავს ლიცენზიატს გამოიყენოს ნაწარმოები იმ პირთა თანაბრად, რომლებმაც იმავე საშუალებებით მიიღეს ასეთი ნაწარმოების გამოყენების ნებართვა.
2. საავტორო ხელშეკრულებით გადაცემული უფლება ჩაითვლება ჩვეულებრივ უფლებად, თუ ხელშეკრულებით სხვა რამ არ არის გათვალისწინებული.
