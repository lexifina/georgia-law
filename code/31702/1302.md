# მუხლი 1302. მეურვეობის შეწყვეტის საფუძვლები
1. მეურვეობა შეწყდება:
ა) თუ გარდაიცვალა სამეურვეო პირი;
ბ) თუ სამეურვეო არასრულწლოვანმა პირმა მიაღწია შვიდი წლის ასაკს, გარდა იმ შემთხვევებისა, როდესაც ის კანონით დადგენილი წესით ქმედუუნაროდ არის აღიარებული;
გ) თუ სამეურვეო არასრულწლოვანი პირი, რომელსაც არ შესრულებია შვიდი წელი, აღსაზრდელად მშობელს დაუბრუნდა;
დ) თუ ქმედუუნაროდ აღიარებული სამეურვეო პირი სასამართლომ ცნო ქმედუნარიანად.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებულ შემთხვევებში მეურვეობა შეწყდება მეურვეობისა და მზრუნველობის ორგანოს გადაწყვეტილებით.
