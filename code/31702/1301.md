# მუხლი 1301. მზრუნველის გათავისუფლება მოვალეობისაგან სამზრუნველო პირის თხოვნით
სრულწლოვანი პირის მზრუნველი შეიძლება გათავისუფლდეს თავისი მოვალეობისაგან სამზრუნველო პირის თხოვნით. ასეთ შემთხვევაში მეურვეობისა და მზრუნველობის ორგანოს შეუძლია სამზრუნველო პირთან შეთანხმებით მას მზრუნველად სხვა პირი დაუნიშნოს.
