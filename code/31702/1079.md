# მუხლი 1079. მომიჯნავე უფლებათა დაცვის ნიშანი
მომიჯნავე უფლებათა წარმოშობისა და განხორციელებისათვის არ არის სავალდებულო რაიმე ფორმალობათა დაცვა. ფონოგრამის ან ვიდეოგრამის დამამზადებელს ან შემსრულებელს თავისი უფლების გაცხადებისათვის შეუძლია გამოიყენოს მომიჯნავე უფლებათა დაცვის ნიშანი, რომელიც მოთავსდება ფონოგრამის ან ვიდეოგრამის ყოველ ეგზემპლარზე ან/და მის ფუტლარზე და შედგება სამი ელემენტისაგან:
ა ) ლათინური ასო P წრეწირში: P ;
ბ ) მომიჯნავე განსაკუთრებული უფლების მფლობელის სახელი (დასახელება);
გ ) ფონოგრამის ან ვიდეოგრამის პირველი გამოცემის წელი.
