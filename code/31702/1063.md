# მუხლი 1063. საავტორო უფლებათა მოქმედების ვადები
1. საავტორო უფლება ნაწარმოებზე, რომელიც ანონიმურად ან ფსევდონიმით გამოქვეყნდა, მოქმედებს ორმოცდაათი წლის განმავლობაში ასეთი ნაწარმოების მართლზომიერად გამოქვეყნების თარიღიდან. თუ აღნიშნულ ვადაში ანონიმურად ან ფსევდონიმით გამოქვეყნებული ნაწარმოების ავტორი გაამჟღავნებს თავის ვინაობას, ან თუ მისი ვინაობა ეჭვს არ იწვევს, მაშინ გამოიყენება 1062-ე მუხლის პირველ ნაწილში აღნიშნული დებულება.
2. საავტორო უფლება თანაავტორობით შექმნილ ნაწარმოებზე მოქმედებს მთელი სიცოცხლის მანძილზე და უკანასკნელი ავტორის გარდაცვალებიდან ორმოცდაათი წლის განმავლობაში.
3. ავტორის გარდაცვალების შემდეგ პირველად გამოქვეყნებულ ნაწარმოებზე საავტორო უფლება მოქმედებს ორმოცდაათი წლის განმავლობაში მისი გამოქვეყნებიდან.
4. საავტორო უფლება 1037-ე მუხლში აღნიშნულ ნაწარმოებებზე მოქმედებს ორმოცდაათი წლის განმავლობაში მათი გამოქვეყნების თარიღიდან, ხოლო, თუ ნაწარმოები არ იყო გამოქვეყნებული, _ მისი შექმნის თარიღიდან.
5. აუდიოვიზუალური ნაწარმოების დამამზადებლის (პროდიუსერის) საავტორო უფლება მოქმედებს ორმოცდაათი წლის განმავლობაში მისი გამოქვეყნების თარიღიდან, ხოლო, თუ ნაწარმოები არ იყო გამოქვეყნებული, _ მისი შექმნის თარიღიდან.
