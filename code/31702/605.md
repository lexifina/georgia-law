# მუხლი 605. საიჯარო ურთიერთობის შეწყვეტა ვადის გასვლის გამო
საიჯარო ურთიერთობა წყდება ხელშეკრულების ვადის გასვლით. სამ წელზე მეტი ვადით დადებული ხელშეკრულება შეიძლება გაგრძელდეს განუსაზღვრელი ვადით, თუ ერთი მხარის წინადადებაზე _ გაგრძელდეს საიჯარო ურთიერთობა _ მეორე მხარე უარს არ იტყვის სამი თვის განმავლობაში. წინადადება და მასზე უარი უნდა გაფორმდეს წერილობით.
