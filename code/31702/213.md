# მუხლი 213. ინდივიდუალური საკუთრების გასხვისების დაუშვებლობა საერთო საკუთრების შესაბამისი წილის გარეშე
1. არ შეიძლება ინდივიდუალური საკუთრების გასხვისება, დაგირავება ან სხვაგვარად დატვირთვა საერთო საკუთრების შესაბამისი წილის გაუთვალისწინებლად.
[1. არ შეიძლება ინდივიდუალური საკუთრების გასხვისება, იპოთეკით ან სხვაგვარად დატვირთვა საერთო საკუთრების შესაბამისი წილის გაუთვალისწინებლად. (ამოქმედდეს 2006 წლის 1 მარტიდან) ]
