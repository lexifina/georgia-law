# მუხლი 1253. მეურვეობაში მყოფი ბავშვის შვილება
1. იმ ბავშვის შვილად აყვანისათვის, რომელიც მეურვეობაში (მზრუნველობაში) იმყოფება, თუ მას მშობლები არა ჰყავს, აუცილებელია მეურვის (მზრუნველის) წერილობითი თანხმობა.
2. საბავშვო დაწესებულების ადმინისტრაციამ ამ დაწესებულებაში ბავშვის მოყვანისას უნდა გაარკვიოს, თანახმა არის თუ არა მშობელი ბავშვის გაშვილებაზე.
- საქართველოს 1999 წლის 9 ივნისის კანონი №2078 - სსმ I, №24(31), 26.06.1999 წ., მუხ.112
