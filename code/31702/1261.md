# მუხლი 1261. შვილად აყვანის გაუქმება
1. შვილად აყვანა შეიძლება გაუქმდეს, თუ მშვილებელი თავს არიდებს მასზე დაკისრებულ მშობლის მოვალეობათა შესრულებას, სასტიკად ეპყრობა ნაშვილებს, არის ნარკომანი ან ქრონიკული ალკოჰოლიკი.
2. ნაშვილების ინტერესებიდან გამომდინარე და პატივსადები მიზეზების არსებობისას სასამართლოს უფლება აქვს გააუქმოს შვილად აყვანა სხვა საფუძვლებითაც.
