# მუხლი 1280. მეურვის დანიშვნა ქმედუუნაროდ აღიარებული პირისათვის
სასამართლო, რომელმაც გამოიტანა გადაწყვეტილება პირის ქმედუუნაროდ აღიარების თაობაზე, მოვალეა გადაწყვეტილების კანონიერ ძალაში შესვლიდან არა უგვიანეს სამი დღისა, აცნობოს ამის შესახებ მეურვეობისა და მზრუნველობის ორგანოს იმ პირის საცხოვრებელი ადგილის მიხედვით, რომელიც ქმედუუნაროდ აღიარების გამო საჭიროებს მეურვეს.
