# მუხლი 1324. სამკვიდროს გახსნის ადგილი
1. სამკვიდროს გახსნის ადგილად ითვლება მამკვიდრებლის საცხოვრებელი ადგილი, ხოლო, თუ იგი ცნობილი არ არის, _ სამკვიდროს ადგილსამყოფელი.
2. თუ სამკვიდრო სხვადასხვა ადგილას იმყოფება, მაშინ სამკვიდროს გახსნის ადგილად მიიჩნევა უძრავი ქონების ან მისი ფასეული ნაწილის ადგილსამყოფელი, ხოლო თუ უძრავი ქონება არ არის, მაშინ _ მოძრავი ქონების ან მისი ძირითადი ნაწილის ადგილსამყოფელი.
