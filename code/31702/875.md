# მუხლი 875. შემნახველი წიგნაკი
საკრედიტო დაწესებულება შემნახველი წიგნაკის გაცემისას უფლებამოსილია შეავსოს იგი როგორც სახელობით, ასევე წარმომდგენზე. თუ წარმომდგენი არ არის უფლებამოსილი, საკრედიტო დაწესებულება პასუხისმგებლობისაგან განთავისუფლდება მხოლოდ მაშინ, როცა წიგნაკის შევსებისას იგი არ მოქმედებდა განზრახ ან უხეში გაუფრთხილებლობით.
