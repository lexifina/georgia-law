# მუხლი 1204. არასრულწლოვანი შვილის დაბრუნების მოთხოვნის უფლება
1. მშობლებს უფლება აქვთ სასამართლოს წესით მოსთხოვონ არასრულწლოვანი შვილის დაბრუნება იმ პირს, რომელიც მას თავისთან ამყოფებს კანონიერი საფუძვლის ან სასამართლოს გადაწყვეტილების გარეშე.
2. სასამართლომ შეიძლება არ დააკმაყოფილოს მშობლების ასეთი მოთხოვნა, თუ იგი ეწინააღმდეგება შვილის ინტერესებს.
[მუხლი 1204. არასრულწლოვანი შვილის დაბრუნების მოთხოვნის უფლება
მშობლებს უფლება აქვთ, მოითხოვონ არასრულწლოვანი შვილის დაბრუნება იმ პირისაგან, რომელიც მას თავისთან ამყოფებს კანონიერი საფუძვლის გარეშე. (ამოქმედდეს 2008 წლის 1 მაისიდან)]
