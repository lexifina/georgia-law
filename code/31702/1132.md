# მუხლი 1132. განქორწინების შესახებ სასამართლოს გადაწყვეტილების აღსრულება
1. განქორწინების შესახებ სასამართლოს კანონიერ ძალაში შესული გადაწყვეტილება აღსრულდება ერთ-ერთი ან ორივე მეუღლის მოთხოვნით, გადაწყვეტილების კანონიერ ძალაში შესვლის დღიდან არა უგვიანეს 3 წლისა, იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოში რეგისტრაციის საშუალებით.
2. ქორწინება შეწყვეტილად ითვლება იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოში განქორწინების რეგისტრაციის მომენტიდან.
- საქართველოს 2004 წლის 24 ივნისის კანონი №179 - სსმ I, №19, 15.07.2004 წ., მუხ.79
