# მუხლი 1132. განქორწინების შესახებ სასამართლოს გადაწყვეტილების აღსრულება
1. განქორწინების შესახებ სასამართლოს გადაწყვეტილება, რომელიც კანონიერ ძალაშია შესული, აღსრულდება ერთ-ერთი ან ორივე მეუღლის მოთხოვნით არა უგვიანეს სამი წლისა კანონიერ ძალაში გადაწყვეტილების შესვლის დღიდან მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში რეგისტრაციის საშუალებით.
2. ქორწინება შეწყვეტილად ითვლება მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში განქორწინების რეგისტრაციის მომენტიდან.
