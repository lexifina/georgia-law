# მუხლი 1085. ფონოგრამის დამამზადებელი
ფონოგრამის დამამზადებლად ჩაითვლება ფიზიკური ან იურიდიული პირი, რომელმაც თავის თავზე აიღო ინიციატივა და პასუხისმგებლობა შესრულების ან სხვა ხმების პირველი ხმოვანი ჩანაწერის განხორციელებისათვის; თუ არ არსებობს საწინააღმდეგო დასაბუთება, ფონოგრამის დამამზადებლად მიიჩნევა ფიზიკური ან იურიდიული პირი, რომელიც აღნიშნულია ამ ფონოგრამაზე ან მის ფუტლარზე სათანადო წესით.
