# მუხლი 1151. ქორწინების რეგისტრაციის მნიშვნელობა
მეუღლეთა უფლება-მოვალეობებს წარმოშობს მხოლოდ მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში რეგისტრირებული დაქორწინება.
