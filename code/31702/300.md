# მუხლი 300. იპოთეკით დატვირთული ნივთის რეალიზაციის მოთხოვნა
1. თუ მოვალე გააჭიანურებს იმ მოთხოვნის დაკმაყოფილებას, რომლის უზრუნველყოფის საშუალებაც იპოთეკაა, იპოთეკარი უფლებამოსილია მოითხოვოს უძრავი ნივთის რეალიზაცია.
2. რეალიზაცია ხორციელდება ამ თავში მოცემული წესებისა და "სააღსრულებო წარმოებათა შესახებ" საქართველოს კანონის ნორმების მიხედვით. "სააღსრულებო წარმოებათა შესახებ" საქართველოს კანონის ნორმები გამოიყენება როგორც სპეციალური ნორმები.
- საქართველოს 2000 წლის 5 დეკემბრის კანონი №638 - სსმ I, №48, 16.12.2000 წ., მუხ.138
