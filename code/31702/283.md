# მუხლი 283. გირაოს მართლზომიერი გასხვისების შედეგები
1. გირაოს მართლზომიერი გასხვისებითა და გადაცემით შემძენზე გადადის დაუტვირთავი საკუთრება.
2. თუ საგანი, როგორც გირაო, ისე გასხვისდება, რომ გამსხვისებელს არა აქვს გირავნობის უფლება, ან, თუ მოთხოვნის დასაკმაყოფილებლად რეალიზაცია არ არის აუცილებელი, კეთილსინდისიერი შემძენი მაინც დაუტვირთავ საკუთრებას იძენს.
