# მუხლი 1087. ვიდეოგრამის დამამზადებელი
ვიდეოგრამის დამამზადებლად ჩაითვლება ფიზიკური ან იურიდიული პირი, რომელმაც თავის თავზე აიღო ინიციატივა და პასუხისმგებლობა გამოსახულებათა თანამიმდევრობის პირველი ჩანაწერის განხორციელებისათვის ხმის თანხლებით ან უამისოდ. თუ არ არსებობს საწინააღმდეგო დასაბუთება, ვიდეოგრამის დამამზადებლად მიიჩნევა ფიზიკური ან იურიდიული პირი, რომელიც აღნიშნულია ვიდეოგრამაზე ან მის ფუტლარზე სათანადო წესით.
