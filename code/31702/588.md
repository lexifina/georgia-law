# მუხლი 588. საიჯარო ქონების უკან დაბრუნება ვადამდე
1. თუ მოიჯარე საიჯარო ურთიერთობის შეწყვეტამდე ქონებას უკან აბრუნებს, იგი საიჯარო ქირის გადახდისაგან მხოლოდ მაშინ თავი სუფლდება, თუ თავის სანაცვლოდ შესთავაზებს ახალ გადახდისუნარიან და მეიჯარისათვის მისაღებ მოიჯარეს. ახალი მოიჯარე თანახმა უნდა იყოს, იჯარის ხელშეკრულება მიიღოს იმავე პირობებით.
2. თუ მოიჯარე ვერ შესთავაზებს ასეთ მოიჯარეს, მან საიჯარო ქირა უნდა იხადოს საიჯარო ურთიერთობათა დასრულებამდე.
