# მუხლი 1091. მაუწყებლობის ორგანიზაციის განსაკუთრებული უფლებები
1. მაუწყებლობის ორგანიზაციას ეკუთვნის განსაკუთრებული უფლება, გამოიყენოს თავისი გადაცემა ნებისმიერი ფორმით, გადაცემის ყოველი გამოყენებისათვის ჰონორარის მიღების უფლების ჩათვლით.
2. გადაცემის გამოყენების განსაკუთრებული უფლება ნიშნავს მაუწყებლობის ორგანიზაციის უფლებას, ნება დართოს ან აკრძალოს:
ა ) გადაცემის ჩაწერა;
ბ ) გადაცემის ჩანაწერის რეპროდუცირება, გარდა იმ შემთხვევისა, როდესაც გადაცემა ჩაწერილია მაუწყებლობის ორგანიზაციის თანხმობით და რეპროდუცირება ხორციელდება იმავე მიზნებისათვის, რისთვისაც მოხდა მისი ჩაწერა;
გ ) გადაცემის ერთდროულად გადაცემა ეთერში (კაბელით) საეთერო (საკაბელო) მაუწყებლობის სხვა ორგანიზაციის მიერ;
დ ) გადაცემის ეთერში (კაბელით) გადაცემა;
ე ) გადაცემის საჯარო გადაცემა ადგილებში, სადაც შესვლა ფასიანია.
