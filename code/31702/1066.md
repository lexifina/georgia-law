## თავი მეოთხე
## საავტორო უფლების გადაცემა
# მუხლი 1066. საავტორო უფლების გადაცემის საფუძვლები
1. საავტორო უფლება გადაეცემა კანონით ან ანდერძით მემკვიდრეობის წესით.
2. კანონით მემკვიდრეებზე საავტორო უფლების მოქმედების ვადის ფარგლებში გადადის 1045-ე მუხლით გათვალისწინებული ნაწარმოების გამოყენების განსაკუთრებული უფლებები, თუ ანდერძით სხვა რამ არ არის გათვალისწინებული.
3. ავტორობის უფლება, სახელის უფლება და ნაწარმოების ხელშეუხებლობის უფლება მემკვიდრეობით არ გადადის. მემკვიდრეებს უფლება აქვთ განახორციელონ აღნიშნულ პირად უფლებათა დაცვა. მათი ეს უფლებამოსილება ვადით არ იზღუდება.
4. თუ ავტორის მიერ მისი სიცოცხლის განმავლობაში სხვა რამ არ იყო განსაზღვრული, მისი პირადი უფლებებიდან მემკვიდრეებზე გადადის:
ა ) უფლება, მისცეს ნებართვა ნაწარმოებისათვის სხვა ავტორთა ნაწარმოებების დართვისა (ილუსტრაცია, წინასიტყვაობა, ბოლოსიტყვაობა, კომენტარი, განმარტება დაა) შ.). აღნიშნული უფლება მემკვიდრეებზე გადადის საავტორო უფლების მოქმედების ვადით;
ბ ) უფლება, გამოაქვეყნოს გამოუქვეყნებელი ნაწარმოები. მემკვიდრეთა აღნიშნული უფლებამოსილება ვადით არ იზღუდება.
