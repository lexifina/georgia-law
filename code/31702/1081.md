# მუხლი 1081. შემსრულებლის პირადი და ქონებრივი უფლებები
შემსრულებელს თავის შესრულებაზე აქვს შემდეგი პირადი და ქონებრივი უფლებები:
ა) უფლება სახელზე;
ბ) უფლება, დაიცვას შესრულება ყოველგვარი დამახინჯებისაგან ან სხვაგვარი ხელყოფისაგან, რასაც შეუძლია ზიანი მიაყენოს შემსრულებლის პატივსა და საქმიან რეპუტაციას (რეპუტაციის პატივისცემის უფლება);
გ) უფლება, გამოიყენოს შესრულება ნებისმიერი ფორმით, შესრულების ყოველი სახით გამოყენებისათვის ჰონორარის მიღების უფლების ჩათვლით.
