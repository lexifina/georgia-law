# მუხლი 1217. სასამართლოს განჩინება შვილის შესანახი სახსრების გადახდევინების შესახებ
თუ მოპასუხე მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში ბავშვის მშობლად არის ჩაწერილი, 1191-ე და 1192-ე მუხლების მიხედვით, სასამართლოს შეუძლია საქმის არსებითად განხილვამდე გამოიტანოს განჩინება შვილის შესანახი სარჩოს გადახდევინების შესახებ.
