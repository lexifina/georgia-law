# მუხლი 35. სახელმწიფო კონტროლი კავშირისა და ფონდის საქმიანობაზე
1. კავშირის ან ფონდის საქმიანობის შეჩერების ან აკრძალვის თაობაზე გადაწყვეტილებას იღებს სასამართლო ორგანული კანონით განსაზღვრულ შემთხვევებში და დადგენილი წესით.
2. თუ კავშირი ან ფონდი არსებითად გადავიდა სამეწარმეო საქმიანობაზე, ან თუ მისი წესდებით გათვალისწინებული მიზნების განხორციელება შეუძლებელი ხდება, სასამართლო საქართველოს იუსტიციის სამინისტროს ან/და დაინტერესებული პირის სარჩელის საფუძველზე განიხილავს და წყვეტს კავშირის ან ფონდის საქმიანობის შეჩერების ან აკრძალვის საკითხს.
3. სასამართლოს მიერ კავშირის ან ფონდის საქმიანობის აკრძალვის შესახებ გადაწყვეტილების მიღების შემდეგ საქართველოს იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელმა ტერიტორიულმა ორგანომ უნდა გააუქმოს რეგისტრაცია.
4. ამ მუხლის მე-2 ნაწილის მოქმედება არ ვრცელდება ამ კოდექსის 1511¹ მუხლით გათვალისწინებულ მიკროსაფინანსო ორგანიზაციებზე.

1. კავშირის ან ფონდის საქმიანობის შეჩერების ან აკრძალვის შესახებ გადაწყვეტილებას იღებს სასამართლო ორგანული კანონით განსაზღვრულ შემთხვევებში და დადგენილი წესით.
2. თუ კავშირი ან ფონდი არსებითად გადავიდა სამეწარმეო საქმიანობაზე, ან თუ მისი წესდებით გათვალისწინებული მიზნების განხორციელება შეუძლებელი ხდება, საგადასახადო ორგანოს ან/და დაინტერესებული პირის სარჩელის საფუძველზე სასამართლო განიხილავს და წყვეტს კავშირის ან ფონდის საქმიანობის შეჩერების ან აკრძალვის საკითხს.
3. სასამართლოს მიერ კავშირის ან ფონდის საქმიანობის აკრძალვის შესახებ გადაწყვეტილების მიღების შემდეგ სახელმწიფო რეესტრის მწარმოებელმა საგადასახადო ორგანომ უნდა გააუქმოს სახელმწიფო და საგადასახადო რეგისტრაცია.
4. ამ მუხლის მე-2 ნაწილის მოქმედება არ ვრცელდება ამ კოდექსის 1511 1 მუხლით გათვალისწინებულ მიკროსაფინანსო ორგანიზაციებზე. (ამოქმედდეს 2006 წლის 1 სექტემბრიდან)]
