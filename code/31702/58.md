# მუხლი 58. გარიგების ბათილობა ქმედუუნარობის ან ფსიქიკური მოშლილობის გამო
- 1. ბათილია მცირეწლოვანის ან სასამართლოს მიერ ქმედუუნაროდ აღიარებული პირის ნების გამოვლენა. [ძალადაკარგულია 2015 წლის 1 აპრილიდან - საქართველოს საკონსტიტუციო სასამართლოს 2014 წლის 8 ოქტომბრის გადაწყვეტილება №2/4//532,533 -ვებგვერდი, 28.10.2014წ.]
2. ბათილად შეიძლება ჩაითვალოს ნების გამოვლენა ცნობიერების დაკარგვის ან დროებითი ფსიქიკური მოშლილობის დროს.
3. ბათილია ნების გამოვლენა სულით ავადმყოფის მიერ, როცა ეს არ შეესაბამება რეალური ვითარების სწორად აღქმას, თუნდაც ის არ იყოს სასამართლოს მიერ ქმედუუნაროდ აღიარებული.
- საქართველოს საკონსტიტუციო სასამართლოს 2014 წლის 8 ოქტომბრის გადაწყვეტილება №2/4/532,533 -ვებგვერდი, 28.10.2014წ.
