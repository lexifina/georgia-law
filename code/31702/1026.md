# მუხლი 1026. გადამუშავებული და შედგენილი ნაწარმოების დაცვა
1. გადამუშავებულ და შედგენილ ნაწარმოებებზე საავტორო უფლებათა დაცვა ხორციელდება მიუხედავად იმისა, წარმოადგენენ თუ არა საავტორო უფლებების ობიექტებს ის ნაწარმოებები, რომლებსაც ემყარებიან ან შეიცავენ ისინი.
2. გადამუშავებული და შედგენილი ნაწარმოების დაცვა ხორციელდება ორიგინალური ნაწარმოების თანაბრად.
