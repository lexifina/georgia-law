# მუხლი 286. ცნება
1. უძრავი ნივთი შეიძლება მოთხოვნის დასაკმაყოფილებლად ისე იქნეს გამოყენებული (დატვირთული), რომ კრედიტორს მიეცეს უფლება, სხვა კრედიტორებთან შედარებით პირველ რიგში მიიღოს თავისი მოთხოვნის დაკმაყოფილება ამ ნივთიდან (იპოთეკა).
2. იპოთეკა შეიძლება ასევე გამოყენებულ იქნეს სამომავლო ან პირობით მოთხოვნებთან დაკავშირებით, თუკი იპოთეკის დადგენის მომენტისათვის შეიძლება ამ მოთხოვნის განსაზღვრა. ასევე შეიძლება განისაზღვროს ის ზღვრული თანხა, რომლის ფარგლებშიც უნდა მოხდეს უძრავი ნივთიდან მოთხოვნის დაკმაყოფილება. ეს თანხა განისაზღვრება საჯარო რეესტრში შეტანით.
3. ის მოთხოვნა, რომელიც უზრუნველყოფილია იპოთეკით, შეიძლება შეიცვალოს სხვა მოთხოვნით. ამისათვის საჭიროა მესაკუთრისა და კრედიტორის (იპოთეკარის) შეთანხმება და ამ შეთანხმების რეგისტრაცია რეესტრში.
