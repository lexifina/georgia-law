# მუხლი 984. პასუხისმგებლობისაგან განთავისუფლება
1. თუ ხელმყოფმა უხეში გაუფრთხილებლობის გამო არ იცოდა უფლებამოსილების ხარვეზი, იგი პასუხისმგებლობისაგან თავისუფლდება, თუ იმ დროისათვის, როდესაც ანაზღაურების მოთხოვნა სასამართლო წარმოებას გადაეცემა, აღარ არსებობს გამდიდრების ნიშნები.
2. ხელმყოფი პირის მიერ გამოყენებული სიკეთის მიმართ გაწეული ხარჯები არ ამცირებს მისი გამდიდრების ოდენობას.
