# მუხლი 1017. საავტორო სამართლის ცნება
საავტორო სამართალი იცავს საავტორო ქონებრივ და პირად არაქონებრივ უფლებებს, რომლებიც წარმოიშობა მეცნიერების, ლიტერატურისა და ხელოვნების ნაწარმოებთა შექმნისა და გამოყენებისას (საავტორო უფლებები), აგრეთვე ზოგიერთ მათ მომიჯნავე უფლებებს, დაკავშირებულს შემსრულებლებთან, ფონოგრამისა და ვიდეოგრამის დამამზადებლებსა და მაუწყებლობის ორგანიზაციებთან (მომიჯნავე უფლებები).
