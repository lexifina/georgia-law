# მუხლი 1268. შვილად აყვანის გაუქმება მეურვეობისა და მზრუნველობის ორგანოს მოთხოვნით
1. მეურვეობისა და მზრუნველობის ორგანოს ყოველთვის აქვს უფლება, მოითხოვოს შვილად აყვანის გაუქმება სასამართლო წესით, თუ ამას არასრულწლოვანი ნაშვილების ინტერესები მოითხოვს.
2. ცალკეული პირები, რომლებსაც მიაჩნიათ, რომ შვილად აყვანა არ შეესაბამება ბავშვის ინტერესებს და იგი უნდა გაუქმდეს, ამის შესახებ აცნობებენ მეურვეობისა და მზრუნველობის ორგანოს, რომელიც წყვეტს შვილად აყვანის გაუქმების თაობაზე მოთხოვნის წარდგენის საკითხს.
