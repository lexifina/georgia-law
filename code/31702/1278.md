# მუხლი 1278. მეურვეობისა და მზრუნველობის ორგანოები
არასრულწლოვანი პირის მეურვეობა და მზრუნველობა ეკისრება განათლების ადგილობრივ ორგანოს, სასამართლოს მიერ ქმედუუნაროდ აღიარებული პირისა _ ჯანმრთელობის დაცვის ადგილობრივ ორგანოს, ხოლო იმ ქმედუნარიანი პირისა, რომელიც ჯანმრთელობის მდგომარეობის გამო საჭიროებს მზრუნველობას, _ სოციალური უზრუნველყოფის ადგილობრივ ორგანოს.
[ მუხლი 1278. მეურვეობისა და მზრუნველობის ორგანოები
1. მეურვეობისა და მზრუნველობის ცენტრალური და ადგილობრივი ორგანოები არიან საქართველოს შრომის, ჯანმრთელობისა და სოციალური დაცვის სამინისტრო ან/და მის სისტემაში შემავალი უფლებამოსილი დაწესებულება (ორგანიზაცია), აგრეთვე მათი ტერიტორიული ორგანოები.
2. მეურვეობისა და მზრუნველობის ცენტრალური და ადგილობრივი ორგანოების მუშაობის წესს განსაზღვრავს საქართველოს შრომის, ჯანმრთელობისა და სოციალური დაცვის მინისტრი. (ამოქმედდეს 2008 წლის 1 მაისიდან)]
