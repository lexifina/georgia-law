# მუხლი 1271. შვილად აყვანის შეწყვეტის მომენტი
1. შვილად აყვანა წყდება შვილად აყვანის გაუქმების შესახებ სასამართლოს გადაწყვეტილების ძალაში შესვლის დღიდან.
2. სასამართლო, რომელმაც გამოიტანა გადაწყვეტილება შვილად აყვანის გაუქმების ან ბათილად ცნობის თაობაზე, ვალდებულია კანონიერ ძალაში შესული გადაწყვეტილების პირი ერთი კვირის ვადაში გადაუგზავნოს მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოს გადაწყვეტილების გამოტანისა და შვილად აყვანის რეგისტრაციის ადგილის მიხედვით.
