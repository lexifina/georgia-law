# მუხლი 1271. შვილად აყვანის შეწყვეტის მომენტი
1. შვილად აყვანა წყდება შვილად აყვანის გაუქმების შესახებ სასამართლოს გადაწყვეტილების ძალაში შესვლის დღიდან.
2. სასამართლო, რომელმაც გამოიტანა გადაწყვეტილება შვილად აყვანის გაუქმების ან ბათილად ცნობის თაობაზე, ვალდებულია კანონიერ ძალაში შესული გადაწყვეტილების პირი 1 კვირის ვადაში გაუგზავნოს იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოს გადაწყვეტილების გამოტანისა და შვილად აყვანის რეგისტრაციის ადგილის მიხედვით.
- საქართველოს 2004 წლის 24 ივნისის კანონი №179 - სსმ I, №19, 15.07.2004 წ., მუხ.79
