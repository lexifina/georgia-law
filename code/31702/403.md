# მუხლი 403. პროცენტიდან პროცენტის გადახდის დაუშვებლობა
1. მოვალე, რომელიც ფულადი თანხის გადახდის ვადას გადააცილებს, ვალდებულია გადაცილებული დროისათვის გადაიხადოს კანონით განსაზღვრული პროცენტი, თუკი კრედიტორს, სხვა საფუძვლიდან გამომდინარე, უფრო მეტის მოთხოვნა არ შეუძლია.
2. დაუშვებელია პროცენტიდან პროცენტის გადახდა.
