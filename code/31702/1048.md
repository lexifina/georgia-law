# მუხლი 1048. საავტორო ჰონორარი
საავტორო ჰონორარის ოდენობა, მისი გამოანგარიშების წესი ეგზემპლარის ყოველი სახით გამოყენებისათვის დადგენილ უნდა იქნეს საავტორო ხელშეკრულებით, აგრეთვე მოსარგებლეებთან იმ ორგანიზაციების მიერ დადებული ხელშეკრულებით, რომლებიც მართავენ ავტორთა ქონებრივ უფლებებს კოლექტიურ საფუძველზე.
