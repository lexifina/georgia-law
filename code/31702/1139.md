# მუხლი 1139. მსჯავრდადებულ მეუღლესთან განქორწინების წესი
1. მეუღლე, რომელსაც განქორწინება სურს 1125-ე მუხლით გათვალისწინებული საფუძვლებით, ვალდებულია მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში წარადგინოს სათანადო წესით დამოწმებული, კანონიერ ძალაში შესული სასამართლოს გადაწყვეტილების პირი მეორე მეუღლის უგზო-უკვლოდ დაკარგულად აღიარების ან ქმედუუნაროდ ცნობის შესახებ, ანდა სასამართლოს განაჩენის პირი ან განაჩენის ამონაწერი იმის შესახებ, რომ მეორე მეუღლეს შეფარდებული აქვს თავისუფლების აღკვეთა არანაკლებ სამი წლისა.
2. შეტანილი განცხადების შესახებ მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანო აუწყებს პატიმრობაში მყოფ მეუღლეს ან ქმედუუნარო მეუღლის მეურვეს. უწყებაში უნდა განისაზღვროს პასუხის შეტყობინების ვადა იმის თაობაზე, არის თუ არა დავა ბავშვების შესახებ, მეუღლეთა საერთო თანასაკუთრების გაყოფაზე ან იმ შრომისუუნარო მეუღლის სასარგებლოდ ალიმენტის გადახდევინებაზე, რომელიც დახმარებას საჭიროებს. პასუხის შეტყობინების ვადა არ უნდა აღემატებოდეს სამ თვეს.
3. თუ მიღებულია ცნობა იმის შესახებ, რომ დავა არ არსებობს ან მითითებულ ვადაში პასუხი არ იქნა მიღებული, მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანო ახდენს განქორწინების რეგისტრაციას.
[ მუხლი 1139. მსჯავრდადებულ მეუღლესთან განქორწინების წესი
1. მეუღლე, რომელსაც განქორწინება სურს ამ კოდექსის 1125-ე მუხლით გათვალისწინებული საფუძვლებით, ვალდებულია იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოს წარუდგინოს სათანადო წესით დამოწმებული, კანონიერ ძალაში შესული სასამართლოს გადაწყვეტილების პირი მეორე მეუღლის უგზო-უკვლოდ დაკარგულად აღიარების ან ქმედუუნაროდ ცნობის შესახებ, ანდა სასამართლოს განაჩენის პირი ან განაჩენის ამონაწერი იმის შესახებ, რომ მეორე მეუღლეს შეფარდებული აქვს თავისუფლების აღკვეთა არანაკლებ სამი წლისა.
2. შეტანილი განცხადების შესახებ იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელი ტერიტორიული ორგანო აუწყებს პატიმრობაში მყოფ მეუღლეს ან ქმედუუნარო მეუღლის მეურვეს. უწყებაში უნდა განისაზღვროს პასუხის შეტყობინების ვადა იმის თაობაზე, არის თუ არა დავა ბავშვების შესახებ, მეუღლეთა საერთო თანასაკუთრების გაყოფაზე ან იმ შრომისუუნარო მეუღლის სასარგებლოდ ალიმენტის გადახდევინებაზე, რომელიც დახმარებას საჭიროებს. პასუხის შეტყობინების ვადა არ უნდა აღემატებოდეს 3 თვეს.
3. თუ მიღებულია ცნობა იმის შესახებ, რომ დავა არ არსებობს, ან მითითებულ ვადაში პასუხი არ იქნა მიღებული, იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელი ტერიტორიული ორგანო ახდენს განქორწინების რეგისტრაციას. (ამოქმედდეს 2004 წლის 15 ნოემბრიდან) ]
