# მუხლი 336. ქუჩაში დადებული ხელშეკრულება
მომხმარებელსა და საკუთარი სარეწის ფარგლებში მოვაჭრე პირს შორის ქუჩაში, სახლის წინ და მსგავს ადგილებში დადებული ხელშეკრულება ძალაშია მხოლოდ მაშინ, თუ მომხმარებელი ერთი კვირის ვადაში ხელშეკრულებას წერილობით არ უარყოფს, გარდა იმ შემთხვევებისა, როცა ხელშეკრულების შესრულება ხდება მისი დადებისთანავე.
