# მუხლი 307. იპოთეკის გაუქმება ნივთის რეალიზაციის შედეგად
1. აუქციონზე ნივთის მყიდველი ვალდებულია, ექსპერტს, რომელმაც განახორციელა იძულებითი აღსრულება, გადასცეს სყიდვის ფასი, რომლიდანაც გამოიქვითება აღსრულებასთან დაკავშირებული ხარჯები.
2. მყიდველი ნივთის მესაკუთრე ხდება მხოლოდ ფასის გადახდის შემდეგ.
3. საკუთრების გადასვლის შედეგად უქმდება ყველა იპოთეკა და სანივთო უფლება, რომლებითაც ნივთი დატვირთული იყო და რომლებიც რეგისტრირებულია იძულებითი აღსრულების განმახორციელებელი კრედიტორის იპოთეკის შემდეგ. ადრე რეგისტრირებული შეზღუდული უფლებები ნივთზე უცვლელი რჩება.
4. ახალი მესაკუთრე ხდება საკუთრების გადასვლის მომენტში არსებული ქირავნობისა და იჯარის ურთიერთობების მონაწილე. ახალ შემძენზე საკუთრების გადასვლით ძველი მესაკუთრე განიხილება დამქირავებლად საბაზრო პირობების შესაბამისად.
