# მუხლი 260. გირავნობის გავრცელება გირავნობის საგანში შემავალ ქონებრივ ფასეულობებზე
გირავნობა ვრცელდება ყველა ქონებრივ ფასეულობაზე, რომლებსაც მოიცავს საკუთრებაში მყოფი გირავნობის საგანი.
[მუხლი 260. ლომბარდში ნივთების დაგირავების წესი
1. ლომბარდში ნივთების დაგირავება ხორციელდება მხარეთა შორის წერილობითი შეთანხმებისა და ნივთის ლომბარდის პირდაპირ მფლობელობაში გადაცემის გზით.
2. თუ მხარეთა შეთანხმებით სხვა რამ არ არის გათვალისწინებული, ლომბარდის მოთხოვნა მოვალის მიმართ წყდება იმ შემთხვევაშიც, როცა გირავნობის საგნის რეალიზაციიდან ამონაგები თანხა მთლიანად არ ფარავს ლომბარდის მიმართ არსებულ ვალდებულებას. (ამოქმედდეს 2006 წლის 1 მარტიდან) ]
