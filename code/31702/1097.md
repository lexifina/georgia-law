# მუხლი 1097. კონტრაფაქციული პროდუქცია
1. ნაწარმოებთა და ფონოგრამების ან ვიდეოგრამების ეგზემპლარები, რომელთა დამზადებაც ან გავრცელებაც იწვევს საავტორო და მომიჯნავე უფლებათა დარღვევას, ჩაითვლებიან კონტრაფაქციულ ეგზემპლარებად.
2. კონტრაფაქციულად ჩაითვლება ასევე იმ ნაწარმოებთა ან ფონოგრამების ეგზემპლარები, რომლებიც დაცულია საქართველოში ამ კოდექსის მიხედვით და რომლებიც საავტორო და მომიჯნავე უფლებათა მფლობელის თანხმობის გარეშე იმპორტირებულია საქართველოში იმ სახელმწიფოდან, სადაც ეს ნაწარმოებები და ფონოგრამები არასდროს ყოფილა დაცული, ან მათი დაცვა შეწყვეტილია.
