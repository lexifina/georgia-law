# მუხლი 579. ლიზინგის მიმღების პასუხისმგებლობა
ლიზინგის მიმღების ბრალით ხელშეკრულების ვადამდე შეწყვეტისას ლიზინგის გამცემს არ შეუძლია წაუყენოს მას ისეთი მოთხოვნები, რომლებიც სცილდება შესრულებასთან დაკავშირებულ მის ინტერესებს. მოთხოვნის განსაზღვრისას მხედველობაში მიიღება სალიზინგო ქონების დარჩენილი ღირებულება, სალიზინგო საზღაურის დარჩენილი პროცენტები და სხვა დაზოგილი ხარჯები.
