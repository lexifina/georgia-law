# მუხლი 1283. პირები, რომლებიც არ შეიძლება დაინიშნონ მეურვედ ან მზრუნველად
მეურვედ ან მზრუნველად არ შეიძლება დაინიშნოს:
ა) პირი, რომელსაც არ მიუღწევია თვრამეტი წლის ასაკისათვის;
ბ) პირი, რომელიც სასამართლოს მიერ ცნობილია ქმედუუნაროდ;
გ) პირი, რომელსაც ჩამორთმეული აქვს მშობლის უფლება;
[გ) პირი, რომელსაც ჩამოერთვა ან შეეზღუდა მშობლის უფლება მშობლის უფლებებისა და მოვალეობების შესრულებისათვის თავის არიდების გამო; (ამოქმედდეს 2008 წლის 1 მაისიდან)]
დ) მშვილებელი, თუ შვილად აყვანა გაუქმდა იმის გამო, რომ იგი ჯეროვნად არ ასრულებდა მშვილებლის მოვალეობებს;
[დ) ამოღებულია. (ამოქმედდეს 2008 წლის 1 მაისიდან)]
ე) პირი, რომელიც განთავისუფლებულია მეურვის ან მზრუნველის მოვალეობისაგან იმის გამო, რომ იგი ჯეროვნად არ ასრულებდა ამ მოვალეობას.
- საქართველოს 2007 წლის 18 დეკემბრის კანონი №5624 - სსმ I, №48, 27.12.2007წ., მუხ.414
