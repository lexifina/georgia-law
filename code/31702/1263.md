# მუხლი 1263. შვილად აყვანის შესახებ ცნობების გამოქვეყნების დაუშვებლობა
1. შვილად აყვანის შესახებ ცნობების შეკრება და გამოქვეყნება მშვილებლის თანხმობის გარეშე აკრძალულია.
2. ის პირი, რომელიც მშვილებლის ნება-სურვილის გარეშე გაამჟღავნებს შვილად აყვანის ფაქტს, პასუხს აგებს კანონით დადგენილი წესით.
შეცდომის გასწორება - პარლამენტის უწყებანი №37-38, 10.09.1997წ., გვ.21
