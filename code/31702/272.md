# მუხლი 272. მოგირავნის დაკმაყოფილება
1. მოგირავნის დაკმაყოფილება ხდება გირავნობის საგნის გაყიდვით ან ამ საგნის შესაბამისი სხვაგვარი რეალიზაციით.
2. მოგირავნე უფლებამოსილია მოახდინოს საგნის რეალიზაცია ფულადი მოთხოვნის მთლიანად ან ნაწილობრივ შესრულების ვადის დადგომისას.
[მუხლი 272. გირავნობის უფლების შეწყვეტა გირავნობაზე უარის თქმით
1. რეგისტრირებული გირავნობის უფლება წყდება იმ შემთხვევაში, როცა მოგირავნე უარს იტყვის გირავნობაზე რეგისტრაციის გზით.
2. მფლობელობითი გირავნობის უფლება წყდება იმ შემთხვევაში, როცა მფლობელობა დამგირავებელს უბრუნდება ან მოგირავნე უარს ამბობს გირავნობის უფლებაზე. (ამოქმედდეს 2006 წლის 1 მარტიდან) ]
