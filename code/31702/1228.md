# მუხლი 1228. მუდმივ აღსაზრდელად და სარჩენლად აყვანილი ბავშვის რჩენის მოვალეობა
1. პირი, რომელიც მუდმივ აღსაზრდელად და სარჩენად აიყვანს ბავშვს, მაგრამ შემდგომ უარს იტყვის მის აღზრდასა და რჩენაზე, მოვალეა არჩინოს როგორც შრომისუუნარო სრულწლოვანი, რომელიც დახმარებას საჭიროებს, ისე არასრულწლოვანი აღსაზრდელი, თუ მათ არა ჰყავთ მშობლები ან არ შეუძლიათ მიიღონ მათგან სარჩო.
2. ამ მუხლით დადგენილი წესი არ ვრცელდება მეურვეზე ან/და მზრუნველზე.
