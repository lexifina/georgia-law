# მუხლი 1134. განცხადება ქორწინებამდელი გვარის დაბრუნების შესახებ
მეუღლემ, რომელსაც სურს დაიბრუნოს ქორწინებამდელი გვარი, ამის შესახებ უნდა განაცხადოს იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოში განქორწინების რეგისტრაციის დროს. მეუღლისათვის ქორწინებამდელი გვარის მიკუთვნების შესახებ იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელი ტერიტორიული ორგანო აკეთებს შესაბამის ჩანაწერს.
- საქართველოს 2004 წლის 24 ივნისის კანონი №179 - სსმ I, №19, 15.07.2004 წ., მუხ.79
