# მუხლი 1042. საავტორო უფლება სამსახურებრივ ნაწარმოებზე
1. საავტორო უფლება ნაწარმოებზე, რომელიც შექმნილია სამუშაოს მიმცემის უშუალო სამსახურებრივი დავალების შესრულების წესით (სამსახურებრივი ნაწარმოები), ეკუთვნის სამსახურებრივი ნაწარმოების ავტორს.
2. სამსახურებრივი ნაწარმოების გამოყენების განსაკუთრებული უფლება, რაც შეპირობებულია დავალების შინაარსითა და მიზნით, ეკუთვნის პირს, რომელთანაც ავტორს აქვს შრომითი ურთიერთობა (სამუშაოს მიმცემი), თუ მასა და ავტორს შორის ხელშეკრულებით სხვა რამ არ არის გათვალისწინებული.
3. ავტორის მიერ სამუშაოს მიმცემისათვის ნაწარმოების გადაცემიდან ხუთი წლის გასვლის შემდეგ ნაწარმოების გამოყენების განსაკუთრებული უფლება გადადის ავტორზე, თუ მასა და სამუშაოს მიმცემს შორის დადებული ხელშეკრულებით სხვა რამ არ არის გათვალისწინებული.
4. თუ ნაწარმოების გადაცემიდან სამი წლის განმავლობაში სამუშაოს მიმცემი არ გამოიყენებს ნაწარმოებს, მისი გამოყენების განსაკუთრებული უფლება გადადის ავტორზე; აღნიშნული წესი გამოიყენება იმ შემთხვევაშიც, როდესაც ნაწარმოების გამოყენება შეწყვეტილია ორ წელზე მეტი ვადით საპატიო მიზეზის გარეშე. აღნიშნული ვადები შეიძლება შემცირდეს მხარეთა შეთანხმებით.
5. სამუშაოს მიმცემს უფლება აქვს სამსახურებრივი ნაწარმოების ყოველი გამოყენებისას მიუთითოს თავისი სახელი (სახელწოდება) ან მოითხოვოს ასეთი მითითება.
6. სამსახურებრივი ნაწარმოების ყოველგვარი გამოყენებისას საავტორო გასამრჯელოს (ჰონორარის) ოდენობა და გადახდის წესი შეიძლება განისაზღვროს ავტორსა და სამუშაოს მიმცემს შორის დადებული ხელშეკრულებით.
7. ამ მუხლის მოქმედება არ ვრცელდება სამსახურებრივი დავალების წესით შექმნილ ნაწარმოებებზე, რომლებიც განსაზღვრულია 1037-ე მუხლით.
