# მუხლი 864. საბანკო ანგარიშსწორების ხელშეკრულების შეწყვეტა
1. საბანკო ანგარიშსწორების ხელშეკრულება შეიძლება შეწყდეს ორივე მხარის მიერ ნებისმიერ დროს.
2. საკრედიტო დაწესებულებას შეუძლია მხოლოდ ისე შეწყვიტოს ხელშეკრულება, რომ ანგარიშის მფლობელმა სხვაგვარად შეძლოს საანგარიშსწორებო მომსახურების მიღება, გარდა იმ შემთხვევისა, როცა შეწყვეტისათვის არსებობს მნიშვნელოვანი საფუძველი.
