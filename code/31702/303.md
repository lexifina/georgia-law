# მუხლი 303. მოვალის უფლებები რეალიზებულ საცხოვრებელ ნაგებობაზე
1. აუქციონზე ნივთის გაყიდვის შესახებ გადაწყვეტილების მიღებიდან მოვალე კარგავს უფლებას დაიტოვოს ნივთის ნაყოფი.
2. თუ მოვალე მარტო ან თავის ოჯახთან ერთად ცხოვრობს იმ შენობაში ან შენობის ნაწილში, რომელიც დატვირთულია იპოთეკით, მას უფლება აქვს დარჩეს დამქირავებლად და მოვალეა გადაიხადოს საბაზრო პირობების შესაბამისი ქირა.
