# მუხლი 1402. ანდერძის ძალადაკარგულად გამოცხადების საფუძვლები
ანდერძი ძალას კარგავს, თუ:
ა) პირი, რომლის სასარგებლოდაც შედგენილი იყო ეს ანდერძი, გარდაიცვალა მოანდერძეზე ადრე;
ბ) ნაანდერძები ქონება დაიკარგა მოანდერძის სიცოცხლეში, ან მოანდერძემ გაასხვისა იგი;
გ) ერთადერთი მემკვიდრე უარს იტყვის სამკვიდროს მიღებაზე.
