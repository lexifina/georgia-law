# მუხლი 1124. განქორწინების წესი
1. მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში ერთ-ერთი მეუღლის საცხოვრებელი ადგილის მიხედვით განქორწინება დაიშვება იმ მეუღლეებს შორის ურთიერთთანხმობით, რომელთაც არა ჰყავთ არასრულწლოვანი შვილები და შეაქვთ ერთობლივი განცხადება განქორწინების შესახებ.
2. განცხადებაში განქორწინების შესახებ მეუღლეები მოვალენი არიან დაადასტურონ არა მარტო ურთიერთთანხმობა, არამედ ისიც, რომ მათ არა ჰყავთ არასრულწლოვანი შვილები.
3. განქორწინება შეიძლება მოხდეს ერთ-ერთი მეუღლის დაუსწრებლად, თუ მას საპატიო მიზეზის გამო არ შეუძლია გამოცხადდეს მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში და თუ მისი სახელით წარმოდგენილია სათანადოდ დამოწმებული განცხადება განქორწინებაზე მისი თანხმობის დასადასტურებლად.
4. განქორწინება ხდება მეუღლეთა მიერ განქორწინების შესახებ განცხადების შეტანის დღიდან ერთი თვის ვადაში, გარდა 1110-ე მუხლის მე-3 ნაწილით გათვალისწინებული შემთხვევებისა.
5. ქორწინება შეწყვეტილად ითვლება მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში განქორწინების რეგისტრაციის მომენტიდან.
