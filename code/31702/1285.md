# მუხლი 1285. საბავშვო დაწესებულების ვალდებულებანი
1. იმ ბავშვის მიმართ, რომელიც საბავშვო დაწესებულებაში იზრდება, აგრეთვე იმ პირის მიმართ, რომელიც მეურვეობას ან მზრუნველობას საჭიროებს და იმყოფება სათანადო დაწესებულებაში, მეურვის ან მზრუნველის მოვალეობის შესრულება ეკისრება ამ დაწესებულების ადმინისტრაციას.
2. ამ მუხლის პირველ ნაწილში დასახელებულ პირთა ქონებრივი ინტერესების (პენსიის მიღების, ქონების გამგებლობის და ა.შ.) დასაცავად, აუცილებლობის შემთხვევაში, შეიძლება დაინიშნოს ქონების მეურვე.
