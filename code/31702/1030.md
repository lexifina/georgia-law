# მუხლი 1030. საავტორო უფლების წარმოშობა
1. საავტორო უფლება მეცნიერების, ლიტერატურისა და ხელოვნების ნაწარმოებებზე წარმოიშობა მათი შექმნის მომენტიდან. ნაწარმოები შექმნილად ჩაითვლება, როდესაც იგი გამოხატულია ობიექტური ფორმით, რაც მისი აღქმისა და რეპროდუცირების საშუალებას იძლევა.
2. საავტორო უფლების წარმოშობისა და განხორციელებისათვის არ არის სავალდებულო ნაწარმოების რეგისტრაცია, მისი სპეციალური გაფორმება ან სხვა ფორმალობათა დაცვა.
