# მუხლი 610. განდობილი ინფორმაციის შენახვის ვალდებულება
ხელშეკრულების დადებისას მხარეებმა დაუფარავად და სრულყოფილად უნდა გააცნონ ერთმანეთს ფრენშაიზინგთან დაკავშირებული საქმის გარემოებანი, განსაკუთრებით კი _ ფრენშაიზინგის სისტემა, და ერთმანეთს კეთილსინდისიერად მისცენ ინფორმაცია. ისინი ვალდებულნი არიან არ გათქვან მათთვის განდობილი ინფორმაცია მაშინაც კი, როცა ხელშეკრულება არ დაიდება.
