# მუხლი 1257. ნაშვილებისათვის სახელისა და გვარის შეცვლა
1. მშვილებლის თხოვნით ნაშვილებს მიეკუთვნება მშვილებლის გვარი.
2. მშვილებლის თხოვნით ნაშვილებს შეიძლება შეეცვალოს სახელი. სახელის შეცვლა ბავშვისათვის, რომელსაც ათი წელი შეუსრულდა, შეიძლება მხოლოდ მისი თანხმობით.
3. ნაშვილებისათვის სახელისა და გვარის შეცვლა შესაძლებელია შვილად აყვანის რეგისტრაციისას, მშვილებლის მოთხოვნით ან სასამართლოს გადაწყვეტილების საფუძველზე.
- საქართველოს 2011 წლის 20 დეკემბრის კანონი №5568 - ვებგვერდი, 28.12.2011 წ.
