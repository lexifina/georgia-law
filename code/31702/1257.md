# მუხლი 1257. ნაშვილებისათვის გვარის მიკუთვნება
1. მშვილებლის თხოვნით ნაშვილებს მიეკუთვნება მშვილებლის გვარი.
2. მშვილებლის თხოვნით ნაშვილებს შეიძლება შეეცვალოს სახელი. სახელის შეცვლა ბავშვისათვის, რომელსაც ათი წელი შეუსრულდა, შეიძლება მხოლოდ მისი თანხმობით.
3. ნაშვილებისათვის გვარის მიკუთვნების, აგრეთვე სახელის გამოცვლის შესახებ აღნიშნული უნდა იყოს სასამართლოს გადაწყვეტილებაში.
