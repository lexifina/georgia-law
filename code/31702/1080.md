# მუხლი 1080. შემსრულებელი
შემსრულებლად ჩაითვლება მსახიობი (თეატრისა, კინოსი და ა.შ.), მომღერალი, მუსიკოსი, მოცეკვავე ან სხვა პირი, რომელიც თამაშობს როლს, კითხულობს, მღერის, ახდენს დეკლამირებას, უკრავს მუსიკალურ ინსტრუმეტზე ან სხვაგვარად ასრულებს ლიტერატურის ან ხელოვნების ნაწარმოებს, მათ შორის, საესტრადო, საცირკო, თოჯინურ ნომერს. შემსრულებლად ჩაითვლებიან აგრეთვე სპექტაკლის დამდგმელი რეჟისორი და დირიჟორი.
