# მუხლი 1195. შვილის გვარის განსაზღვრა
შვილის გვარი განისაზღვრება მშობლების გვარის მიხედვით. თუ მშობლებს საერთო გვარი არა აქვთ, შვილს მიეკუთვნება დედის ან მამის გვარი, ან შეერთებული გვარი მშობლების შეთანხმებით.
[მუხლი 1195. შვილის გვარის განსაზღვრა
1. შვილის გვარი განისაზღვრება მშობლების გვარის მიხედვით. თუ მშობლებს საერთო გვარი არა აქვთ, შვილს მიეკუთვნება დედის ან მამის გვარი, ან შეერთებული გვარი მშობლების შეთანხმებით.
2. მიტოვებულად აღიარებულ ბავშვს გვარი ეძლევა საქართველოს კანონმდებლობის შესაბამისად. (ამოქმედდეს 2008 წლის 1 მაისიდან)]
