# მუხლი 478. მოძრავი ნივთის გაყიდვის ხარჯები
გაყიდული ნივთის გადაცემასთან დაკავშირებული ხარჯები, კერძოდ, აწონის, გაზომვისა და შეფუთვის ხარჯები, ეკისრება გამყიდველს, ხოლო ხელშეკრულების დადების ადგილიდან სხვა ადგილზე საქონლის მიღებისა და გადაგზავნის ხარჯები _ მყიდველს, თუ ხელშეკრულებით სხვა რამ არ არის გათვალისწინებული.
