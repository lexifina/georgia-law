# მუხლი 1256. უარი გაშვილებაზე
სასამართლოს მიერ გადაწყვეტილების გამოტანამდე გამშვილებელს, შვილად ამყვანსა და ათი წლის ასაკს მიღწეულ შვილად ასაყვანს უფლება აქვთ უარი განაცხადონ თავიანთ თანხმობაზე.
