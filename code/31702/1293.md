# მუხლი 1293. მეურვისა და მზრუნველის თანხმობა გარიგების დადებისას
1. მეურვე კანონიერი წარმომადგენელია სამეურვეო პირისა და მისი სახელით, მისი ინტერესებიდან გამომდინარე, დებს ყველა აუცილებელ გარიგებას.
2. არასრულწლოვანი პირი შვიდიდან თვრამეტი წლის ასაკამდე ისეთ გარიგებას, რომლის დამოუკიდებლად დადების უფლებაც მას კანონით არა აქვს, დებს მზრუნველის თანხმობით.
შეცდომის გასწორება - პარლამენტის უწყებანი №37-38, 10.09.1997წ., გვ.21
