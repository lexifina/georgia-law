# მუხლი 1293. მეურვისა და მზრუნველის თანხმობა გარიგების დადებისას
1. მეურვე კანონიერი წარმომადგენელია სამეურვეო პირისა და მისი სახელით, მისი ინტერესებიდან გამომდინარე, დებს ყველა აუცილებელ გარიგებას. [ძალადაკარგულია 2015 წლის 1 აპრილიდან ის ნორმატიული შინაარსი, რომელიც შეეხება სასამართლოს მიერ ქმედუუნაროდ აღიარებული პირის მეურვის უფლებამოსილებას, სამეურვეო პირის სახელით ყველა აუცილებელი გარიგების დადებას - საქართველოს საკონსტიტუციო სასამართლოს 2014 წლის 8 ოქტომბრის გადაწყვეტილება №2/4//532,533 -ვებგვერდი, 28.10.2014წ.
2. არასრულწლოვანი პირი შვიდიდან თვრამეტი წლის ასაკამდე ისეთ გარიგებას, რომლის დამოუკიდებლად დადების უფლებაც მას კანონით არა აქვს, დებს მზრუნველის თანხმობით.
შეცდომის გასწორება - პარლამენტის უწყებანი №37-38, 10.09.1997წ., გვ.21
