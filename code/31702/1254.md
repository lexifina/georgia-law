# მუხლი 1254. გაშვილება მშობლის თანხმობის გარეშე
1. გაშვილებაზე მშობლის თანხმობა საჭირო არ არის, თუ იგი აღიარებულია ქმედუუნაროდ ან უგზო-უკვლოდ დაკარგულად.
2. მშობლის უფლებაჩამორთმეული მშობლის (მშობლების) თანხმობის მიუღებლად ბავშვის გაშვილება დასაშვებია ერთი წლის შემდეგ ამ უფლების ჩამორთმევის დღიდან.
