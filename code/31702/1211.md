# მუხლი 1211. იმ მშობლის უფლებები, რომელსაც შვილი ჩამოართვეს
იმ მშობელს (მშობლებს), რომლის უფლებებიც შვილის ჩამორთმევით შეზღუდულია, შეიძლება ბავშვთან ურთიერთობის ნება დაერთოს, თუ ეს ცუდ გავლენას არ მოახდენს ბავშვზე.
[მუხლი 1211. მშობლის უფლებებისა და მოვალეობების გადაცემა
1. ბავშვის ქონების მართვის უფლება კონკრეტულ ქონებასთან დაკავშირებით შეიძლება გადაეცეს ქონების მეურვეს მშობლების მიერ ნოტარიალურად ან, თუ ნოტარიუსი ხელმისაწვდომი არ არის, ადგილობრივი თვითმმართველობის ორგანოს მიერ დამოწმებული დოკუმენტის საფუძველზე.
2. ბავშვის ქონების მართვის უფლება კონკრეტულ ქონებასთან დაკავშირებით შეიძლება გადაეცეს ქონების მეურვეს ანდერძის საფუძველზე. (ამოქმედდეს 2008 წლის 1 მაისიდან)]
- საქართველოს 2007 წლის 18 დეკემბრის კანონი №5624 - სსმ I, №48, 27.12.2007წ., მუხ.414
