# მუხლი 1112. დაქორწინების შესახებ განცხადების შეტანა
დაქორწინების მსურველ პირთ პირადად შეაქვთ განცხადება მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში. განცხადებაში მათ უნდა დაადასტურონ, რომ არ არსებობს ქორწინების დამაბრკოლებელი გარემოებები, რომლებიც გათვალისწინებულია 1120-ე მუხლით, იცნობენ ერთმანეთის ოჯახურ მდგომარეობას, აგრეთვე იციან, მერამდენეა თითოეული მათგანისათვის ეს ქორწინება და ჰყავთ თუ არა შვილები.
[მუხლი 1112. დაქორწინების შესახებ განცხადების შეტანა
დაქორწინების მსურველ პირებს პირადად შეაქვთ განცხადება იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოში. განცხადებაში მათ უნდა დაადასტურონ, რომ მათთვის არ არსებობს ქორწინების დამაბრკოლებელი გარემოებები, რომლებიც გათვალისწინებულია ამ კოდექსის 1120-ე მუხლით, ცნობილია ერთმანეთის ოჯახური მდგომარეობა, იციან, მერამდენეა თითოეული მათგანისათვის ეს ქორწინება, აგრეთვე აღნიშნონ, ჰყავთ თუ არა შვილები. (ამოქმედდეს 2004 წლის 15 ნოემბრიდან) ]
