# მუხლი 1463. საადგილმამულო მეურნეობის გადასვლა მემკვიდრეობით
1. თუ საადგილმამულო მეურნეობა კომლის მეურნეობაა და კომლის ბოლო წევრს ანდერძი არ დაუტოვებია, მაშინ კომლის საერთო ქონება გადავა კანონით მემკვიდრეებზე იმ პირობით, რომ კომლის მეურნეობა არ დაიშალოს.
2. კომლის ბოლო წევრის მიერ ანდერძით რამდენიმე მემკვიდრის დანიშვნის შემთხვევაში ის წესი უნდა იქნეს გამოყენებული, რომელიც საერთოდ საადგილმამულო მეურნეობას ეხება.
