# მუხლი 729. დავალების ხელშეკრულების წესების გამოყენება
საკუთრების მინდობის მიმართ გამოიყენება დავალების ხელშეკრულების შესაბამისი წესები, გარდა საპენსიო სქემის ხელშეკრულებისა, რომელიც რეგულირდება "ნებაყოფლობითი კერძო პენსიის შესახებ" საქართველოს კანონით.
- საქართველოს 2023 წლის 28 ივნისის კანონი №3353 - ვებგვერდი, 19.07.2023წ.
