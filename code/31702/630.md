# მუხლი 630. შეთანხმება ანაზღაურებაზე
1. ანაზღაურება უსიტყვოდაც ითვლება შეთანხმებულად, თუ გარემოებების მიხედვით ნარდობა მხოლოდ ანაზღაურებითაა მოსალოდნელი.
2. თუ ანაზღაურების ოდენობა შეთანხმებული არ არის, ტარიფის არსებობისას შეთანხმებულად მიიჩნევა სატარიფო განაკვეთი, ხოლო, თუ ტარიფები არ არსებობს, მაშინ _ ჩვეულებრივი ანაზღაურება.
