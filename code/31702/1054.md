# მუხლი 1054. ნაწარმოების რეპროგრაფიული გამრავლება
დაშვებულია რეპროგრაფიული გამრავლება (ასლის გადაღება) პირდაპირი და არაპირდაპირი მოგების მიუღებლად ავტორის ან საავტორო უფლების სხვა მფლობელის თანხმობისა და მისთვის საავტორო ჰონორარის გადახდის გარეშე, ოღონდ გამოყენებული ნაწარმოების ავტორისა და დასესხების წყაროს აუცილებელი მითითებით, და ცალკეულ შემთხვევებში იმ მოცულობით, რაც განსაზღვრულია დასახული მიზნით. ასეთი რეპროგრაფიული გამრავლება დაიშვება:
ა ) ერთეულ ეგზემპლარად, მართლზომიერად გამოცემული ნაწარმოებებისა დაღუპულ, დაკარგულ, სარგებლობისათვის გამოუსადეგარ ეგზემპლართა შესაცვლელად ბიბლიოთეკებისა და არქივების მიერ; ნაწარმოების ეგზემპლარების სხვა ბიბლიოთეკებისათვის გადასაცემად მათი ფონდებიდან დაკარგული, დაღუპული ან სარგებლობისათვის გამოუსადეგარად ქცეული ნაწარმოების ეგზემპლართა შესაცვლელად, თუ ასეთი ეგზემპლარების მიღება ჩვეულებრივ პირობებში სხვა გზით შეუძლებელია;
ბ ) ერთეულ ეგზემპლარად, მართლზომიერად გამოცემული ცალკეული სტატიებისა და სხვა მცირე მოცულობის ნაწარმოებების ან წერილობითი ნაწარმოების მოკლე ნაწყვეტებისა (კომპიუტერული პროგრამების გამოკლებით) ბიბლიოთეკებისა და არქივების მიერ, _ ფიზიკურ პირთა მოთხოვნით, სასწავლო, სამეცნიერო ან პირადი მიზნებისათვის;
გ ) მართლზომიერად გამოცემული ცალკეული სტატიებისა და სხვა მცირე მოცულობის ნაწარმოებების ან წერილობითი ნაწარმოების მოკლე ნაწყვეტებისა (კომპიუტერული პროგრამების გამოკლებით) საგანმანათლებლო დაწესებულებათა მიერ _ მეცადინეობისათვის.
