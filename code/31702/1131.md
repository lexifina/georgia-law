# მუხლი 1131. ბაჟი განქორწინების მოწმობის გაცემისას
განქორწინების შესახებ გადაწყვეტილების გამოტანისას სასამართლო განსაზღვრავს, თუ რომელმა მეუღლემ უნდა გადაიხადოს კანონით განსაზღვრული ბაჟი, ასევე თუ საჭიროდ მიიჩნევს, რომ ბაჟი უნდა გადახდეს ორივე მეუღლეს, იგი განსაზღვრავს თითოეული მეუღლის მიერ გადასახდელ თანხას.
- საქართველოს 2005 წლის 28 დეკემბრის კანონი №2626 - სსმ I, №3, 16.01.2006წ., მუხ.20
