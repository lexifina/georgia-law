# მუხლი 1131. ბაჟი განქორწინების მოწმობის გაცემისას
განქორწინების შესახებ გადაწყვეტილების გამოტანისას სასამართლო განსაზღვრავს თანხას 50-დან 200 ლარამდე, რომელიც უნდა გადახდეს ერთ-ერთ ან ორივე მეუღლეს განქორწინების მოწმობის გაცემისას. თუ სასამართლო საჭიროდ მიიჩნევს, რომ ბაჟი უნდა გადახდეს ორივე მეუღლეს, იგი განსაზღვრავს თითოეული მეუღლის მიერ გადასახდელ თანხას.
