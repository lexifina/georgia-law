# მუხლი 1093. კომერციული მიზნებისთვის დამზადებული ფონოგრამების გამოყენება
1. დაიშვება მოგების მიღების მიზნით გამოცემული ფონოგრამების ან ვიდეოგრამების დამამზადებლის და ასეთ ფონოგრამაზე ან ვიდეოგრამაზე ჩაწერილი შემსრულებლის თანხმობის გარეშე, ოღონდ ჰონორარის გადახდით:
ა ) ფონოგრამების ან ვიდეოგრამების საჯარო შესრულება;
ბ ) ფონოგრამის ან ვიდეოგრამის გადაცემა ეთერში;
გ ) ფონოგრამის ან ვიდეოგრამის გადაცემა კაბელით.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ჰონორარის შეგროვება, განაწილება და გადახდა ხორციელდება იმ ორგანიზაციებიდან ერთ-ერთის მიერ, რომლებიც მართავენ ფონოგრამის დამამზადებლისა და შემსრულებლის უფლებებს კოლექტიურ საფუძველზე ამ ორგანიზაციათა შორის შეთანხმების მიხედვით.
3. ჰონორარის ოდენობა და მისი გადახდის პირობები განისაზღვრება, ერთი მხრივ, ფონოგრამებით მოსარგებლეს ან ასეთ მოსარგებლეთა და ერთ-ერთ იმ ორგანიზაციას შორის შეთანხმებით, რომლებიც მართავენ ფონოგრამებისა და ვიდეოგრამების დამამზადებელთა და შემსრულებელთა უფლებებს, ხოლო, თუ მხარეები ვერ მიაღწევენ ასეთ შეთანხმებას, _ სპეციალურად უფლებამოსილი ორგანოს მიერ. ჰონორარის ოდენობა დგინდება ფონოგრამისა და ვიდეოგრამის გამოყენების ყოველი სახეობისათვის.
4. ფონოგრამებით მოსარგებლეებმა ამ მუხლის მე-2 ნაწილში აღნიშნულ ორგანიზაციებს უნდა წარუდგინონ პროგრამები (გეგმები), რომლებიც შეიცავენ ზუსტ ცნობებს ფონოგრამებისა და ვიდეოგრამების გამოყენების ოდენობის შესახებ, აგრეთვე სხვა ცნობები და საბუთები, რაც აუცილებელია ჰონორარის მოკრებისა და განაწილებისათვის.
