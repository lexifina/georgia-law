# მუხლი 183. უძრავ ნივთზე საკუთრების შეძენა გარიგების საფუძველზე

- საქართველოს 2010 წლის 23 მარტის კანონი №2799 - სსმ I, №14, 30.03.2010წ., მუხ.94
- საქართველოს 2011 წლის 1 ივლისის კანონი №5017 - ვებგვერდი, 14.07.2011წ.
