# მუხლი 28. იურიდიული პირის ფილიალი
1. იურიდიული პირის ფილიალი _ განცალკევებული ქვედანაყოფი, რომელიც მდებარეობს იურიდიული პირის ადგილსამყოფლის გარეთ, მთლიანად ან ნაწილობრივ წარმოადგენს ან ახორციელებს მის ფუნქციებს.
2. ფილიალი არ არის იურიდიული პირი. იგი საქმიანობას ეწევა იურიდიული პირის მიერ დამტკიცებული აქტის საფუძველზე.
