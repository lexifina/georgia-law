# მუხლი 1289. მეურვისა და მზრუნველის მოვალეობანი
1. მეურვე და მზრუნველი მოვალენი არიან იზრუნონ სამეურვეო (სამზრუნველო) პირის რჩენისათვის, შეუქმნან მას აუცილებელი ყოფითი პირობები, უზრუნველყონ მოვლითა და მკურნალობით, დაიცვან მისი უფლებები და ინტერესები.
2. ამ მუხლის პირველ ნაწილში გათვალისწინებულის გარდა, სულით ავადმყოფის მეურვე მოვალეა თვალყური ადევნოს სამეურვეო პირის მუდმივ სამედიცინო მომსახურებას.
[3. ბავშვის მეურვე და მზრუნველი ვალდებული არიან, შეასრულონ მათთვის დაკისრებული მშობლის მოვალეობები. (ამოქმედდეს 2008 წლის 1 მაისიდან)]
- საქართველოს 2007 წლის 18 დეკემბრის კანონი №5624 - სსმ I, №48, 27.12.2007წ., მუხ.414
