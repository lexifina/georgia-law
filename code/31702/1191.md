# მუხლი 1191. დაქორწინებული მშობლების ჩაწერა დაბადების ჩაწერის წიგნში
1. დაქორწინებულ დედასა და მამას დაბადების ჩაწერის წიგნში ბავშვის მშობლებად ჩაწერენ ერთ-ერთი მათგანის განცხადებით.
2. ბავშვის დედად ან მამად ჩაწერილ პირს უფლება აქვს სადავო გახადოს ჩანაწერი ერთი წლის განმავლობაში იმ დროიდან, როდესაც მისთვის ცნობილი გახდა ან ცნობილი უნდა ყოფილიყო ჩანაწერი. თუ ამ დროისათვის დედად ან მამად ჩაწერილი პირი არასრულწლოვანი იყო, ერთწლიანი ვადა გამოითვლება მისი თვრამეტი წლის ასაკს მიღწევიდან.
