# მუხლი 1209. მშობლის უფლების აღდგენა
1. მშობლის უფლების აღდგენა შეიძლება მხოლოდ სასამართლო წესით ბავშვის, ერთ-ერთი მშობლის ან მეურვეობისა და მზრუნველობის ორგანოს განცხადებით.
2. მშობლის უფლების აღდგენა შეიძლება მხოლოდ იმ შემთხვევაში, თუ დადგინდება, რომ მშობლის ყოფაქცევა და მისი ცხოვრების პირობები შეიცვალა და მას შეუძლია აღზარდოს შვილი, და თუ მშობლის უფლების აღდგენას მოითხოვს ბავშვის ინტერესები.
3. თუ ბავშვს შეუსრულდა ათი წელი, სასამართლო ითვალისწინებს აგრეთვე ბავშვის სურვილსაც.
4. მშობლის უფლების აღდგენა არ დაიშვება იმ ბავშვის მიმართ, რომელიც სხვამ იშვილა.
