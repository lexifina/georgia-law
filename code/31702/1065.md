# მუხლი 1065. ვადაგასული საავტორო უფლების გამოყენების წესი
1. ნაწარმოები, რომლის საავტორო უფლების მოქმედების ვადა გასულია, შეიძლება თავისუფლად გამოიყენოს ნებისმიერმა პირმა საავტორო ჰონორარის გადაუხდელად; ამასთანავე, დაცული უნდა იყოს ავტორობის, სახელისა და ნაწარმოების ხელშეუხებლობის უფლება. ეს წესი ვრცელდება იმ ნაწარმოებებზედაც, რომლებიც არ იყო დაცული საქართველოს ტერიტორიაზე.
2. საქართველოს კანონმდებლობით შეიძლება დადგინდეს სპეციალური ანარიცხები საქართველოს ტერიტორიაზე იმ ნაწარმოებთა გამოყენებისათვის, რომელთა საავტორო უფლებების მოქმედების ვადა გასულია. ასეთი ანარიცხებიდან მიღებული შემოსავალი გადაეცემათ ავტორთა პროფესიულ ფონდებსა და ორგანიზაციებს, რომლებიც მართავენ ავტორთა ქონებრივ უფლებებს კოლექტიურ საფუძველზე. აღნიშნული ანარიცხების ოდენობა არ უნდა აღემატებოდეს ასეთ ნაწარმოებთა გამოყენების შედეგად მიღებული მოგების სამ პროცენტს.
