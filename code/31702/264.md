# მუხლი 264. სუროგაცია
1. თუ დაგირავებულია მოთხოვნა, ხოლო მოვალე ვალდებულებას ასრულებს გირავნობის ვადის გასვლამდე, მაშინ შესრულება იკავებს მოთხოვნის ადგილს მხოლოდ იმ შემთხვევაში, თუ ეს გათვალისწინებულია მხარეთა შეთანხმებით.
2. გირავნობის საგნის დაკარგვასთან, დაზიანებასთან, განადგურებასთან ან გაუფასურებასთან დაკავშირებით მიღებული ნებისმიერი სახის ანაზღაურება, მათ შორის, სადაზღვევო ანაზღაურება, იკავებს გირავნობის საგნის ადგილს მხოლოდ იმ შემთხვევაში, თუ ეს გათვალისწინებულია მხარეთა შეთანხმებით.
3. ამ მუხლის მე-2 ნაწილით გათვალისწინებულ შემთხვევებში დამგირავებელს უფლება აქვს მის მიერ მიღებული თანხით შეიძინოს დაკარგული, დაზიანებული, განადგურებული, გაუფასურებული ნივთის შემცვლელი ნივთი, რომელიც დაიკავებს გირავნობის საგნის ადგილს.
- საქართველოს 2005 წლის 30 ივნისის კანონი №1826 - სსმ I, №41, 19.07.2005წ., მუხ.284
