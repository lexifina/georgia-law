# მუხლი 1118. უცხოელთა დაქორწინების წესი
1. საქართველოში უცხოელთა დაქორწინებისათვის აუცილებელია მათი ქვეყნის სათანადო ორგანოების ცნობა, რომ არ არსებობს ამ ქორწინების დამაბრკოლებელი გარემოებანი.
2. ეს წესი არ გამოიყენება მოქალაქეობის არმქონე პირთა მიმართ ან იმ სახელმწიფოს მოქალაქეების მიმართ, რომლებიც არ გასცემენ ზემოაღნიშნულ ცნობას.
