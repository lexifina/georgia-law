# მუხლი 1279. მეურვეობის და მზრუნველობის დაწესება
მეურვეობისა და მზრუნველობის დაწესება შეიძლება იმ შემთხვევაში, როდესაც ბავშვი არ ცხოვრობს მშობლებთან და ეს უკანასკნელნი თავს არიდებენ მისი აღზრდის მოვალეობას. თუ ბავშვი ცხოვრობს მშობლებთან, რომლებიც არ ასრულებენ მისი აღზრდის მოვალეობებს, მეურვეობისა და მზრუნველობის ორგანოს შეუძლია მიმართოს სასამართლოს ასეთი მშობლებისათვის ბავშვის ჩამორთმევისა და მისი მეურვეობაში ან მზრუნველობაში გადაცემის საკითხის გადასაწყვეტად.
