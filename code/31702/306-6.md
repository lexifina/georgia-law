# მუხლი 306⁶. აუქციონზე შეძენილ ქონებაზე უფლების გადაცემის გაუქმება
თუ სპეციალისტი (აღმასრულებელი) აუქციონის პირობებით განსაზღვრულ ვადაში მის მიერ მითითებულ სადეპოზიტო ანგარიშზე არ მიიღებს აუქციონზე ქონების შემძენის მიერ გადასახდელ თანხას, სპეციალისტი (აღმასრულებელი) აუქმებს განკარგულებას აუქციონზე შეძენილ ქონებაზე უფლების გადაცემის შესახებ და ატარებს ხელახალ აუქციონს, რაც არ ჩაითვლება განმეორებით აუქციონად.
