# მუხლი 306⁶. აუქციონზე შეძენილ ქონებაზე უფლების გადაცემის გაუქმება
თუ სპეციალისტი (სასამართლო აღმასრულებელი) აუქციონის პირობებით განსაზღვრულ ვადაში მის მიერ მითითებულ სადეპოზიტო ანგარიშზე არ მიიღებს აუქციონზე ქონების შემძენის მიერ გადასახდელ თანხას, სპეციალისტი (სასამართლო აღმასრულებელი) აუქმებს განკარგულებას აუქციონზე შეძენილ ქონებაზე უფლების გადაცემის შესახებ და ატარებს ხელახალ აუქციონს, რაც არ ჩაითვლება განმეორებით აუქციონად.
- საქართველოს 2007 წლის 29 ივნისის კანონი №5127 - სსმ I, №27, 17.07.2007წ., მუხ.260
