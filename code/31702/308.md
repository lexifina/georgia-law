# მუხლი 308. საპროცესო და აღსრულების ხარჯების (აღსრულების საფასური) დაფარვა
იპოთეკით დატვირთული უძრავი ნივთის რეალიზაციის შედეგად მიღებული შემოსავლიდან მოთხოვნები უნდა დაიფაროს შემდეგი რიგითობით: საპროცესო ხარჯები, აღსრულების ხარჯები (აღსრულების საფასური), აღსრულების უფლების მქონე კრედიტორის მოთხოვნა სრული ოდენობით. თუ ამონაგები თანხით სრულად არ იფარება საპროცესო და აღსრულების ხარჯები (აღსრულების საფასური), განსხვავების გადახდის ვალდებულება ეკისრება კრედიტორს.
- საქართველოს 2007 წლის 29 ივნისის კანონი №5127 - სსმ I, №27, 17.07.2007წ., მუხ.260
- საქართველოს 2008 წლის 15 ივლისის კანონი №219 - სსმ I, №17, 28.07.2008წ., მუხ.135
