# მუხლი 308. საპროცესო და აღსრულების ხარჯების დაფარვა
იპოთეკით დატვირთული უძრავი ნივთის რეალიზაციის შედეგად მიღებული შემოსავლიდან მოთხოვნები უნდა დაიფაროს შემდეგი რიგითობით: საპროცესო ხარჯები, აღსრულების ხარჯები, აღსრულების უფლების მქონე კრედიტორის მოთხოვნა სრული ოდენობით. თუ ამონაგები თანხით სრულად არ იფარება საპროცესო და აღსრულების ხარჯები, განსხვავების გადახდის ვალდებულება ეკისრება კრედიტორს.
- საქართველოს 2007 წლის 29 ივნისის კანონი №5127 - სსმ I, №27, 17.07.2007წ., მუხ.260
