# მუხლი 578. ლიზინგის გამცემის პასუხისმგებლობა
1. ლიზინგის გამცემი ქირავნობის ხელშეკრულების წესების მიხედვით პასუხს აგებს ლიზინგის მიმღების წინაშე ქონების მიწოდების ვადის გადაცილების ან მიუწოდებლობისათვის, აგრეთვე ნაკლის მქონე ქონების მიწოდებისათვის.
2. მხარეები შეიძლება შეთანხმდნენ, რომ ლიზინგის მიმღებმა ლიზინგის გამცემისათვის პრეტენზიის წაყენებამდე უნდა მოითხოვოს დაკმაყოფილება ქონების მიმწოდებლისაგან.
