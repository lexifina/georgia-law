# მუხლი 479. უძრავი ნივთის გაყიდვის ხარჯები
მიწის ნაკვეთისა და სხვა უძრავი ნივთის მყიდველს ეკისრება ნასყიდობის ხელშეკრულების გაფორმების, საკუთრების უფლების გადაცემის სანოტარო დამოწმების, საჯარო რეესტრში რეგისტრაციისა და ამისათვის აუცილებელი საბუთების წარდგენის ხარჯები.
