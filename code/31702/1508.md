# მუხლი 1508. საავტორო სამართლის ნორმათა გავრცელება ადრე წარმოშობილ ურთიერთობებზე
1. სამოქალაქო კოდექსის მეოთხე წიგნის პირველი კარი _ "საავტორო სამართალი" _ ვრცელდება საავტორო და მომიჯნავე უფლებათა ობიექტების შექმნასა და აგრეთვე გამოყენებასთან დაკავშირებულ ურთიერთობებზე, რომლებიც წარმოიშვა ამ კოდექსის ამოქმედების შემდეგ.
2. იმ ნაწარმოებთა მიმართ, რომლებზედაც 1995 წლის 16 მაისისათვის, ესე იგი, ლიტერატურულ და მხატვრულ ნაწარმოებთა დაცვის შესახებ ბერნის კონვენციასთან საქართველოს მიერთებამდე, არ არის გასული საავტორო უფლების დაცვის ოცდახუთწლიანი ვადა, ვრცელდება ამ კოდექსის 1062-1063-ე მუხლებით გათვალისწინებული საავტორო უფლების მოქმედების ვადები.
3. იმ შესრულებაზე, რომელზედაც 1997 წლის 25 ნოემბრისათვის არ არის გასული ოცდახუთი წელი მისი პირველი შესრულებიდან, ვრცელდება ამ კოდექსის 1095-ე მუხლის პირველი ნაწილით გათვალისწინებული შემსრულებლის უფლების დაცვის ვადა.
4. იმ ფონოგრამასა და ვიდეოგრამაზე, რომლებზედაც 1997 წლის 25 ნოემბრისათვის არ არის გასული ოცდახუთი წელი მათი პირველი მართლზომიერი გამოქვეყნებიდან ან შექმნიდან იმ შემთხვევაში, თუ აღნიშნულ ვადაში ისინი არ ყოფილან გამოქვეყნებული, ვრცელდება ამ კოდექსის 1095-ე მუხლის მე-3 ნაწილით გათვალისწინებული მომიჯნავე უფლების დაცვის ვადა.
5. მაუწყებლობის ორგანიზაციების გადაცემებზე, რომლებზედაც 1997 წლის 25 ნოემბრისათვის არ არის გასული ოცდახუთი წელი მათი პირველი მართლზომიერი გამოქვეყნებიდან ან შექმნიდან იმ შემთხვევაში, თუ აღნიშნულ ვადაში ისინი არ ყოფილა გამოქვეყნებული, ვრცელდება ამ კოდექსის 1095-ე მუხლის მე-4 ნაწილით გათვალისწინებული მომიჯნავე უფლების დაცვის ვადა.
6. იურიდიულ პირთა საავტორო უფლებები, რომლებიც წარმოიშვა ამ კოდექსის ძალაში შესვლამდე, მოქმედებს ორმოცდაათი წლის განმავლობაში ნაწარმოების მართლზომიერი გამოქვეყნებიდან ან მისი შექმნიდან, თუ აღნიშნული დროის მონაკვეთში ნაწარმოები არ გამოქვეყნებულა.
