# მუხლი 1052. ჰონორარის გადამხდელები და მისი გადახდის წესი პირადი სარგებლობისათვის რეპროდუცირებისას
1. ჰონორარის გადახდა ხდება პირადი სარგებლობის მიზნით რეპროდუცირებისათვის გამოსაყენებელ მოწყობილობათა (აუდიო- და ვიდეომაგნიტოფონებისა და სხვა მოწყობილობების) და მატერიალურ მატარებელთა (ფონო- ან/და ვიდეოფირების, კასეტების, ლაზერული ფირფიტების, კომპაქტფირფიტებისა და სხვა მატერიალურ მატარებელთა) დამამზადებლებისა და იმპორტიორების მიერ.
2. ამ ჰონორართა შეგროვება და განაწილება ხორციელდება ერთ-ერთი იმ ორგანიზაციის მიერ, რომელიც მართავს ავტორთა, შემსრულებელთა და ფონოგრამისა და ვიდეოგრამის დამამზადებელთა ქონებრივ უფლებებს კოლექტიურ საფუძველზე ამ ორგანიზაციათა შორის შეთანხმების შესაბამისად.
3. ჰონორარის ოდენობა და გადახდის პირობები განისაზღვრება, ერთი მხრივ, აღნიშნულ დამამზადებლებსა და იმპორტიორებსა და, მეორე მხრივ, იმ ორგანიზაციათა შორის შეთანხმებით, რომლებიც მართავენ ავტორთა, შემსრულებელთა, ფონოგრამებისა და ვიდეოგრამების დამამზადებელთა ქონებრივ უფლებებს კოლექტიურ საფუძველზე. იმ შემთხვევაში, თუ მხარეები ვერ მიაღწევენ ასეთ შეთანხმებას სპეციალურად უფლებამოსილი ორგანოს მიერ, ჰონორარი ნაწილდება იმ ნაწარმოებთა ავტორებსა და საავტორო ან/და მომიჯნავე უფლების სხვა მფლობელთა შორის, რომლებიც მითითებულია 1051-ე და 1052-ე მუხლებში და რომელთა მიმართაც ჩვეულებრივ პირობებში შეიძლება ვივარაუდოთ, რომ მათი ნაწარმოებების რეპროდუცირება ხდებოდა პირადი მიზნებისათვის.
