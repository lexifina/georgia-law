# მუხლი 1284. ზედამხედველობა მეურვის ან მზრუნველის საქმიანობაზე
1. მეურვის ან მზრუნველის საქმიანობაზე ზედამხედველობას ახორციელებს მეურვეობისა და მზრუნველობის ორგანო სამეურვეო (სამზრუნველო) პირის საცხოვრებელი ადგილის მიხედვით.
2. ზედამხედველობის განხორციელების წესი და პირობები განისაზღვრება მეურვეობისა და მზრუნველობის ორგანოთა დებულებით.
