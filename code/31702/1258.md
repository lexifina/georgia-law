# მუხლი 1258. ჩანაწერი ნაშვილების მშობლების შესახებ
1. მშვილებლები, შვილად აყვანის რეგისტრაციისას, მათი მო თხოვნით ან სასამართლოს გადაწყვეტილების საფუძველზე, დაბადების აქტის ჩანაწერში შეიძლება ჩაიწერონ ნაშვილების მშობლებად.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული ჩაწერისათვის აუცილებელია ნაშვილების თანხმობა, თუ მას ათი წელი შეუსრულდა.
- საქართველოს 2011 წლის 20 დეკემბრის კანონი №5568 - ვებგვერდი, 28.12.2011 წ.
