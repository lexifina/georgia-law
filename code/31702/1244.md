# მუხლი 1244. შვილად აყვანის შესახებ გადაწყვეტილების რეგისტრაცია
1. შვილად აყვანის შესახებ გადაწყვეტილების რეგისტრაცია ხდება იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოში გადაწყვეტილების გამოტანის ადგილის მიხედვით.
2. სასამართლო ვალდებულია გადაწყვეტილების კანონიერ ძალაში შესვლის დღიდან 1 თვის ვადაში აცნობოს თავისი გადაწყვეტილება იუსტიციის სამინისტროს სახელმწიფო რეესტრის მწარმოებელ ტერიტორიულ ორგანოს.
3. შვილება ნამდვილია სასამართლოს გადაწყვეტილების კანონიერ ძალაში შესვლის დღიდან.
- საქართველოს 2004 წლის 24 ივნისის კანონი №179 - სსმ I, №19, 15.07.2004 წ., მუხ.79
