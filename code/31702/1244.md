# მუხლი 1244. შვილად აყვანის შესახებ გადაწყვეტილების რეგისტრაცია
1. შვილად აყვანის შესახებ გადაწყვეტილების რეგისტრაცია ხდება სააგენტოს ტერიტორიულ სამსახურში მშვილებლის ან შვილად ასაყვანის საცხოვრებელი ადგილის მიხედვით ან ბავშვის შვილად აყვანის შესახებ სასამართლოს გადაწყვეტილების გამოტანის ადგილის მიხედვით.
2. სასამართლო ვალდებულია გადაწყვეტილების კანონიერ ძალაში შესვლიდან 1 თვის ვადაში აცნობოს თავისი გადაწყვეტილება სააგენტოს ტერიტორიულ სამსახურს.
[2. სასამართლო ვალდებულია გადაწყვეტილების კანონიერ ძალაში შესვლიდან 5 დღის ვადაში აცნობოს თავისი გადაწყვეტილება სააგენტოს ტერიტორიულ სამსახურს. (ამოქმედდეს 2010 წლის 1 მარტიდან)]
3. შვილება ნამდვილია სასამართლოს გადაწყვეტილების კანონიერ ძალაში შესვლის დღიდან.
