# მუხლი 1244. შვილად აყვანის შესახებ გადაწყვეტილების რეგისტრაცია
1. გადაწყვეტილება შვილად აყვანის შესახებ რეგისტრირებულ უნდა იქნეს მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში გადაწყვეტილების გამოტანის ადგილის მიხედვით.
2. სასამართლო ვალდებულია გადაწყვეტილების კანონიერ ძალაში შესვლის დღიდან ერთი თვის ვადაში თავისი გადაწყვეტილების შესახებ აცნობოს მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოს.
3. შვილება ნამდვილია სასამართლოს გადაწყვეტილების კანონიერ ძალაში შესვლის დღიდან.
