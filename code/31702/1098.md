# მუხლი 1098. კონტრაფაქციული პროდუქციის ჩამორთმევა
1. სასამართლოს შეუძლია გამოიტანოს გადაწყვეტილება ნაწარმოების ან ფონოგრამებისა და ვიდეოგრამების კონტრაფაქციული ეგზემპლარების, აგრეთვე მათი რეპროდუცირებისათვის საჭირო მასალებისა და მოწყობილობების ჩამორთმევის შესახებ. ნაწარმოების ან ფონოგრამის კონტრაფაქციული ეგზემპლარები, საავტორო და მომიჯნავე უფლებათა მფლობელის მოთხოვნისამებრ შეიძლება გადაეცეს ამ უკანასკნელს.
2. ნაწარმოების ან ფონოგრამისა და ვიდეოგრამების კონტრაფაქციული ეგზემპლარები, რომლებიც არ იქნა გამოთხოვილი საავტორო და მომიჯნავე უფლებათა მფლობელის მიერ, აგრეთვე მათი რეპროდუცირებისათვის საჭირო მასალები და მოწყობილობები, სასამართლოს გადაწყვეტილების მიხედვით ექვემდებარება განადგურებას.
3. ჩამორთმევას არ ექვემდებარება მესამე პირების მიერ კეთილსინდისიერად შეძენილი ნაწარმოების ან ფონოგრამებისა და ვიდეოგრამების კონტრაფაქციული ეგზემპლარები.
