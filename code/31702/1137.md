# მუხლი 1137. განქორწინების რეგისტრაცია საცხოვრებელი ადგილის მიხედვით
განქორწინების რეგისტრაცია ხდება მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოებში ორივე ან ერთ-ერთი მეუღლის საცხოვრებელი ადგილის მიხედვით.
