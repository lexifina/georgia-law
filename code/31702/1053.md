# მუხლი 1053. ჰონორარის გადახდისაგან განთავისუფლება
1. ჰონორარის გადახდევინება არ მოხდება 1051-ე და 1052-ე მუხლებში გათვალისწინებულ მოწყობილობებსა და მატერიალურ მატარებლებთან დაკავშირებით, რომლებიც წარმოადგენენ:
ა) ექსპორტის საგანს;
ბ) პროფესიულ მოწყობილობას, რომელიც არ არის განკუთვნილი საშინაო გამოყენებისათვის.
2. ჰონორარის გადახდევინება ასევე არ მოხდება აღნიშნული მოწყობილობებისა და მასალების პირადი მიზნებისათვის ფიზიკურ პირთა მიერ იმპორტის შემთხვევაში.
