# მუხლი 1307. მემკვიდრეები
მემკვიდრეები შეიძლება იყვნენ:
ა ) კანონით მემკვიდრეობის დროს _ პირები, რომლებიც ცოცხლები იყვნენ მამკვიდრებლის სიკვდილის მომენტისათვის, და აგრეთვე მამკვიდრებლის შვილები, რომლებიც მისი გარდაცვალების შემდეგ ცოცხალი დაიბადებიან;
ბ ) ანდერძით მემკვიდრეობისას _ პირები, რომლებიც ცოცხლები იყვნენ მამკვიდრებლის სიკვდილის მომენტისათვის, აგრეთვე ისინი, რომლებიც ჩაისახნენ მის სიცოცხლეში და დაიბადნენ მისი გარდაცვალების შემდეგ, მიუხედავად იმისა, მისი შვილები არიან ისინი თუ არა, ასევე იურიდიული პირები.
