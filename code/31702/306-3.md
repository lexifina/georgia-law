# მუხლი 306³. აუქციონის ჩატარების წესები
1. აუქციონს ატარებს სპეციალისტი (სასამართლო აღმასრულებელი). იგი აუქციონს გახსნილად აცხადებს და სთავაზობს საწყის ფასს.
2. სპეციალისტი (სასამართლო აღმასრულებელი) აუქციონის ჩატარებამდე ადგენს, საჯარო რეესტრში რეგისტრირებული უფლებებიდან რომელი სარგებლობს უპირატესი უფლებით იმ კრედიტორის პრეტენზიასთან შედარებით, რომლისთვისაც ხორციელდება აღსრულება.
3. აუქციონზე სპეციალისტი (სასამართლო აღმასრულებელი) აცხადებს:
ა) რომ საჯარო რეესტრში რეგისტრირებული უპირატესი უფლებები იმ კრედიტორის მოთხოვნასთან შედარებით, რომლისთვისაც ხორციელდება აღსრულება, ძალაში რჩება და გადახდით არ დაკმაყოფილდება;
ბ) თუ რა ღირებულება აქვს გარდამავალ უფლებებს (კრედიტორის მოთხოვნასთან შედარებით უპირატეს უფლებებს ან უფლებებს, რომლებიც გადაჰყვება უძრავ ნივთს აუქციონის წესით მისი რეალიზაციის შემდეგ);
გ) რომ აუქციონზე შემოთავაზებულ ფასებს უნდა გამოაკლდეს გარდამავალ უფლებათა ფასი, ხოლო დანარჩენი გადახდილი უნდა იქნეს ნაღდი ფულით.
4. სპეციალისტი (სასამართლო აღმასრულებელი) მონაწილე მხარეებს აუქციონის პროცესის დაწყებამდე განუმარტავს აუქციონის პირობებს.
