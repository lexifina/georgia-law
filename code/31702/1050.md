# მუხლი 1050. მართლზომიერად გამოქვეყნებულ ნაწარმოებთა ეგზემპლარების რეპროდუცირება
1. დაშვებულია მართლზომიერად გამოქვეყნებულ ნაწარმოებთა ეგზემპლარების რეპროდუცირება ფიზიკურ პირთა მიერ მხოლოდ და მხოლოდ პირადი სარგებლობისათვის ავტორის ან საავტორო უფლების სხვა მფლობელის თანხმობისა და მისთვის ჰონორარის გადახდის გარეშე, გარდა იმ შემთხვევებისა, რომლებიც გათვალისწინებულია 1051-ე და 1052-ე მუხლებით.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული დებულებები არ გამოიყენება:
ა ) არქიტექტურის ნაწარმოებთა რეპროდუცირებისას შენობებისა და ანალოგიურ ნაგებობათა ფორმით;
ბ ) მონაცემთა ბაზების რეპროდუცირებისას;
გ ) კომპიუტერული პროგრამების რეპროდუცირებისას, იმ შემთხვევათა გარდა, რომლებიც გათვალისწინებულია 1060-ე მუხლით;
დ ) წიგნების (მთლიანობაში), ნოტებისა და სახვითი ხელოვნების ნაწარმოებების რეპროგრაფიული რეპროდუცირებისას (ასლების გადაღება).
