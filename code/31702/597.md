# მუხლი 597. საიჯარო ქირის შემცირების მოთხოვნა
თუ საიჯარო მიწაზე სტიქიური უბედურებების ან სხვა ფორსმაჟორული გარემოებების შედეგად მოიჯარეს მოსავლის ნახევარზე მეტი გაუნადგურდა, მას უფლება აქვს მოითხოვოს საიჯარო ქირის, ხოლო მიწის მესაკუთრეს - მიწის გადასახდის შესაბამისი პროპორციით შემცირება. საიჯარო ქირის და მიწის გადასახადის შემცირების მოთხოვნის უფლება მოიჯარესა და მესაკუთრეს აქვთ მხოლოდ მოსავლის აღებამდე, ზარალის ოდენობისა და მიზეზების შესახებ დადგენილი წესით გაფორმებული აქტის საფუძველზე.
- საქართველოს 2002 წლის 14 თებერვლის კანონი №1282 - სსმ I, №4, 05.03.2002 წ., მუხ.18
