# მუხლი 1511. არაკომერციული იურიდიული პირების ხელახალი რეგისტრაცია
1. სამოქალაქო კოდექსის ამოქმედებამდე მოქალაქეთა საზოგადოებრივი გაერთიანებების შესახებ საქართველოს რესპუბლიკის კანონის საფუძველზე შექმნილი არაკომერციული იურიდიული პირები ექვემდებარებიან ხელახალ რეგისტრაციას 1999 წლის 1 სექტემბრამდე; აღნიშნული იურიდიული პირები ხელახალ რეგისტრაციას ექვემდებარებიან ამ ვადამდე იმ შემთხვევაშიც, თუ მათი დამფუძნებლები ან წევრები მიიღებენ გადაწყვეტილებას წესდებაში ან სხვა დამფუძნებელ დოკუმენტებში ცვლილებების შეტანის თაობაზე.
2. ხელახალი რეგისტრაციისათვის აუცილებელია:
ა) არაკომერციული იურიდიული პირების იმ ორგანოთა გადაწყვეტილება, რომლებიც მოქალაქეთა საზოგადოებრივი გაერთიანებების შესახებ საქართველოს რესპუბლიკის კანონის ან ამ იურიდიული პირების წესდების შესაბამისად უფლებამოსილნი არიან მიიღონ გადაწყვეტილება წესდებაში ცვლილებების შეტანის ან მათი რეორგანიზაციის შესახებ;
ბ) წესდების ახალი რედაქცია, რომელიც უნდა შეესაბამებოდეს სამოქალაქო კოდექსის მოთხოვნებს.
3. ხელახალი რეგისტრაციის შედეგად რეგისტრირებული არაკომერციული იურიდიული პირი ადრე რეგისტრირებული იურიდიული პირის უფლებამონაცვლეა.
4. თუ არაკომერციული იურიდიული პირები არ გაივლიან ხელახალ რეგისტრაციას, საქართველოს იუსტიციის სამინისტრო ან სასამართლო, რომლის ტერიტორიაზედაც ამ პირებს აქვთ ადგილსამყოფელი, ვალდებულნი არიან გააუქმონ რეგისტრაცია.
5. ხელახალი რეგისტრაციისათვის არაკომერციული იურიდიული პირები იხდიან ჩვეულებრივი რეგისტრაციისათვის გათვალისწინებული სარეგისტრაციო მოსაკრებლის ოცდახუთ პროცენტს.
- საქართველოს 1999 წლის 19 მარტის კანონი №1860 - სსმ I, №10(17), 01.04.1999 წ., მუხ.32
