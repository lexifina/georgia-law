# მუხლი 1179. მოვალეობები, რომელთა შეცვლაც საქორწინო ხელშეკრულებით დაუშვებელია
1. საქორწინო ხელშეკრულებით არ შეიძლება შეიცვალოს მეუღლეთა ურთიერთრჩენის მოვალეობა, მშობლების უფლება-მოვალეობანი შვილების მიმართ, საალიმენტო მოვალეობანი და _ დავის შემთხვევაში _ სასამართლოში მიმართვის უფლება.
2. ხელშეკრულებით ასევე არ შეიძლება გათვალისწინებულ იქნეს ისეთი პირობები, რომლებიც მძიმე მდგომარეობაში აყენებენ ერთ-ერთ მეუღლეს.
