# მუხლი 1260. ნაშვილების ურთიერთობანი ღვიძლ მშობლებთან
[ მუხლი 1260. ნაშვილების ურთიერთობანი ბიოლოგიურ მშობლებთან
(ამოქმედდეს 2008 წლის 1 მაისიდან)]
1. ნაშვილები კარგავს პირად და ქონებრივ უფლებებს და თავისუფლდება მოვალეობისაგან თავისი ღვიძლი მშობლებისა და წარმოშობით ნათესავების მიმართ.
[1. ნაშვილები კარგავს პირად და ქონებრივ უფლებებს და თავისუფლდება მოვალეობისაგან თავისი ბიოლოგიური მშობლებისა და წარმოშობით ნათესავების მიმართ. (ამოქმედდეს 2008 წლის 1 მაისიდან)]
2. ერთი პირის მიერ ბავშვის შვილად აყვანის შემთხვევაში ნაშვილები ინარჩუნებს აღნიშნულ უფლება-მოვალეობებს _ დედის სურვილით, თუ მშვილებელი მამაკაცია, ან მამის სურვილით _ თუ მშვილებელი ქალია.
