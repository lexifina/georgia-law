# მუხლი 301. იძულებით გაყიდვა აუქციონზე
1. იძულებით გაყიდვა აუქციონზე ხდება კრედიტორის განცხადების საფუძველზე სასამართლოს მიერ, რომელიც ნიშნავს სპეციალისტს (ექსპერტს).
2. სასამართლოს გადაწყვეტილება ქვეყნდება საჯაროდ. გარდა ამისა, სასამართლო ვალდებულია მოსალოდნელი აუქციონის შესახებ შეატყობინოს რეესტრში შეტანილ უფლებამოსილ პირებს.
