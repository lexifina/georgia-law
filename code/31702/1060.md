# მუხლი 1060. კომპიუტერული პროგრამისა და მონაცემთა ბაზის თავისუფალი გამოყენება
1. პირი, რომელიც მართლზომიერად ფლობს კომპიუტერულ პროგრამას ან მონაცემთა ბაზის ეგზემპლარს, ავტორის ან საავტორო უფლების სხვა მფლობელის თანხმობისა და მისთვის საავტორო ჰონორარის გადახდის გარეშე უფლებამოსილია:
ა ) შეიტანოს კომპიუტერულ პროგრამაში ან მონაცემთა ბაზაში ცვლილებები, რომლებიც აუცილებელია მომხმარებლის ტექნიკურ საშუალებათა ფუნქციონირებისათვის, ასევე განახორციელოს კომპიუტერული პროგრამის ან მონაცემთა ბაზის ფუნქციონირებასთან დაკავშირებული ნებისმიერი მოქმედება, მათ შორის, ჩაწერა და კომპიუტერის მეხსიერებაში შენახვა (ერთი კომპიუტერის ან ქსელის ერთი მომხმარებლისათვის), აგრეთვე აშკარა შეცდომების გასწორება, თუ საავტორო ხელშეკრულებით სხვა რამ არ არის გათვალისწინებული;
ბ ) დაამზადოს კომპიუტერის პროგრამის ან მონაცემთა ბაზის სარეზერვო ეგზემპლარი იმ პირობით, რომ ეს ეგზემპლარი განკუთვნილია მხოლოდ საარქივო მიზნებისათვის და მართლზომიერი მფლობელის დაკარგული, განადგურებული ან გამოსაყენებლად უვარგისი ეგზემპლარის შესაცვლელად.
2. კომპიუტერული პროგრამის ან მონაცემთა ბაზის სარეზერვო ეგზემპლარი არ შეიძლება გამოყენებულ იქნეს ამ მუხლის პირველი ნაწილით დადგენილი წესებისაგან განსხვავებული მიზნებისათვის და უნდა განადგურდეს კომპიუტერული პროგრამის ან მონაცემთა ბაზის მფლობელობის უფლების შეწყვეტისთანავე.
