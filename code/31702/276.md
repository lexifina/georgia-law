# მუხლი 276. მოგირავნის დაკმაყოფილება
1. მოგირავნის დაკმაყოფილება ხდება გირავნობის საგნის რეალიზაციით, თუ კანონით სხვა რამ არ არის გათვალისწინებული.
2. თუ გირავნობის საგნის რეალიზაციიდან ამონაგები თანხა საკმარისი არ არის გირავნობით უზრუნველყოფილი მოთხოვნის დასაფარავად, მაშინ მოგირავნის მოთხოვნა დაუკმაყოფილებელ ნაწილში ძალაში რჩება.
