# მუხლი 1125. განქორწინება ერთ-ერთი მეუღლის განცხადებით
მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში ერთ-ერთი მეუღლის განცხადებით განქორწინება ხდება იმ პირთან, რომელიც:
ა) კანონით დადგენილი წესით აღიარებულია უგზო-უკვლოდ დაკარგულად;
ბ) სულით ავადმყოფობის ან ჭკუასუსტობის გამო აღიარებულია ქმედუუნაროდ;
გ) სასამართლოს მიერ მსჯავრდადებულია დანაშაულისათვის თავისუფლების აღკვეთით არანაკლებ სამი წლისა.
