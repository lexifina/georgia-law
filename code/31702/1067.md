# მუხლი 1067. ავტორის ქონებრივი უფლების გადაცემა
1. ავტორს ან საავტორო უფლების სხვა მფლობელს შეუძლია გადასცეს თავისი ქონებრივი უფლებები სხვა პირს _ უფლებამონაცვლეს. ასეთი ხელშეკრულებით უფლებამონაცვლეზე გადადის ნაწარმოების გამოყენების ყველა განსაკუთრებული უფლება, რომელიც გათვალისწინებულია 1045-ე მუხლით.
2. ავტორს ან საავტორო უფლების სხვა მფლობელს შეუძლია აგრეთვე სხვა პირს მისცეს ნებართვა განსაზღვრული საშუალებებით ნაწარმოების გამოსაყენებლად.
3. განსაზღვრული საშუალებებით ნაწარმოების გამოყენების ნებართვა გაიცემა განსაკუთრებული ან ჩვეულებრივი ლიცენზიის გაცემის შესახებ საავტორო ხელშეკრულების საფუძველზე.
