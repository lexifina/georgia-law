# მუხლი 1071. საავტორო ხელშეკრულება
1. საავტორო ხელშეკრულება უნდა ითვალისწინებდეს: გამოსაყენებელი ნაწარმოების ზუსტ აღწერას (მოცულობა, ჟანრი, სახელწოდება), ნაწარმოების გამოყენების კონკრეტულ საშუალებებს, ვადასა და ტერიტორიას, რომლის ფარგლებშიც ხდება უფლების გადაცემა; ჰონორარის ოდენობას ან/და ჰონორარის ოდენობის განსაზღვრის წესს ნაწარმოების გამოყენების ყოველი საშუალებისათვის, მისი გადახდის წესსა და ვადას, აგრეთვე სხვა პირობებს, რომლებსაც მხარეები არსებითად მიიჩნევენ.
2. ნაწარმოების ყველა იმ საშუალებით გამოყენების უფლება, რომლებიც ხელშეკრულებით პირდაპირ არ არის გათვალისწინებული, ეკუთვნის ავტორს.
3. თუ საავტორო ხელშეკრულებაში არ არის გათვალისწინებული ნაწარმოების გამოყენების საშუალებები (საავტორო ხელშეკრულებით გადაცემული კონკრეტული უფლებები), ხელშეკრულება ითვლება დადებულად ნაწარმოების გამოყენების ისეთ საშუალებებზე, რომლებიც შეიძლება ჩაითვალოს აუცილებლად მხარეთა იმ განზრახვის შესასრულებლად, რომელიც მათ ჰქონდათ ხელშეკრულების დადებისას.
4. თუ ხელშეკრულებაში არ არის გათვალისწინებული უფლების გადაცემის ვადა, ხელშეკრულება შეიძლება გაუქმებულ იქნეს ავტორის მიერ მისი დადებიდან სამი წლის გასვლის შემდეგ. მოსარგებლეს ამის თაობაზე უნდა ეცნობოს წერილობით, ხელშეკრულების გაუქმებამდე ექვსი თვით ადრე.
5. თუ საავტორო ხელშეკრულებაში არ არის გათვალისწინებული უფლების გადაცემის ტერიტორია, ხელშეკრულებით გადაცემული უფლების მოქმედება შემოიფარგლება საქართველოს ტერიტორიით.
6. საავტორო ხელშეკრულებაში ჰონორარის ოდენობა და მისი გადახდის წესი განისაზღვრება მხარეთა შეთანხმებით.
7. თუ გამოცემის ან ნაწარმოების სხვაგვარი რეპროდუცირების საავტორო ხელშეკრულებაში ჰონორარი განისაზღვრება ფიქსირებული თანხით, მაშინ ხელშეკრულებით უნდა იყოს დადგენილი ნაწარმოების მაქსიმალური ტირაჟი.
8. საავტორო ხელშეკრულებით გადაცემული უფლებები შეიძლება მთლიანად ან ნაწილობრივ გადაეცეს სხვა პირებს, თუ ეს პირდაპირ არის გათვალისწინებული ხელშეკრულებით.
