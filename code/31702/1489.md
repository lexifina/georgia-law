# მუხლი 1489. ხანდაზმულობის საერთო ვადის გამოყენება
1. კრედიტორების მიერ მოთხოვნის წარდგენის ვადა არ ვრცელდება იმ დანახარჯების მოთხოვნებზე, რომლებიც გამოწვეული იყო მამკვიდრებლის უკანასკნელი ავადმყოფობის დროს მოვლითა და მკურნალობით, ხელფასის გასტუმრებით, დაკრძალვით, სამკვიდროს დაცვითა და მართვით, ასევე მესამე პირების მოთხოვნებზე _ ქონებაზე საკუთრების უფლების ცნობის და მათი კუთვნილი ქონების გამოთხოვის თაობაზე.
2. ამ მუხლის პირველ ნაწილში აღნიშნული მოთხოვნების მიმართ გამოიყენება ხანდაზმულობის საერთო ვადები.
