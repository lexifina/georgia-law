# მუხლი 295. იპოთეკისა და მის საფუძვლად არსებული მოთხოვნის გადასვლა სხვა პირზე
იპოთეკა და მის საფუძვლად არსებული მოთხოვნა შეიძლება მხოლოდ ერთდროულად და ერთობლივად იქნეს სხვა პირისათვის გადაცემული. მოთხოვნის გადაცემასთან ერთად ახალ კრედიტორზე გადადის იპოთეკაც. მოთხოვნის გადაცემა მხოლოდ მაშინ ჩაითვლება ნამდვილად, როცა წერილობითი ფორმით დადებული გარიგება იპოთეკის დადგენის შესახებ გადაეცემა ახალ კრედიტორს და საჯარო რეესტრში იგი რეგისტრირებული იქნება, როგორც ახალი კრედიტორი.
- საქართველოს 2006 წლის 8 დეკემბერის კანონი №3879 - სსმ I, №48, 22.12.2006 წ., მუხ.321
