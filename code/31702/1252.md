# მუხლი 1252. ქორწინებისგარეშე დაბადებული ბავშვის შვილება
1. ქორწინებისგარეშე დაბადებული ბავშვის შვილად აყვანისას აუცილებელია დედის წერილობითი თანხმობა, რომელსაც იგი გასცემს ბავშვის დაბადებიდან ექვსი კვირის შემდეგ. მესამე პირის მიერ ასეთი ბავშვის შვილად აყვანის დროს გადაწყვეტილება არ მიიღება, თუ მამამ შეიტანა განცხადება მამობის დადგენის ან ბავშვის შვილად აყვანის შესახებ.
2. ამ მუხლის მოქმედება არ ვრცელდება ქორწინების გარეშე დაბადებული ბავშვის სხვა სახელმწიფოში გაშვილებაზე. ქორწინების გარეშე დაბადებული ბავშვის სხვა სახელმწიფოში გაშვილება რეგულირდება საქართველოს კანონით "შვილად აყვანის წესის შესახებ".
- საქართველოს 1999 წლის 9 ივნისის კანონი №2078 - სსმ I, №24(31), 26.06.1999 წ., მუხ.112
