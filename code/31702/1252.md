# მუხლი 1252. ქორწინებისგარეშე დაბადებული ბავშვის შვილება
ქორწინებისგარეშე დაბადებული ბავშვის შვილად აყვანისას აუცილებელია დედის წერილობითი თანხმობა, რომელსაც იგი გასცემს ბავშვის დაბადებიდან ექვსი კვირის შემდეგ. მესამე პირის მიერ ასეთი ბავშვის შვილად აყვანის დროს გადაწყვეტილება არ მიიღება, თუ მამამ შეიტანა განცხადება მამობის დადგენის ან ბავშვის შვილად აყვანის შესახებ.
- საქართველოს 1999 წლის 9 ივნისის კანონი №2078 - სსმ I, №24(31), 26.06.1999 წ., მუხ.112
