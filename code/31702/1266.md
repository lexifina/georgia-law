# მუხლი 1266. თანხმობის გარეშე განხორციელებული შვილად აყვანის გაუქმება
1. შვილად აყვანა მშობელთა თანხმობის გარეშე, როცა ასეთი თანხმობა აუცილებელია, შეიძლება მშობელთა სარჩელით გააუქმოს სასამართლომ, თუ იგი დაადგენს, რომ მშობლებისათვის ბავშვის დაბრუნება შეესაბამება მის ინტერესებს.
2. მშობელთა თხოვნით, შვილად აყვანის გაუქმება, თუ ნაშვილებს შეუსრულდა ათი წელი, დაიშვება მხოლოდ ნაშვილების თანხმობით.

(ამოქმედდეს 2008 წლის 1 მაისიდან)]
