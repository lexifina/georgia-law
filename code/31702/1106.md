# მუხლი 1106. ქორწინების ცნება
ქორწინება ოჯახის შექმნის მიზნით ქალისა და მამაკაცის ნებაყოფლობითი კავშირია, რომელიც რეგისტრირებულია მოქალაქეთა მდგომარეობის რეგისტრაციის სახელმწიფო ორგანოში.
