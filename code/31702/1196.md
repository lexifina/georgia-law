# მუხლი 1196. შვილის გვარის გამოცვლა
1. მშობლებს შორის ქორწინების შეწყვეტა არ იწვევს შვილის გვარის გამოცვლას.
2. მშობლებს, რომლებთანაც არასრულწლოვანი შვილი საცხოვრებლად დარჩა ქორწინების შეწყვეტის ან ბათილად ცნობის შემდეგ, უფლება აქვთ, შვილის ინტერესების შესაბამისად, მიმართონ სასამართლოს შვილისათვის თავიანთი გვარის მიკუთვნების შესახებ. თუ ბავშვი ათ წელზე მეტი ხნისაა, გვარის შეცვლისათვის საჭიროა მისი თანხმობაც.
