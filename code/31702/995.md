# მუხლი 995. სულით ავადმყოფის მიერ მიყენებული ზიანის ანაზღაურება
1. თუ ჭკუასუსტი ან სულით ავადმყოფი პირი მართლსაწინააღმდეგო მოქმედებით მიაყენებს ზიანს სხვა პირს, მას არ ეკისრება ზიანის ანაზღაურების ვალდებულება.
2. თუ პირს ეკისრება მეთვალყურეობა ზიანის მიმყენებელზე, მაშინ იგი ვალდებულია აანაზღაუროს ზიანი, გარდა იმ შემთხვევებისა, როცა შეუძლებელი იყო ამ ზიანის თავიდან აცილება.
