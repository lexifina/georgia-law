# მუხლი 1041. აუდიოვიზუალურ ნაწარმოებში ჩართული ნაწარმოების ავტორის უფლებები
ავტორი ადრე შექმნილი იმ ნაწარმოებისა, რომელიც გადამუშავებული ან ჩართულია შემადგენელ ნაწილად აუდიოვიზუალურ ნაწარმოებში, აგრეთვე ავტორები იმ ნაწარმოებებისა, რომლებიც შექმნილია აუდიოვიზუალური ნაწარმოების შექმნის პროცესში, ინარჩუნებენ საავტორო უფლებას დამოუკიდებელი მნიშვნელობის მქონე თავიანთ ნაწარმოებებზე და უფლება აქვთ დამოუკიდებლად გამოიყენონ ასეთი ნაწარმოებები, თუ ხელშეკრულებით სხვა რამ არ არის გათვალისწინებული _ იმ პირობით, რომ ასეთი სარგებლობა ხელს არ შეუშლის აუდიოვიზუალური ნაწარმოების ნორმალურ გამოყენებას.
