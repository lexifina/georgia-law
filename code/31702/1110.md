# მუხლი 1110. დაქორწინების გაფორმება
1. დაქორწინება ფორმდება ერთი თვის გასვლის შემდეგ იმ დღიდან, როცა დაქორწინების მსურველნი განცხადებას შეიტანენ მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში. განცხადება ძალაშია ერთთვიანი ვადის გასვლიდან ორი თვის განმავლობაში.
2. ცალკეულ შემთხვევებში, პატივსადები მიზეზის არსებობისას, ერთთვიანი ვადა შეიძლება შემცირდეს მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოს მიერ.
3. თუ არსებობს განსაკუთრებული გარემოებები, როგორიცაა ბავშვის დაბადება, ერთ-ერთი მხარის სიცოცხლისათვის რეალური საფრთხე და სხვა მსგავსი გარემოებები, ქორწინების რეგისტრაცია შეიძლება მოხდეს განცხადების შეტანის დღესვე.
