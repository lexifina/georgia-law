# მუხლი 1347. ერთობლივი ანდერძი
ანდერძი უნდა შეიცავდეს ერთი მამკვიდრებლის განკარგულებას. ორი ან მეტი პირის მიერ ერთობლივად ანდერძის შედგენა არ დაიშვება. მხოლოდ მეუღლეებს შეუძლიათ შეადგინონ ერთობლივი ანდერძი ურთიერთმემკვიდრეობის შესახებ, რომელიც შეიძლება გაუქმდეს ერთ-ერთი მეუღლის მოთხოვნით, მაგრამ _ ჯერ კიდევ ორივე მეუღლის სიცოცხლეში.
