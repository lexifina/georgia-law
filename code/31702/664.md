# მუხლი 664. პასუხისმგებლობის შეზღუდვა
მოგზაურობის მომწყობს ტურისტთან შეთანხმებით შეუძლია შეზღუდოს თავისი პასუხისმგებლობა მომსახურების ღირებულების სამმაგი ოდენობით, თუ:
ა ) ტურისტისათვის მიყენებული ზიანი არ იყო გამოწვეული განზრახ ან უხეში გაუფრთხილებლობით,
ან
ბ ) მოგზაურობის მომწყობი ერთპიროვნულად მთლიანად არ აგებს პასუხს ტურისტის წინაშე იმ ზიანისათვის, რომელიც წარმოიშვა მოგზაურობის მომწყობის ვალდებულების შემსრულებელთაგან ერთ-ერთის ბრალის შედეგად.
