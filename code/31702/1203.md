# მუხლი 1203. პაპისა და ბებიის უფლებები არასრულწლოვანი შვილიშვილების მიმართ
პაპასა და ბებიას უფლება აქვთ ურთიერთობა იქონიონ თავიანთ არასრულწლოვან შვილიშვილებთან მაშინაც, როცა ისინი უშუალოდ არ მონაწილეობენ შვილიშვილების აღზრდაში. თუ მშობლები უარს ეუბნებიან პაპასა და ბებიას შვილიშვილებთან ურთიერთობაზე, სასამართლოს შეუძლია დაავალდებულოს მშობლები საშუალება მისცენ პაპასა და ბებიას, ურთიერთობა იქონიონ შვილიშვილებთან სასამართლოს მიერ დადგენილი წესით, თუკი ეს ხელს არ შეუშლის ბავშვების ნორმალურ აღზრდას და ცუდ გავლენას არ მოახდენს მათზე.
