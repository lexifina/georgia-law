# მუხლი 1306. ცნება
1. გარდაცვლილი პირის (მამკვიდრებლის) ქონების გადასვლა სხვა პირებზე (მემკვიდრეებზე) ხორციელდება კანონით ან ანდერძით, ანდა ორივე საფუძვლით.
2. კანონით მემკვიდრეობა _ გარდაცვლილის ქონების გადასვლა კანონში მითითებულ პირებზე _ მოქმედებს, თუ მამკვიდრებელს არ დაუტოვებია ანდერძი, ან თუ ანდერძი მოიცავს სამკვიდროს ნაწილს, ან თუ ანდერძი მთლიანად ან ნაწილობრივ ბათილად იქნება ცნობილი.
