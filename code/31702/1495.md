## სამკვიდროს დაცვა
# მუხლი 1495. ცნება
ადგილზე არმყოფი მემკვიდრეების, საანდერძო დანაკისრის მიმღებთა და საჯარო ინტერესების დასაცავად სამკვიდროს გახსნის ადგილის ნოტარიუსი დაინტერესებული პირების, ანდერძის აღმსრულებლის ან თავისი ინიციატივით იღებს სამკვიდროს დაცვისათვის აუცილებელ ზომებს, რაც გაგრძელდება ყველა მემკვიდრის მიერ სამკვიდროს მიღებამდე ან სამკვიდროს მისაღებად დადგენილი ვადის გასვლამდე.
