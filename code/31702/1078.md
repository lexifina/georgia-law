# მუხლი 1078. მომიჯნავე უფლებათა სუბიექტები
1. მომიჯნავე უფლებების სუბიექტებს წარმოადგენენ შემსრულებელები, ფონოგრამის ან ვიდეოგრამის დამამზადებლები და მაუწყებლობის ორგანიზაციები.
2. ფონოგრამის ან ვიდეოგრამის დამამზადებლები და მაუწყებლობის ორგანიზაციები ამ კარით გათვალისწინებულ უფლებებს ახორციელებენ ფონოგრამაზე ან ვიდეოგრამაზე ჩაწერილი ანდა ეთერში ან კაბელით გადასაცემი ნაწარმოების შემსრულებელსა და ავტორთან დადებული ხელშეკრულებით მინიჭებული უფლებების ფარგლებში.
3. შემსრულებელი ახორციელებს ამ კარში აღნიშნულ უფლებებს შესრულებული ნაწარმოების ავტორის უფლებათა დაცვის პირობით.
