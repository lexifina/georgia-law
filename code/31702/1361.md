# მუხლი 1361. ყრუს, წერა-კითხვის არმცოდნე ყრუს, უსინათლოს ან წერა-კითხვის არმცოდნე პირის ანდერძი
1. თუ მოანდერძე ყრუა ან წერა-კითხვის არმცოდნე ყრუა, საანდერძო განკარგულება შედგენილი უნდა იქნეს ნოტარიუსთან 2 მოწმისა და ისეთი პირის თანდასწრებით, რომელსაც შეუძლია მას განუმარტოს საქმის არსი და თავისი ხელმოწერით დაადასტუროს, რომ ანდერძის შინაარსი მოანდერძის ნებას შეესაბამება.
2. თუ მოანდერძე უსინათლოა ან წერა-კითხვის არმცოდნე პირია, საანდერძო განკარგულება შედგენილი უნდა იქნეს ნოტარიუსთან 3 მოწმის თანდასწრებით და ამის შესახებ უნდა გაკეთდეს სათანადო ჩანაწერი, ხოლო შესაბამისი ტექსტი მოანდერძეს უნდა წაეკითხოს.
3. ჩამწერი და წამკითხველი შეიძლება იყვნენ მოწმეებიც, მაგრამ ჩამწერი არ უნდა იყოს წამკითხველი.
4. ჩანაწერში მითითებულ უნდა იქნეს, თუ ვინ გააკეთა ჩანაწერი და ვინ წაუკითხა მოანდერძეს. ჩანაწერს ხელი უნდა მოაწერონ მოწმეებმა და დაადასტუროს ნოტარიუსმა.
- საქართველოს 2025 წლის 26 ივნისის კანონი №837 - ვებგვერდი, 03.07.2025წ.
