# მუხლი 285. რეალიზაციიდან მიღებული შემოსავალი
ვინაიდან გირაოს რეალიზაციიდან მიღებული შემოსავალი გათვალისწინებულია მოგირავნეთა დასაკმაყოფილებლად, მოთხოვნა ითვლება მესაკუთრისაგან კრედიტორის სასარგებლოდ დაკმაყოფილებულად. სხვა შემთხვევაში შემოსავალი იკავებს გირაოს ადგილს.
[მუხლი 285. გირავნობის საგნის რეალიზაციის შედეგები

2. მოგირავნის მიერ გირავნობის საგნის არამართლზომიერი რეალიზაციის შემთხვევაში შემძენი იძენს საკუთრების უფლებას, თუ იგი ამ ფაქტის მიმართ კეთილსინდისიერია. (ამოქმედდეს 2006 წლის 1 მარტიდან) ]
