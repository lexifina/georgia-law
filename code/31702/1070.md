# მუხლი 1070. ნაწარმოების გამოყენება განსაკუთრებული ლიცენზიის გადაცემის შემდეგ
ნაწარმოების გამოყენებაზე განსაკუთრებულ უფლებათა გადაცემის (განსაკუთრებული ლიცენზია) შემთხვევაშიც კი ავტორს უნარჩუნდება ასეთი ნაწარმოების გამოყენების უფლება თავისი ნაწარმოების მხოლოდ და მხოლოდ სრული კრებულის გამოქვეყნებისას, თუ განსაკუთრებულ უფლებათა გადაცემის შედეგად ნაწარმოების გამოქვეყნებიდან გავიდა ხუთი წელი. ამასთანავე, ავტორს არა აქვს უფლება, გამოიყენოს ასეთი ნაწარმოები სრული კრებულისაგან დამოუკიდებლად.
