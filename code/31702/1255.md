# მუხლი 1255. ათი წლის ასაკს მიღწეული ბავშვის შვილება
1. იმ ბავშვის შვილად აყვანა, რომელსაც ათი წელი შეუსრულდა, დაუშვებელია მისი თანხმობის გარეშე.
2. ბავშვის თანხმობას არკვევს მეურვეობისა და მზრუნველობის ორგანო.
3. თუ შვილად აყვანის შესახებ განცხადების წარდგენამდე ბავშვი მშვილებლის ოჯახში ცხოვრობდა და მშვილებელს თავის მშობლად თვლიდა, შვილება, როგორც გამონაკლისი, შეიძლება შვილად ასაყვანის თანხმობის გარეშეც.
