# მუხლი 306. აუქციონის ჩატარება განმეორებით
თუ პირველი აუქციონის დროს არ იქნება შემოთავაზებული ისეთი წინადადება, რომელიც აღწევს ექსპერტის მიერ შეფასებული ნივთის ღირებულების სამოცდაათ პროცენტს, აუქციონი ხელახლა უნდა ჩატარდეს. განმეორებითი აუქციონი იმავე ფორმით უნდა გამოცხადდეს, რა ფორმითაც პირველი აუქციონი, ამასთან, უნდა მიეთითოს, რომ აუქციონი ტარდება განმეორებით. აუქციონის მეორედ ჩატარების დროს ყველაზე დაბალი ფასი, სულ ცოტა, პროცესის ხარჯებსა და კრედიტორის მოთხოვნებს მაინც უნდა ფარავდეს. თუ ეს არ მოხდება, მაშინ აუქციონი არ ჩატარდება. აუქციონის ხარჯები ეკისრება მესაკუთრეს.
