# მუხლი 306. განცხადება იძულებითი აუქციონის ჩატარების შესახებ
სააღსრულებო ფურცლის ან ხელშეკრულების საფუძველზე იძულებითი აუქციონის ჩატარების შესახებ განცხადება სპეციალისტთან (აღმასრულებელთან) შეიძლება შეიტანოს როგორც ერთმა, ისე რამდენიმე კრედიტორმა. განცხადებაში აღნიშნული უნდა იყოს იპოთეკით დატვირთული უძრავი ნივთი, მესაკუთრე, მოვალე, მოთხოვნა და სააღსრულებო ფურცელი ან ხელშეკრულება.
- საქართველოს 2007 წლის 29 ივნისის კანონი №5127 - სსმ I, №27, 17.07.2007წ., მუხ.260
- საქართველოს 2008 წლის 15 ივლისის კანონი №219 - სსმ I, №17, 28.07.2008წ., მუხ.135
