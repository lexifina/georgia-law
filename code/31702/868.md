# მუხლი 868. საბანკო კრედიტის საპროცენტო განაკვეთები
1. მხარეთა შეთანხმებით კრედიტორისათვის შეიძლება განისაზღვროს მყარი ან ცვალებადი საპროცენტო განაკვეთი.
2. თუ შეთანხმებით გათვალისწინებული ცვალებადი საპროცენტო განაკვეთისა და მისი სიდიდის განსაზღვრა შეეძლო კრედიტის გამცემს, იგი ვალდებულია ეს განსაზღვროს სამართლიანობის საფუძველზე; იგი ასევე მოვალეა საბაზრო საპროცენტო განაკვეთის გაზრდას ან შემცირებას შეუსაბამოს თავისი საპროცენტო განაკვეთი.
3. პროცენტის ცვალებადობა უნდა შეესაბამებოდეს საქართველოს ეროვნული ბანკის სადისკონტო განაკვეთს ან ბანკთაშორის საკრედიტო აუქციონზე დაფიქსირებულ საპროცენტო განაკვეთს.
4. საკრედიტო ხელშეკრულების დადებისას უნდა განისაზღვროს საპროცენტო განაკვეთის ზრდისა და შემცირების ზღვარი და ცვლილებათა მინიმალური შუალედი.
5. კრედიტის გამცემი მოვალეა მისაღები ფორმით შეატყობინოს მსესხებელს კრედიტისათვის საპროცენტო განაკვეთის შესახებ.
6. თუ წლიური საპროცენტო განაკვეთი არ არის მითითებული, მაშინ გამოიყენება მხოლოდ კანონით გათვალისწინებული წლიური პროცენტი. თუკი ხარჯების დაკისრება არ იყო გათვალისწინებული წლიური პროცენტის გამოთვლისას, მაშინ ეს ხარჯები არ ანაზღაურდება.
