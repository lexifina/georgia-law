# მუხლი 1035. გადამუშავებული ნაწარმოების ავტორის უფლებები
1. გადამუშავებული ნაწარმოების ავტორს აქვს საავტორო უფლება მის მიერ განხორციელებულ გადაკეთებაზე, ადაპტაციაზე, არანჟირებასა და სხვა გადამუშავებაზე.
2. გადამუშავებული ნაწარმოების ავტორმა უნდა დაიცვას გადაკეთებული, არანჟირებული ან სხვაგვარად გადამუშავებული ნაწარმოების ავტორის საავტორო უფლება.
3. გადამუშავებული ნაწარმოების ავტორის საავტორო უფლება ხელს არ უშლის სხვა პირებს გადაამუშაონ იგივე ნაწარმოები.
