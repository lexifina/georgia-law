# მუხლი 397. საკასაციო საჩივრის შეტანის ვადა
1. საკასაციო საჩივრის შეტანის ვადა არის ერთი თვე. ამ ვადის გაგრძელება არ შეიძლება და იგი იწყება ორივე მხარისათვის გადაწყვეტილების გადაცემის მომენტიდან.
2. თუ გადაწყვეტილების გამოცხადებას ესწრება საკასაციო საჩივრის შეტანის უფლების მქონე პირი, საკასაციო საჩივრის შეტანის ვადა იწყება მისი გამოცხადების მომენტიდან.
- საქართველოს 1999 წლის 9 სექტემბრის კანონი №2398 - სსმ I, №43(50), 21.09.1999 წ., მუხ.227
