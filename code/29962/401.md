# მუხლი 401. საკასაციო საჩივრის დასაშვებობის შემოწმება
1. საკასაციო სასამართლომ უნდა შეამოწმოს, დასაშვებია თუ არა საკასაციო საჩივარი. თუ ასეთი შემოწმების შედეგად გამოვლინდება, რომ არ არსებობს საკასაციო საჩივრის წანამძღვრები, მაშინ საკასაციო სასამართლო გამოიტანს განჩინებას საჩივრის განუხილველად დატოვების შესახებ.
2. განჩინება შეიძლება მიღებულ იქნეს საკასაციო სასამართლოს მიერ საქმის ზეპირი განხილვის გარეშე.
