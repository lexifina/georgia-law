# მუხლი 344. რეგისტრაციის ვადა
1. სასამართლო ვალდებულია საწარმოს რეგისტრაცია განახორციელოს საჭირო საბუთების წარმოდგენიდან 5 კალენდარული დღის განმავლობაში.
2. თუ ამ ვადაში რეგისტრაცია არ განხორციელდება ან განმცხადებელს არ ეცნობება მოტივირებული უარი რეგისტრაციაზე, საწარმო რეგისტრირებულად ჩაითვლება და სასამართლო ვალდებულია განმცხადებლის მოთხოვნით, დაუყოვნებლივ გასცეს სარეგისტრაციო მოწმობა.
3. სასამართლო განჩინებაზე სარეგისტრაციო მოწმობის გაცემაზე უარის თქმის შესახებ შეიძლება კერძო საჩივრის შეტანა.
- საქართველოს 2003 წლის 23 აპრილის კანონი №2105 - სსმ I, №12, 21.05.2003 წ., მუხ.63
- საქართველოს 2004 წლის 24 ივნისის კანონი №177 - სსმ I, №19, 15.07.2004 წ., მუხ.78
