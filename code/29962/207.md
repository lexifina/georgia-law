# მუხლი 207. განჩინება საქმის სასამართლოს მთავარ სხდომაზე განხილვის შესახებ
1. მოსამართლეს, მას შემდეგ, რაც საქმეს საკმაოდ მომზადებულად ცნობს, გამოაქვს განჩინება სასამართლოს მთავარ სხდომაზე მისი არსებითად განხილვის დანიშვნის შესახებ. საქმის სასამართლოს მთავარ სხდომაზე განხილვის დღეს სასამართლო ნიშნავს იმ ვარაუდით, რომ მხარეებს შესაძლებლობა ჰქონდეთ, მოემზადონ ზეპირი შეჯიბრებისათვის.
2. საქმის ზეპირი მოსმენის გარეშე განხილვაზე მხარეთა თანხმობის შემთხვევაში სასამართლოს შეუძლია საქმე განიხილოს ზეპირი მოსმენის გარეშე, რის შესახებაც გამოაქვს მოტივირებული განჩინება. საქმის ზეპირი მოსმენის გარეშე განხილვის თაობაზე სასამართლომ წინასწარ უნდა აცნობოს მხარეებს.
- საქართველოს 2007 წლის 28 დეკემბრის კანონი №5669 - სსმ I, №1, 03.01.2008წ., მუხ.1
