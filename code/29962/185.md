# მუხლი 185. სარჩელის უმოძრაოდ დატოვება
თუ მოსამართლე გამოარკვევს, რომ სარჩელი შეტანილია 178-ე და 179-ე მუხლებში მითითებული პირობების დარღვევით, ან სახელმწიფო ბაჟი არ არის გადახდილი, გამოიტანს განჩინებას სარჩელის უმოძრაოდ დატოვების შესახებ, რასაც აცნობებს მოსარჩელეს და მისცემს მას ვადას ხარვეზის შესავსებად. თუ მოსარჩელე დანიშნულ ვადაში შეავსებს განჩინებაში მითითებულ ხარვეზს, მოსამართლე გამოიტანს განჩინებას ამ სარჩელის წარმოებაში მიღების შესახებ. წინააღმდეგ შემთხვევაში სარჩელი შეტანილად არ ჩაითვლება და დაუბრუნდება მოსარჩელეს.
