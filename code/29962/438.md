# მუხლი 438. საქართველოს უზენაესი სასამართლოს სამოქალაქო სამართლის საქმეთა კოლეგიის, სამოქალაქო სამართლის საქმეთა პალატისა და უზენაესი სასამართლოს პლენუმის მიერ ეკონომიკური (სამეურნეო) საქმეთა განხილვის წესი
"საერთო სასამართლოების შესახებ " ორგანული კანონის 88-ე მუხლის შესაბამისად საოლქო სასამართლოების ამოქმედებამდე ეკონომიკური (სამეურნეო) დავების განსახილველად შექმნილი საქართველოს უზენაესი სასამართლოს სამოქალაქო სამართლის საქმეთა კოლეგია მოქმედებს როგორც პირველი ინსტანციის სასამართლო და ხელმძღვანელობს პირველი ინსტანციის სასამართლოში საქმეთა განხილვის წესებით; საქართველოს უზენაესი სასამართლოს სამოქალაქო სამართლის საქმეთა პალატა და საქართველოს უზენაესი სასამართლოს პლენუმი, რომლებიც განიხილავენ საჩივრებს სამოქალაქო სამართლის საქმეთა კოლეგიის გადაწყვეტილებებზე, მოქმედებენ შესაბამისად, როგორც სააპელაციო სასამართლო და საკასაციო სასამართლო და ხელმძღვანელობენ სააპელაციო სასამართლოსა და საკასაციო სასამართლოში სამოქალაქო საპროცესო კოდექსით დადგენილი წესებით.
