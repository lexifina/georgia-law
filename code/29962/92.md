# მუხლი 92. საპროცესო უფლებამონაცვლეობა
1. სადავო ან სასამართლოს გადაწყვეტილებით დადგენილი სამართლებრივი ურთიერთობიდან ერთ-ერთი მხარის გასვლის შემთხვევაში (მოქალაქის გარდაცვალება, იურიდიული პირის ლიკვიდაცია, მოთხოვნის დათმობა, ვალის გადაცემა) სასამართლო დაუშვებს ამ მხარის შეცვლას მისი უფლებამონაცვლით. უფლებამონაცვლეობა შესაძლებელია პროცესის ყოველ სტადიაზე.
2. უფლებამონაცვლისათვის პროცესში მის დაშვებამდე შესასრულებელი ყველა მოქმედება სავალდებულოა იმ ოდენობით, რაც სავალდებულო იქნებოდა იმ პირისათვის, რომელიც მან შეცვალა.
3. უფლებამონაცვლეობის შემთხვევაში სასამართლო შეაჩერებს საქმის წარმოებას 279-ე მუხლის შესაბამისად.
