# მუხლი 316. სასამართლოს გადაწყვეტილება ფაქტის დადგენის შესახებ
სასამართლოს გადაწყვეტილება ფაქტის დადგენის შესახებ, რომელიც რეგისტრირებულ უნდა იქნეს მოქალაქეობრივი მდგომარეობის რეგისტრაციის ორგანოში ან სხვა ორგანოში, წარმოადგენს საფუძველს ასეთი რეგისტრაციისა და გაფორმებისათვის, მაგრამ ვერ შეცვლის ამ ორგანოების მიერ გასაცემ დოკუმენტებს.
[მუხლი 3161 . იურიდიული მნიშვნელობის მქონე ფაქტების დადგენის შესახებ საქმეთა განხილვისა და გადაწყვეტილების გასაჩივრების წესი
1. იურიდიული მნიშვნელობის მქონე ფაქტების დადგენის შესახებ საქმეებს განიხილავს მოსამართლე ან სასამართლოს შესაბამისი მოხელე ამ კოდექსის 311-ე მუხლით დადგენილი წესებით.
2. სასამართლოს შესაბამისი მოხელის მიერ გამოტანილი გადაწყვეტილება შეიძლება გასაჩივრდეს იმავე სასამართლოში საჩივრის შეტანის გზით, მხარისათვის დასაბუთებული გადაწყვეტილების ჩაბარებიდან 10 დღის ვადაში. ( ამოქმედდეს 2012 წლის 1 იანვრიდან)]
- საქართველოს 2011 წლის 11 ნოემბრის კანონი №5265 - ვებგვერდი, 24.11.2011წ.
