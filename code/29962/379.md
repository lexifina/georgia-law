# მუხლი 379. შეგებებული სააპელაციო საჩივარი
მოწინააღმდეგე მხარეს შეუძლია სააპელაციო საჩივრის გადაცემიდან 10 დღის განმავლობაში წარადგინოს შეგებებული სააპელაციო საჩივარი, მიუხედავად იმისა, აქვს თუ არა ნათქვამი უარი სააპელაციო საჩივრის შეტანაზე.
- საქართველოს 2005 წლის 23 ივნისის კანონი №1740 - სსმ I, №36, 11.07.2005წ., მუხ.227
