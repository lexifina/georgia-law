# მუხლი 362. სადავო ნორმატიული აქტის მოქმედების შეჩერება
1. სასამართლოს შეუძლია, საქმეზე გადაწყვეტილების გამოტანამდე, მოსარჩელის განცხადებით შეაჩეროს სადავო ნორმატიული აქტის მოქმედება, რის შესახებაც მას გამოაქვს განჩინება საქმის ზეპირი განხილვის გარეშე.
2. ნორმატიული აქტის მოქმედების შეჩერება დაუშვებელია, თუ იგი მიმართულია საჯარო ან პროცესის რომელიმე მონაწილის განსაკუთრებული ინტერესების დასაცავად.
3. სადავო ნორმატიული აქტის შეჩერების შესახებ განჩინებაზე შეიძლება კერძო საჩივრის შეტანა.
4. სასამართლოს ნებისმიერ დროს შეუძლია აღნიშნული განჩინების შეცვლა ან გაუქმება. ასეთი შეცვლისა თუ გაუქმების შესახებ მოთხოვნა შეიძლება აღძრას პროცესის თითოეულმა მონაწილემ.
