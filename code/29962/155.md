# მუხლი 155. სასამართლო, რომელსაც უნდა წარედგინოს ნივთიერი მტკიცებულება
გამოთხოვილი ნივთიერი მტკიცებულება მოქალაქეებმა და იურიდიულმა პირებმა უნდა გადაუგზავნონ უშუალოდ სასამართლოს დანიშნულ ვადაში. სასამართლოს შეუძლია აგრეთვე ნივთიერი მტკიცებულების გამოთხოვაზე შუამდგომლობის აღმძვრელ პირს მისცეს უფლება მიიღოს საბუთი სასამართლოში წარსადგენად.
