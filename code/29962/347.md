# მუხლი 347. ინფორმაციის მიწოდების ვალდებულება
სასამართლოებმა, პროკურატურის, პოლიციის, გამგეობების თანამშრომლებმა ან ნოტარიუსებმა უნდა შეატყობინონ სარეგისტრაციო სასამართლოებს არასწორი, არასრულფასოვანი ან საერთოდ არშემდგარი რეგისტრაციის შემთხვევების შესახებ, რაც ცნობილი გახდა მათთვის.
[მუხლი 347. ინფორმაციის მიწოდების ვალდებულება
სასამართლოებმა, პროკურატურის, პოლიციის, ადგილობრივი თვითმმართველობისა და მმართველობის ორგანოების თანამშრომლებმა ან ნოტარიუსებმა უნდა შეატყობინონ რეგისტრაციის განმახორციელებელ სასამართლოებს არასწორი, არასრულფასოვანი ან არშემდგარი რეგისტრაციის შემთხვევების შესახებ, რომლებიც მათთვის გახდა ცნობილი. (ამოქმედდეს 2005 წლის 1 მარტიდან)]
