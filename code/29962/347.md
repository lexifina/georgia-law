# მუხლი 347. ინფორმაციის მიწოდების ვალდებულება
სასამართლოებმა, პროკურატურის, პოლიციის, ადგილობრივი თვითმმართველობისა და მმართველობის ორგანოების თანამშრომლებმა ან ნოტარიუსებმა უნდა შეატყობინონ რეგისტრაციის განმახორციელებელ სასამართლოებს არასწორი, არასრულფასოვანი ან არშემდგარი რეგისტრაციის შემთხვევების შესახებ, რომლებიც მათთვის გახდა ცნობილი.
- საქართველოს 2004 წლის 24 ივნისის კანონი №177 - სსმ I, №19, 15.07.2004 წ., მუხ.78
