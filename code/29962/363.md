# მუხლი 363. მესამე პირის მოწვევა
1. სასამართლოს შეუძლია თავისი ინიციატივით ან მხარეთა განცხადების საფუძველზე მოიწვიოს სხვა ისეთი ფიზიკური და იურიდიული პირები, რომელთა სამართლებრივ ინტერესებს შეიძლება შეეხოს გადაწყვეტილება.
2. თუ მოწვეული პირი სადავო სამართლებრივ ურთიერთობაში ისეთი სახით იღებს მონაწილეობას, რომ მასზე გავრცელდება სასამართლოს გადაწყვეტილების კანონიერი ძალა, იგი აუცილებლად უნდა იქნეს მოწვეული (აუცილებელი მოწვევა).
3. მოწვეულ პირებს, მხარეთა განცხადების ფარგლებში, შეუძლიათ ისარგებლონ ყველა საპროცესო უფლებით და მიიღონ აქტიური მონაწილეობა საქმის წარმოების ყველა ეტაპზე.
