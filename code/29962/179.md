# მუხლი 179. სარჩელისა და თანდართული დოკუმენტების ასლები
1. სარჩელი შეიძლება აღიძრას უფლებისა თუ სამართლებრივი ურთიერთობების არსებობა-არარსებობის დადგენის, დოკუმენტების ნამდვილობის აღიარების ან დოკუმენტების სიყალბის დადგენის შესახებ, თუ მოსარჩელეს აქვს იმის იურიდიული ინტერესი, რომ ასეთი აღიარება სასამართლოს გადაწყვეტილებით მოხდეს.
2. სარჩელის (განცხადების) აღმძვრელ პირს შეუძლია სარჩელის (განცხადების) შეტანისას განაცხადოს, რომ თანახმაა, წერილობითი მასალები მიიღოს ელექტრონული ფოსტით. ასეთ შემთხვევაში სასამართლო, როგორც წესი, სარჩელის (განცხადების) აღმძვრელ პირს მასალებს უგზავნის ელექტრონული ფოსტით.
- საქართველოს 2007 წლის 28 დეკემბრის კანონი №5669 - სსმ I, №1, 03.01.2008წ., მუხ.1
