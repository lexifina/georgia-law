# მუხლი 78. საჯარო შეტყობინება
1. თუ მხარის ადგილსამყოფელი უცნობია ან მისთვის სასამართლო უწყების ჩაბარება სხვაგვარად ვერ ხერხდება, სასამართლო უფლებამოსილია გამოიტანოს განჩინება სასამართლო შეტყობინების საჯაროდ გავრცელების შესახებ. საჯარო შეტყობინება ხორციელდება იმ გაზეთის საშუალებით, რომელიც მასობრივადაა გავრცელებული მხარის საცხოვრებელი ადგილის შესაბამის ადმინისტრაციულ-ტერიტორიულ ერთეულში.
2. მხარე უფლებამოსილია, სასამართლო განჩინების საფუძველზე, თავისი ხარჯებით განახორციელოს საჯარო შეტყობინება ინფორმაციის სხვა საშუალებებით.
3. ამ მუხლის პირველი ნაწილით გათვალისწინებულ შემთხვევაში სასამართლო უწყება მხარისათვის ჩაბარებულად ითვლება გაზეთში გამოქვეყნებიდან მე-7 დღეს.
