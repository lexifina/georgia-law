# მუხლი 309³⁴. განსჯადობა
1. კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენების შესახებ განცხადება წარედგინება საქართველოს საერთო სასამართლოს, თუ მას აქვს უფლებამოსილება კეიპტაუნის კონვენციის 43-ე მუხლის შესაბამისად.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებული განცხადება სასამართლოს წარედგინება ამ კოდექსით დადგენილი წესით.
3. ამ მუხლის პირველი ნაწილით გათვალისწინებული განცხადება სასამართლოს შეიძლება წარედგინოს მიუხედავად იმისა, დავის საგანზე სარჩელი განსახილველად წარედგინება საქართველოს საერთო სასამართლოს, კეიპტაუნის კონვენციის ხელშემკვრელი სხვა სახელმწიფოს სასამართლოს თუ არბიტრაჟს.
- საქართველოს 2026 წლის 24 ივნისის კანონი №1761 - ვებგვერდი, 03.07.2026წ.
