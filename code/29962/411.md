# მუხლი 411. საკასაციო სასამართლოს გადაწყვეტილება
საკასაციო სასამართლო თვითონ მიიღებს გადაწყვეტილებას საქმეზე, თუ საქმის გარემოებები სააპელაციო სასამართლოს მიერ საპროცესო ნორმების დარღვევის გარეშეა დადგენილი და საჭირო არ არის მტკიცებულებათა დამატებითი გამოკვლევა.
- საქართველოს 1999 წლის 28 მაისის კანონი №1972 - სსმ I, №18(25), 01.06.1999 წ., მუხ.71
- საქართველოს 2005 წლის 23 ივნისის კანონი №1740 - სსმ I, №36, 11.07.2005წ., მუხ.227
