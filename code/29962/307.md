# მუხლი 307. მოპასუხის შესაგებელი (პროტესტი)
მოპასუხეს შეუძლია არ ცნოს გადახდის ბრძანება მთლიანად ან ნაწილობრივ და შეიტანოს მის წინააღმდეგ შესაგებელი (პროტესტი) სასამართლოში, რომელმაც მიიღო ეს ბრძანება გადახდის ბრძანების მიღებიდან 10 დღის განმავლობაში. მოპასუხეს შეუძლია გააპროტესტოს გადახდის ბრძანება იმ შემთხვევაშიც, როდესაც გაპროტესტების ვადის გასვლას სასამართლო საპატიოდ მიიჩნევს.
