# მუხლი 437. საოლქო სასამართლოების განსჯადი სამოქალაქო საქმეების განხილვა
სამოქალაქო საპროცესო კოდექსით საოლქო სასამართლოების განსჯადობას მიკუთვნებულ საქმეებს, გარდა იმ ეკონომიკური (სამეურნეო) დავებისა, რომელთა განხილვაც "საერთო სასამართლოების შესახებ " ორგანული კანონის 88-ე მუხლის თანახმად მინდობილი აქვს საქართველოს უზენაესი სასამართლოს სამოქალაქო სამართლოს საქმეთა კოლეგიას, განიხილავენ რაიონის (ქალაქის) სასამართლოები.
