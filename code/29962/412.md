# მუხლი 412. სააპელაციო სასამართლოში საქმის დაბრუნება ხელახლა განსახილველად
1. თუ ამ კოდექსის 411-ე მუხლის შესაბამისად საკასაციო სასამართლოს მიერ გადაწყვეტილების მიღება შეუძლებელია, იგი აუქმებს გადაწყვეტილებას და საქმეს ხელახლა განსახილველად უბრუნებს სააპელაციო სასამართლოს.
2. თუ საკასაციო სასამართლომ თავის გადაწყვეტილებას საფუძვლად დაუდო სამართლებრივი შეფასება, რომლის გამოც აუქმებს გადაწყვეტილებას, მაშინ ის განჩინებაში უთითებს, თუ რომელი ფაქტები საჭიროებს გამოკვლევას, რა მტკიცებულებებია შესაკრები და რა სხვა კონკრეტული საპროცესო მოქმედება უნდა შეასრულოს სააპელაციო სასამართლომ. საქმე ხელახლა განსახილველად შეიძლება დაუბრუნდეს სასამართლოს იმავე ან სხვა შემადგენლობას.
- საქართველოს 1999 წლის 28 მაისის კანონი №1972 - სსმ I, №18(25), 01.06.1999 წ., მუხ.71
- საქართველოს 2005 წლის 23 ივნისის კანონი №1740 - სსმ I, №36, 11.07.2005წ., მუხ.227
