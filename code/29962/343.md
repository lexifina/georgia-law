# მუხლი 343. განცხადების შინაარსი
საწარმოს რეგისტრაციის შესახებ განცხადება უნდა შეესაბამებოდეს "მეწარმეთა შესახებ" საქართველოს კანონის 5.4 მუხლის მოთხოვნებს და მას უნდა ერთვოდეს იმავე კანონის 5.5 მუხლით გათვალისწინებული დოკუმენტები.
- საქართველოს 2004 წლის 24 ივნისის კანონი №177 - სსმ I, №19, 15.07.2004 წ., მუხ.78
