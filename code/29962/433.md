# მუხლი 433. საქართველოს სამოქალაქო საპროცესო კოდექსის ამოქმედება
საქართველოს სამოქალაქო საპროცესო კოდექსი ამოქმედდეს 1998 წლის 1 მაისიდან, როდესაც "საერთო სასამართლოების შესახებ " საქართველოს ორგანული კანონის თანახმად დამთავრდება საერთო სასამართლოების სისტემის ჩამოყალიბება და დაინიშნებიან ამ სისტემის მოსამართლეები.
