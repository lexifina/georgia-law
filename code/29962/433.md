# მუხლი 433. საქართველოს სამოქალაქო საპროცესო კოდექსის ამოქმედება
საქართველოს სამოქალაქო საპროცესო კოდექსი ამოქმედდეს 1999 წლის 20 იანვრიდან, როდესაც "საერთო სასამართლოების შესახებ " საქართველოს ორგანული კანონის თანახმად დამთავრდება საერთო სასამართლოების სისტემის ჩამოყალიბება და დაინიშნებიან ამ სისტემის მოსამართლეები.
საქართველოს 1998 წლის 20 თებერვლის კანონი №1261 - პარლამენტის უწყებანი, №11-12, 14.03.1998 წ., გვ.32
