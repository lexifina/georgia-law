# მუხლი 407. შემოწმების ფაქტობრივი საფუძველი
1. საკასაციო სასამართლო იმსჯელებს მხარის მხოლოდ იმ ახსნა-განმარტების მიმართ, რომელიც ასახულია სააპელაციო სასამართლოს გადაწყვეტილებაში ან საქმის მასალებში; მხედველობაში შეიძლება მიღებულ იქნეს მხოლოდ 396-ე მუხლის პირველი ნაწილის "ვ" ქვეპუნქტში მითითებული ფაქტები.
2. სააპელაციო სასამართლოს მიერ დამტკიცებულად ცნობილი ფაქტობრივი გარემოებები სავალდებულოა სასამართლოსათვის, თუ წამოყენებული არ არის დამატებითი და დასაბუთებული საკასაციო პრეტენზია.
