# მუხლი 407. შემოწმების ფაქტობრივი საფუძველი
1. საკასაციო სასამართლო იმსჯელებს მხარის მხოლოდ იმ ახსნა-განმარტებაზე, რომელიც ასახულია სააპელაციო სასამართლოს გადაწყვეტილებაში ან საქმის მასალებში. გათვალისწინებული იქნება მხოლოდ ამ კოდექსის 396-ე მუხლის პირველი ნაწილის "ვ" ქვეპუნქტში მითითებული ფაქტები.
2. სააპელაციო სასამართლოს მიერ დამტკიცებულად ცნობილი ფაქტობრივი გარემოებები სავალდებულოა სასამართლოსათვის, თუ წამოყენებული არ არის დამატებითი და დასაბუთებული საკასაციო პრეტენზია.

- საქართველოს 2005 წლის 23 ივნისის კანონი №1740 - სსმ I, №36, 11.07.2005წ., მუხ.227
