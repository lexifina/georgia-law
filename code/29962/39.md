# მუხლი 39. სახელმწიფო ბაჟის ოდენობა
სახელმწიფო ბაჟის ოდენობა დამოკიდებულია დავის საგნის ღირებულებაზე და შეადგენს:
ა) 38-ე მუხლის "ა"- "ე" ქვეპუნქტებით გათვალისწინებულ შემთხვევებში - სადავო საგნის ღირებულების 5 პროცენტს;
ბ) სააპელაციო საჩივრისათვის - სადავო საგნის ღირებულების 6,5 პროცენტს;
გ) საკასაციო საჩივრისათვის - სადავო საგნის ღირებულების 8 პროცენტს;
დ) კერძო საჩივრისათვის - სადავო საგნის ღირებულების 3 პროცენტს.
