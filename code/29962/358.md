# მუხლი 358. საქმის გარემოებათა გამოკვლევა სასამართლოს ინიციატივით
1. სასამართლო არ არის შეზღუდული მხარეთა მიერ წარმოდგენილი არგუმენტებითა თუ მტკიცებულებებით და საქმის გარემოებებს იკვლევს თავისი ინიციატივით.
2. მოსარჩელის მიერ სარჩელზე უარის თქმა, მოპასუხის მიერ სარჩელის აღიარება სასამართლოსათვის სავალდებულო არ არის. ასევე დაუშვებელია მხარეთა გამოუცხადებლობის გამო დაუსწრებელი გადაწყვეტილების გამოტანა.
