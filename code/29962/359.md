# მუხლი 359. სარჩელი ადმინისტრაციული ორგანოს მიერ მიღებული აქტების გაუქმებისა და სარჩელი ვალდებულების იძულებით შესრულების შესახებ
1. შესაბამისი სარჩელის შეტანით პირმა შეიძლება მოითხოვოს ადმინისტრაციული ორგანოს ან თვითმმართველობის (მმართველობის) ორგანოს მიერ მიღებული აქტების გაუქმება ან მათი მოქმედების შეწყვეტა.
2. ადმინისტრაციულ აქტს წარმოადგენს ნებისმიერი დადგენილება, გადაწყვეტილება ან სხვა მსგავსი დოკუმენტი, რომელიც მიღებულია ამა თუ იმ ორგანოს მიერ საჯარო-სამართლებრივ სფეროში რომელიმე კონკრეტული შემთხვევის მოსაწესრიგებლად.
3. სასამართლოში ასეთი სარჩელის აღძვრის შემთხვევაში მოსარჩელემ უნდა დაამტკიცოს, რომ შესაბამისი ორგანოს მიერ მიღებული აქტი კანონსაწინააღმდეგოა და ლახავს მოსარჩელის უფლებებსა და კანონიერ ინტერესებს.
- საქართველოს 1999 წლის 8 სექტემბრის კანონი №2365 - სსმ I, №43(50), 21.09.1999 წ., მუხ.214
