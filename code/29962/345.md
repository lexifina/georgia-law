# მუხლი 345. განცხადების უმოძრაოდ დატოვება
1. თუ საწარმოს რეგისტრაციის შესახებ განცხადება და თანდართული დოკუმენტები არ შეესაბამება კანონით გათვალისწინებულ მოთხოვნებს ან არ არის გადახდილი შესაბამისი ბაჟი, სასამართლო გამოიტანს განჩინებას, რომ განცხადებას არ მიეცეს მსვლელობა, რასაც აცნობებს განმცხადებელს და მისცემს მას ვადას ხარვეზის შევსებისათვის.
2. თუ ამ ვადაში ხარვეზი შეივსება, განცხადება შეტანილად ითვლება სასამართლოში მისი პირველად შეტანის დღიდან. სხვა შემთხვევაში განცხადება შეტანილად არ ჩაითვლება და განმცხადებელს დაუბრუნდება.
3. სასამართლო განჩინებაზე ხარვეზის შევსების შესახებ, აგრეთვე განჩინებაზე განცხადების უკან დაბრუნების შესახებ შეიძლება კერძო საჩივრის შეტანა.
- საქართველოს 2004 წლის 24 ივნისის კანონი №177 - სსმ I, №19, 15.07.2004 წ., მუხ.78
