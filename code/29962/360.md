# მუხლი 360. განსჯადობა
1. სარჩელი შეტანილ უნდა იქნეს იმ საჯარო-სამართლებრივი ორგანიზაციის წინააღმდეგ, რომლის მმართველმა ორგანომაც მიიღო ეს აქტი.
2. აღნიშნული სარჩელი შეტანილ უნდა იქნეს იმ სასამართლოებში, რომელთა სამოქმედო ტერიტორიაზედაც მდებარეობს სადავო აქტის მიმღები ორგანო.
- საქართველოს 1999 წლის 28 მაისის კანონი №1972 - სსმ I, №18(25), 01.06.1999 წ., მუხ.71
