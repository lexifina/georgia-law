# მუხლი 395. საკასაციო საჩივრის შეტანა
საკასაციო საჩივარი გადახდილი სახელმწიფო ბაჟის ქვითართან ერთად (თუ იგი გათავისუფლებული არ არის ბაჟის გადახდისაგან) შეიტანება წერილობითი ფორმით იმ სასამართლოში, რომელმაც გამოიტანა გადაწყვეტილება.
- საქართველოს 1999 წლის 28 მაისის კანონი №1972 - სსმ I, №18(25), 01.06.1999 წ., მუხ.71
- საქართველოს 1999 წლის 9 სექტემბრის კანონი №2398 - სსმ I, №43(50), 21.09.1999 წ., მუხ.227
