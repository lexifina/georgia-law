# მუხლი 250. გადაწყვეტილების სარეზოლუციო ნაწილის ჩამოყალიბება
თუ მხარეები მოითხოვენ გადაწყვეტილებას დასაბუთების გარეშე, სასამართლოს შეუძლია შემოიფარგლოს გადაწყვეტილების შესავალი, აღწერილობითი და სარეზოლუციო ნაწილების ჩამოყალიბებით.
- საქართველოს 1999 წლის 9 სექტემბრის კანონი №2398 - სსმ I, №43(50), 21.09.1999 წ., მუხ.227
