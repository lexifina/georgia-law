# მუხლი 419. გადაწყვეტილება კერძო საჩივრის თაობაზე
1. კერძო საჩივრის თაობაზე განჩინება გამოაქვს სააპელაციო სასამართლოს.
2. განჩინება მიიღება მოწინააღმდეგე მხარის მოსმენის შემდეგ, საქმის ზეპირი განხილვის გარეშე. სასამართლოს შეუძლია დაადგინოს კერძო საჩივრის ზეპირი განხილვაც, თუ ეს საჭიროა და ხელს შეუწყობს საქმის ვითარების გარკვევას. სააპელაციო სასამართლოს შეუძლია აგრეთვე განიხილოს კერძო საჩივარი მოწინააღმდეგე მხარის მოსმენის გარეშეც, თუ კერძო საჩივარი დაუშვებელი ან აშკარად უსაფუძვლოა.
