# მუხლი 156. ნივთიერი მტკიცებულების წარდგენის მოვალეობა
1. მოქალაქეები თუ იურიდიული პირები ვალდებულნი არიან სასამართლოს აცნობონ იმის შესახებ, რომ არა აქვთ საშუალება წარადგინონ გამოთხოვილი ნივთიერი მტკიცებულება ან წარადგინონ იგი სასამართლოს მიერ დანიშნულ ვადაში.
2. შეუტყობინებლობის, აგრეთვე იმ შემთხვევაში, როცა სასამართლოს მოთხოვნა ნივთის წარდგენის შესახებ არ შესრულებულა ისეთი მიზეზით, რომელიც სასამართლოს არასაპატიოდ მიაჩნია, სასამართლო აჯარიმებს შესაბამის მოქალაქეს ან იურიდიული პირის თანამდებობის პირს 10 ლარით.
3. დაჯარიმება არ ათავისუფლებს მოქალაქეს ან სათანადო თანამდებობის პირს სასამართლოს მიერ გამოთხოვილი ნივთის წარდგენის მოვალეობისაგან.
4. ნივთიერი მტკიცებულების განმეორებით წარუდგენლობის შემთხვევაში სასამართლო აჯარიმებს შესაბამის პირებს პირველი ჯარიმის ხუთმაგი ოდენობით.
