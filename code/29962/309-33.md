# მუხლი 309³³. კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენების შესახებ განცხადება
1. საქმის გამარტივებული წესით განხილვის საფუძვლის − კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენების შესახებ განცხადების მიზანი უნდა იყოს სასამართლოს მიერ კეიპტაუნის კონვენციით განსაზღვრული კრედიტორის მიმართ ამ კოდექსის 309³⁵ მუხლით გათვალისწინებული უფლების დაცვის ერთი ან რამდენიმე ღონისძიების გამოყენების თაობაზე ბრძანების მიღება.
2. კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენების შესახებ განცხადება უნდა შეიცავდეს შემდეგ მონაცემებს:
ა) სასამართლოს დასახელებას;
ბ) მხარეებისა და მათი წარმომადგენლების დასახელებებს;
გ) განმცხადებლის მოთხოვნას ამ კოდექსის 309³⁵ მუხლით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების (ღონისძიებების) კონკრეტული სახის (სახეების) გამოყენების შესახებ;
დ) სახელმწიფო ბაჟის გადახდის დამადასტურებელ ქვითარს;
ე) კეიპტაუნის კონვენციით განსაზღვრული მოვალის მიერ ხელშეკრულების დარღვევის − კეიპტაუნის კონვენციის მე-11 მუხლით გათვალისწინებული დეფოლტის არსებობის მტკიცებულებას;
ვ) კრედიტორის მიერ კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების (ღონისძიებების) გამოყენების თაობაზე კეიპტაუნის კონვენციით განსაზღვრული მოვალის თანხმობას.
3. სასამართლო ამ მუხლის პირველი ნაწილით გათვალისწინებულ განცხადებას განიხილავს კეიპტაუნის კონვენციის შესაბამისი დებულებებისა და ამ კოდექსით დადგენილი საპროცესო ნორმების დაცვით.
4. სასამართლო ამ მუხლის პირველი ნაწილით გათვალისწინებულ განცხადებას განიხილავს მისი შეტანიდან 1 სამუშაო დღის ვადაში.
5. ამ მუხლის პირველი ნაწილით გათვალისწინებული განცხადება სასამართლოს შეიძლება წარედგინოს კრედიტორის მიერ სარჩელის აღძვრამდეც.
- საქართველოს 2026 წლის 24 ივნისის კანონი №1761 - ვებგვერდი, 03.07.2026წ.
