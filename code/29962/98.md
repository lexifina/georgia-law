# მუხლი 98. წარმომადგენლის უფლებამოსილება
1. სასამართლოში საქმის წარმოების უფლებამოსილება წარმომადგენელს აძლევს უფლებას, მარწმუნებლის სახელით შეასრულოს ყველა საპროცესო მოქმედება, გარდა სარჩელის აღძვრისა, საქმის არბიტრაჟისთვის გადაცემისა, სასამართლო მედიაციის პროცესში წარმომადგენლობისა, სასარჩელო მოთხოვნაზე მთლიანად ან ნაწილობრივ უარის თქმისა, სარჩელის ცნობისა, სარჩელის საგნის შეცვლისა, მორიგებისა, სასამართლო გადაწყვეტილების გასაჩივრებისა, სააღსრულებო ფურცლის გადასახდევინებლად წარდგენისა, მიკუთვნებული ქონების ან ფულის მიღებისა. წარმომადგენლის უფლებამოსილება ამ მუხლით გათვალისწინებული თითოეული საპროცესო მოქმედების შესრულებისთვის სპეციალურად უნდა იქნეს აღნიშნული მარწმუნებლის მიერ გაცემულ მინდობილობაში.
2. მხარის მიერ უფლებამოსილ პირს შეუძლია ცალკეული საპროცესო მოქმედების შესრულება მიანდოს სხვა ადვოკატს ან მის თანაშემწეს.
- საქართველოს 2006 წლის 13 ივლისის კანონი №3435 - სსმ I, №32, 31.07.2006წ., მუხ.243
- საქართველოს 2025 წლის 9 დეკემბრის კანონი №1159 - ვებგვერდი, 12.12.2025წ.
