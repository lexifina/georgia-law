# მუხლი 50. ბრალდებულის მიერ პენიტენციური დაწესებულების დროებით დატოვება
1. გამომძიებელს ან პროკურორს უფლება აქვს, გასცეს ნებართვა ბრალდებულის მიერ პენიტენციური დაწესებულების დროებით, 2 დღე-ღამემდე ვადით დატოვებაზე, თუ მიღებულია სარწმუნო ცნობა ბრალდებულის ახლო ნათესავის გარდაცვალების ან სიცოცხლისთვის საშიში ავადმყოფობის თაობაზე, ან სხვა განსაკუთრებულ, პირად გარემოებასთან დაკავშირებით, ან თუ აუცილებელია ბრალდებულის საგამოძიებო ან სხვა საპროცესო მოქმედებაში მონაწილეობა. ბრალდებულის მიერ პენიტენციური დაწესებულების დროებით დატოვებასთან დაკავშირებული ხარჯები ანაზღაურდება საქართველოს სახელმწიფო ბიუჯეტიდან.
2. ბრალდებულის მიერ პენიტენციური დაწესებულების დროებით დატოვების წესს განსაზღვრავს მინისტრი.
- საქართველოს 2026 წლის 28 მაისის კანონი №1619 - ვებგვერდი, 01.06.2026წ.
