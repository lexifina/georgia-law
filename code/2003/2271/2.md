# მუხლი 2. საქართველოს კანონმდებლობა ადამიანის ჯანმრთელობისათვის უსაფრთხო გარემოს უზრუნველყოფის სფეროში
საქართველოს კანონმდებლობა ადამიანის ჯანმრთელობისათვის უსაფრთხო გარემოს უზრუნველყოფის სფეროში ეფუძნება საქართველოს კონსტიტუციას, საერთაშორისო ხელშეკრულებებსა და შეთანხმებებს, "ჯანმრთელობის დაცვის შესახებ" საქართველოს კანონსა და სხვა ნორმატიულ აქტებს.
