# მუხლი 66. მითითებების, ვალდებულებებისა და გადაწყვეტილებების შეუსრულებლობა ცხოველის ჯანმრთელობისა და მცენარის მავნე ორგანიზმებისაგან დაცვასთან დაკავშირებით
1. ამ კოდექსის მე-15 მუხლის პირველი ნაწილის "გ" ქვეპუნქტით და მე-16 მუხლის პირველი ნაწილის "გ" ქვეპუნქტით გათვალისწინებულ შემთხვევებში სააგენტოს მითითებების შეუსრულებლობა ეპიზოოტიის საწინააღმდეგო, პრევენციული და სალიკვიდაციო ღონისძიებების განსახორციელებლად, ასევე მავნე ორგანიზმების მასობრივი გავრცელების თავიდან ასაცილებლად -
გამოიწვევს ოჯახური წარმოების სუბიექტის დაჯარიმებას 100 ლარის ოდენობით, ხოლო ბიზნესოპერატორისას − 300 ლარის ოდენობით.
2. ამ კოდექსის მე-15 მუხლის პირველი ნაწილის "ბ" ქვეპუნქტით გათვალისწინებულ შემთხვევაში ცხოველის დაკვლა მისი რეალიზაციის მიზნით, ვეტერინარული ზედამხედველობის გარეშე −
გამოიწვევს ბიზნესოპერატორის დაჯარიმებას 300 ლარის ოდენობით.
3. ვეტერინარული კარანტინისა და მცენარეთა კარანტინის ფარგლებში უფლებამოსილი ორგანოების გადაწყვეტილებებისა და მითითებების შეუსრულებლობა −
გამოიწვევს ოჯახური წარმოების სუბიექტის დაჯარიმებას 100 ლარის ოდენობით, ხოლო ბიზნესოპერატორისას - 500 ლარის ოდენობით.
