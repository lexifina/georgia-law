# მუხლი 13. ბიზნესოპერატორად რეგისტრაცია
პირი, რომლის საქმიანობაც დაკავშირებულია სურსათის/ცხოველის საკვების წარმოებასთან, გადამუშავებასთან ან/და დისტრიბუციასთან, ასევე პირველად წარმოებასთან, ვალდებულია დარეგისტრირდეს ბიზნესოპერატორად საქართველოს კანონმდებლობით დადგენილი წესისა და პირობების შესაბამისად.
