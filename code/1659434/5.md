# მუხლი 5. რისკის შეფასება
1. რისკის შეფასება მოიცავს ოთხ საფეხურს: საფრთხის იდენტიფიცირებას, საფრთხის აღწერას, საფრთხის გამოვლენის შეფასებას და რისკის დახასიათებას და ეფუძნება მეცნიერულად (ანალიტიკურად) დასაბუთებულ შედეგებსა და მონაცემებს.
2. რისკის შეფასება ხორციელდება დამოუკიდებლად, ობიექტურად და გამჭვირვალედ.
