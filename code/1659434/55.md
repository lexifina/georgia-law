# მუხლი 55. ვეტერინარული კარანტინისა და მცენარეთა კარანტინის დაწესება და მოხსნა
საქართველოს ტერიტორიაზე ვეტერინარული კარანტინი და მცენარეთა კარანტინი , გარდა ამ კოდექსის 53-ე მუხლის მე-4 ნაწილით განსაზღვრული პროფილაქტიკური კარანტინისა, წესდება და იხსნება სააგენტოს მოთხოვნის საფუძველზე :
ა) თვითმმართველი ერთეულის ტერიტორიაზე − ადგილობრივი თვითმ მ ართველობის ორგანოს მიერ ;
ბ) ერთზე მეტი თვითმმართველი ერთეულის ტერიტორიაზე − ამ თვითმმართველ ერთეულებში სახელმწიფო რწმუნებულის − გუბერნატორის ან საქართველოს მთავრობის მიერ.
