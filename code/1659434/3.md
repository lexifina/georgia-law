# მუხლი 3. სურსათის/ცხოველის საკვების უვნებლობის, ცხოველთა ჯანმრთელობისა და მცენარეთა დაცვის ძირითადი პრინციპები

ბ) პრევენცია;
გ) გამჭვირვალობა;
დ) მომხმარებელთა ინტერესების დაცვა.
