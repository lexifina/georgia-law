# მუხლი 3. სურსათის/ცხოველის საკვების უვნებლობის, ცხოველთა ჯანმრთელობისა და მცენარეთა დაცვის ძირითადი პრინციპები
სურსათის/ცხოველის საკვების უვნებლობის, ცხოველთა ჯანმრთელობისა და მცენარეთა დაცვის ძირითადი პრინციპებია: რისკის ანალიზი, პრევენცია, გამჭვირვალობა და მომხმარებელთა ინტერესების დაცვა.
