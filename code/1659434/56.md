# მუხლი 56. შიდასაკარანტინო ღონისძიებები
1. საკარანტინო ობიექტის აღმოჩენისას განსაზღვრული ტერიტორია ცხადდება საკარანტინო ზონად.
2. საკარანტინო ზონის ტერიტორიაზე იზღუდება სატრანსპორტო საშუალებების შესვლა-გამოსვლა; აკრძალულია კარანტინისადმი დაქვემდებარებული პროდუქტის შეტანა-გამოტანა; ამასთანავე, ადგილზე ხდება მისი გაუსნებოვნება, ტექნიკური გადამუშავება ან განადგურება სათანადო დოკუმენტაციის გაფორმების შემდეგ.
3. საკარანტინო ზონიდან უნებართვოდ გამოტანილი, კარანტინისადმი დაქვემდებარებული პროდუქტი უნდა დაბრუნდეს, ჩამორთმეულ იქნეს და გადაეცეს შესაბამის სავაჭრო-გადამამუშავებელ საწარმოს ან განადგურდეს სათანადო დოკუმენტაციის გაფორმების შემდეგ.
