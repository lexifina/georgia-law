# მუხლი 121. საბაჟო გადამზიდველთა რეგისტრაცია და ინფორმირება მათ შესახებ
1. საბაჟო ორგანო სახელმწიფო რეესტრში რეგისტრაციას უკეთებს საბაჟო გადამზიდველებს, რომლებსაც განზრახული აქვთ ასეთი ფუნქციების შესრულება მოცემული საბაჟო ორგანოს საქმიანობის ზონაში. რეგისტრაცია ხდება საბაჟო გადამზიდველის განცხადების საფუძველზე.
2. საბაჟო ორგანო უზრუნველყოფს რეგისტრირებულ საბაჟო გადამზიდველთა ნუსხის სახელმწიფო რეესტრის გაცნობას დაინტერესებულ პირთათვის.
