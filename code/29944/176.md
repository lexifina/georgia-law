# მუხლი 176. გარდამავალი დებულებანი
2000 წლის 31 დეკემბრამდე:
ა) საქართველოში ნავთობის მსუბუქი, საშუალო და მძიმე დისტილატებისათვის არ გამოიყენება საქართველოს საბაჟო კოდექსის მე-8 მუხლის ,,დ"_"ლ" ქვეპუნქტებით განსაზღვრული საბაჟო რეჟიმები. ამასთან, ამ საქონლის რეექსპორტი დასაშვებია მხოლოდ ერთი თვის ვადით;
ბ) ამ მუხლის ,,ა" ქვეპუნქტში აღნიშნული საქონლის იმპორტის გარდა, სხვა საბაჟო რეჟიმებში მოსაქცევად (რომელთა შედეგად ნავთობის მსუბუქი, საშუალო და მძიმე დისტილატები გადმოკვეთენ საქართველოს სახელმწიფო საზღვარს, ტრანზიტის ჩათვლით) საბაჟო ორგანოებში წარმოდგენილი იქნება საბანკო გარანტია ან ფინანსური რისკის დაზღვევის პოლისი, ან იდება ფულადი დეპოზიტი იმ თანხის ოდენობით, რაც გადაიხდებოდა იმპორტის რეჟიმის შემთხვევაში. საქართველოდან აღნიშნული საქონლის გატანისას უქმდება საბანკო გარანტია ან ფინანსური რისკის დაზღვევის პოლისი, ან ბრუნდება ფულადი დეპოზიტი გატანილი საქონლის ოდენობის შესაბამისად.
