# მუხლი 28. საბაჟო საწყობის შექმნა და გაუქმება
1. საბაჟო საწყობი შეიძლება შეიქმნას საქართველოს საბაჟო დეპარტამენტის ლიცენზიით. ლიცენზია საჭირო არ არის, თუ საბაჟო საწყობის მფლობელია საქართველოს საბაჟო ორგანო.
2. ლიცენზიის გაცემის, გაუქმების, ჩამორთმევისა და შეჩერების წესი განისაზღვრება კანონმდებლობით.
3. საბაჟო საწყობის გაუქმება ხდება ლიცენზიის ვადის გასვლის, ლიცენზიის გაუქმების ან ჩამორთმევის შედეგად, ანდა მფლობელის სურვილით. საბაჟო საწყობის გაუქმების დღიდან იგი წარმოადგენს დროებით შესანახ საწყობს, სადაც არსებული საქონელი ინახება ამ კოდექსით განსაზღვრული პირობებით.
4. ლიცენზიის ვადის გასვლის, მისი გაუქმების ან ჩამორთმევის დროს საწყობში არსებული საქონელი ექვემდებარება განმეორებით საბაჟო გაფორმებას. საქონლის შენახვის მთელ პერიოდში საწყობის მფლობელი იხდის დადგენილ გადასახდელებს.
5. ლიცენზიის მოქმედების შეჩერებისას საწყობში ახალი საქონლის მოთავსება დაუშვებელია. საქონლის გაშვება საწყობიდან ხდება ამ კოდექსით გათვალისწინებული წესით.
