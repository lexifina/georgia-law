# მუხლი 57. საქართველოს საბაჟო ტერიტორიის გარეთ გადასამუშავებლად გატანილი საქონლის ან გადამუშავებით მიღებული პროდუქტების დაუბრუნებლობა მათი განადგურების, დაკარგვის, დანაკლისის, ანდა უცხო სახელმწიფოს ორგანოთა ან თანამდებობის პირთა არამართლზომიერი მოქმედების შედეგად
პირს, რომელმაც მიიღო საბაჟო ტერიტორიის გარეთ საქონლის გადამუშავების ლიცენზია და არ დააბრუნა საქონელი ან დადგენილ ვადაში არ შემოიტანა გადამუშავებით მიღებული პროდუქტები, არ ეკისრება პასუხისმგებლობა მხოლოდ იმ შემთხვევაში, თუ ავარიის ან დაუძლეველი ძალის მოქმედების შედეგად საქონლის ან გადამუშავებით მიღებული პროდუქტების განადგურების, დაკარგვის, ბუნებრივი ცვეთის, ტრანსპორტირების ან შენახვის ნორმალურ პირობებში ბუნებრივი დანაკარგების გამო დანაკლისის ან უცხო სახელმწიფო ორგანოებისა თუ თანამდებობის პირთა საქართველოს კანონმდებლობის მიხედვით არამართლზომიერი მოქმედების გამო, ამ ფაქტს დაადასტურებენ საქართველოს შესაბამისი საკონსულო დაწესებულებები.
