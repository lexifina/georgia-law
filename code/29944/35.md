# მუხლი 35. საქართველოს საბაჟო ტერიტორიაზე საქონლის გადამუშავების ლიცენზია
1. საქართველოს საბაჟო ტერიტორიაზე საქონლის გადამუშავება ხორციელდება საქართველოს ფინანსთა სამინისტროს საბაჟო დეპარტამენტის ლიცენზიით.
2. ლიცენზია მიეცემა საქართველოს ფიზიკურ ან იურიდიულ პირს იმ პირობით, თუ:
ა) შესაძლებელია შემოტანილი საქონლის გადამუშავების პროდუქტების იდენტიფიკაცია, გარდა იმ შემთხვევებისა, რომლებიც განისაზღვრება კანონქვემდებარე ნორმატიული აქტებით;
ბ) გადამუშავება იძლევა საქართველოს საწარმოო სიმძლავრეთა გამოყენებისა და გადამუშავების პროდუქტის ექსპორტის საშუალებას;
გ) შესრულებულია საბაჟო კანონმდებლობის დაცვის მოთხოვნები.
დ) ლიცენზიის გაცემის, გაუქმების, ჩამორთმევისა და შეჩერების წესი განისაზღვრება კანონმდებლობით.
