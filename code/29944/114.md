# მუხლი 114. საბაჟო ბროკერის საქმიანობის ლიცენზია
1. ლიცენზიის მისაღებად, რომელიც იძლევა საბაჟო ბროკერის საქმიანობის უფლებას, საჭიროა:
ა) დაიდოს ბროკერის საქმიანობის საგარანტიო ხელშეკრულება. საგარანტიო თანხა არ უნდა იყოს 30 000 ლარზე ნაკლები;
ბ) ჰქონდეს მატერიალურ-ტექნიკური აღჭურვილობა, რომელიც საჭიროა საბაჟო ბროკერის საქმიანობის განსახორციელებლად;
გ) არსებობდეს პირობები, რომლებიც უზრუნველყოფენ საბაჟო გაფორმებას, აღრიცხვის წარმოებასა და ანგარიშგებას, რომლებშიც ზუსტად აისახება საბაჟო კონტროლს დაქვემდებარებული საქონლის მიმართ წარმოებული ოპერაციები.
2. ლიცენზიის გაცემის წესს განსაზღვრავს კანონი და კანონმდებლობის სხვა აქტები.
