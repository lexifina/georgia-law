# მუხლი 31. უბაჟო საცალო ვაჭრობის ობიექტების შექმნა და გაუქმება
1. უბაჟო საცალო ვაჭრობის ობიექტი შეუძლია დააარსოს საქართველოში სამეწარმეო საქმიანობის უფლების მქონე პირმა საქართველოს საბაჟო დეპარტამენტის ლიცენზიის საფუძველზე.
2. ლიცენზიის გაცემის, გაუქმების, ჩამორთმევისა და შეჩერების წესი განისაზღვრება კანონმდებლობით.
3. უბაჟო საცალო ვაჭრობის ობიექტის გაუქმება ხდება ლიცენზიის ვადის გასვლის, ლიცენზიის გაუქმების ან ჩამორთმევის შედეგად, ანდა მფლობელის სურვილით.
4. ლიცენზიის ვადის გასვლის, მისი გაუქმების ან ჩამორთმევის დროს უბაჟო საცალო ვაჭრობის ობიექტში არსებული საქონელი ექვემდებარება განმეორებით საბაჟო გაფორმებას. საქონლის შენახვის მთელ პერიოდში ობიექტის მფლობელი იხდის დადგენილ გადასახდელებს.
5. ლიცენზიის მოქმედების შეჩერებისას დაუშვებელია საქონლის გაყიდვა უბაჟო საცალო ვაჭრობის ობიექტში.
