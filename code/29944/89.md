# მუხლი 89. საბაჟო გაფორმებისათვის საჭირო საბუთები და ცნობები
1. საბაჟო დეკლარაციასთან ერთად საბაჟო ორგანოს უნდა წარედგინოს საბაჟო გაფორმებისათვის საჭირო საბუთები, მათ შორის, საქონლის გადაზიდვამდე ჩატარებული ინსპექტირების და ადამიანის ჯანმრთელობისათვის საქონლის უსაფრთხოების დამადასტურებელი დოკუმენტები.
2. აღნიშნული საბუთებისა და ცნობების და გადაზიდვამდე ინსპექტირებას დაუქვემდებარებელი საქონლის ნუსხა განისაზღვრება კანონქვემდებარე ნორმატიული აქტებით.
