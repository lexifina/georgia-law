# მუხლი 3. საბაჟო პოლიტიკა და საერთაშორისო ეკონომიკური ინტეგრაცია
საერთაშორისო ეკონომიკური ინტეგრაციის განვითარებისა და განმტკიცებისათვის საქართველოს სხვა სახელმწიფოებთან ერთად შეუძლია შექმნას საბაჟო კავშირები, თავისუფალი ვაჭრობის ზონები, საერთაშორისო სამართლის ნორმების შესაბამისად დადოს ორმხრივი და მრავალმხრივი ხელშეკრულებები საბაჟო საკითხებზე.
