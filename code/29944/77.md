# მუხლი 77. საბაჟო გაფორმების დრო და ადგილი
1. საბაჟო გაფორმება, როგორც წესი, წარმოებს საქართველოს საგადასახადო შემოსავლების სამინისტროს საბაჟო დეპარტამენტის მიერ განსაზღვრულ დროსა და ადგილას - საბაჟო ორგანოს სამოქმედო ტერიტორიაზე, სადაც იმყოფებიან საქონლის გამგზავნი, მიმღები ან მათი სტრუქტურული ქვედანაყოფი.
2. დაინტერესებული პირის თხოვნით, მისი ხარჯითა და საბაჟო ორგანოს წერილობითი თანხმობით საბაჟო გაფორმება შეიძლება განხორციელდეს განცხადებაში მითითებულ ადგილზე და/ან საბაჟო ორგანოს არასამუშაო დროსაც.
3. საქართველოს საგადასახადო შემოსავლების სამინისტროს საბაჟო დეპარტამენტს უფლება აქვს დაადგინოს, რომ ცალკეული კატეგორიის საქონლისა და სატრანსპორტო საშუალებების საბაჟო გაფორმება განახორციელონ მხოლოდ განსაზღვრულმა საბაჟო ორგანოებმა.
