# მუხლი 73. საბაჟო მოსაკრებლები
საბაჟო კონტროლიდან საქონლისა და სატრანსპორტო საშუალებების (საქონლის სახით გადაადგილებული სატრანსპორტო საშუალებების ჩათვლით) მოხსნისას და კანონმდებლობით განსაზღვრულ სხვა შემთხვევებში, აგრეთვე საერთაშორისო საფოსტო გზავნილების საბაჟო პროცედურების გაფორმებისა და საბაჟო ორგანოების მიერ ლიცენზიების გაცემისათვის პირები იხდიან სათანადო მოსაკრებლებს კანონმდებლობით დადგენილი წესითა და ოდენობით.
