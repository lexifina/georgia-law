# მუხლი 36. საქართველოს საბაჟო ტერიტორიაზე საქონლის გადამუშავების ვადები
საქართველოს საბაჟო ტერიტორიაზე საქონელი უნდა გადამუშავდეს საბაჟო ორგანოს მიერ დადგენილ ვადებში, რომლის განსაზღვრის წესი დგინდება კანონქვემდებარე ნორმატიული აქტით. ვადების დადგენა უნდა ემყარებოდეს საქონლის გადამუშავებისა და გადამუშავების პროდუქტის ექსპორტის პროცესის ეკონომიკურად გამართლებულ ხანგრძლივობას.
