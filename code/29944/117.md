# მუხლი 117. საბაჟო ბროკერის ლიცენზია
1. საბაჟო გაფორმების ოპერაციების განხორციელების უფლება აქვს საბაჟო დეპარტამენტის მიერ ლიცენზირებულ საბაჟო ბროკერს.
2. ბროკერის ლიცენზია შეიძლება გააუქმოს საბაჟო დეპარტამენტმა, თუ მისი გაცემა განმცხადებლისათვის დადგენილი წესის საფუძველზე არ შეიძლებოდა, ან იგი გაიცა არასრული ან არასარწმუნო ცნობების საფუძველზე, რომლებსაც არსებითი მნიშვნელობა ჰქონდა ლიცენზიის გაცემის გადაწყვეტილების მისაღებად. გადაწყვეტილება გაუქმების შესახებ მოქმედებს მისი გამოტანის დღიდან.
3. საბაჟო ბროკერს ლიცენზია შეიძლება ჩამოართვას საბაჟო დეპარტამენტმა იმ შემთხვევაში, თუ ბროკერი:
ა) არ ან ვერ ასრულებს თავის მოვალეობებს;
ბ) არღვევს ან არ ასრულებს საბაჟო კანონმდებლობის მოთხოვნებს;
გ) არამართლზომიერად აყენებს ზიანს მარწმუნებელს, მათ შორის, იმ ცნობების უკანონოდ გამოყენების გზით, რომლებიც შეიცავს კომერციულ საიდუმლოებას ან კონფიდენციალურ ინფორმაციას, რაც დადგენილია სასამართლოს მიერ.
4. საბაჟო ბროკერის ვალაუვალად ცნობის შემთხვევაში, ან თუ იგი თავს გაკოტრებულად გამოაცხადებს, მისი ლიცენზია ავტომატურად ძალადაკარგულად ითვლება.
5. საბაჟო ბროკერს ლიცენზია შეიძლება ჩამოერთვას სასამართლოს გადაწყვეტილებით. ლიცენზიის გაცემაზე განმეორებით განცხადება შეიძლება განხილულ იქნეს მისი გაუქმების, ჩამორთმევის ან ძალადაკარგულად ცნობის დღიდან ექვსი თვის შემდეგ - იმ პირობით, თუ აღმოფხვრილი იქნება მიზეზები, რომლებიც საფუძვლად დაედო ზემოაღნიშნულ გადაწყვეტილებებს, ან - სასამართლოს მიერ დადგენილი ვადის გასვლის შემდეგ.
6. საბროკერო ლიცენზიის მოქმედება შეიძლება შეჩერდეს, თუ საკმარისი საფუძველია იმის სავარაუდოდ, რომ საბაჟო ბროკერი არაკეთილსინდისიერად ასრულებს თავის მოვალეობებს.
7. საბროკერო ლიცენზიის მოქმედების შეჩერება შეუძლია საბაჟო დეპარტამენტს ორ თვემდე ვადით.
8. გადაწყვეტილება საბროკერო ლიცენზიის გაუქმების, ჩამორთმევის, ძალადაკარგულად ცნობის, მოქმედების შეჩერების შესახებ შეიძლება გასაჩივრდეს კანონმდებლობით დადგენილი წესით.
