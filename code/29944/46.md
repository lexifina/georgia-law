# მუხლი 46. დროებით გატანილი საქონლის დაუბრუნებლობა მისი განადგურების, დაკარგვის, დანაკლისის ან უცხო სახელმწიფოს ორგანოების ან თანამდებობის პირთა არამართლზომიერი მოქმედების გამო
პირი, რომელმაც დროებით გაიტანა საქონელი და არ დააბრუნა დადგენილ ვადაში, პასუხს არ აგებს მხოლოდ იმ შემთხვევაში, თუ ავარიის ან დაუძლეველი ძალის მოქმედების შედეგად საქონლის განადგურების ან დაკარგვის, ბუნებრივი ცვეთის, ტრანსპორტირების ან შენახვის ნორმალურ პირობებში ბუნებრივი დანაკარგების, ან უცხო სახელმწიფოს ორგანოებისა თუ თანამდებობის პირთა საქართველოს კანონმდებლობის მიხედვით არამართლზომიერი მოქმედების გამო, ამ ფაქტს დაადასტურებს საქართველოს შესაბამისი საკონსულო დაწესებულება.
