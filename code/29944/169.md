# მუხლი 169. საბაჟო ორგანოების მუშაკთა მატერიალური სტიმულირება და საბაჟო ორგანოების მატერიალურ-ტექნიკური უზრუნველყოფა
საბაჟო მოსაკრებლების სახით სახელმწიფო ბიუჯეტში ჩარიცხული თანხები ნაწილობრივ მიიმართება საბაჟო ორგანოების მუშაკთა მატერიალური სტიმულირებისა და საბაჟო ორგანოების მატერიალურ-ტექნიკური უზრუნველყოფის ღონისძიებათა მიზნობრივი დაფინანსებისათვის, შესაბამისი წლის სახელმწიფო ბიუჯეტის შესახებ კანონის თანახმად.
საქართველოს 1998 წლის 18 თებერვლის კანონი №1235 - პარლამენტის უწყებანი, №11-12, 14.03.1998წ., გვ.26
