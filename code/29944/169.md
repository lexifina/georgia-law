# მუხლი 169. საბაჟო ორგანოების მუშაკთა მატერიალური სტიმულირება და საბაჟო ორგანოების მატერიალურ-ტექნიკური უზრუნველყოფა
1. საბაჟო მოსაკრებლების სახით ამოღებული თანხები მთლიანად მიიმართება საბაჟო ორგანოების მუშაკთა მატერიალური სტიმულირებისა და საბაჟო ორგანოების მატერიალურ-ტექნიკური უზრუნველყოფის ღონისძიებათა მიზნობრივი დაფინანსებისათვის.
2. საბაჟო ორგანოთა მატერიალური სტიმულირებისა და მატერიალურ-ტექნიკური უზრუნველყოფისათვის საბაჟო ორგანოების მიერ კონტროლირებადი შემოსავლების მიხედვით სახელმწიფო ბიუჯეტში ფაქტობრივად ჩარიცხული თანხების 3%, აგრეთვე სახელმწიფო ბიუჯეტის სასარგებლოდ დამატებით დარიცხული და ჩარიცხული თანხების 50% ირიცხება ხაზინაში საბაჟო ორგანოებისათვის გახსნილ სპეციალურ ანგარიშზე. აღნიშნულ ანგარიშზე თანხების ჩარიცხვა საბანკო დაწესებულების მიერ ხდება სახელმწიფო ბიუჯეტში ჩარიცხული თანხების პროპორციულად.
3. მატერიალური სტიმულირებისა და მატერიალურ-ტექნიკური უზრუნველყოფისათვის თანხების ხარჯვის წესს ადგენს საქართველოს სახელმწიფო საბაჟო დეპარტამენტი საქართველოს ფინანსთა სამინისტროსთან შეთანხმებით.
საქართველოს 1998 წლის 18 თებერვლის კანონი №1235 - პარლამენტის უწყებანი, №11-12, 14.03.1998წ., გვ.26
