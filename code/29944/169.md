# მუხლი 169. საქართველოს საგადასახადო შემოსავლების სამინისტროს სტრუქტურული ქვედანაყოფებისა და საბაჟო ორგანოების მუშაკთა მატერიალური წახალისება და მატერიალურ-ტექნიკური უზრუნველყოფა
1. საქართველოს საგადასახადო შემოსავლების სამინისტროს სტრუქტურული ქვედანაყოფებისა და საბაჟო ორგანოების მუშაკთა მატერიალური წახალისებისა და მატერიალურ-ტექნიკური უზრუნველყოფისათვის საბაჟო ორგანოების მიერ კონტროლირებადი შემოსავლების მიხედვით ბიუჯეტებსა და სახელმწიფო სპეციალურ ფონდებში ფაქტობრივად ჩარიცხული თანხების 3 პროცენტი, აგრეთვე ბიუჯეტებისა და სპეციალური ფონდების სასარგებლოდ დამატებით დარიცხული და ჩარიცხული თანხების 50 პროცენტი ირიცხება ხაზინაში საქართველოს საგადასახადო შემოსავლების სამინისტროს სპეციალურ ანგარიშზე. ამ ანგარიშზე თანხების ჩარიცხვა ხდება ბიუჯეტებსა და სახელმწიფო სპეციალურ ფონდებში ჩარიცხული თანხების პროპორციულად საბანკო დაწესებულებების მიერ.
2. საბაჟო მოსაკრებლების სახით ამოღებული თანხები მთლიანად მიიმართება საბაჟო ორგანოების მუშაკთა მატერიალური სტიმულირებისა და ამ ორგანოების მატერიალურ-ტექნიკური უზრუნველყოფის ღონისძიებათა მიზნობრივად დაფინანსებისათვის.
3. ამ მუხლით გათვალისწინებული სახსრების ხარჯვის წესს ადგენს საქართველოს საგადასახადო შემოსავლების მინისტრი.
