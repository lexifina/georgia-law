# მუხლი 169. საგადასახადო სისტემის სრულყოფის მიზნით საქართველოს საგადასახადო შემოსავლების სამინისტროს სპეციალურ ანგარიშზე თანხების აკუმულირება და განაწილება
1. საქართველოს პრეზიდენტის ბრძანებულებით განსაზღვრული სახელმწიფო ორგანოების მატერიალური უზრუნველყოფისათვის საბაჟო ორგანოების მიერ კონტროლირებადი შემოსავლების მიხედვით ბიუჯეტებსა და სახელმწიფო სპეციალურ ფონდებში ფაქტობრივად ჩარიცხული თანხების 3 პროცენტი, აგრეთვე ბიუჯეტებისა და სპეციალური ფონდების სასარგებლოდ დამატებით დარიცხული და ჩარიცხული თანხების 50 პროცენტი ირიცხება ხაზინაში საქართველოს საგადასახადო შემოსავლების სამინისტროს სპეციალურ ანგარიშზე. ამ ანგარიშზე თანხების ჩარიცხვა ხდება ბიუჯეტებსა და სახელმწიფო სპეციალურ ფონდებში ჩარიცხული თანხების პროპორციულად საბანკო დაწესებულებების მიერ.
2. საბაჟო მოსაკრებლების სახით ამოღებული თანხები მთლიანად მიიმართება საბაჟო ორგანოების მუშაკთა მატერიალური სტიმულირებისა და ამ ორგანოების მატერიალურ-ტექნიკური უზრუნველყოფის ღონისძიებათა მიზნობრივად დაფინანსებისათვის.
3. ამ მუხლის პირველი ნაწილით გათვალისიწინებული სახსრების განაწილების წესს ადგენს საქართველოს პრეზიდენტი.
