# მუხლი 54. საქართველოს საბაჟო ტერიტორიის გარეთ საქონლის გადამუშავების შედეგად მიღებული პროდუქციის გამოსავლიანობა
საქართველოს საბაჟო ტერიტორიის გარეთ საქონლის გადამუშავების შედეგად მიღებული პროდუქციის სავალდებულო გამოსავლიანობა განისაზღვრება საქართველოს საგადასახადო შემოსავლების სამინისტროს საბაჟო დეპარტამენტის, საქართველოს ფინანსთა სამინისტროსა და საქართველოს ეკონომიკის, მრეწველობისა და ვაჭრობის სამინისტროს მიერ ერთობლივად დადგენილი წესით.
- საქართველოს 1998 წლის 13 ოქტომბრის კანონი №1627 - სსმI, №2, 26.10.1998წ., მუხ.24
