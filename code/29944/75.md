# მუხლი 75. საბაჟო გადასახდელების ზედმეტად გადახდილი თანხის დაბრუნება
1. ზედმეტად გადახდილი საბაჟო გადასახდელების თანხა უბრუნდება გადამხდელს 30 დღის განმავლობაში განცხადების მიღების დღიდან სამოქალაქო კოდექსით განსაზღვრული ხანდაზმულობის ვადის გათვალისწინებით.
2. საბაჟო გადასახდელების უკან დაბრუნებისას მათზე დაირიცხება პროცენტი საგადასახადო კოდექსის 252-ე მუხლის მეორე ნაწილით დადგენილი წესით.
