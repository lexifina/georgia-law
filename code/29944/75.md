# მუხლი 75. საბაჟო გადასახდელების ზედმეტად გადახდილი თანხის დაბრუნება
1. ზედმეტად გადახდილი საბაჟო გადასახდელების თანხა უბრუნდება გადამხდელს 30 დღის განმავლობაში განცხადების მიღების დღიდან სამოქალაქო კოდექსით განსაზღვრული ხანდაზმულობის ვადის გათვალისწინებით, ან ჩაეთვლება გადასახდელების გადამხდელს საბაჟო გადასახდელების გადახდის ანგარიშში.
2. საბაჟო გადასახდელების უკან დაბრუნებისას მათზე დაირიცხება პროცენტი საგადასახადო კოდექსის 252-ე მუხლის მეორე ნაწილით დადგენილი წესით.
3. ზედმეტად გადახდილი საბაჟო გადასახდელების ჩათვლა (გადატანა) სხვა გადამხდელების საბაჟო გადასახდელების ვალდებულებათა დაფარვის ანგარიშში დაუშვებელია.
- საქართველოს 2001 წლის 25 მაისის კანონი №891 - სსმI, №15, 11.06.2001წ., მუხ.49
- საქართველოს 2003 წლის 28 მარტის კანონი №2020 - სსმI, №10, 24.04.2003წ., მუხ.54
