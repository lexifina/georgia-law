# მუხლი 118. საბაჟო ბროკერისა და მისი მუშაკების დამოკიდებულება მარწმუნებლის ინფორმაციისადმი
1. საბაჟო ბროკერის ან მისი მუშაკების მიერ მარწმუნებლისაგან მიღებული ინფორმაციის გამოყენება დაიშვება მხოლოდ საბაჟო მიზნებისათვის.
2. ინფორმაცია, რომელიც შეიცავს კომერციულ, საბანკო და კანონით დაცულ სხვა საიდუმლოებას, აგრეთვე მარწმუნებლის კონფიდენციალური ინფორმაცია არ შეიძლება გახმაურდეს, დაუშვებელია მათი გამოყენება საბაჟო ბროკერის მიერ საკუთარი მიზნებისათვის, გადაცემა მესამე პირისათვის (საბაჟო ორგანოების გარდა), საკანონმდებლო აქტებით გათვალისწინებული შემთხვევების გარდა.
