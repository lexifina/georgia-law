# მუხლი 122. საბაჟო გადამზიდველისა და მისი მუშაკების დამოკიდებულება საქონლისა და მისი საბუთებიდან მიღებული ინფორმაციისადმი
საქონლისა და მისი საბუთებიდან მიღებული ინფორმაცია, რომელიც შეიცავს კომერციულ, საბანკო ან კანონით დაცულ სხვა საიდუმლოებას, ანდა კონფიდენციალური ინფორმაცია არ უნდა გახმაურდეს. დაუშვებელია ინფორმაციის გამოყენება საბაჟო გადამზიდველისა და მისი მუშაკების მიერ საკუთარი მიზნებისათვის, გადაცემა მესამე პირისათვის (გარდა საბაჟო ორგანოებისა), საქართველოს საკანონმდებლო აქტებით გათვალისწინებული შემთხვევების გარდა.
