# მუხლი 37. საქართველოს საბაჟო ტერიტორიაზე საქონლის გადამუშავების შედეგად მიღებული პროდუქციის გამოსავლიანობა
საქართველოს საბაჟო ტერიტორიაზე საქონლის გადამუშავების შედეგად მიღებული პროდუქციის სავალდებულო გამოსავლიანობის ნორმები განისაზღვრება საბაჟო დეპარტამენტის საქართველოს ფინანსთა სამინისტროსა და საქართველოს ეკონომიკის სამინისტროს მიერ ერთობლივად დადგენილი წესით.
- საქართველოს 1998 წლის 13 ოქტომბრის კანონი №1627 - სსმI, №2, 26.10.1998წ., მუხ.24
