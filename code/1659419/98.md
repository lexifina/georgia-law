# მუხლი 98. აკრედიტაციის მოწმობა და ვადა
1. აკრედიტაციის მოწმობა არის მკაცრი აღრიცხვის დოკუმენტ ი. იგი გაიცემა აკრედიტაციის ცენტრის მიერ განსაზღვრული ვადით, რომელიც საერთოა ერთი ტიპის აკრედიტებული პირებისათვის. აკრედიტაციის მოწმობა არის აკრედიტაციის დამადასტურებელ ი მტკიცებულება.
2. აკრედიტაციის ვადის განმავლობაში აკრედიტებული პირი უნდა აკმაყოფილებდეს აკრედიტაციის პირობებს.
