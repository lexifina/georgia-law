# მუხლი 52. იმ ავარიული შენობა-ნაგებობის რეკონსტრუქციის ან დემონტაჟის განუხორციელებლობა, რომლის რეკონსტრუქციის ან დემონტაჟის გარეშე არსებობა უშუალო საფრთხეს უქმნის ადამიანის სიცოცხლეს ან/და ჯანმრთელობას
იმ ავარიული შენობა-ნაგებობის რეკონსტრუქციის ან დემონტაჟის განუხორციელებლობა, რომლის რეკონსტრუქციის ან დემონტაჟის გარეშე არსებობა უშუალო საფრთხეს უქმნის ადამიანის სიცოცხლეს ან/და ჯანმრთელობას, −
გამოიწვევს დაჯარიმებას 5 000 ლარით.
შენიშვნა: თუ შენობა-ნაგებობის მესაკუთრისთვის ცნობილი გახდა, რომ მისი საკუთრება საფრთხეს უქმნის მესამე პირის სიცოცხლეს ან/და ჯანმრთელობას, იგი ვალდებულია მიმართოს შესაბამის ორგანოებს და აცნობოს ასეთი საფრთხის შესახებ. მესაკუთრე ვალდებულია თავისი შესაძლებლობის ფარგლებში მიიღოს უსაფრთხოების ზომები საფრთხის თავიდან ასაცილებლად. შენობა-ნაგებობის მესაკუთრეს ამ მუხლით გათვალისწინებული პასუხისმგებლობა მხოლოდ იმ შემთხვევაში დაეკისრება, თუ იგი არ განახორციელებს ამ შენიშვნით განსაზღვრულ ღონისძიებებს.
