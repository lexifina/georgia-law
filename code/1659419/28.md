# მუხლი 28. ჟანგბადის წარმოებისა და მასთან დაკავშირებული სხვა აფეთქებასაფრთხიანი პროცესის, თხევადი ჟანგბადის წარმოების, რეზერვუარში/ცილინდრში ჟანგბადის ჩაჭირხვნის, სამეწარმეო დანიშნულებით გამოყენებადი, ამიაკზე მომუშავე სამაცივრო დანადგარის, ფუნიკულიორის, საბაგირო გზის, ატრაქციონის, საქვაბე დანადგარის, წნევაზე მომუშავე ჭურჭლის, მარცვლეულის შესანახი და გადამამუშავებელი საწარმოს (წისქვილკომბინატის) ექსპლუატაციისას უსაფრთხოების წესების დარღვევა
1. ჟანგბადის წარმოებისა და მასთან დაკავშირებული სხვა აფეთქებასაფრთხიანი პროცესის, თხევადი ჟანგბადის წარმოების, რეზერვუარში/ცილინდრში ჟანგბადის ჩაჭირხვნის, სამეწარმეო დანიშნულებით გამოყენებადი, ამიაკზე მომუშავე სამაცივრო დანადგარის, ფუნიკულიორის, საბაგირო გზის, ატრაქციონის, საქვაბე დანადგარის, წნევაზე მომუშავე ჭურჭლის, მარცვლეულის შესანახი და გადამამუშავებელი საწარმოს (წისქვილკომბინატის) ექსპლუატაციისას უსაფრთხოების წესების დარღვევა, რამაც გამოიწვია არსებითი შეუსაბამობა, −
გამოიწვევს დაჯარიმებას 200 ლარამდე.
2. ჟანგბადის წარმოებისა და მასთან დაკავშირებული სხვა აფეთქებასაფრთხიანი პროცესის, თხევადი ჟანგბადის წარმოების, რეზერვუარში/ცილინდრში ჟანგბადის ჩაჭირხვნის, სამეწარმეო დანიშნულებით გამოყენებადი, ამიაკზე მომუშავე სამაცივრო დანადგარის, ფუნიკულიორის, საბაგირო გზის, ატრაქციონის, საქვაბე დანადგარის, წნევაზე მომუშავე ჭურჭლის, მარცვლეულის შესანახი და გადამამუშავებელი საწარმოს (წისქვილკომბინატის) ექსპლუატაციისას უსაფრთხოების წესების დარღვევა, რამაც გამოიწვია კრიტიკული შეუსაბამობა, −
გამოიწვევს დაჯარიმებას 1500 ლარამდე.
- საქართველოს 2014 წლის 26 დეკემბრის კანონი №3004 - ვებგვერდი, 12.01.2015წ.
