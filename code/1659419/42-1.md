# მუხლი 42¹. ეკონომიკური ოპერატორის მიერ საჯარო სამართლის იურიდიული პირისთვის − ბაზარზე ზედამხედველობის სააგენტოსთვის ბაზარზე განთავსებული პროდუქტის ზედამხედველობის განხორციელების პროცესში ხელის შეშლა
