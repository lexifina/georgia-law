# მუხლი 190². სპეციალური საწარმოს სტატუსის მქონე პირის აქციზით დაბეგვრა

- საქართველოს 2018 წლის 6 ივნისის კანონი № 2476 - ვებგვერდი, 21.06.2018წ.
