# მუხლი 37. მოთხოვნები მოსახლეობაში ინფექციური და მასობრივი არაგადამდები დაავადებებისა და მოშხამვების გავრცელების თავიდან აცილებისა და ლიკვიდაციის მიზნით
სახელმწიფო ხელისუფლების ორგანოები, ფიზიკური ან/და იურიდიული პირი ვალდებულნი არიან საქართველოს კანონმდებლობით დადგენილი წესით უზრუნველყონ საორგანიზაციო, საინჟინრო-ტექნიკური, სამკურნალო-პროფილაქტიკური, პროფილაქტიკური სანიტარიულ-ჰიგიენური და სანიტარიულ-ეპიდსაწინააღმდეგო ღონისძიებების დროულად განხორციელება ინფექციური და მასობრივი არაგადამდები დაავადებებისა და მოშხამვების თავიდან აცილების, ხოლო მათი აღმოცენების შემთხვევაში - ლიკვიდაციის მიზნით.
