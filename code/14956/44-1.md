# მუხლი 44¹. სანიტარიული კონტროლი გარდამავალ პერიოდში
1. ამ მუხლის მე-3 პუნქტით განსაზღვრული საკანონმდებლო აქტის ამოქმედებამდე ამ კოდექსით გათვალისწინებული სახელმწიფო კონტროლი განხორციელდეს მხოლოდ:
ა) აგრარულ ბაზრებზე;
ბ) საგანმანათლებლო და სააღმზრდელო დაწესებულებებზე;
გ) საცურაო აუზებზე;
დ) სასმელ-სამეურნეო წყალმომარაგების სისტემებზე;
ე) სამედიცინო დაწესებულებებზე;
ვ) საზღვარზე - მხოლოდ იმ შემთხვევაში, თუ კონტრაგენტ ქვეყანაში გავრცელებულია ინფექციური დაავადებები, ეპიდემიები ან ეპიზოოტიები.
2. საქართველოს მთავრობამ, შესაბამისი საერთაშორისო ორგანიზაციების ინფორმაციის საფუძველზე, უზრუნველყოს საშიში ინფექციური დაავადებების, ეპიდემიების, ეპიზოოტიების გავრცელების გამო არაკეთილსაიმედო ქვეყნების ნუსხის გამოქვეყნება სისტემატურად, აღნიშნულ ნუსხაში ცვლილებების შეტანის შესაბამისად.
3. საქართველოს მთავრობამ 2005 წლის 1 ოქტომბრამდე საქართველოს პარლამენტს განსახილველად წარუდგინოს კანონპროექტი, რომელიც გაითვალისწინებს სისტემურ და სტრუქტურულ რეორგანიზაციას სურსათის უსაფრთხოებისა და წამლის სფეროში მოქმედი მაკონტროლებელი ორგანოების (სანიტარიული ზედამხედველობის ინსპექციის, წამლის სააგენტოს, ვეტერინარიის დეპარტამენტის, კვების პროდუქტების ექსპერტიზისა და მონიტორინგის სამსახურის და ფიტოსანიტარიული სამსახურის) რაოდენობისა და ფუნქციების ოპტიმიზაციის მიზნით.
- საქართველოს 2005 წლის 24 ივნისის კანონი №1783-რს - სსმ I, №40, 18.07.2005 წ., მუხ.271
