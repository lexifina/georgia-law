# მუხლი 106. უცხო სახელმწიფოების საძებნ-სამაშველო რაზმების დაშვება საქართველოს ტერიტორიაზე
1. საქართველოსთან დადებული ხელშეკრულებების საფუძველზე მის ტერიტორიაზე დაიშვებიან უცხო სახელმწიფოების საძებნ-სამაშველო რაზმები.
