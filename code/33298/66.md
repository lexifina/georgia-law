# მუხლი 66. სატრანსპორტო საბუთები
მგზავრების გადაყვანის, ბარგის, ტვირთისა და საფოსტო გზავნილების გადაზიდვის ხელშეკრულება დასტურდება შესაბამისად: ბილეთით, საბარგო, სატვირთო ან საფოსტო ზედნადებით.
ამ საბუთების ფორმებს ადგენს საქართველოს საჰაერო ტრანსპორტის დეპარტამენტი, საერთაშორისო ნიმუშებისა და სტანდარტების საფუძველზე.
