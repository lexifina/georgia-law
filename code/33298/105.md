# მუხლი 105. საავარიო-სამაშველო სამუშაოები
1. აეროდრომების ტერიტორიასა და მათ მიმდებარე რაიონებში საავარიო-სამაშველო სამუშაოებს, რომლებიც დაკავშირებულია საავიაციო შემთხვევებსა და ინციდენტებთან, ახორციელებენ აეროდრომების საავარიო-სამაშველო რაზმები.
2. ამ სამუშაოების ხარჯებს ანაზღაურებს საჰაერო ხომალდის ექსპლუატანტი.
