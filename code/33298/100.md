# მუხლი 100. უბედურების მაუწყებელი სიგნალები
ხიფათში მყოფი ან მარცხგანცდილი საჰაერო ხომალდის შეტყობინების ეთერში დაუბრკოლებლად გასვლის მიზნით, გამოიყენება გადაუდებელი და უბედურების მაუწყებელი ერთიანი საერთაშორისო რადიოსატელეფონო და რადიოსატელეგრაფო სიგნალები.
სიგნალები და მათი გამოყენების წესი განსაზღვრულია კანონმდებლობით.
