# მუხლი 7. საავიაციო საშუალებებზე საკუთრების უფლება
საქართველოში საავიაციო საშუალებები შეიძლება იყოს სახელმწიფო, იურიდიული და ფიზიკური პირების (მათ შორის უცხო სახელმწიფოს) საკუთრება, გარდა აეროდრომების, საჰაერო მოძრაობის მართვისა და კონტროლის საშუალებების, საჰაერო ტრასების, ადგილობრივი საჰაერო ხაზებისა და აეროდრომების რადიოტექნიკური მოწყობილობებისა, რაც საქართველოში სახელმწიფო საკუთრებაა.
