# მუხლი 8. საავიაციო საქმიანობაზე ზედამხედველობისა და რეგულირების სახელმწიფო ორგანოები და მათი კომპეტენცია
1. საავიაციო დარგში სახელმწიფო პოლიტიკას ახორციელებს საქართველოს ეკონომიკური განვითარების სამინისტრო.

3. სახელმწიფო ავიაციის საქმიანობაზე ზედამხედველობასა და რეგულირებას ახორციელებს საქართველოს თავდაცვის სამინისტრო.
