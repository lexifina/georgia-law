# მუხლი 15. შავი ზღვის აკვატორიის ღია საჰაერო სივრცის გამოყენების რეგულირება
საქართველოს ტერიტორიული წყლების ფარგლებს გარეთ შავი ზღვის აკვატორიის ღია საჰაერო სივრცეში საჰაერო ხომალდების ფრენის მომსახურებას, საჰაერო ტრასების, საჰაერო მოძრაობის მართვის არეებსა და საზღვრებს ადგენს საქართველოს საჰაერო ტრანსპორტის დეპარტამენტი, საქართველოს თავდაცვის სამინისტროსთან შეთანხმებით, საქართველოსა და მის მოსაზღვრე სახელმწიფოებს შორის სამოქალაქო ავიაციის საერთაშორისო ორგანიზაციის (ICAO) მოთხოვნების საფუძველზე დადებული შეთანხმებების შესაბამისად.
