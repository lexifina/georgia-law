# მუხლი 83. ქონებრივი პასუხისმგებლობა საჰაერო ხომალდების შეტაკების შედეგად მესამე პირისათვის მიყენებული ზარალისათვის
საჰაერო ხომალდების შეტაკების შედეგად გამოწვეული, აგრეთვე, ჰაერში მყოფი ხომალდით მესამე პირისათვის მიყენებული ზიანი მთლიანად ანაზღაურდება გადამყვან-გადამზიდველის მიერ, მაგრამ არა უმეტეს იმ ფარგლებისა, რაც დადგენილია საქართველოს კანონმდებლობით და საერთაშორისო სამართლებრივი ნორმებით.
ამ მუხლთან მიმართებაში, საჰაერო ხომალდი ჰაერში მყოფად ითვლება ასაფრენად ძრავის ამუშავებიდან დაფრენის შემდეგ მის გამორთვამდე.
