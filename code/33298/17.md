# მუხლი 17. ჰაერსანაოსნო და საინფორმაციო მომსახურების გადასახადი
1. ჰაერსანაოსნო და საინფორმაციო მომსახურების გადასახადს ამტკიცებს საქართველოს პარლამენტი.
2. გადასახადიდან თავისუფლდებიან:
ა) სახელმწიფო ავიაცია;
ბ) საჰაერო ხომალდები, რომლებიც მონაწილეობენ ადამიანების, სახელმწიფო და კერძო ქონების გადარჩენაში სტიქიური უბედურებების, კატასტროფებისა და ავარიების დროს.
