# მუხლი 13. საჰაერო ტრასები და ადგილობრივი საჰაერო ხაზები
1. საჰაერო ტრასები და ადგილობრივი საჰაერო ხაზები ექვემდებარება რეგისტრირებასა და სერტიფიცირებას, საქართველოს საჰაერო ტრანსპორტის დეპარტამენტის მიერ დადგენილი წესით, რომელსაც ამტკიცებს საქართველოს ტრანსპორტის სამინისტრო.
2. ინფორმაციას საჰაერო ტრასითა და ადგილობრივი საჰაერო ხაზით სარგებლობის შეზღუდვის შესახებ საქართველოს საჰაერო ტრანსპორტის დეპარტამენტი აწვდის საქართველოსა და უცხო სახელმწიფოების იურიდიულ და ფიზიკურ პირებს, საერთაშორისო საავიაციო ორგანიზაციებს, რისთვისაც გამოიყენება ჰაერსანაოსნო ინფორმაციის გავრცელების არხების სისტემა.
