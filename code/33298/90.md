# მუხლი 90. სასარჩელო ხანდაზმულობის ვადა და გადაყვანა-გადაზიდვასთან დაკავშირებული საქმეების სასამართლო წესით განხილვა
საჰაერო გადაყვანა-გადაზიდვასთან დაკავშირებული სარჩელი შეიძლება აღიძრას შესაბამის სასამართლო ორგანოებში, საქართველოს კანონმდებლობით დადგენილი წესით, საჰაერო ხომალდის ჩამოფრენის ან გადაყვანა-გადაზიდვის შეწყვეტის დღიდან არა უგვიანეს ექვსი თვის ვადაში.
