# მუხლი 49. ფრენის წესების დამრღვევი საჰაერო ხომალდი
საჰაერო ხომალდი, რომელიც უნებართვოდ შემოფრინდება საქართველოს საჰაერო სივრცეში ან დაარღვევს საჰაერო სივრცის გამოყენების სხვა წესებს, ითვლება დამრღვევ საჰაერო ხომალდად და, გაფრთხილების უგულებელყოფის შემთხვევაში, შეიძლება იძულებით იქნეს დაფრენილი. დამრღვევი საჰაერო ხომალდი სათანადო ბრძანების მიღებისთანავე ვალდებულია დაფრინდეს მითითებულ ადგილზე.
