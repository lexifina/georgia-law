# მუხლი 46. ფრენის ნებართვა. საფრენოსნო დავალება
1. სამოქალაქო საჰაერო ხომალდის თითოეული გაფრენა სრულდება ფრენის გეგმის მიხედვით, საჰაერო მოძრაობის მართვის ორგანოს მიერ გაცემული ლიცენზიის საფუძველზე.
2. სახელმწიფო საჰაერო ხომალდის ყოველი გაფრენა სრულდება ფრენის გეგმის სიხედვით, სამხედრო საჰაერო ძალების ცენტრალური სახელმძღვანელო პუნქტის მიერ გაცემული ლიცენზიის საფუძველზე.
3. ფრენის გეგმიდან გადახვევა დაიშვება აღნიშნული ორგანოს თანხმობით ან ამ კოდექსის 36-ე მუხლის მე-7 და მე-8 პუნქტებით გათვალისწინებულ შემთხვევებში.
4. ძირითადი საბუთი, რომელიც განსაზღვრავს ფრენის მიზანს, ამოცანასა და მარშრუტს, არის უფლებამოსილი თანამდებობის პირის მიერ ხელმოწერილი საფრენოსნო დავალება. საბუთის ფორმას და მისი შევსების წესს ადგენენ საქართველოს საჰაერო ტრანსპორტის დეპარტამენტი და საქართველოს თავდაცვის სამინისტრო.
