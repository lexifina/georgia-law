# მუხლი 11. საჰაერო სივრცით სარგებლობის ორგანიზება
საჰაერო სივრცით სარგებლობის ორგანიზებას, ფრენისა და საჰაერო სივრცეში სხვაგვარი საქმიანობის კოორდინირებას უზრუნველყოფს საქართველოს საჰაერო ტრანსპორტის დეპარტამენტი, საქართველოს თავდაცვის სამინისტროსა და საქართველოს ტრანსპორტის სამინისტროსთან შეთანხმებით.
