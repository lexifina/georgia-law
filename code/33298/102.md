# მუხლი 102. ხიფათში მყოფი საჰაერო ხომალდისა და მასზე მყოფი ადამიანებისათვის დახმარების აღმოჩენა
საჰაერო ხომალდის მეთაური, რომელმაც სხვა საჰაერო ან საზღვაო ხომალდისაგან მიიღო უბედურების მაუწყებელი სიგნალი ან შენიშნა ხიფათში მყოფი ხომალდი და ადამიანები, ვალდებულია დაეხმაროს მათ, თუ ეს საფრთხეს არ უქმნის მგზავრებს, ეკიპაჟს და მისთვის მინდობილ ხომალდს. იგი აგრეთვე ვალდებულია აღნიშნოს რუკაზე საავიაციო ან საზღვაო შემთხვევის ადგილი და გადასცეს მის ხელთ არსებული ინფორმაცია საჰაერო მოძრაობის მართვის ორგანოებს.
