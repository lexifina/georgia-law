# მუხლი 43. აეროპორტის კავშირი ქალაქებსა და დასახლებულ ადგილებთან
1. უახლოეს ქალაქებსა და დასახლებულ ადგილებთან აეროპორტს უნდა ჰქონდეს როგორც სატრანსპორტო მიმოსვლა, ასევე საფოსტო, სატელეფონო, სატელეგრაფო და სხვა სახეობის კავშირი.
2. შესაბამისი სახელმწიფო ორგანოები უზრუნველყოფენ აეროპორტებთან მისასვლელი გზების კეთილმოწყობას, ექსპლუატირებასა და მათზე შეუფერხებელ სატრანსპორტო მოძრაობას.
[მუხლი 43. აეროპორტის კავშირი უახლოეს ქალაქსა და სხვა დასახლებასთან
1. აეროპორტს უახლოეს ქალაქსა და სხვა დასახლებასთან სატრანსპორტო მიმოსვლა და საკომუნიკაციო საშუალებები უნდა ჰქონდეს.
2. შესაბამისი სახელმწიფო ორგანოები უზრუნველყოფენ აეროპორტთან მისასვლელი გზის კეთილმოწყობას და მასზე შეუფერხებელ სატრანსპორტო მოძრაობას. (ამოქმედდეს 2023 წლის 31 დეკემბრიდან)]
- საქართველოს 2023 წლის 13 ივნისის კანონი №3115 - ვებგვერდი, 30.06.2023წ.
