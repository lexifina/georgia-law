# მუხლი 18. რადიოკავშირის ენა საჰაერო მოძრაობის მომსახურებისა
საქართველოს საჰაერო სივრცეში საჰაერო მოძრაობის მართვის ორგანოებსა და საჰაერო ხომალდის ეკიპაჟებს შორის რადიოკავშირი ხორციელდება ქართულ ენაზე, ხოლო უცხო სახელმწიფოს საჰაერო ხომალდის ეკიპაჟთან - სამოქალაქო ავიაციის საერთაშორისო ორგანიზაციის სამუშაო ენაზე.
