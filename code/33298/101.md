# მუხლი 101. ეკიპაჟის მოქმედება საჰაერო ხომალდის ხიფათში ყოფნის დროს
თუ საჰაერო ხომალდს ჰაერში ყოფნისას ემუქრება საფრთხე, საჰაერო ხომალდის მეთაური და ეკიპაჟის წევრები ვალდებული არიან მიიღონ ყველა შესაძლო ზომა ხომალდზე მყოფი ადამიანების სიცოცხლისა და ჯანმრთელობის, ასევე ხომალდისა და მასზე არსებული ქონების დასაცავად.
