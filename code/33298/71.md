# მუხლი 71. გადაზიდვის განსაკუთრებული პირობები
ფეთქებად ნივთიერებათა, იარაღის, ტყვია-წამლის, მომწამლავი, სწრაფაალებადი, რადიოაქტიური და სხვა სახიფათო ნივთიერებებისა და საგნების ნუსხას, რომელთა გადაზიდვაც სამოქალაქო ავიაციის საჰაერო ხომალდებით აკრძალულია, განსაზღვრავს საქართველოს საჰაერო ტრანსპორტის დეპარტამენტი და ამტკიცებს საქართველოს ტრანსპორტისა და კომუნიკაციების სამინისტრო.
