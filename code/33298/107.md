# მუხლი 107. ინფორმაცია ხიფათში მყოფი ან მარცხგანცდილი ხომალდის შესახებ
იურიდიული და ფიზიკური პირები, რომლებსაც აქვთ კავშირგაბმულობის საშუალებები, ვალდებული არიან დაუყოვნებლივ და უსასყიდლოდ გადასცენ ინფორმაცია საჰაერო ხომალდის ხიფათში ყოფნის ან მისი მარცხის შესახებ. მოქალაქეები ვალდებული არიან დაუყოვნებლივ აცნობონ ქვეყნის შესაბამის სახელმწიფო ორგანოებს საჰაერო ხომალდის ხიფათში ყოფნის ან მარცხის შესახებ მათთვის ცნობილი ფაქტები.
