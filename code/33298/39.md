# მუხლი 39. აეროდრომებისა და აეროპორტების სერტიფიცირება და საექსპლუატაციოდ გადაცემა
1. აეროდრომის ექსპლუატირება დაიშვება სახელმწიფო რეგისტრირების გავლისა და აეროდრომის ვარგისობის სერტიფიკატის მიღების შემდეგ.
2. სამოქალაქო ავიაციის აეროდრომების (აეროპორტების) სერტიფიცირების წესს შეიმუშავებს და გამოსცემს სააგენტო.
3. სახელმწიფო ავიაციის აეროდრომები საექსპლუატაციოდ გადაეცემა საქართველოს თავდაცვის სამინისტროს მიერ შემუშავებული წესით, რომელსაც ამტკიცებს საქართველოს მთავრობა.
4. (ამოღებულია).

- საქართველოს 2007 წლის 30 მარტის კანონი №4597 - სსმ I, №11, 10.04.2007 წ., მუხ.101
