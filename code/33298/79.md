# მუხლი 79. გადამზიდველის პასუხისმგებლობა საფოსტო გზავნილების მთლიანად ან ნაწილობრივ დაკარგვის, დაზიანების ან დაგვიანებით გადაზიდვის შემთხვევაში
გადამზიდველის მიზეზით საფოსტო გზავნილების მთლიანად ან ნაწილობრივ დაკარგვის, დაზიანების ან დაგვიანებით გადაზიდვის შემთხვევაში, იგი პასუხს აგებს კავშირგაბმულობის უწყების წინაშე იმ ოდენობით, რასაც ითვალისწინებს აღნიშნული უწყების პასუხისმგებლობა გამგზავნთა ან ადრესატთა მიმართ კავშირგაბმულობის წესდებისა და მსოფლიო საფოსტო კავშირის აქტების შესაბამისად.
