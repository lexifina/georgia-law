# მუხლი 79. გადამზიდველის პასუხისმგებლობა მისი მიზეზით საფოსტო გზავნილების მთლიანად ან ნაწილობრივ დაკარგვის, დაზიანების ან დაგვიანებით გადაზიდვის შემთხვევაში
