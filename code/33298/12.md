# მუხლი 12. საქართველოს საჰაერო სივრცის სტრუქტურა
1. საქართველოს საჰაერო სივრცის სტრუქტურა მოიცავს შემდეგ ძირითად ელემენტებს:
ა) საჰაერო ტრასები, ადგილობრივი საჰაერო ხაზები, სწორხაზოვანი მარშრუტები, ადგილობრივი საჰაერო ხაზებისა და საჰაერო ტრასების ფარგლებს გარეთ ფრენის მუდმივი მარშრუტები;
ბ) საქართველოს სახელმწიფო საზღვრის გადამკვეთი საჰაერო დერეფნები;
გ) აეროდრომების რაიონები, აეროკვანძები, პოლიგონები და საპილოტაჟო არეები;
დ) ფრენისათვის შეზღუდული არეები;
ე) ფრენისათვის სახიფათო არეები;
ვ) ფრენისათვის აკრძალული არეები.
2. საქართველოს საჰაერო სივრცის სტრუქტურას ამტკიცებს საქართველოს პრეზიდენტი.
3. ინფორმაცია საქართველოს საჰაერო სივრცის სტრუქტურის შესახებ შეიტანება ჰაერსანაოსნო ინფორმაციის კრებულებში და აისახება ჰაერსანაოსნო რუკებზე.
