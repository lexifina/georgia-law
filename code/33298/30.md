# მუხლი 30. საავიაციო პერსონალის საქმიანობის ლიცენზიის გაცემა
1. საავიაციო პერსონალს უფლება აქვს შეასრულოს ფრენა ან მისი მომსახურება საავიაციო წესების შესაბამისად გაცემული ლიცენზიის საფუძველზე.
2. საავიაციო წესებს შეიმუშავებენ:
ა) სამოქალაქო ავიაციის სფეროში-საქართველოს საჰაერო ტრანსპორტის დეპარტამენტი;
ბ) სახელმწიფო ავიაციის სფეროში-საქართველოს თავდაცვის სამინისტრო.
3. საავიაციო პერსონალმა საქმიანობის განხორციელებისას თან უნდა იქონიოს ლიცენზია, რომელიც უნდა შეესაბამებოდეს აღნიშნულ წესებს.
