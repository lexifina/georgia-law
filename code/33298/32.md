# მუხლი 32. უცხო სახელმწიფოების მიერ საავიაციო პერსონალზე გაცემული სერტიფიკატების ცნობა
უცხო სახელმწიფოების მიერ საავიაციო პერსონალზე გაცემული სერტიფიკატები შეიძლება მოქმედებდეს საქართველოს ტერიტორიაზე, თუ არსებობს სახელმწიფოთაშორისო შეთანხმება საავიაციო პერსონალის სერტიფიკატების ურთიერთცნობის შესახებ.
