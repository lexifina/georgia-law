# მუხლი 108. საჰაერო ხომალდისა და მასზე მყოფი ადამიანების ძებნის შეწყვეტა
1. თუ საჰაერო ხომალდისა და მასზე მყოფი ადამიანების ძებნა უშედეგო აღმოჩნდა, ძებნის შეწყვეტის თაობაზე გადაწყვეტილებას იღებს საქართველოს მთავრობა.
2. საჰაერო ხომალდი, რომლის ძებნა ოფიციალურად შეწყდა, მიიჩნევა უკვალოდ დაკარგულად.
- საქართველოს 2013 წლის 6 სექტემბრის კანონი №1038 - ვებგვერდი, 23.09.2013წ.
