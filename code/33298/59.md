# მუხლი 59. სამოქალაქო საავიაციო საქმიანობის ლიცენზირება
1. საჰაერო გადაყვანა-გადაზიდვა, საავიაციო სამუშაოები და სამოქალაქო საჰაერო ხომალდის გამოყენებასთან დაკავშირებული სხვა საქმიანობა შეიძლება განხორციელდეს მხოლოდ საქართველოს საჰაერო ტრანსპორტის დეპარტამენტის მიერ გაცემული ლიცენზიის საფუძველზე.
2. ექსპლუატანტის სერტიფიკატის უქონლად ლიცენზიით გათვალისწინებული უფლებების განხორციელება აკრძალულია.
3. ლიცენზირების წესს ამტკიცებს ტრანსპორტისა და კომუნიკაციების სამინისტრო.
4. ლიცენზიის გაცემაზე უარის თქმა შეიძლება გასაჩივრდეს საქართველოს კანონმდებლობით დადგენილი წესით.
