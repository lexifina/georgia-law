# მუხლი 32. სამშენებლო ან სხვა ინერტული ნარჩენებით გარემოს დანაგვიანება
1. 1 მ³-მდე მოცულობის სამშენებლო ან სხვა ინერტული ნარჩენით გარემოს დანაგვიანება -
გამოიწვევს ფიზიკური პირის დაჯარიმებას 200 ლარის ოდენობით, იურიდიული პირის დაჯარიმებას 500 ლარის ოდენობით.
2. 1 მ³ ან 1 მ³-ზე მეტი მოცულობის სამშენებლო ან სხვა ინერტული ნარჩენით გარემოს დანაგვიანება -
გამოიწვევს ფიზიკური პირის დაჯარიმებას 500 ლარის ოდენობით, იურიდიული პირის დაჯარიმებას 1500 ლარის ოდენობით.
შენიშვნა: ამ მუხლის პირველი ნაწილით გათვალისწინებულ შემთხვევაში პირი, რომლის მიმართაც შედგენილია ადმინისტრაციული სამართალდარღვევის შესახებ ოქმი, ვალდებულია დაუყოვნებლივ დაასუფთაოს სამშენებლო ან სხვა ინერტული ნარჩენებით დანაგვიანებული ტერიტორია.
