# მუხლი 40. ნარჩენების შეგროვების, ტრანსპორტირების, წინასწარი დამუშავებისა და დროებითი შენახვის რეგისტრაციის წესისა და პირობების დარღვევა

გამოიწვევს დაჯარიმებას 1000 ლარის ოდენობით.

გამოიწვევს დაჯარიმებას 1 500 ლარის ოდენობით.
