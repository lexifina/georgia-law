# მუხლი 363⁵⁶. სარჩელის წარმოებაში მიღება
1. სასამართლო სარჩელის წარდგენიდან 3 დღის ვადაში იხილავს მისი წარმოებაში მიღების საკითხს.
2. სარჩელის საქართველოს კანონმდებლობის მოთხოვნების დაუცველად წარდგენის შემთხვევაში სასამართლო ადგენს ხარვეზს და მოსარჩელეს მის აღმოსაფხვრელად გონივრულ ვადას განუსაზღვრავს. ეს ვადა 3 დღეზე ნაკლები არ უნდა იყოს. განსაზღვრულ ვადაში ხარვეზის აღმოფხვრის შემთხვევაში სასამართლო სარჩელს წარმოებაში იღებს, ხოლო თუ ხარვეზი არ აღმოიფხვრა, მას გამოაქვს განჩინება სარჩელის წარმოებაში მიღებაზე უარის თქმის შესახებ და სარჩელსა და თანდართულ დოკუმენტებს მოსარჩელეს უბრუნებს.
3. სარჩელის წარმოებაში მიღებაზე უარის თქმის შესახებ სასამართლო განჩინება შეიძლება კერძო საჩივრით გასაჩივრდეს სააპელაციო სასამართლოში საქართველოს კანონმდებლობით დადგენილი წესით მოსარჩელისთვის მისი ჩაბარებიდან 3 დღის ვადაში.
4. სარჩელის წარმოებაში მიღების შემდეგ სარჩელისა და თანდართული დოკუმენტების ასლები საქართველოს კანონმდებლობით დადგენილი წესით, დაუყოვნებლივ ეგზავნება მოპასუხეს და მას შესაგებლის წარსადგენად 10 დღის ვადა ეძლევა.
- საქართველოს 2025 წლის 26 ივნისის კანონი №826 - ვებგვერდი, 27.06.2025წ.
