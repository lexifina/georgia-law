# მუხლი 309³⁷. კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენების შესახებ სასამართლოს ბრძანება
1. კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენების შესახებ სასამართლოს ბრძანებაში უნდა აღინიშნოს, რომ ეს ბრძანება ექვემდებარება დაუყოვნებლივ აღსრულებას, გარდა ამ კოდექსის 309³⁵ მუხლის პირველი ნაწილის "დ" და "ე" ქვეპუნქტებით განსაზღვრული ღონისძიებების გამოყენების შესახებ ბრძანებებისა, აგრეთვე მისი გასაჩივრების წესი და ვადა და მხარეთა შორის კეიპტაუნის კონვენციით გათვალისწინებული უფლების დაცვის დროებითი ღონისძიების გამოყენებასთან დაკავშირებული ხარჯების განაწილების წესი.
2. ამ კოდექსის 309³⁵ მუხლის პირველი ნაწილის "დ" და "ე" ქვეპუნქტებით განსაზღვრული უფლების დაცვის დროებითი ღონისძიებების გამოყენების შესახებ ამ თავით გათვალისწინებული სასამართლოს ბრძანებების აღსრულებას უზრუნველყოფს კეიპტაუნის კონვენციით განსაზღვრული კრედიტორი.
