# მუხლი 309³⁰. კოოპერატივის საერთო კრების მოწვევა
კოოპერატივის წევრთა 10%-ის ან მისი წესდებით გათვალისწინებული რაოდენობის წევრთა მოთხოვნის შემთხვევაში სასამართლო ამ კოდექსის 309²⁸ მუხლით დადგენილი წესით განიხილავს განმცხადებელ კოოპერატივის წევრთათვის კოოპერატივის საერთო კრების მოწვევის უფლებამოსილების მინიჭების საკითხს.
- საქართველოს 2021 წლის 2 აგვისტოს კანონი №888 - ვებგვერდი, 04.08.2021წ.
