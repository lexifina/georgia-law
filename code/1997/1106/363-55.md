# მუხლი 363⁵⁵. მტკიცების ტვირთი
ცილისწამებასთან დაკავშირებული საქმის განხილვისას საქმისთვის მნიშვნელობის მქონე გარემოებების შესახებ მტკიცების ტვირთი ნაწილდება "სიტყვისა და გამოხატვის თავისუფლების შესახებ" საქართველოს კანონის შესაბამისი ნორმების გათვალისწინებით.
- საქართველოს 2025 წლის 26 ივნისის კანონი №826 - ვებგვერდი, 27.06.2025წ.
