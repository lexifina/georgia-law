# მუხლი 92
1. პასუხისმგებლობა გემის მიერ მომხდარი ავარიული საზღვაო შემთხვევისათვის ეკისრება გემის კაპიტანს, ხოლო თუ ეს მოხდა სამსახურებრივი მოვალეობის შესრულებისას ლოცმანის მიზეზით - სალოცმანო სამსახურსაც.
