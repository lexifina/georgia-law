# მუხლი 32
1. რეესტრი შედგება წიგნებისაგან, კერძოდ:
ა) საერთაშორისო ნაოსნობის გემების წიგნისაგან;
ბ) შიდა ნაოსნობის გემების წიგნისაგან;
გ) ბერბოუტ-ჩარტერის წიგნისაგან;
დ) მშენებარე გემების წიგნისაგან;
ე) შიდა სახმელეთო წყლების გემების წიგნისგან.
1¹. ამ მუხლის პირველ ნაწილში მითითებული რეესტრი შეიძლება ელექტრონული ფორმით იწარმოებოდეს, მათ შორის, შეიძლება გაიცეს გემის რეგისტრაციასთან დაკავშირებული ელექტრონული მოწმობები.
1². გემის რეგისტრაციასთან დაკავშირებულ ელექტრონულ მოწმობებთან დაკავშირებული საკითხები რეგულირდება "ელექტრონული დოკუმენტისა და ელექტრონული სანდო მომსახურების შესახებ" საქართველოს კანონით.
2. ერთი და იმავე გემის რეგისტრაცია ერთსა და იმავე დროს ხდება რეესტრის მხოლოდ ერთ წიგნში.
2¹. თუ მცურავი საშუალება რეგისტრირებულია ამ მუხლის პირველი ნაწილის "ა"−"დ" ქვეპუნქტებით გათვალისწინებულ წიგნებში, მას აქვს შიდა სახმელეთო წყლებში ნაოსნობის უფლება და არ საჭიროებს შიდა სახმელეთო წყლების გემების წიგნში რეგისტრაციას.
2². თუ მცურავი საშუალება რეგისტრირებულია შიდა სახმელეთო წყლების გემების წიგნში, იგი ვალდებულია მოიხსნას რეგისტრაციიდან და საზღვაო წყლებში ნაოსნობისთვის დარეგისტრირდეს ამ მუხლის პირველი ნაწილის "ა"−"დ" ქვეპუნქტებით გათვალისწინებულ წიგნებში.
3. გემზე საკუთრების უფლება, სხვა უფლებები და ქონებრივი შეზღუდვები (საზღვაო გირავნობა, საზღვაო იპოთეკა და სხვა) რეგისტრირდება რეესტრის შესაბამის წიგნში. იმ გემის რეესტრში რეგისტრაცია, რეგისტრაციიდან მოხსნა ან რეგისტრაციის შეწყვეტა, რომელზედაც არსებობს ქონებრივი შეზღუდვა (საზღვაო გირავნობა, საზღვაო იპოთეკა და სხვა), ხორციელდება მხოლოდ მოთხოვნის უფლების მქონე პირის წერილობითი თანხმობით, რომლის სასარგებლოდაც დარეგისტრირებულია ასეთი ქონებრივი შეზღუდვა.
4. გემის ბერბოუტ-ჩარტერის წიგნში რეგისტრაცია წარმოშობს იმავე უფლებებსა და მოვალეობებს, რომლებსაც მისი მუდმივი რეგისტრაცია. გემის ბერბოუტ-ჩარტერის წიგნში რეგისტრაციის ვადა განისაზღვრება ბერბოუტ-ჩარტერის ხელშეკრულების მოქმედების ვადით ან გემის სხვა ქვეყნის სათანადო რეესტრში რეგისტრაციის შეჩერების ვადის შესაბამისად.
4¹. აკრძალულია ბერბოუტ-ჩარტერის წიგნში რეგისტრირებულ გემზე საზღვაო იპოთეკის ან სხვა ქონებრივი შეზღუდვის რეგისტრაცია.
5. გემის რეესტრში რეგისტრაცია არის საქართველოს სახელმწიფო დროშით სარგებლობის (ნაოსნობის) უფლების პირველადი მტკიცებულება.
6. ზომამცირე გემის რეგისტრაციის წესსა და პირობებს განსაზღვრავს სააგენტო.
7. შიდა სახმელეთო წყლებში ნაოსნობაში ჩართული გემის რეგისტრაციასთან დაკავშირებით გამოიყენება აგრეთვე ამ კოდექსის მე-14 მუხლის პირველი ნაწილით, 28-ე მუხლის "ბ"−"ზ¹", "თ.ა", "თ.გ" და "კ" ქვეპუნქტებით, 29-ე მუხლის პირველი და მე-3 ნაწილებით, მე-5 ნაწილის "ა"−"გ" ქვეპუნქტებითა და მე-6, მე-7 და მე-9 ნაწილებით, 30-ე მუხლის პირველი, მე-2 და მე-4 ნაწილებით, 31-ე მუხლის პირველი და მე-2 ნაწილებითა და მე-3 ნაწილის "ა" ქვეპუნქტით, ამ მუხლის 1¹, 1², მე-2 და მე-3 ნაწილებით, ამ კოდექსის 35-ე მუხლის პირველი და მე-7 ნაწილებით, 36-ე მუხლის პირველი ნაწილის "ა"−"გ" ქვეპუნქტებით, მე-2 ნაწილის "ბ", "გ" და "ე"−"თ" ქვეპუნქტებით, მე-3 ნაწილის "ა"−"დ" და "ზ" ქვეპუნქტებითა და მე-5−მე-7 ნაწილებით, 39-ე მუხლის პირველი ნაწილის "ა" ქვეპუნქტით, მე-40 მუხლის პირველი ნაწილითა და XIII თავით განსაზღვრული უფლებები და მოვალეობები.
