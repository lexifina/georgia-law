# მუხლი 44¹⁷
1. გემის ინსპექტორს ან გემების შემმოწმებელს, რომელიც სააგენტოს ან აღიარებული ორგანიზაციის სახელით მუშაობს, ინსპექტირების/შემოწმების, გემის სერტიფიცირების ან ამ კოდექსის 44³ მუხლის მიზნებისთვის უნდა ჰქონდეს შემდეგი უფლებები:
ა) ავიდეს საქართველოს დროშით მცურავ გემზე;
ბ) განახორციელოს ყველა საჭირო ინსპექტირება და შემოწმება, რომელთა ჩატარებაც მოითხოვება საერთაშორისო საზღვაო ორგანიზაციის კონვენციებით, რომელთა მხარეც არის საქართველო;
გ) მოითხოვოს დაფიქსირებული შეუსაბამობებისა და ხარვეზების აღმოფხვრა;
დ) აუკრძალოს გემს ნაოსნობა, თუ არსებობს დასაბუთებული ვარაუდი, რომ დაფიქსირებული შეუსაბამობები საერთაშორისო საზღვაო ორგანიზაციის კონვენციების სერიოზული დარღვევაა, ემუქრება გემზე მყოფ მეზღვაურთა უსაფრთხოებას ან ჯანმრთელობას ან მიმართულია საზღვაო უშიშროების წინააღმდეგ.
2. გემის ინსპექტორმა ან გემების შემმოწმებელმა უნდა განახორციელოს ყველა შესაბამისი ღონისძიება გემის უსაფუძვლო მოცდენის თავიდან ასაცილებლად.
3. გემის ინსპექტორმა ან გემების შემმოწმებელმა, რომელიც ახორციელებს გემის ინსპექტირებას/შემოწმებას შრომის საერთაშორისო ორგანიზაციის 2006 წლის 23 თებერვლის "საზღვაო შრომის კონვენციის" (MLC 2006) სტანდარტების დაცვის კუთხით, უნდა უზრუნველყოს, რომ ინსპექტირების ანგარიშის ასლი გადაეცეს გემის კაპიტანს. ამასთანავე, ინსპექტირების ანგარიშის ასლი უნდა განთავსდეს გემზე თვალსაჩინო ადგილას, აგრეთვე გაეგზავნოს სააგენტოს.
4. გემთმფლობელს, დამფრახტავს ან კომპანიას ეკრძალება გემის ინსპექტორის ან გემების შემმოწმებლის მიერ საკუთარი მოვალეობების შესრულების პროცესში მისთვის ხელის შეშლა.
