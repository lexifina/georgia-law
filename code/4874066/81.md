# მუხლი 81. სარეკონსტრუქციო ჭრა
1. მოვლითი სარეკონსტრუქციო ჭრა ხორციელდება განსაზღვრული ადგილისთვის ნაკლებად ღირებულ და დაბალი წარმადობის კორომებში მათი სახეობრივი შემადგენლობის, სტრუქტურისა და პროდუქტიულობის გაუმჯობესების მიზნით. იგი გულისხმობს არასასურველი ხეების ან/და მარადმწვანე ქვეტყის მოჭრას და ჭრის შედეგად გათავისუფლებულ ფართობზე ბუნებრივი განახლების ხელშეწყობას ან/და ტყის კულტურების გაშენებას.
2. საკურორტო და სარეკრეაციო ტყეში სარეკონსტრუქციო ჭრა შეიძლება განხორციელდეს ლანდშაფტის (ღია, დახურული, ნახევრად დახურული ლანდშაფტის) ჩამოყალიბებისთვის.
