# მუხლი 80. სანიტარიული ჭრა
1. მოვლითი სანიტარიული ჭრა, რომელიც არ მიეკუთვნება ტყის სისტემურ ჭრებს, არის სატყეო-სამეურნეო ღონისძიება, რომლის მიზანია ტყის სანიტარიული მდგომარეობის გაუმჯობესება. იგი გულისხმობს განსაზღვრულ ადგილზე ხმელი, ძლიერ ფაუტი (ფუტურო) და ტყის მავნებელ-დაავადებებით ძლიერ დაზიანებული ხეების დადგენილ ვადებში მოჭრას, აგრეთვე მათი და სტიქიის შედეგად მოთხრილი და მოტეხილი ხეების ტყიდან გატანას.
2. თუ მოსალოდნელია, რომ სანიტარიული ჭრის შედეგად კორომის სიხშირე 0,3-ზე ნაკლები გახდება, ჭრის განხორციელება დასაშვებია მხოლოდ გადაუდებელი აუცილებლობის შემთხვევაში, სათანადო დასაბუთების საფუძველზე, ერთიანი ღონისძიებების გატარებისას.
