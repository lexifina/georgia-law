# მუხლი 39. ტყის მართვის ორგანოს მიერ სახელმწიფო ტყით სპეციალური სარგებლობის განხორციელება
1. ტყის მართვის ორგანო ტყის მდგრადი მართვის მიზნებიდან გამომდინარე, ამ კოდექსით მისთვის მინიჭებული უფლებამოსილების ფარგლებში, ტყის მართვის გეგმის ან/და წლიური სამოქმედო გეგმის შესაბამისად, მერქნის დასამზადებლად ახორციელებს სახელმწიფო ტყით სპეციალურ სარგებლობას. ამასთანავე, ხეტყე შეიძლება დაამზადოს ხეტყის დამზადების მიზნით ჩატარებულ აუქციონში გამარჯვებულმა პირმა ტყის მართვის ორგანოს ზედამხედველობით.
2. ტყეში ხეტყის ნარჩენების მოპოვებისა და ბოძით, სარითა და ჭიგოთი სარგებლობის უფლების მესამე პირისთვის გადაცემის წესები დგინდება "ტყითსარგებლობის წესის შესახებ" დებულებით.
- საქართველოს 2026 წლის 24 ივნისის კანონი №1772 - ვებგვერდი, 01.07.2026წ.
