# მუხლი 79. მოვლითი ჭრა
მოვლითი ჭრა ხორციელდება 0,7 ან 0,7-ზე მეტი სიხშირის მომწიფარ ხნოვანებამდე კორომში. მისი მიზანია შერჩეული ხეების ამორჩევითი ჭრის მეთოდით მოჭრის შედეგად განსაზღვრული ადგილისთვის დამახასიათებელი ძვირფასი, მეურნეობისთვის სასურველი სახეობის ხეების ფართობის ერთეულზე თანაბარი განაწილება, მათი განათებით უზრუნველყოფა, აგრეთვე ხის ღეროსა და ვარჯის სრულყოფილად ჩამოყალიბებისა და მერქნის შემატების ზრდისთვის შესაბამისი პირობების შექმნა/გაუმჯობესება.
