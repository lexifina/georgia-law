# მუხლი 105. სარეკონსტრუქციო ჭრა
სარეკონსტრუქციო ჭრა ხორციელდება იაფფასიანი და განსაზღვრული ადგილისათვის ნაკლებად ღირებული და დაბალი წარმადობის მერქნიანი სახეობის ხეების კორომებში მათი სახეობრივი და სტრუქტურული შემადგენლობის, აგრეთვე პროდუქტიულობის გაუმჯობესების მიზნით და იმ შემთხვევაში, თუ ჭრის შედეგად განთავისუფლებულ ფართობზე ტყის აღდგენა გარანტირებულია.
