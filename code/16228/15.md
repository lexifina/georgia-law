# მუხლი 15. სახელმწიფო ტყის ფონდის დაცული ტერიტორიების მართვა
სახელმწიფო ტყის ფონდის დაცულ ტერიტორიებს და მათ რესურსებს მართავს საქართველოს დაცული ტერიტორიების, ნაკრძალებისა და სამონადირეო მეურნეობის სახელმწიფო დეპარტამენტი "დაცული ტერიტორიების სისტემის შესახებ" საქართველოს კანონის, ამ კოდექსის და სხვა ნორმატიული აქტების შესაბამისად.
