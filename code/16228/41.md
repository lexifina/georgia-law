# მუხლი 41. სახელმწიფო სამეურნეო ტყის ფონდის კატეგორიებისათვის დაცვის რეჟიმის მიკუთვნება
1. სახელმწიფო სამეურნეო ტყის ფონდის საკურორტო და მწვანე ზონებს, აგრეთვე ჭალის ტყეებსა და ტყის სუბალპურ ზოლს მიეკუთვნება დაცვის განსაკუთრებული რეჟიმი.
2. ნიადაგდაცვით და წყალმარეგულირებელ ტყეებს მიეკუთვნება დაცვის საერთო რეჟიმი, ამ კოდექსის 42-ე მუხლით გათვალისწინებული წესით.
