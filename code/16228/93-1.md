# მუხლი 93¹. მერქნული რესურსების მართვის ელექტრონული სისტემა
საქართველოს ტერიტორიაზე ხე-ტყით სარგებლობასთან, ხე-ტყის მოძრაობასთან და პირველად გადამუშავებასთან დაკავშირებული ღონისძიებების აღრიცხვის მიზნით იქმნება მერქნული რესურსების მართვის ელექტრონული სისტემა, რომლის წარმოების ინსტრუქციას კანონქვემდებარე ნორმატიული აქტით ამტკიცებს საქართველოს გარემოსა და ბუნებრივი რესურსების დაცვის მინისტრი. მერქნული რესურსების მართვის ელექტრონულ სისტემას აწარმოებენ ამ კოდექსის მე-15 და მე-16 მუხლებით გათვალისწინებული საქართველოს ტყის ფონდის მართვის უფლების მქონე ორგანოები, აგრეთვე სხვა შესაბამისი პირები მერქნული რესურსების მართვის ელექტრონული სისტემის წარმოების ინსტრუქციისა და საქართველოს კანონმდებლობის შესაბამისად.
- საქართველოს 2013 წლის 25 მარტის კანონი №465 - ვებგვერდი, 05.04.2013წ.
