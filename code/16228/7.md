# მუხლი 7. სახელმწიფო, როგორც სატყეო ურთიერთობების სუბიექტი
1. საქართველოს ტყის ფონდთან დაკავშირებულ სამართლებრივ ურთიერთობებში საქართველოს კანონმდებლობის შესაბამისად სახელმწიფოს სახელით მონაწილეობენ საქართველოს გარემოსა და ბუნებრივი რესურსების დაცვის სამინისტრო, საქართველოს სატყეო მეურნეობის სახელმწიფო დეპარტამენტი, საქართველოს დაცული ტერიტორიების, ნაკრძალებისა და სამონადირეო მეურნეობის სახელმწიფო დეპარტამენტი და მათი ტერიტორიული ორგანოები, აგრეთვე ადგილობრივი თვითმმართველობისა და მმართველობის ორგანოები.
2. სახელმწიფო ტყის ფონდთან დაკავშირებულ სამართლებრივ ურთიერთობებში სახელმწიფოს სახელით მონაწილე ორგანოების უფლებამოსილება განისაზღვრება ამ კოდექსით და საქართველოს სხვა საკანონმდებლო აქტებით.
