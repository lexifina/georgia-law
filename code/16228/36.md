# მუხლი 36. სახელმწიფო ტყის ფონდის მართვის უფლების მქონე ორგანოების პასუხისმგებლობა
1. ამ კოდექსის 35-ე მუხლით გათვალისწინებულ შემთხვევებში, სახელმწიფო ტყის ფონდის მართვის უფლების მქონე ორგანოები უზრუნველყოფენ შესაბამისი გადაწყვეტილების მიღებამდე მოსახლეობისა და საზოგადოებრივი გაერთიანებების წარმომადგენელთა მიერ გამოთქმული შენიშვნებისა და წინადადებების განხილვას.
2. სატყეო მეურნეობის და დაცული ტერიტორიების, ნაკრძალებისა და სამონადირეო მეურნეობის სახელმწიფო დეპარტამენტები, საქართველოს კანონმდებლობით უფლებამოსილი სხვა ორგანოები, ამ კოდექსის 35-ე მუხლის მე-3 ნაწილით განსაზღვრული ინფორმაციის გამოქვეყნების გარდა, აგრეთვე უზრუნველყოფენ:
ა) სახელმწიფო ტყის ფონდის მდგომარეობის შესახებ სხვა ინფორმაციის ხელმისაწვდომობას, საქართველოს კანონმდებლობით დადგენილი შემთხვევების გარდა;
ბ) ტყისა და მისი რესურსების მნიშვნელობისა და დაცვის პროპაგანდას, საქართველოს მოსახლეობის ინფორმირების მიზნით სამეცნიერო და საგანმანათლებლო პროგრამების შემუშავებას;
გ) ბიოლოგიური მრავალფეროვნების შენარჩუნების ღონისძიებების მორალურ და მატერიალურ სტიმულირებას.
