# მუხლი 102. გამოხშირვითი ჭრა
გამოხშირვითი ჭრა ხორციელდება 60 წლამდე (სახეობრივი შემადგენლობის მიხედვით) ხნოვანების 0,7 და მეტი სიხშირის კორომებში და გულისხმობს განსაზღვრული უბნის ტერიტორიაზე ზრდაში ჩამორჩენილი, მრუდღეროიანი და დაზიანებული ხეების მოჭრას დანარჩენი ხეების ღეროებისა და ვარჯების სასურველი ფორმის მისაღებად აუცილებელი პირობების შექმნის მიზნით.
