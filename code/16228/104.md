# მუხლი 104. სანიტარიული ჭრა
1. სანიტარიული ჭრა ხორციელდება 0,4-ზე მეტი სიხშირის კორომებში მათი სანიტარიული მდგომარეობის გაუმჯობესების აუცილებლობის შემთხვევაში და გულისხმობს განსაზღვრული უბნის ტერიტორიაზე ზეხმელი, ხმელი, ხმობადი, ძლიერ ფაუტი (ფუტურო) და მავნებლებით ძლიერ დაზიანებული ხეების მოჭრას და ტყიდან გამოტანას, აგრეთვე სტიქიით მოთხრილი და მოტეხილი ხეების ტყიდან გამოტანას.
2. 0,4-მდე სიხშირის კორომებში სანიტარიული ჭრა დაიშვება მხოლოდ განსაკუთრებული აუცილებლობის და სათანადო არგუმენტების არსებობის შემთხვევაში.
