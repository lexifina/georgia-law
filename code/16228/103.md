# მუხლი 103. გავლითი ჭრა
1. გავლითი ჭრა ხორციელდება 61 წლის და მეტი ხნოვანების 0,7 და მეტი სიხშირის კორომებში და გულისხმობს განსაზღვრული უბნის ტერიტორიაზე გადაბერებული, დაზიანებული, მრუდღეროიანი და ჭრისათვის მიზანშეწონილი სხვა ხეების მოჭრას დანარჩენი ხეებისათვის მერქნის შემატების პირობების გაუმჯობესების მიზნით.
2. გავლითი ჭრა ხორციელდება მხოლოდ იმ შემთხვევაში, თუ გარანტირებულია ჭრის შედეგად მიღებული პროდუქციის რეალიზაცია.
