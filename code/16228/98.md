# მუხლი 98. ტყის სუბალპური ზოლის მოვლა და დაცვა
1. ტყის სუბალპურ ზოლში, ამ კოდექსის 39-ე მუხლით განსაზღვრული ღონისძიებების განხორციელებასთან ერთად, იკრძალება ყველა სახის ტყითსარგებლობა.
2. ტყის სუბალპური ზოლის მოვლის და დაცვის ღონისძიებებია:
ა) მავნებლებით დასახლებული ზეხმელი ხეების მოჭრა და ტყიდან გამოტანა;
ბ) ზვავებისა და ნიადაგის ეროზიის საწინააღმდეგო ღონისძიებების განხორციელება;
გ) განსაკუთრებული აუცილებლობის შემთხვევაში ტყის დაცვისა და აღდგენის სხვა ღონისძიებების განხორციელება.
