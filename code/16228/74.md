# მუხლი 74. ტყითსარგებლობის წესები ხე-ტყის დამზადებისას
ხე-ტყის დამზადების მიზნით ტყითსარგებლობის განსახორციელებლად სატყეო მეურნეობის სახელმწიფო დეპარტამენტი:
ა) გარემოსა და ბუნებრივი რესურსების დაცვის სამინისტროსთან შეთანხმებით შეიმუშავებს და საქართველოს პრეზიდენტს დასამტკიცებლად წარუდგენს დებულებას "მთავარი სარგებლობის ჭრის წესის შესახებ";
ბ) გარემოსა და ბუნებრივი რესურსების დაცვის სამინისტროსთან შეთანხმებით შეიმუშავებს და ამტკიცებს დებულებას "საანგარიშო ტყეკაფის დადგენის წესის შესახებ";
გ) გარემოსა და ბუნებრივი რესურსების დაცვის სამინისტროსთან შეთანხმებით შეიმუშავებს და ამტკიცებს დებულებას "ტყითსარგებლობის უფლების შეზღუდვის, შეჩერებისა და შეწყვეტის წესის შესახებ";
დ) შეიმუშავებს და საქართველოს პრეზიდენტს დასამტკიცებლად წარუდგენს დებულებას "ხე-ტყის ზეზეურად გაცემის წესის შესახებ";
ე) შეიმუშავებს და ამტკიცებს დებულებას "ტყეკაფის გამოყოფის წესის შესახებ".
