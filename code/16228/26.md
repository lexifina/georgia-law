# მუხლი 26. სახელმწიფო ტყის ფონდის კადასტრის წარმოება
1. დაცული ტერიტორიებისა და სახელმწიფო სამეურნეო ტყის ფონდის კადასტრებს, თავიანთ სამოქმედო ტერიტორიებზე, აწარმოებენ ამ კოდექსის მე-15 და მე-16 მუხლებით უფლებამოსილი ორგანოები, აგრეთვე, მათთან შეთანხმებით, უფლებამოსილი იურიდიული პირები.
2. სახელმწიფო ტყის ფონდის კადასტრი არის სახელმწიფო ტყის ფონდის მდგომარეობის, აგრეთვე მისი მოვლის, დაცვის, აღდგენისა და რაციონალური გამოყენების სტრატეგიული დაგეგმვის შესახებ სახელმწიფო ორგანოებისა და მოსახლეობის ინფორმაციით უზრუნველყოფის საფუძველი.
3. სახელმწიფო ტყის ფონდის კადასტრს აწარმოებს სატყეო მეურნე-ობის სახელმწიფო დეპარტამენტი.
