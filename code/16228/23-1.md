# მუხლი 23¹. საქართველოს ტყის ფონდის ეროვნული აღრიცხვა
1. საქართველოს ტყის ფონდის ეროვნული აღრიცხვის მიზანია საქართველოს ტყეებისა და მათი რესურსების თაობაზე სტატისტიკური ინფორმაციის მიღება, ტყეების მდგომარეობის უწყვეტი მონიტორინგი და ტყეებთან დაკავშირებული მონაცემების შესახებ საერთაშორისო ანგარიშგება.
2. საქართველოს ტყის ფონდის ეროვნული აღრიცხვა ქვეყნის მთელ ტერიტორიაზე, მიუხედავად ტერიტორიის საკუთრებისა, მათ შორის, მუნიციპალიტეტის საკუთრებასა და კერძო საკუთრებაში არსებულ ტერიტორიებზე, შეიძლება განახორციელოს სამინისტრომ ტერიტორიის მესაკუთრესთან შეთანხმებით.
3. საქართველოს ტყის ფონდის ეროვნული აღრიცხვა სამინისტროსთან შეთანხმების საფუძველზე შეიძლება განხორციელდეს ფიზიკური ან იურიდიული პირის სახსრებით.
4. საქართველოს ტყის ფონდის ეროვნული აღრიცხვის წესი განისაზღვრება "ტყის აღრიცხვის, დაგეგმვისა და მონიტორინგის წესით".
- საქართველოს 2018 წლის 4 მაისის კანონი №2325 - ვებგვერდი, 11.05.2018წ.
