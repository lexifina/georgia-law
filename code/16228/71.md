# მუხლი 71. ტყის სიმწიფისა და ჭრის ოპტიმალური ხნოვანების დადგენა
მთავარი სარგებლობის ჭრების განსახორციელებლად ტყის შემქმნელი ხეების ძირითად მერქნიან სახეობათა მიხედვით ბიოლოგიურ, რაოდენობრივ, ტექნიკურ და სხვა სახის სიმწიფესა და ჭრის ოპტიმალურ ხნოვანებას გარემოსა და ბუნებრივი რესურსების დაცვის სამინისტროსთან შეთანხმებით ამტკიცებს სატყეო მეურნეობის სახელმწიფო დეპარტამენტი.
