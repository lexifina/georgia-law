# მუხლი 118¹. ხე-მცენარეების ადგილწარმოშობის ცნობა
2021 წლის 1 იანვრამდე მუნიციპალიტეტისა და კერძო საკუთრების ტერიტორიებზე არსებული ხე-მცენარეებიდან მიღებული მერქნული რესურსის ტრანსპორტირებისა და პირველადი გადამუშავების მიზნით ხეტყის წარმოშობის დოკუმენტი გაიცემა საქართველოს კანონმდებლობით დადგენილი წესით მუნიციპალიტეტის აღმასრულებელი ორგანოს ან მისი უფლებამოსილი პირის მიერ გაცემული საქონლის (მერქნული რესურსის) ადგილწარმოშობის ცნობის საფუძველზე, გარდა ამ კანონის 93-ე მუხლის მე-2 ნაწილით განსაზღვრული შემთხვევისა.
- საქართველოს 2020 წლის 15 ივლისის კანონი №6935 - ვებგვერდი, 28.07.2020წ.
