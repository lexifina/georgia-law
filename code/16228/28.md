# მუხლი 28. სახელმწიფო ტყის ფონდის აღრიცხვის სისტემა და წესი
1. დებულებას "სახელმწიფო ტყის ფონდის აღრიცხვის სისტემის შესახებ" საქართველოს ეკონომიკური განვითარებისა და ფინანსთა სამინისტროებთან და საქართველოს სტატისტიკის ეროვნულ სამსახურთან (საქსტატთან) შეთანხმებით შეიმუშავებს და საქართველოს პრეზიდენტს დასამტკიცებლად წარუდგენს საქართველოს გარემოს დაცვისა და ბუნებრივი რესურსების სამინისტრო.
2. დებულებას "სახელმწიფო ტყის ფონდის აღრიცხვის წესის შესახებ" საქართველოს სტატისტიკის ეროვნულ სამსახურთან (საქსტატთან) შეთანხმებით შეიმუშავებს და ამტკიცებს საქართველოს გარემოს დაცვისა და ბუნებრივი რესურსების სამინისტრო.
3. დებულებას "სახელმწიფო ტყის ფონდის დაცული ტერიტორიების აღრიცხვის სისტემის განსაკუთრებული მოთხოვნების შესახებ" შეიმუშავებს და დაცული ტერიტორიების, ნაკრძალებისა და სამონადირეო მეურნეობის სახელმწიფო დეპარტამენტთან შეთანხმებით საქართველოს პრეზიდენტს დასამტკიცებლად წარუდგენს გარემოსა და ბუნებრივი რესურსების დაცვის სამინისტრო.
