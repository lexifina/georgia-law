# მუხლი 30. ინფორმაცია საქართველოს ტყის ფონდის მდგომარეობის შესახებ
ინფორმაცია საქართველოს ტყის ფონდის მდგომარეობის შესახებ მოიცავს "სტატისტიკის შესახებ" საქართველოს კანონისა და საერთაშორისო სტანდარტების შესაბამისად საქართველოს ტყის ფონდის აღრიცხვის სისტემისა და ტყითსარგებლობის განხორციელების დროს მიღებულ ინფორმაციას, რომელიც მიეწოდება საქართველოს სტატისტიკის სახელმწიფო დეპარტამენტს.
