# მუხლი 43. სახელმწიფო სამეურნეო ტყის ფონდის უბნისათვის დაცვის განსაკუთრებული რეჟიმის მიკუთვნებისა და ამ რეჟიმის პირობებში სატყეო-სამეურნეო ღონისძიებების განხორციელების წესი
დებულებას "სახელმწიფო სამეურნეო ტყის ფონდის უბნისათვის დაცვის განსაკუთრებული რეჟიმის მიკუთვნებისა და ამ რეჟიმის პირობებში სატყეო-სამეურნეო ღონისძიებების განხორციელების წესის შესახებ" გარემოსა და ბუნებრივი რესურსების დაცვის სამინისტროსთან და დაცული ტერიტორიების, ნაკრძალებისა და სამონადირეო მეურნეობის სახელმწიფო დეპარტამენტთან შეთანხმებით შეიმუშავებს და ამტკიცებს სატყეო მეურნეობის სახელმწიფო დეპარტამენტი.
