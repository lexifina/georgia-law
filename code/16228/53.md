# მუხლი 53. ტყითსარგებლობის უფლება და მისი განხორციელება
1. აკრძალულია ტყითსარგებლობა ტყითსარგებლობის ლიცენზიის, ხელშეკრულებისა და ბილეთის გარეშე, ამ კოდექსის 78-ე მუხლითა და 106-ე მუხლის პირველი ნაწილით განსაზღვრული შემთხვევების გარდა.
2. ტყითმოსარგებლე შეიძლება იყოს ფიზიკური ან იურიდიული პირი.
3. სატყეო მეურნეობის და დაცული ტერიტორიების, ნაკრძალებისა და სამონადირეო მეურნეობის სახელმწიფო დეპარტამენტების ტერიტორიული ორგანოები სახელმწიფო ტყის ფონდის მოვლის, დაცვის, აღდგენისა და გაშენების სამუშაოებს ახორციელებენ არასამეწარმეო მიზნით.
