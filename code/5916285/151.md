# მუხლი 151. ფორმის ტანსაცმელი
1. სამინისტროს სისტემის მოსამსახურე, კადეტი, ამ კოდექსის 41-ე მუხლით გათვალისწინებულ სამხედრო მომზადების პროგრამაზე ჩარიცხული პირი, სამხედრო სასწავლებელში ქართულ ენაში მომზადების საგანმანათლებლო პროგრამაზე ჩარიცხული პირი უფლებამოსილია საქართველოს კანონმდებლობით დადგენილი წესით ატაროს ფორმის ტანსაცმელი.
2. სამინისტროს სისტემაში დადგენილი ფორმის ტანსაცმელი, ფორმის ტანსაცმლის განმასხვავებელი ნიშანი და მისი ტარების წესი განისაზღვრება მინისტრის ნორმატიული აქტით.
3. პირის სამსახურიდან გათავისუფლების შემდეგ მისთვის სამინისტროს სისტემაში დადგენილი ფორმის ტანსაცმლის განმასხვავებელი ნიშნით ტარების უფლების შენარჩუნების საკითხს წყვეტს მინისტრი.
4. სამინისტროს სისტემაში დადგენილი ფორმის ტანსაცმლის განმასხვავებელი ნიშნით უკანონოდ ტარება იწვევს პირის პასუხისმგებლობას საქართველოს კანონმდებლობის შესაბამისად.
- საქართველოს 2025 წლის 24 ივნისის კანონი №713 - ვებგვერდი, 26.06.2025წ.
