# მუხლი 69. გამწვევი კომისიის გადაწყვეტილება
გამწვევი კომისია უფლებამოსილია თავისი კომპეტენციის ფარგლებში წვევამდელის მიმართ მიიღოს ერთ-ერთი შემდეგი გადაწყვეტილება:
ა) წვევამდელის წვევამდელთა ეროვნულ სამხედრო სამსახურში გაწვევისგან გათავისუფლების შესახებ;
ბ) წვევამდელის წვევამდელთა ეროვნულ სამხედრო სამსახურში გაწვევის გადავადების შესახებ;
გ) სამედიცინო შემოწმების გასავლელად წვევამდელის მუდმივმოქმედ სამედიცინო საექსპერტო კომისიაში წარგზავნის შესახებ;
დ) წვევამდელის წვევამდელთა ეროვნულ სამხედრო სამსახურში გაწვევის შესახებ.
- საქართველოს 2025 წლის 24 ივნისის კანონი №713 - ვებგვერდი, 26.06.2025წ.
