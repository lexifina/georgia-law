# მუხლი 79¹. უცხოელი ან მოქალაქეობის არმქონე არასრულწლოვანი ბრალდებულისთვის ან მსჯავრდებულისთვის ინფორმაციის მიწოდება
უცხოელ ან მოქალაქეობის არმქონე არასრულწლოვან ბრალდებულს ან მსჯავრდებულს (გარდა განზრახი მძიმე ან განსაკუთრებით მძიმე დანაშაულისთვის, აგრეთვე ოჯახური დანაშაულისთვის მსჯავრდებული პირისა) თავისუფლების აღკვეთის დაწესებულებაში მოთავსებისთანავე, არაუგვიანეს მე-2 სამუშაო დღისა, თავისუფლების აღკვეთის დაწესებულების უფლებამოსილი პირი საქართველოს კანონმდებლობით დადგენილი წესით, წერილობით, მისთვის გასაგებ ენაზე ან იმ ენაზე, რომელიც მას ესმის, როგორც ეს შეიძლება გონივრულად ჩაითვალოს, აწვდის ინფორმაციას პენიტენციური კოდექსის 41¹ მუხლით გათვალისწინებული საკითხების შესახებ.
- საქართველოს 2025 წლის 26 ივნისის კანონი №877 - ვებგვერდი, 07.07.2025წ.
