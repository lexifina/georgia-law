# მუხლი 21. არასრულწლოვანთა მართლმსაჯულებაში სპეციალიზებული სხვა პირები
არასრულწლოვანთა მართლმსაჯულების პროცესში მონაწილეობენ არასრულწლოვანთა მართლმსაჯულებაში სპეციალიზებული სოციალური მუშაკი, მედიატორი, პრობაციის ოფიცერი, არასრულწლოვანთა სარეაბილიტაციო დაწესებულების პერსონალი და შესაბამისი პატიმრობის დაწესებულების პერსონალი.
