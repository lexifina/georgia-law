# მუხლი 21. არასრულწლოვანთა მართლმსაჯულებაში სპეციალიზებული სხვა პირები
არასრულწლოვანთა მართლმსაჯულების პროცესში მონაწილეობენ არასრულწლოვანთა მართლმსაჯულებაში სპეციალიზებული სოციალური მუშაკი, მედიატორი, პრობაციის ოფიცერი, მოწმისა და დაზარალებულის კოორდინატორი, არასრულწლოვანთა სარეაბილიტაციო დაწესებულების პერსონალი და შესაბამისი პატიმრობის დაწესებულების პერსონალი.
- საქართველოს 2018 წლის 4 მაისის კანონი №2271 - ვებგვერდი, 21.05.2018წ.
