# მუხლი 82. არასრულწლოვნის მკურნალობა
1. არასრულწლოვანი ბრალდებული/მსჯავრდებული უზრუნველყოფილია რეგულარული სამედიცინო შემოწმებით, საჭირო მკურნალობით, პრევენციული სამედიცინო მომსახურებითა და სპეციალური სამედიცინო ინვენტარით.
2. თუ სამედიცინო შემოწმებისას გამოვლინდა არასრულწლოვნის მიმართ განხორციელებული ძალადობის ნიშნები, შემოწმების ჩამტარებელი პირი ვალდებულია ამის შესახებ დაუყოვნებლივ აცნობოს არასრულწლოვნის კანონიერ წარმომადგენელს და იმ დაწესებულების ხელმძღვანელს, სადაც მოთავსებულია არასრულწლოვანი ბრალდებული/მსჯავრდებული.
