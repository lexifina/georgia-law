# მუხლი 21¹²⁷. საქართველოს შინაგან საქმეთა სამინისტროს უფლებამოსილი ორგანოს მიერ "უცხოელთა და მოქალაქეობის არმქონე პირთა სამართლებრივი მდგომარეობის შესახებ" საქართველოს კანონის IX ან X თავის ან 64³ მუხლის მე-3 პუნქტის საფუძველზე მიღებული გადაწყვეტილების გასაჩივრების წესი
1. საქართველოს შინაგან საქმეთა სამინისტროს უფლებამოსილი ორგანოს მიერ "უცხოელთა და მოქალაქეობის არმქონე პირთა სამართლებრივი მდგომარეობის შესახებ" საქართველოს კანონის IX ან X თავის ან 64³ მუხლის მე-3 პუნქტის საფუძველზე მიღებული გადაწყვეტილება საჩივრდება მისი ჩაბარებიდან 10 დღის ვადაში.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებულ შემთხვევაში რაიონული (საქალაქო) სასამართლო სარჩელს განიხილავს ამ კოდექსის 21¹²² მუხლით დადგენილი წესით და დადგენილ ვადაში.
3. რაიონული (საქალაქო) სასამართლოს გადაწყვეტილება საჩივრდება ამ კოდექსის 21¹²⁶ მუხლით დადგენილი წესით და დადგენილ ვადაში.
