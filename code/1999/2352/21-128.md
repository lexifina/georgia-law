# მუხლი 21¹²⁸. სასამართლოს გადაწყვეტილების ასლის მხარისთვის ჩაბარების წესი
1. ამ თავით გათვალისწინებული, სასამართლოს მიერ მიღებული გადაწყვეტილება მხარეს (პირს) მხოლოდ ქართულ ენაზე ჰბარდება. ამ მიზნით სასამართლოს უფლებამოსილი პირებისთვის ხელმისაწვდომია საქართველოს შინაგან საქმეთა სამინისტროს შესაბამისი მონაცემთა ბაზა.
2. ამ მუხლის პირველი ნაწილით გათვალისწინებულ შემთხვევაში სასამართლოს გადაწყვეტილება, განჩინება ან სასამართლო უწყება შესაბამისი პირისთვის ჩაბარებულად ჩაითვლება საქართველოს შინაგან საქმეთა სამინისტროს ვებგვერდზე განთავსების დღის მომდევნო დღიდან.
3. დროებითი განთავსების ცენტრში ან დროებითი მოთავსების იზოლატორში მყოფ უცხოელს შესაბამისი შეტყობინება ან/და გადაწყვეტილება პირადად ჰბარდება, რასაც იგი ხელმოწერით ადასტურებს. უცხოელის მიერ ხელმოწერაზე უარის თქმის შემთხვევაში შეტყობინება ან/და გადაწყვეტილება მისთვის ჩაბარებულად ჩაითვლება.
4. უცხოელის მიერ საქართველოს დატოვების შემთხვევაში სასამართლოს მიერ ამ კანონის საფუძველზე მიღებული გადაწყვეტილება საქართველოს შინაგან საქმეთა სამინისტროს ვებგვერდზე განთავსდება, აგრეთვე ეგზავნება უცხოელს მის მიერ მითითებულ ელექტრონული ფოსტის მისამართზე (მისი არსებობის შემთხვევაში). უცხოელის მიერ სასამართლოსა და საქართველოს შინაგან საქმეთა სამინისტროსთვის ელექტრონული ფოსტის მისამართის შესახებ ინფორმაციის წარუდგენლობის შემთხვევაში სასამართლოს გადაწყვეტილება/სასამართლო განჩინება/ბრძანება ძალაში შედის მისი აღნიშნულ ვებგვერდზე განთავსებიდან მე-15 დღეს.
5. უცხოელის მიერ "უცხოელთა და მოქალაქეობის არმქონე პირთა სამართლებრივი მდგომარეობის შესახებ" საქართველოს კანონის 51¹ მუხლის მე-2 პუნქტით გათვალისწინებული ვალდებულების შეუსრულებლობის შემთხვევაში სასამართლო მიღებულ გადაწყვეტილებას საჯაროდ აქვეყნებს საქართველოს შინაგან საქმეთა სამინისტროს ვებგვერდზე. ეს გადაწყვეტილება ძალაში შედის მისი საჯაროდ გამოქვეყნებიდან მე-15 დღეს.
