# მუხლი 355. ქონებრივი მდგომარეობის დეკლარაციის ან საფინანსო დეკლარაციის წარუდგენლობა ან დეკლარაციაში განზრახ არასრული ან არასწორი მონაცემის შეტანა
1. ქონებრივი მდგომარეობის დეკლარაციის წარუდგენლობა, ჩადენილი ასეთი ქმედებისთვის ადმინისტრაციული სახდელის დადების შემდეგ, ან დეკლარაციაში განზრახ არასრული ან არასწორი მონაცემის შეტანა -
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ვადით ას ოციდან ორას საათამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
2. პარტიულ-პოლიტიკური მიზნის მქონე პირის მიერ საფინანსო დეკლარაციის წარუდგენლობა, დეკლარაციაში განზრახ არასრული ან არასწორი მონაცემის შეტანა ან დეკლარაციაში არსებული ხარვეზის საქართველოს კანონმდებლობით დადგენილ ვადაში აღმოუფხვრელობა −
ისჯება ჯარიმით ან საზოგადოებისათვის სასარგებლო შრომით ვადით ას ოციდან ორას საათამდე, თანამდებობის დაკავების ან საქმიანობის უფლების ჩამორთმევით ვადით სამ წლამდე.
