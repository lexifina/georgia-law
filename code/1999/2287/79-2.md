# მუხლი 79². ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობა და მისი მიზნები
1. ფიზიკურ პირს ამ კოდექსის XXXIII თავით გათვალისწინებული დანაშაულის ჩადენისთვის სასჯელთან ერთად ექიმ-ნარკოლოგთა კომისიის დასკვნის საფუძველზე, არაუმეტეს 2 წლის ვადით შეიძლება დაენიშნოს ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობა.
2. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობა შეიძლება დაინიშნოს მსჯავრდებულის სასჯელისგან სრულად გათავისუფლებისას ან მისთვის სასჯელის პირობითად ჩათვლისას, ხოლო სასჯელის მოხდისგან პირობით ვადამდე გათავისუფლებისას სავალდებულო მკურნალობის გაგრძელება შესაძლებელია.
3. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობის მიზნებია:
ა) პირის მიერ ახალი დანაშაულის ან მართლსაწინააღმდეგო ქმედების ჩადენის თავიდან აცილება;
ბ) საზოგადოებრივი წესრიგისა და მოსახლეობის დაცვა;
გ) პირის განკურნება.
4. ნარკომანიით დაავადებული პირის სავალდებულო მკურნალობის მიზანი არ არის ადამიანის ფიზიკური ტანჯვა ან მისი ღირსების დამცირება.
- საქართველოს 2025 წლის 16 აპრილის კანონი №499 - ვებგვერდი, 17.04.2025წ.
