# მუხლი 34. შეურაცხაობა ფსიქიკური აშლილობის გამო
1. ამ კოდექსით გათვალისწინებული მართლსაწინააღმდეგო ქმედება არ შეერაცხება ბრალად იმას, ვისაც ამ ქმედების ჩადენის დროს ქრონიკული ან დროებითი ფსიქიკური აშლილობის, გონებრივი განვითარების შეფერხების, დემენციის ან სხვაგვარი ფსიქიკური აშლილობის გამო არ შეეძლო გაეცნობიერებინა თავისი ქმედების ფაქტობრივი ხასიათი ან მართლწინააღმდეგობა ანდა ეხელმძღვანელა მისთვის.
2. თუ დანაშაული შერაცხადმა პირმა ჩაიდინა, მაგრამ განაჩენის გამოტანამდე მას ფსიქიკური აშლილობა განუვითარდა, რის გამოც აღარ შეუძლია თავს ანგარიში გაუწიოს ან უხელმძღვანელოს მას, ეს პირი სასამართლოს მიერ შეფარდებულ სასჯელს გამოჯანმრთელებამდე შესაბამის სამედიცინო (სამკურნალო) დაწესებულებაში მოიხდის.

- საქართველოს 2007 წლის 3 ივლისის კანონი №5181 - სსმ I. №28, 18.07.2007 წ., მუხ.278
