# მუხლი 266. ნარკოტიკული საშუალების, მისი ანალოგის, პრეკურსორის, ახალი ფსიქოაქტიური ნივთიერების, ფსიქოტროპული ნივთიერების ან მისი ანალოგის უკანონო წარმოებისთვის ფარული ლაბორატორიის მოწყობა ან შენახვა
1. ნარკოტიკული საშუალების, მისი ანალოგის, პრეკურსორის, ახალი ფსიქოაქტიური ნივთიერების, ფსიქოტროპული ნივთიერების ან მისი ანალოგის უკანონო წარმოებისთვის ფარული ლაბორატორიის მოწყობა ან შენახვა -
ისჯება თავისუფლების აღკვეთით ვადით თორმეტიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
2. იგივე ქმედება, ჩადენილი:
ა) ჯგუფურად;
ბ) სამსახურებრივი მდგომარეობის გამოყენებით;
გ) არაერთგზის;
დ) იმის მიერ, ვინც ნასამართლევია ამ თავით გათვალისწინებული რომელიმე განზრახი დანაშაულის ჩადენისთვის, -
ისჯება თავისუფლების აღკვეთით ვადით თოთხმეტიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
3. იგივე ქმედება, ჩადენილი ორგანიზებული ჯგუფის მიერ, −
ისჯება თავისუფლების აღკვეთით ვადით თექვსმეტიდან ოც წლამდე ან უვადო თავისუფლების აღკვეთით.
შენიშვნა: ამ მუხლით გათვალისწინებული ქმედების ჩადენისთვის იურიდიული პირი ისჯება ჯარიმით, საქმიანობის უფლების ჩამორთმევით ან ლიკვიდაციითა და ჯარიმით.
