# მუხლი 259. ცხოველის წამება, მისდამი სასტიკი მოპყრობა ან სხვაგვარი ძალადობა
1. ცხოველის წამება, მისდამი სასტიკი მოპყრობა ან სხვაგვარი ძალადობა, რამაც მისი დასახიჩრება გამოიწვია, −
ისჯება ჯარიმით, შინაპატიმრობით ვადით ექვსი თვიდან ერთ წლამდე ან თავისუფლების აღკვეთით ვადით სამ წლამდე.
2. იგივე ქმედება, ჩადენილი:
ა) ჯგუფურად;
ბ) საჯაროდ;
გ) არაერთგზის;
დ) არასრულწლოვანის თანდასწრებით;
ე) ორი ან ორზე მეტი ცხოველის მიმართ, −
ისჯება ჯარიმით, შინაპატიმრობით ვადით ერთიდან ორ წლამდე ან თავისუფლების აღკვეთით ვადით სამიდან ოთხ წლამდე.
3. ცხოველის წამება, მისდამი სასტიკი მოპყრობა ან სხვაგვარი ძალადობა, რამაც მისი დაღუპვა გამოიწვია, −
ისჯება ჯარიმით, შინაპატიმრობით ვადით ერთიდან ორ წლამდე ან თავისუფლების აღკვეთით ვადით ორიდან ხუთ წლამდე.
4. ამ მუხლის მე-3 ნაწილით გათვალისწინებული ქმედება, ჩადენილი:
ა) ჯგუფურად;
ბ) საჯაროდ;
გ) არაერთგზის;
დ) არასრულწლოვანის თანდასწრებით;
ე) ორი ან ორზე მეტი ცხოველის მიმართ, −
ისჯება ჯარიმით, შინაპატიმრობით ვადით ერთიდან ორ წლამდე ან თავისუფლების აღკვეთით ვადით სამიდან ხუთ წლამდე.
