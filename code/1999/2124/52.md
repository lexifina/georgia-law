# მუხლი 52. ტყითსარგებლობის ვადები
საქართველოს ტყის ფონდი გაიცემა მოკლევადიანი (1 წლამდე, მათ შორის, სეზონური) და გრძელვადიანი (49 წლამდე) სარგებლობისათვის. გრძელვადიანი სარგებლობისას, ყოველ კონკრეტულ შემთხვევაში, ვადაზე გადაწყვეტილებას იღებს საქართველოს მთავრობა. საქართველოს მთავრობის თანხმობით, შესაძლებელია გაგრძელებულ იქნეს ტყის ფონდით სარგებლობის ვადა.
- საქართველოს 2011 წლის 17 მაისის კანონი №4677 - ვებგვერდი, 01.06.2011წ.
