# მუხლი 128. პრეტენდენტისათვის საჯარო შესყიდვის პროცედურის განმარტება
1. სახელმწიფო ორგანო ვალდებულია საკვალიფიკაცი მოთხოვნებისა და საჯარო შესყიდვის პირობებთან დაკავშირებით განმარტება მისცეს პრეტენდენტს.
2. თუ კანონმდებლობით სხვა ვადა არ არის დადგენილი, შემსყიდველი ორგანიზაცია ვალდებულია პასუხი გასცეს პრეტენდენტის შეკითხვას 2 დღის ვადაში.
3. შემსყიდველი ორგანიზაცია ვალდებულია განმარტების ტექსტი შეკითხვის წყაროს დაუსახელებლად იმავდროულად გაუგზავნოს ყველა პრეტენდენტსა და მიმწოდებელს.
