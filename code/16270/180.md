# მუხლი 180. ადმინისტრაციული აქტის გასაჩივრების ვადა
1. ადმინისტრაციული საჩივარი წარდგენილ უნდა იქნეს ადმინისტრაციულ-სამართლებრივი აქტის გამოქვეყნების ან ოფიციალური წესით გაცნობის დღიდან ერთი თვის ვადაში, თუ კანონით სხვა რამ არ არის დადგენილი.
2. ადმინისტრაციული ორგანოს ქმედება უნდა გასაჩივრდეს ერთი თვის ვადაში იმ დღიდან, როდესაც შესაბამისი დაინტერესებული მხარისათვის ცნობილი გახდა ამ ქმედებათა განხორციელების შესახებ.
3. გასაჩივრების ვადა არ შეიძლება დადგინდეს ადმინისტრაციული ორგანოს მიერ ადმინისტრაციულ-სამართლებრივი აქტის გამოცემის ვადის დარღვევის შემთხვევაში.
4. ადმინისტრაციული აქტის გასაჩივრებისათვის დადგენილი ვადის გაშვების შემთხვევაში იგი უნდა აღდგეს, თუ ამ ვადის გაშვება მოხდა დაუძლეველი ძალის ან სხვა საპატიო მიზეზით.
