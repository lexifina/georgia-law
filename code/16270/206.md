# მუხლი 206. ადმინისტრაციული საჩივრის განხილვასთან დაკავშირებული ხარჯების განაწილება მხარეთა შორის
1. თუ მხარის საჩივრის მხოლოდ ნაწილი დაკმაყოფილდა, ადმინისტრაციული საჩივრის განხილვასთან დაკავშირებული ხარჯები შესაბამისი პროპორციულობით განაწილდება მხარეთა შორის.
2. თუ მხარე, რომელიც ვალდებულია გადაიხადოს ადმინისტრაციული საჩივრის განხილვასთან დაკავშირებული ხარჯები, რამდენიმე ფიზიკური ან იურიდიული პირისაგან შედგება, მაშინ ხარჯები მათ შორის თანაბრად ნაწილდება.
