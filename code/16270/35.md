# მუხლი 35. საჯარო რეესტრი
საჯარო დაწესებულება ვალდებულია შეიტანოს ამ დაწესებულებაში არსებული საჯარო ინფორმაცია საჯარო რეესტრში. საჯარო რეესტრში შეტანილი უნდა იქნეს საჯარო ინფორმაციაზე მითითება მისი მიღებიდან, შექმნიდან, დამუშავებიდან ან გამოცემიდან 2 დღის ვადაში საჯარო ინფორმაციის დასახელების, მიღების თარიღის, იმ ფიზიკური ან იურიდიული პირის, საჯარო მოხელის, საჯარო დაწესებულების დასახელების მითითებით, რომლისგანაც შემოვიდა ან რომელსაც გაეგზავნა ეს ინფორმაცია.
