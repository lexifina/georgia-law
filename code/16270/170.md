# მუხლი 170. სხვა პირისათვის ადმინისტრაციული აქტის აღსრულების დავალება
1. თუ შესაძლებელია სხვა პირის მიერ ადმინისტრაციული აქტის აღსრულება, ადმინისტრაციული ორგანო უფლებამოსილია ამ კოდექსით დადგენილი წესის მიხედვით სხვა პირს დაავალოს აღსრულება.
2. პირს, რომელსაც დაევალება ადმინისტრაციული აქტის აღსრულება, აღსრულებასთან დაკავშირებულ ხარჯებს აუნაზღაურებს ეს ადმინისტრაციული ორგანო. ადმინისტრაციული ორგანო ამ ხარჯებს კანონმდებლობის შესაბამისად აინაზღაურებს შესაბამისი ფიზიკური ან იურიდიული პირისაგან.
