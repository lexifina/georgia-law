# მუხლი 170. სხვა პირისათვის ადმინისტრაციული აქტის აღსრულების დავალება
1. თუ შესაძლებელია სხვა პირის მიერ ადმინისტრაციული აქტის აღსრულება, ადმინისტრაციული ორგანო უფლებამოსილია ამ კოდექსით და სხვა საკანონმდებლო აქტებით დადგენილი წესის მიხედვით სხვა პირს დაავალოს აღსრულება.
2. ადმინისტრაციული ორგანო ადმინისტრაციული აქტის აღსრულებასთან დაკავშირებულ ხარჯებს აინაზღაურებს შესაბამისი ფიზიკური ან იურიდიული პირისაგან.
