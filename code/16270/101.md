# მუხლი 101. განმცხადებლის მიერ საკუთარი მოსაზრების წარდგენა ადმინისტრაციული აქტის გამოცემაზე უარის თქმის შემთხვევაში
1. განცხადების დაკმაყოფილებაზე უარის თქმის შესახებ ადმინისტრაციული აქტის გამოცემამდე ადმინისტრაციული ორგანო ვალდებულია მისცეს განმცხადებელს განცხადების უარმყოფელ გარემოებათა შესახებ საკუთარი აზრის წარდგენის შესაძლებლობა, თუ:
ა) უარი ეფუძნება ინფორმაციას განმცხადებლის შესახებ;
ბ) ინფორმაცია, რომელსაც ეფუძნება უარი, განსხვავდება განმცხადებლის მიერ წარდგენილი ინფორმაციისაგან.
2. თუ კანონით ან მის საფუძველზე გამოცემული აქტით სხვა ვადა არ არის დადგენილი, განმცხადებელმა ამ მუხლის პირველ ნაწილში აღნიშნულ გარემოებებთან დაკავშირებით საკუთარი მოსაზრება უნდა წარადგინოს 5 დღის ვადაში.
3. ამ მუხლის პირველი ნაწილის მოთხოვნა არ გამოიყენება, თუ განმცხადებელს უკვე წარდგენილი აქვს საკუთარი მოსაზრება აღნიშნულ გარემოებასთან დაკავშირებით, აგრეთვე გადაუდებელ შემთხვევებში, როდესაც ადმინისტრაციული აქტის გამოცემის დაყოვნებამ შეიძლება არსებითი ზიანი მიაყენოს საჯარო ინტერესს. ასეთ შემთხვევაში ადმინისტრაციული ორგანო ვალდებულია მიუთითოს, თუ რა გადაუდებელი გარემოება არსებობს.
