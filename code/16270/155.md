# მუხლი 155. საჩივრის განხილვა შემსყიდველი ორგანიზაციის მიერ
1. საჯარო შესყიდვის ხელშეკრულების ძალაში შესვლამდე წარდგენილ საჩივარს განიხილავს შემსყიდველი ორგანიზაციის ხელმძღვანელი თანამდებობის პირი.
2. შემსყიდველი ორგანიზაციის ხელმძღვანელი თანამდებობის პირი საჩივართან დაკავშირებით გადაწყვეტილებას იღებს 10 დღის ვადაში.
3. თუ ამ მუხლის მე-2 ნაწილში მითითებულ ვადაში საჩივართან დაკავშირებით გადაწყვეტილება არ იქნა მიღებული, პირი უფლებამოსილია საჩივარი წარადგინოს ზემდგომ ორგანოში ან სარჩელი შეიტანოს სასამართლოში.
