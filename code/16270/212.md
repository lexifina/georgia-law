# მუხლი 212. ნორმატიული ადმინისტრაციულ-სამართლებრივი აქტის მომზადება
1. თუ კანონით ან მის საფუძველზე გამოცემული კანონქვემდებარე აქტით სხვა რამ არ არის დადგენილი, ნორმატიული ადმინისტრაციულ-სამართლებრივი აქტის პროექტს ამზადებს ის ადმინისტრაციული ორგანო, რომელიც უფლებამოსილია გამოსცეს იგი.
2. საკუთარ უფლებამოსილებათა ფარგლებში ადმინისტრაციულ ორგანოს უფლება აქვს ნორმატიული ადმინისტრაციულ-სამართლებრივი აქტის მომზადება დაავალოს ქვემდგომ ადმინისტრაციულ ორგანოს, აგრეთვე კანონმდებლობით გათვალისწინებულ შემთხვევებში სხვა ფიზიკურ ან იურიდიულ პირს ხელშეკრულების საფუძველზე.
3. სხვა ადმინისტრაციული ორგანოსათვის ნორმატიული ადმინისტრაციულ-სამართლებრივი აქტის მომზადების დავალების შესახებ გადაწყვეტილების გამოტანამდე აუცილებელია ამ უკანასკნელის წერილობითი თანხმობა.
