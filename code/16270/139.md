# მუხლი 139. ცვლილება სატენდერო დოკუმენტაციაში
1. შემსყიდველი ორგანიზაცია უფლებამოსილია სატენდერო წინადადებების წარდგენამდე ცვლილებები შეიტანოს სატენდერო დოკუმენტაციაში. ამ შემთხვევაში შემსყიდველ ორგანიზაციას შესაბამისად გადააქვს სატენდერო წინადადებების წარდგენის საბოლოო თარიღი.
2. ცვლილება უნდა გამოქვეყნდეს ტენდერის გამოცხადების შესახებ განცხადების მსგავსი წესით.
