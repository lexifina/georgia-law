# მუხლი 163. ადმინისტრაციული აქტის აღსრულების წესი
1. აღსრულებაზე პასუხისმგებელი ადმინისტრაციული ორგანო (თანამდებობის პირი) ვალდებულია განახორციელოს მისთვის კანონით მინიჭებული უფლებამოსილება მხოლოდ იმ ფარგლებში, რომლებიც აუცილებელია ადმინისტრაციული აქტის აღსრულების უზრუნველსაყოფად.
2. აღსრულებაზე პასუხისმგებელი ადმინისტრაციული ორგანოს (თანამდებობის პირის) უფლებამოსილება შეიძლება შეიზღუდოს ზემდგომი ადმინისტრაციული ორგანოს (თანამდებობის პირის) ადმინისტრაციული აქტით.
