# მუხლი 148. საჯარო შესყიდვის ხელშეკრულების დადების შესახებ ცნობის გამოქვეყნება
1. შემსყიდველი ორგანიზაცია ვალდებულია გამოაქვეყნოს ცნობა საჯარო შესყიდვის ხელშეკრულების დადების, შესყიდვის ობიექტის, ხელშეკრულების ფასის და ხელშეკრულების მონაწილეთა შესახებ.
2. ამ მუხლის პირველ ნაწილში აღნიშნული წესი არ ვრცელდება იმ საჯარო შესყიდვის ხელშეკრულებაზე, რომლის ფასი არ აღემატება 2000 ლარს.
