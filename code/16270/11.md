# მუხლი 11. კონფიდენციალობა
1. ადმინისტრაციული ორგანოს თანამდებობის პირს უფლება არა აქვს გაამჟღავნოს ან არასამსახურებრივი მიზნებისათვის გამოიყენოს ადმინისტრაციული წარმოების დროს მიღებული საიდუმლო ან კონფიდენციალური ინფორმაცია. ეს არ შეიძლება გახდეს ამ კოდექსის მე-10 მუხლში გათვალისწინებული მოვალეობის შესრულებაზე უარის თქმის საფუძველი.
2. სამსახურებრივი უფლებამოსილების განხორციელებისას მიღებული ინფორმაციის კონფიდენციალობის დაცვის წესს ადგენს კანონი.
