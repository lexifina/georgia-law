# მუხლი 91. წარმომადგენლის ხარჯების ანაზღაურება
1. ადმინისტრაციული ორგანოს მიერ დანიშნულ წარმომადგენელს უფლება აქვს მოსთხოვოს ადმინისტრაციულ ორგანოს გასამრჯელო და ადმინისტრაციულ წარმოებასთან დაკავშირებული ყველა დანახარჯის ანაზღაურება.
2. ყოველი მხარე თვითონ ანაზღაურებს მის მიერ დანიშნული წარმომადგენლის ადმინისტრაციულ წარმოებასთან დაკავშირებით გაღებულ ხარჯებს.
