# მუხლი 178. ადმინიტრაციული საჩივრის განმხილველი უფლებამოსილი ადმინისტრაციული ორგანო
1. თუ კანონით ან მის საფუძველზე გამოცემული კანონქვემდებარე აქტით სხვა რამ არ არის დადგენილი, ადმინისტრაციულ საჩივარს განიხილავს და გადაწყვეტს ადმინისტრაციულ-სამართლებრივი აქტის გამომცემი ადმინისტრაციული ორგანო, თუ იქ არსებობს ადმინისტრაციულ-სამართლებრივი აქტის გამომცემი თანამდებობის პირი ან სტრუქტურული ქვედანაყოფის ზემდგომი თანამდებობის პირი.
2. ადმინისტრაციული ორგანოს ხელმძღვანელი თანამდებობის პირის მიერ გამოცემული ადმინისტრაციულ-სამართლებრივი აქტი გასაჩივრდება ზემდგომ ადმინისტრაციულ ორგანოში.
