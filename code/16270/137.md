# მუხლი 137. ტენდერის გამოცხადების შესახებ ცნობის გამოქვეყნება
1. ტენდერს საჯარო შესყიდვების განთავსებისათვის ატარებს შემსყიდველი ორგანიზაცია, რომელიც ამ მიზნით ქმნის სპეციალურ სატენდერო კომისიას.
2. თუ საჯარო შესყიდვის სავარაუდო ღირებულება აღემატება 50 000 ლარს, განცხადება ტენდერის გამოქვეყნების შესახებ ქვეყნდება "საქართველოს საკანონმდებლო მაცნეში".
