# მუხლი 164. უფლებამოსილი ადმინისტრაციული ორგანოს მოთხოვნის შესრულების სავალდებულოობა
1. ყველა ვალდებულია შეასრულოს ინდივიდუალური ადმინისტრაციულ-სამართლებრივი აქტის აღსრულებასთან დაკავშირებით უფლებამოსილი ადმინისტრაციული ორგანოს (თანამდებობის პირის) კანონიერი მოთხოვნა.
2. თუ კანონით ან მის საფუძველზე გამოცემული კანონქვემდებარე აქტით სხვა რამ არ არის დადგენილი, პირი უფლებამოსილია უარი განაცხადოს აღსრულებასთან დაკავშირებული მოთხოვნის შესრულებაზე, თუ ეს ეწინააღმდეგება მისთვის კანონით დაკისრებულ ვალდებულებას ან გამოიწვევს სახელმწიფო, კომერციული, პროფესიული ან პირადი საიდუმლოების გამჟღავნებას, რომლის დაცვის ვალდებულებაც კანონით მას აკისრია.
