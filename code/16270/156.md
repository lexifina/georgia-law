# მუხლი 156. საჩივრის განხილვის წესი
1. საჯარო შესყიდვასთან დაკავშირებით საჩივრის წარდგენიდან 3 დღის განმავლობაში საჩივრის განმხილველი შესაბამისი თანამდებობის პირი აცნობებს ყველა დაინტერესებულ მხარეს და სახელმწიფო (ადგილობრივი თვითმმართველობისა და მმართველობის) ორგანოს საჩივრის არსებობას და მის შინაარსს.
2. დაინტერესებული მხარე, რომლის უფლებებსა და კანონიერ ინტერესებსაც ეხება საჩივარი, უფლებამოსილია მონაწილეობა მიიღოს საჩივრის განხილვასთან დაკავშირებულ ადმინისტრაციულ წარმოებაში.
