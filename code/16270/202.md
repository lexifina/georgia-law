# მუხლი 202. ადმინისტრაციულ საჩივრთან დაკავშირებით ადმინისტრაციულ-სამართლებრივი აქტის გამოცემა
1. ადმინისტრაციული საჩივრის განხილვის თაობაზე ადმინისტრაციული ორგანოს მიერ მიღებული გადაწყვეტილება წარმოადგენს ადმინისტრაციულ აქტს და იგი უნდა აკმაყოფილებდეს ადმინისტრაციული აქტისათვის ამ კოდექსით დადგენილ მოთხოვნებს.
2. ადმინისტრაციული ორგანო ვალდებულია ადმინისტრაციულ საჩივართან დაკავშირებით გამოცემულ ადმინისტრაციულ აქტში მიუთითოს ის ორგანო, რომელშიც შეიძლება ადმინისტრაციულ-სამართლებრივი აქტის გასაჩივრება, მისი მისამართი და საჩივრის წარდგენის ვადა.
