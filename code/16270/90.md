# მუხლი 90. წარმომადგენლის დანიშვნა ადმინისტრაციული ორგანოს ინიციატივით
1. ადმინისტრაციული ორგანო ვალდებულია მიმართოს სასამართლოს ადმინისტრაციულ წარმოებაში მონაწილე დაინტერესებული მხარისათვის წარმომადგენლის დანიშვნის მოთხოვნით, თუ წარმომადგენლის მონაწილეობა პროცესში სავალდებულოა და დაინტერესებულმა მხარემ ადმინისტრაციული ორგანოს მიერ დადგენილ ვადაში არ დანიშნა იგი.
2. თუ ამ კოდექსის 89-ე მუხლის პირველ ნაწილში გათვალისწინებული პირები არ დანიშნავენ წარმომადგენელს ადმინისტრაციული ორგანოს მიერ დადგენილ ვადაში, მათ წარმომადგენლად ჩაითვლება განცხადებაზე პირველი ხელმომწერი პირი.
