# მუხლი 44. პერსონალური მონაცემების საიდუმლოება
საჯარო დაწესებულება ვალდებულია არ გაახმაუროს პირის პერსონალური მონაცემები თვით ამ პირის თანხმობის გარეშე, გარდა კანონით გათვალისწინებული შემთხვევებისა, როდესაც ეს აუცილებელია სახელმწიფო ან საზოგადოებრივი უსაფრთხოების უზრუნველსაყოფად, საჯარო ინტერესების, ჯანმრთელობის ან სხვათა უფლებების დასაცავად. თანამდებობის პირის, აგრეთვე თანამდებობაზე წარდგენილი კანდიდატის პერსონალური მონაცემები საჯაროა.
- საქართველოს 2001 წლის 2 მარტის კანონი №772 - სსმ I, №6, 20.03.2001წ., მუხ.8
- საქართველოს 2012 წლის 25 მაისის კანონი №6327 - ვებგვერდი, 12.06.2012წ.
- საქართველოს 2018 წლის 29 ივნისის კანონი №2767 - ვებგვერდი, 19.07.2018წ.
