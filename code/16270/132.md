# მუხლი 132. საჯარო შესყიდვის პროცედურის შეწყვეტა
1. შემსყიდველი ორგანიზაცია უფლებამოსილია შეწყვიტოს საჯარო შესყიდვის პროცედურა, თუ ასეთი გადაწყვეტილება გამომდინარეობს ობიექტური აუცილებლობიდან ან საზოგადოებრივი ინტერესებიდან.
2. შემსყიდველი ორგანიზაცია ვალდებულია ერთი დღის ვადაში აცნობოს თავისი გადაწყვეტილების და მისი გამომწვევი მიზეზების შესახებ შესყიდვის პროცედურაში მონაწილე ყველა პრეტენდენტს, მაგრამ ვალდებული არ არის წარუდგინოს პრეტენდენტებს რაიმე კონკრეტული მტკიცებულებანი ან დეტალური ინფორმაცია, რომელთა საფუძველზედაც იყო მიღებული ასეთი გადაწყვეტილება და აუნაზღაუროს მათ პროცედურაში მონაწილეობასთან დაკავშირებული ხარჯები.
