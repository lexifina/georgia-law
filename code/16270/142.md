# მუხლი 142. სატენდერო წინადადების განმარტება
1. შემსყიდველი ორგანიზაცია უფლებამოსილია სატენდერო წინადადებასთან დაკავშირებით პრეტენდენტისაგან მოითხოვოს განმარტება.
2. განმარტება, რომელიც ცვლის სატენდერო წინადადების არსს ან ფასს, არ მიიღება.
3. პრეტენდენტის თანხმობით შემსყიდველი ორგანიზაცია უფლებამოსილია შეასწოროს სატენდერო წინადადებაში აღმოჩენილი ტექნიკური ან გამოთვლისას დაშვებული შეცდომა.
