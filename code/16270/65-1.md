# მუხლი 65¹. ადმინისტრაციული ორგანოს მიერ კერძოსამართლებრივი ხელშეკრულების დადების უფლებამოსილება
1. კერძოსამართლებრივ ურთიერთობებში ადმინისტრაციული ორგანო მოქმედებს, როგორც სამოქალაქო სამართლის სუბიექტი.
