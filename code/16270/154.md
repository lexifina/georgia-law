# მუხლი 154. შემსყიდველი ორგანიზაციის გადაწყვეტილების გასაჩივრება
1. პრეტენდენტს და მიმწოდებელს, აგრეთვე ყველა დაინტერესებულ მხარეს უფლება აქვს გაასაჩივროს შემსყიდველი ორგანიზაციის ნებისმიერი გადაწყვეტილება მისი მიღებიდან 20 დღის ვადაში ან იმ დღიდან, როდესაც მათთვის ცნობილი გახდა მათი უფლებების ან კანონიერი ინტერესების შემლახველი გარემოებების შესახებ.
2. საჩივარი ამ მუხლის პირველ ნაწილში აღნიშნული ვადის გასვლის შემდეგ შეიძლება წარდგენილ იქნეს მხოლოდ საპატიო მიზეზის არსებობისას.
3. საჩივარი წარდგენილ უნდა იქნეს წერილობით.
