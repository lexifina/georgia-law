# მუხლი 119. ადმინისტრაციული აქტის პროექტის მომზადება და საჯარო გაცნობისათვის წარდგენა
თუ კანონით ან მის საფუძველზე გამოცემული კანონქვემდებარე აქტით სხვა ვადა არ არის დადგენილი, ადმინისტრაციული ორგანო ვალდებულია განცხადების რეგისტრაციდან ერთი თვის განმავლობაში მოამზადოს ადმინისტრაციული აქტის პროექტი.
