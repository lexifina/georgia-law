# მუხლი 58. ადმინისტრაციული აქტის ოფიციალური გაცნობის წესი
1. თუ კანონით სხვა რამ არ არის დადგენილი, დაინტერესებული მხარისათვის ადმინისტრაციული აქტის ოფიციალური გაცნობა ნიშნავს მისთვის ადმინისტრაციული აქტის გადაცემას ან ფოსტის მეშვეობით გაგზავნას.
2. ფოსტის მეშვეობით გაგზავნილი ადმინისტრაციული აქტის მიუღებლობის შემთხვევაში პირს უფლება აქვს მისი ასლი მიიღოს ადმინისტრაციულ ორგანოში. ადმინისტრაციული აქტის ასლის გაცემისათვის რაიმე გადასახდელი არ გადაიხდება.
