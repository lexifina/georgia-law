# მუხლი 145. სატენდერო წინადადების შეფასება
1. შემსყიდველი ორგანიზაცია ტენდერში გამარჯვებულის გამოსავლენად სატენდერო წინადადებას აფასებს სატენდერო დოკუმენტაციაში მოცემული კრიტერიუმებისა და წესის შესაბამისად.
2. დაუშვებელია სატენდერო დოკუმენტაციაში აღნიშნულის გარდა სატენდერო წინადადების სხვა კრიტერიუმებით ან წესით შეფასება.
