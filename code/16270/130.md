# მუხლი 130. საჯარო შესყიდვის პროცედურაში მონაწილეობის მიღების უფლება
1. პრეტენდენტი და მიმწოდებელი საჯარო შესყიდვის პროცედურაში მონაწილეობის მისაღებად უნდა აკმაყოფილებდნენ შემსყიდველი ორგანოს მიერ ამ კოდექსით დადგენილი წესით წაყენებულ მოთხოვნებს.
2. საჯარო შესყიდვის პროცედურაში მონაწილეობის მიღების უფლება აქვს მხოლოდ იმ პრეტენდენტს, რომელმაც ამ კოდექსით დადგენილი წესით წარადგინა წინადადება ან განცხადება საჯარო შესყიდვის პროცედურაში მონაწილეობის მიღების შესახებ.
3. შემსყიდველი ორგანიზაცია ვალდებულია აცნობოს პრეტენდენტს, რომელსაც უარი ეთქვა საჯარო შესყიდვის პროცედურაში მონაწილეობაზე, უარის თქმის საფუძველი.
