# მუხლი 231. გადახდილი თანხების შესახებ ინფორმაციის წარდგენა
პირი, რომელიც ახორციელებს შესრულებული სამუშაოს ან გაწეული მომსახურების ანაზღაურებას, ან სხვა სახის გაცემებს, ვალდებულია საგადასახადო ორგანოსა და თანხის მიმღებს წარუდგინოს ინფორმაცია გადახდილი თანხების შესახებ შესაბამისი ინსტრუქციის თანახმად.
