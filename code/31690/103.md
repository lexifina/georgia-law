# მუხლი 103. საერთაშორისო და სატრანზიტო გადაზიდვების დაბეგვრა
1. საქონლის საერთაშორისო გადაზიდვებთან ან მგზავრთა საერთაშორისო გადაყვანასთან უშუალოდ დაკავშირებული სატრანსპორტო და სხვა მომსახურების გაწევა ან სამუშაოს შესრულება, ისევე როგორც საავიაციო საწვავი, საპოხი და სხვა დამხმარე საშუალებების ბორტზე მიწოდება საერთაშორისო ფრენის განსახორციელებლად, იბეგრება ნულოვანი განაკვეთით.
2. 101-ე მუხლის პირველი ნაწილის " ჭ" პუნქტში აღნიშნული ტრანზიტული საქონლის ტრანსპორტირება და მომსახურება იბეგრება ნულოვანი განაკვეთით.
