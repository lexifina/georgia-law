# მუხლი 273. გარდამავალი დებულებები
1. საგადასახადო კოდექსის 54-ე მუხლით გათვალისწინებული ძირითადი საშუალებების ღირებულებითი ბალანსი 1998 წლის 1 იანვრისათვის განისაზღვროს 1997 წლის ბოლოსათვის ამ საშუალებების ნარჩენი ღირებულებით.
2. 2000 წლის 31 დეკემბრამდე მსუბუქი ავტომობილების იმპორტის დროს იმპორტიორის გადასახდელ გადასახადად განისაზღვროს:
ა. აქციზი - 0,1 ლარის ოდენობით იმპორტული ავტომობილის ძრავის მოცულობის ყოველ კუბურ სანტიმეტრზე.
ბ. დამატებული ღირებულების გადასახადი - 5%-ის ოდენობით.
3. ელექტროენერგეტიკული სექტორის საწარმოებისათვის, 2000 წლის 1 იანვრამდე პროდუქციის (სამუშაოების, მომსახურების) მიწოდების მოცულობა განისაზღვროს ფაქტობრივად ანაზღაურებული ღირებულების მიხედვით.
4. აღმასრულებელმა ხელისუფლებამ საგადასახადო კოდექსს შეუსაბამოს გადასახადებთან დაკავშირებული კანონქვემდებარე აქტები.
5. საქართველოს პარლამენტის საფინანსო-საბიუჯეტო კომიტეტმა შეიმუშაოს და პარლამენტს განსახილველად წარუდგინოს კანონპროექტი საგადასახადო ორგანოების მიერ ქონებაზე ყადაღის დადების სამართლებრივი მექანიზმის თაობაზე.
