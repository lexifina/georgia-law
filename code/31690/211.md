# მუხლი 211. საკურორტო გადასახადი
1. საკურორტო გადასახადს იხდიან ფიზიკური პირები საკურორტო ადგილებში დასვენებისა (მკურნალობისა) და საკურორტო მომსახურების მიღებისათვის.
