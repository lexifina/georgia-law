# მუხლი 184. სოციალური გადასახადი
სოციალური გადასახადი წარმოადგენს სოციალური უზრუნველყოფის ერთიანი სახელმწიფო ფონდის ფორმირებისა და დასაქმების ხელშეწყობის სახელმწიფო პროგრამების ფინანსური უზრუნველყოფისათვის აუცილებელ მიზნობრივ შენატანს, რომელსაც გადასახადის გადამხდელები ამ კარში დადგენილი განაკვეთების შესაბამისად იხდიან შრომის ანაზღაურებისა და მასთან გათანაბრებულ გაცემულობათა თანხებზე, აგრეთვე ფიზიკური პირების მიერ ეკონომიკური საქმიანობიდან მიღებულ შემოსავალზე.
- საქართველოს 1998 წლის 30 ოქტომბრის კანონი №1666-სსმI,№4, 20.11.1998წ.,მუხ.34
