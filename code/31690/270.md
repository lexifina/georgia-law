# მუხლი 270. საგადასახადო სისტემის სრულყოფის მიზნით საქართველოს საგადასახადო შემოსავლების სამინისტროს სპეციალურ ანგარიშზე თანხების აკუმულირება და განაწილება
1. საქართველოს პრეზიდენტის ბრძანებულებით განსაზღვრული სახელმწიფო ორგანოების მატერიალური უზრუნველყოფისათვის საგადასახადო ორგანოების მიერ კონტროლირებადი შემოსავლების მიხედვით ბიუჯეტებსა და სახელმწიფო სპეციალურ ფონდებში ფაქტობრივად ჩარიცხული თანხების 3 პროცენტი, აგრეთვე ბიუჯეტებისა და სპეციალური ფონდების სასარგებლოდ დამატებით დარიცხული და ჩარიცხული თანხების 10 პროცენტი ირიცხება ხაზინაში საქართველოს საგადასახადო შემოსავლების სამინისტროს სპეციალურ ანგარიშზე. ამ ანგარიშზე თანხების ჩარიცხვა ხდება ბიუჯეტებსა და სახელმწიფო სპეციალურ ფონდებში ჩარიცხული თანხების პროპორციულად საბანკო დაწესებულებების მიერ.
