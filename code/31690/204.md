# მუხლი 204. დაბეგვრის ობიექტი
1. გადასახადით დაბეგვრის ობიექტია:
ა. საქართველოს ტერიტორიაზე შემოსული უცხო ქვეყანაში რეგისტრირებული ავტოსატრანსპორტო საშუალება;
ბ. საქართველოში რეგისტრირებული ავტოსატრანსპორტო საშუალება, რომელიც საქართველოს ტერიტორიაზე ახორციელებს სატრანზიტო ტვირთზიდვას.
2. ამ კარის მიხედვით, ავტოსატრანსპორტო საშუალებებში იგულისხმება ნებისმიერი ავტოსატრანსპორტო საშუალება, რომელიც მითითებულია საგარეო ეკონომიკური საქმიანობის სასაქონლო ნომენკლატურის 87-ე თავში (8702-8704 კოდით).
