# მუხლი 270¹. საგადასახადო ორგანოებში სამსახურის გავლის წესი
1. საგადასახადო ორგანოებში უფლებამოსილ თანამდებობის პირებად როგორც წესი, შეიძლება დაინიშნონ უმაღლესი ეკონომიკური ან იურიდიული განათლების მქონე პირები. აგრეთვე სპეციალობით პრაქტიკული მუშაობის არანაკლებ 5 წლის სტაჟის მქონე საშუალო-სპეციალური ეკონომიკური განათლების მქონე პირები.
2. საგადასახადო ორგანოებში თანამდებობებზე ინიშნებიან კონკურსისა (ტესტირების) საფუძველზე, მოქმედი კანონმდებლობის შესაბამისად.
