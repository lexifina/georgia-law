# მუხლი 252 1 . საურავის დარიცხვა გაკოტრების ან რეაბილიტაციის რეჟიმში მყოფი საწარმოს ვადაგადაცილებულ საგადასახადო დავალიანებებზე
1. გაკოტრების საქმის წარმოების გახსნის, რეაბილიტაციის ან საგაკოტრებო მორიგების დამტკიცების შესახებ განჩინების კანონიერ ძალაში შესვლიდან შესაბამისი რეჟიმის დასრულებამდე გაკოტრების ან რეაბილიტაციის რეჟიმში მყოფ საწარმოს ვადაგადაცილებულ საგადასახადო დავალიანებებზე საურავი არ დაერიცხება.
2. ამ კანონის ამოქმედებისას გაკოტრების ან რეაბილიტაციის რეჟიმში მყოფ საწარმოზე ამ მუხლის პირველი ნაწილის მოქმედება ვრცელდება რეჟიმის მთელ პერიოდზე, მისი დასაწყისიდან დასრულებამდე.
