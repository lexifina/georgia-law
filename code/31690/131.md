# მუხლი 131. აქციზის გადახდა
1. აქციზური საქონლის მიწოდებისას საანგარიშო თვეში განხორციელებული დასაბეგრი ოპერაციების მიხედვით გამოანგარიშებული აქციზი გადახდას ექვემდებარება საანგარიშო პერიოდში არა უგვიანეს 10 დღის განმავლობაში, ამ კოდექსის 126-ე მუხლის მიხედვით დასაბეგრი ოპერაციის განხორციელების მომენტიდან.
2. თუ გადასახადის გადამხდელს დროის რომელიმე პერიოდისათვის აქვს აქციზის ვადაგადაცილებული დავალიანება, მაშინ ამ დავალიანების წარმოქმნის მომენტიდან მისი დაფარვის მომენტამდე მას ეკრძალება საქონლის მიწოდება მასზე აქციზის გადაუხდელად.
3. საქონლის იმპორტისას აქციზის გადახდევინება ხორციელდება საბაჟო ორგანოების მიერ საბაჟო გადასახადისათვის მიღებული პროცედურების შესაბამისად.
