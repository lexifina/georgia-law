# მუხლი 232. საგადასახადო დეკლარაციის წარდგენის ვადის გაგრძელება
თუ გადასახადის გადამხდელი დეკლარაციის წარდგენის ვადის გასვლამდე მიმართავს საგადასახადო ორგანოს ვადის გაგრძელების თაობაზე და მიმართვასთან ერთად გადაიხდის იმ დროისათვის მოსალოდნელ გადასახადსაც, დეკლარაციის წარდგენის ვადა ავტომატურად გაგრძელდება სამი თვით. ამ მუხლის მიხედვით დეკლარაციის წარდგენის ვადის გაგრძელება არ ცვლის გადასახადის გადახდის დროს.
