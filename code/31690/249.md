# მუხლი 249. ქონების მიმღების პასუხისმგებლობა გადასახადის გადახდისათვის
თუ გადასახადის გადამხდელმა არ შეასრულა თავისი საგადასახადო ვალდებულებები, პირი, რომელიც იღებს ასეთი გადასახადის გადამხდელის ქონებას, წარმოადგენს მეორე ვალდებულ პირს ამ გადასახადთან მიმართებით, მის მიერ მიღებული ქონებისა და გადამცემი პირის მიერ გადაუხდელი თანხის ფარგლებში.
