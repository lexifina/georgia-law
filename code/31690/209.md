# მუხლი 209. გადასახადი ეკონომიკური საქმიანობისათვის
1. ეკონომიკური საქმიანობისათვის გადასახადს იხდიან პირები, რომლებიც შესაბამისი ქალაქის (რაიონის) ტერიტორიაზე ეწევიან ეკონომიკურ საქმიანობას, გარდა საგანმანათლებლო დაწესებულებებისა მათ მიერ გაწეული განათლების მომსახურების ნაწილში და სამედიცინო დაწესებულებებისა მათ მიერ გაწეული სამედიცინო მომსახურების ნაწილში.
2. ეკონომიკური საქმიანობისათვის გადასახადის განაკვეთის ზღვრული ოდენობა განისაზღვრება პროდუქციის (სამუშაოს, მომსახურების) მიწოდებით მიღებული შემოსავლების (დღგ-ისა და მატერიალური დანახარჯების გარეშე) არა უმეტეს 1 პროცენტით, მათ შორის, საქართველოს ნავსადგურებსა და მათთან გათანაბრებულ ნავმისადგომებზე ტვირთების გემებში ჩატვირთვაზე და გემებიდან გადმოტვირთვაზე მომსახურების გაწევით მიღებული შემოსავლების (დღგ-ის გარეშე) არა უმეტეს 2 პროცენტით.
