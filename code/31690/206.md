# მუხლი 206. გადასახადის გადახდის წესი
1. გადასახადი გადაიხდება სახელმწიფო საგზაო ფონდში ავტოსატრანსპორტო საშუალებების მიერ საქართველოს საზღვრის გადაკვეთისას ან საბაჟო ტერიტორიის დატოვებისას.
2. გადასახადის გადახდის დამადასტურებელი დოკუმენტის გარეშე საქართველოს ტერიტორიაზე ავტოსატრანსპორტო საშუალებათა მოძრაობა არ დაიშვება.
3. გადასახადის აკრეფას, ავტოსატრანსპორტო საშუალებების წონითი და გაბარიტული პარამეტრების შემოწმებას, მძიმეწონიანი და მსხვილგაბარიტიანი ავტოსატრანსპორტო საშუალებების საქართველოს საავტომობილო გზებზე გატარების მარშრუტებს ადგენს საგზაო დარგის მართვის ორგანოს მიერ შექმნილი სამსახური საბაჟო დეპარტამენტთან შეთანხმებით განსაზღვრულ ადგილებში.
