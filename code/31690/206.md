# მუხლი 206. გადასახადის გადახდის წესი
1. საქართველოს ტერიტორიაზე ავტოსატრანსპორტო საშუალებების შემოსვლისათვის და ზენორმატიული დატვირთვისათვის, გადასახადი გადაიხდება საქართველოს სახელმწიფო საგზაო ფონდში ავტოსატრანსპორტო საშუალების მიერ საქართველოს საზღვრის გადაკვეთისას, ხოლო გადასახადი ზენორმატიული დატვირთვისათვის იმავე ფონდში, საქართველოს საავტომობილო გზების სახელმწიფო დეპარტამენტის მიერ შერჩეულ ადგილებში .
2. გადასახადის გადახდის დამადასტურებელი დოკუმენტის გარეშე საქართველოს ტერიტორიაზე ავტოსატრანსპორტო საშუალებათა მოძრაობა არ დაიშვება.
3. საქართველოს ტერიტორიაზე ავტოსატრანსპორტო საშუალებების შემოსვლისათვის და ზენორმატიული დატვირთვისათვის გადასახადის აკრეფას, აგრეთვე ავტოსატრანსპორტო საშუალებების წონითი და გაბარიტული პარამეტრების შემოწმებას ახორციელებს:
ა. საქართველოს საბაჟო ორგანო - საქართველოს საზღვრის გადაკვეთისას;
ბ. საქართველოს საავტომობილო გზების სახელმწიფო დეპარტამენტი - საქართველოს საზღვრის შიგნით გადაადგილებისას.
