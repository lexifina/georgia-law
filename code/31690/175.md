# მუხლი 175. გადასახადის გადახდის წესი
1. გადასახადის გადამხდელი გადასახადს იხდის დამოუკიდებლად საგადასახადო ორგანოს მიერ წერილობითი შეტყობინების გარეშე.
2. გადასახადის გადამხდელი ქონების მემკვიდრეობით მიღებისას გადასახადს იხდის მემკვიდრეობის უფლების შესახებ დამადასტურებელი დოკუმენტების გაცემის დღიდან არა უგვიანეს ექვსი თვისა, ხოლო ჩუქებით ქონების მიღებისას - ჩუქების შესახებ ხელშეკრულების გაფორმებიდან არა უგვიანეს ერთი თვისა.
3. გადასახადის გადამხდელი ვალდებულია ამ მუხლის მე-2 ნაწილით დადგენილ ვადებში საგადასახადო ორგანოში წარადგინოს დეკლარაცია.
