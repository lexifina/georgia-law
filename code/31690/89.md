# მუხლი 89. გადასახადის მიმდინარე გადასახდელები
1. ფიზიკური და იურიდიული პირები, რომლებიც ეწევიან სამეწარმეო საქმიანობას, ვალდებულნი არიან შეიტანონ ბიუჯეტში მიმდინარე გადასახდელების თანხები ყოველკვარტალურად არა უგვიანეს გასული კვარტალის მომდევნო თვის თხუთმეტი რიცხვისა, წინა საგადასახადო წლის წლიური გადასახადიდან 25 პროცენტის ოდენობით.
2. მიმდინარე გადასახდელთა ბიუჯეტში ჩარიცხული თანხები გადასახადის გადამხდელს ჩაეთვლება საგადასახადო წლის მიხედვით დარიცხულ გადასახადში.
