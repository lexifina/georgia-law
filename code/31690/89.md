# მუხლი 89. გადასახადის მიმდინარე გადასახდელები
1. ფიზიკური და იურიდიული პირები, რომლებიც ეწევიან სამეწარმეო საქმიანობას, ვალდებულნი არიან შეიტანონ ბიუჯეტში მიმდინარე გადასახდელების თანხები ყოველკვარტალურად არა უგვიანეს კვარტალის მეორე თვის, თხუთმეტი რიცხვისა, წინა საგადასახადო წლის წლიური გადასახადიდან 25 პროცენტის ოდენობით. პირებს, რომლებსაც წინა საგადასახადო წელს არ ჰქონდათ დასაბეგრი შემოსავალი, მიმდინარე გადასახდელებს იხდიან საანგარიშო წლის გასული კვარტალის ფაქტობრივი შემოსავლებიდან გამომდინარე.
2. მიმდინარე გადასახდელთა ბიუჯეტში ჩარიცხული თანხები გადასახადის გადამხდელს ჩაეთვლება საგადასახადო წლის მიხედვით დარიცხულ გადასახადში.
საქართველოს 1997 წლის 18 სექტემბრის კანონი №870-პარლამენტის უწყებანი, №41,08.10.1997წ.,
