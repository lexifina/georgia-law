# მუხლი 119. დღგ-ის ანაზღაურება გრანტის შემთხვევებში
1. პირს, რომელიც ყიდულობს გრანტით დაფინანსებულ საქონელს ან/და ამავე საწყისებზე იღებს სამუშაოს ან მომსახურებას, უფლება აქვს აინაზღაუროს ამ საქონლისათვის, სამუშაოსა თუ მომსახურებისათვის გადახდილი დღგ საგადასახადო ორგანოში საგადასახადო ანგარიშ-ფაქტურის წარდგენის შემდეგ.
2. დღგ-ის ანაზღაურება ხდება მხოლოდ იმ შემთხვევაში, თუ განცხადება საგადასახადო ორგანოს წარედგინება დასაბეგრი ოპერაციის განხორციელების მომდევნო თვის ბოლომდე. ამ კოდექსის 118-ე მუხლის პირველი და მე-3 ნაწილების მოთხოვნები გამოიყენება ამ მუხლის მიმართაც.
