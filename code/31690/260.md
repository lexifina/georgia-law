# მუხლი 260. საქართველოს საგადასახადო ორგანოების სტატუსი, სტრუქტურა და უფლებამოსილებანი
საქართველოს საგადასახადო ორგანოები შედიან საქართველოს საგადასახადო შემოსავლების სამინისტროს სისტემაში. მათი სტატუსი, სტრუქტურა და უფლებამოსილებანი, აგრეთვე სპეციალური სამართალდამცავი ორგანოს სტატუსის მქონე იმ ოპერატიული დეპარტამენტის სტრუქტურა და უფლებამოსილებანი, რომელიც ახორციელებს მოკვლევასა და ოპერატიულ-სამძებრო ღონისძიებებს და უზრუნველყოფს საგადასახადო სფეროში სამართალდარღვევათა წინააღმდეგ ბრძოლას, საგადასახადო ორგანოების საქმიანობის უსაფრთხოებასა და მათი მუშაკების დაცვას სამსახურებრივ მოვალეობათა შესრულების დროს კანონსაწინააღმდეგო ხელყოფისაგან, განისაზღვრება ამ კოდექსით, "აღმასრულებელი ხელისუფლების სტრუქტურისა და საქმიანობის წესის შესახებ" საქართველოს კანონით, სხვა საკანონმდებლო აქტებითა და საქართველოს პრეზიდენტის ბრძანებულებით. მხოლოდ საგადასახადო ორგანოები არიან უფლებამოსილნი უზრუნველყონ გადასახადების სრულად და დროულად გადახდის სახელმწიფო კონტროლი, იმ შემთხვევების გარდა, როცა ამ კოდექსით გათვალისწინებულია გადასახადის აკრეფა სხვა ორგანოების მიერ.
