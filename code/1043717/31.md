# მუხლი 31. საბიუჯეტო ორგანიზაცია
საბიუჯეტო ორგანიზაციად ითვლება ბიუჯეტის დაფინანსებაზე მყოფი ორგანიზაცია, რომლისთვისაც ბიუჯეტით გათვალისწინებულია ასიგნება და რომელიც პასუხისმგებელია მისი მართვისთვის, ასევე ახორციელებს საკუთარი ბიუჯეტის პროექტის მომზადებას, ბიუჯეტის შესრულებასა და ანგარიშგებას დადგენილი ნორმების, პროცედურებისა და წესების შესაბამისად.
