# მუხლი 214¹. წინასწარი ინფორმაცია
საერთაშორისო საჰაერო გადაზიდვების განმახორციელებელი პირი ვალდებულია საგადასახადო ორგანოს წარუდგინოს წინასწარი ინფორმაცია საერთაშორისო საჰაერო გადაზიდვების განმახორციელებელი სატრანსპორტო საშუალების, ამ სატრანსპორტო საშუალებით გადასაადგილებელი საქონლის ან/და მგზავრების შესახებ საქართველოს ფინანსთა მინისტრის მიერ დადგენილი წესის შესაბამისად.
- საქართველოს 2017 წლის 30 ივნისის კანონი №1182 - ვებგვერდი, 13.07.2017წ.
