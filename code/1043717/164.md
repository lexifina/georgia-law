# მუხლი 164. საქონლის დროებით ი შემოტანა, დროებით ი შემოტანის თანხა და დრო
საქონლის დროებითი შემოტანა განისაზღვრება ამ კოდექსის მიხედვით, რომლის დროსაც:
ა) საქონლის დროებითი შემოტანის თანხა ტოლია დროებითი შემოტანის სასაქონლო დეკლარაციის რეგისტრაციის დღეს ამ საქონლის იმპორტში მოქცევის შემთხვევაში ამ კოდექსის 162-ე მუხლის პირველი ნაწილის "ა" ქვეპუნქტით განსაზღვრული იმპორტის თანხისა;
ბ) საქონლის დროებითი შემოტანა ხორციელდება მაშინ, როდესაც საქონელი საქართველოს საგადასახადო კანონმდებლობის მიხედვით იბეგრება ან, გათავისუფლებული რომ არ ყოფილიყო, დაიბეგრებოდა იმპორტის გადასახადით.
