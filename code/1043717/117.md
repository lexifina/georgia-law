# მუხლი 117. საქველმოქმედო ორგანიზაციებზე გაცემული თანხის გამოქვითვა
ერთობლივი შემოსავლიდან გამოიქვითება საწარმოს/მეწარმე ფიზიკური პირის მიერ საქველმოქმედო ორგანიზაციებზე გაცემული თანხა, მაგრამ არა უმეტეს ერთობლივი შემოსავლიდან ამ კოდექსით გათვალისწინებული გამოქვითვების (ამ მუხლით გათვალისწინებული გამოქვითვის გარეშე) შემდეგ დარჩენილი თანხის 10 პროცენტისა.
