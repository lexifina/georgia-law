# მუხლი 208. საქართველოს ეკონომიკური ტერიტორია
1. საქართველოს ეკონომიკური ტერიტორია შედგება საქართველოს სახმელეთო ტერიტორიისაგან, ტერიტორიული და შიდა წყლებისაგან და მათი საჰაერო სივრცისაგან. საქართველოს ეკონომიკური ტერიტორია აგრეთვე მოიცავს განსაკუთრებულ საზღვაო ეკონომიკურ ზონაში განლაგებული დანადგარების, ნაგებობებისა და ხელოვნური კუნძულების ტერიტორიებს, რომლებზედაც ვრცელდება საქართველოს განსაკუთრებული იურისდიქცია.
2. საქართველოს ეკონომიკური საზღვარი ემთხვევა საქართველოს სახელმწიფო საზღვარს.
