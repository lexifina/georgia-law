# მუხლი 191. დეკლარაციის წარდგენა
1. არა უგვიანეს საანგარიშო პერიოდის მომდევნო თვის 15 რიცხვისა აქციზური საქონლის მწარმოებელმა და ამ კოდექსის 182-ე მუხლის პირველი ნაწილის "დ" და "ე" ქვეპუნქტებით განსაზღვრულმა აქციზის გადამხდელმა ყოველი საანგარიშო პერიოდის მიხედვით უნდა წარადგინონ აქციზის დეკლარაცია განხორციელებული დასაბეგრი ოპერაციების აღნიშვნით.
2. აქციზის დეკლარაციის წარდგენის წესს და დეკლარაციის ფორმას განსაზღვრავს საქართველოს ფინანსთა მინისტრი.
