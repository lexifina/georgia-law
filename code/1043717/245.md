# მუხლი 245. საბანკო ანგარიშზე ოპერაციების შეჩერება
1. ამ კოდექსით გათვალისწინებულ შემთხვევებში საგადასახადო ორგანოს უფლება აქვს, შეზღუდოს პირის უფლება - განკარგოს თავის საბანკო ანგარიშზე არსებული ან ჩარიცხული ფულადი სახსრები, აგრეთვე გახსნას საბანკო ანგარიში იმავე ან სხვა საბანკო დაწესებულებაში.
2. პირის საბანკო ანგარიშზე არსებული ან ჩარიცხული ფულადი სახსრების განკარგვის უფლების შეზღუდვა არ ვრცელდება ამ პირის მიერ გადასახადისა და სანქციის თანხების გადახდის ვალდებულების შესრულებაზე.
3. გადასახადის გადამხდელის საბანკო ანგარიშზე ოპერაციების შეჩერების შესახებ საგადასახადო ორგანოს გადაწყვეტილება საბანკო დაწესებულებამ უპირობოდ უნდა შეასრულოს.
4. გადასახადის გადამხდელის საბანკო ანგარიშზე ოპერაციის შეჩერება მოქმედებს საბანკო დაწესებულების მიერ ასეთი ოპერაციის შეჩერების შესახებ გადაწყვეტილების მიღების მომენტიდან საბანკო ანგარიშზე ოპერაციების შეჩერების შესახებ საგადასახადო ორგანოს მიერ გადაწყვეტილების გაუქმებამდე.
5. გადასახადის გადამხდელის საბანკო ანგარიშზე ოპერაციის შეჩერების შესახებ საგადასახადო ორგანოს გადაწყვეტილებაში მიეთითება პირის საიდენტიფიკაციო ნომერი და თანხის ოდენობა.
