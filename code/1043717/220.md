# მუხლი 220. საქონლის გაშვება
1. თუ სასაქონლო დეკლარაციის შემოწმების შედეგად დადგინდა, რომ სრულადაა დაცული საქართველოს კანონმდებლობის მოთხოვნები, საქონელი დაუყოვნებლივ გაიშვება.
2. ერთი სასაქონლო დეკლარაციით დეკლარირებული საქონელი გაშვებული უნდა იქნეს ერთდროულად, გარდა გამონაკლისი შემთხვევისა, რომელზედაც გადაწყვეტილებას იღებს საგადასახადო ორგანო.
3. თუ ერთი სასაქონლო დეკლარაციით დეკლარირებულია სხვადასხვა სახეობის საქონელი, საქონლის თითოეული სახეობა ითვლება ცალ-ცალკე დეკლარირებულად.
4. საქონლის გაშვება არ გამორიცხავს სახელმწიფო კონტროლისა და სახელმწიფო ზედამხედველობის ვადის გაგრძელებას.
