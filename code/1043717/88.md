# მუხლი 88. მცირე ბიზნესი
1. მცირე ბიზნესის სტატუსი შეიძლება მიენიჭოს მეწარმე ფიზიკურ პირს.
2. საქართველოს პარლამენტის საფინანსო-საბიუჯეტო კომიტეტთან შეთანხმებით, საქართველოს მთავრობას უფლება აქვს, აკრძალოს ცალკეული საქმიანობის განხორციელება, რომლის ფარგლებშიც მცირე ბიზნესის სტატუსი არ შეიძლება მიენიჭოს მეწარმე ფიზიკურ პირს.
3. საქართველოს პარლამენტის საფინანსო-საბიუჯეტო კომიტეტთან შეთანხმებით, საქართველოს მთავრობას უფლება აქვს, განსაზღვროს შემოსავლის სახეები, რომლებიც არ დაიბეგრება სპეციალური რეჟიმით და არ გაითვალისწინება ერთობლივ შემოსავალში მცირე ბიზნესის სტატუსის მქონე ფიზიკური პირისთვის დადგენილი კალენდარული წლის განმავლობაში მიღებული ერთობლივი შემოსავლის 500 000-ლარიანი ზღვრის, ხოლო ღვინის ტურიზმის საქმიანობის სუბიექტისა და აგროტურისტული საქმიანობის სუბიექტის შემთხვევაში − 700 000-ლარიანი ზღვრის გაანგარიშებისას.
- საქართველოს 2018 წლის 30 მაისის კანონი №2391 - ვებგვერდი, 12.06.2018წ.
- საქართველოს 2023 წლის 13 დეკემბრის კანონი №3922 - ვებგვერდი, 27.12.2023წ.
