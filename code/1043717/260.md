# მუხლი 260. დათვალიერება
1. საგადასახადო ორგანოს უფლებამოსილ პირს უფლება აქვს, საგადასახადო კონტროლის განხორციელების მიზნით ჩაატაროს პირის ტერიტორიებისა და შენობა-ნაგებობების ვიზუალური დათვალიერება.
2. ფიზიკური პირის საცხოვრებელი ბინის დათვალიერება დასაშვებია მხოლოდ სასამართლოს გადაწყვეტილების საფუძველზე.
3. დათვალიერებისას აკრძალულია გადასახადის გადამხდელის დოკუმენტაციისა და სასაქონლო-მატერიალური ფასეულობების შემოწმება.
4. დათვალიერების პროცედურა არ მოიცავს სეიფის, კარადის, უჯრისა და სხვა მსგავსი სათავსის შიგთავსის ვიზუალურ დათვალიერებასა და შემოწმებას.
