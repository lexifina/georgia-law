# მუხლი 287. გადასახადის გადამხდელის მიერ ბრუნვის შემცირება
1. თუ მომსახურების გაწევის ობიექტზე ქრონომეტრაჟით გამოვლენილი უწყვეტი 7 კალენდარული დღის ჯამურ ბრუნვასა (მაქსიმალური და მინიმალური დღიური ბრუნვების გამოკლებით) და გადასახადის გადამხდელის მიერ დაფიქსირებულ ქრონომეტრაჟის დაწყების დღის წინა უწყვეტი 7 კალენდარული დღის ჯამურ ბრუნვას (მაქსიმალური და მინიმალური დღიური ბრუნვების გამოკლებით) შორის სხვაობა აღემატება საქართველოს მთავრობის მიერ დადგენილ ზღვრულ ოდენობას, რომელიც არ შეიძლება იყოს 10 პროცენტზე ნაკლები, -
იწვევს პირის დაჯარიმებას ქრონომეტრაჟით გამოვლენილი უწყვეტი 7 კალენდარული დღის ჯამურ ბრუნვასა (მაქსიმალური და მინიმალური დღიური ბრუნვების გამოკლებით) და გადასახადის გადამხდელის მიერ დაფიქსირებულ ქრონომეტრაჟის დაწყების დღის წინა უწყვეტი 7 კალენდარული დღის ჯამურ ბრუნვას (მაქსიმალური და მინიმალური დღიური ბრუნვების გამოკლებით) შორის სხვაობის ოცმაგი ოდენობით.
2. თუ ქრონომეტრაჟით გამოვლენილი უწყვეტი 7 კალენდარული დღის ჯამური ბრუნვა (მაქსიმალური და მინიმალური დღიური ბრუნვების გამოკლებით) შეადგენს არა უმეტეს 25 000 ლარს, ამ პირისათვის ამ მუხლის პირველი ნაწილით დაკისრებული სანქცია არ უნდა აღემატებოდეს 100 000 ლარს.
3. მომსახურების გაწევის ობიექტში ქრონომეტრაჟის მიმდინარეობისას პირის მიერ მომხმარებლისთვის მომსახურების გაწევაზე დაუსაბუთებელი უარი ან/და მომხმარებლის გადაწყვეტილებაზე ზემოქმედება მოსალოდნელი საგადასახადო ვალდებულებისათვის თავის არიდების მიზნით -
იწვევს პირის დაჯარიმებას 2 500 ლარის ოდენობით.
4. ამ მუხლის დებულებების გამოყენებისას საგადასახადო ორგანომ მხედველობაში უნდა მიიღოს სხვადასხვა ფაქტები და გარემოებები (მათ შორის, სეზონურობა, ფორსმაჟორი და სხვა), რომლებსაც შეეძლო გავლენა მოეხდინა ქრონომეტრაჟის შედეგზე, და გადასახადის გადამხდელის მტკიცებულების შემთხვევაში - ის ფაქტები და გარემოებები, რომლებიც არ იყო დამოკიდებული გადამხდელის ნებაზე და გავლენა იქონია ქრონომეტრაჟის შედეგზე.
