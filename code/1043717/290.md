# მუხლი 290. სანებართვო პირობების შეუსრულებლობა
საწყობის, თავისუფალი საწყობის ან თავისუფალი ვაჭრობის პუნქტის საქართველოს კანონმდებლობით დადგენილი სანებართვო პირობების დარღვევა -
იწვევს ნებართვის მფლობელის დაჯარიმებას 4 000 ლარის ოდენობით, ხოლო იმავე პირობის დარღვევის ყოველ შემდგომ განმეორებაზე - ჯარიმის ოდენობის გასამმაგებას.
