# მუხლი 229. ექსპორტი
1. ექსპორტის სასაქონლო ოპერაცია საშუალებას იძლევა, საქართველოს საქონელი გატანილ იქნეს საქართველოს ეკონომიკური ტერიტორიის გარეთ. ექსპორტის სასაქონლო ოპერაცია გამოიყენება, თუ საქონელი საქართველოს ეკონომიკური ტერიტორიიდან გატანისას იმავე მდგომარეობაში იყო, როგორშიც ექსპორტის დეკლარაციის რეგისტრაციის დღეს, გარდა ბუნებრივი დანაკარგებით გამოწვეული ცვლილებებისა.
2. ექსპორტისას ხორციელდება სავაჭრო პოლიტიკის ღონისძიებები.
