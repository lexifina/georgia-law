# მუხლი 422. შუამდგომლობის განხილვა
1. სამართალში მიცემის საკითხის გადაწყვეტისას მოსამართლე (სასამართლო) ვალდებულია განიხილოს მხარეებისაგან შემოსული შუამდგომლობები დამატებითი მტკიცებულებების გამოთხოვის, აღკვეთის ღონისძიებების გაუქმებისა და შეცვლის, სამოქალაქო სარჩელისა და მისი უზრუნველყოფის ზომების შესახებ. ამასთანავე, მოსამართლე (სასამართლო) ვალდებულია განმარტების მისაცემად დაიბაროს შუამდგომლობის განმცხადებელი პირი, თუ იგი ამას მოითხოვს.
2. შუამდგომლობის გადაწყვეტის შედეგი ეცნობება შუამდგომლობის განმცხადებელ პირს. შუამდგომლობაზე უარის თქმა გასაჩივრებას არ ექვემდებარება, მაგრამ იგი შეიძლება კვლავ იქნეს განცხადებული სასამართლო სხდომაზე.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
- საქართველოს 1999 წლის 28 მაისის კანონი №2048 - სსმ I, №18(25), 01.06.1999 წ., მუხ.75
