# მუხლი 422. მოსამართლის კომპეტენცია, როცა წინასწარი მოსმენა არ ტარდება
თუ წინასწარი მოსმენა არ ტარდება, მოსამართლე შეისწავლის საქმის მასალებს, პროცესის მონაწილეთა შუამდგომლობებს, განცხადებებს, არკვევს 423-ე მუხლით გათვალისწინებულ საკითხებს და იღებს 424-ე მუხლში აღნიშნულ ერთ-ერთ დადგენილებას. ასეთ შემთხვევაში სასამართლოს სხდომა ტარდება მხარეთა მონაწილეობის გარეშე.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
