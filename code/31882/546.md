# მუხლი 546. საკასაციო გასაჩივრების სუბიექტები
საკასაციო გასაჩივრების სუბიექტები არიან 518-ე მუხლში მითითებული პირები. [(ძალადაკარგულია ის ნორმატიული შინაარსი , რომელიც უგულებელყოფს გამართლებულის მიერ განაჩენის საკასაციო წესით გასაჩივრების შესაძლებლობას)]
- საქართველოს საკონსტიტუციო სასამართლოს 2014 წლის 24 დეკემბრის გადაწყვეტილება №3/3/601 - ვებგვერდი, 12.01.2015წ.
