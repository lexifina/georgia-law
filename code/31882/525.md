# მუხლი 525. კერძო სააპელაციო საჩივარი
1. რაიონული (საქალაქო) სასამართლოს ყოველი შემაჯამებელი გადაწყვეტილება, განაჩენის გარდა, შეიძლება გასაჩივრდეს სააპელაციო წესით, კერძო სააპელაციო საჩივრის შეტანის გზით.
2. რაიონული (საქალაქო) სასამართლოს განჩინება (დადგენილება), რომელიც გამოტანილია საქმის განხილვისას და არ არის შემაჯამებელი ხასიათისა, შეიძლება სააპელაციო წესით სასამართლოს განაჩენთან ერთად გასაჩივრდეს.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
