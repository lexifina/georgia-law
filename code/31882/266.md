# მუხლი 266. დანაშაულის ჩადენის შესახებ ცნობების შემოწმების საფუძველზე მიღებული გადაწყვეტილება

გ) საგამოძიებო ქვემდებარეობის მიხედვით მასალების გადაგზავნის შესახებ.
