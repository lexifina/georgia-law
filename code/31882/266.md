# მუხლი 266. საქმის ქვემდებარეობით გადაგზავნა
თუ წინასწარი გამოძიების დაწყების შემდეგ გამოიკვეთა, რომ სისხლის სამართლის საქმის გამოძიება განეკუთვნება გამოძიების სხვა ორგანოს, გამომძიებელი გადაუდებელი საგამოძიებო მოქმედებათა შესრულების შემდეგ დაუყოვნებლივ გადააგზავნის საქმეს ქვემდებარეობის მიხედვით.
- საქართველოს 2005 წლის 25 მარტის კანონი №1204 - სსმ I, №14, 18.04.2005 წ., მუხ.94
