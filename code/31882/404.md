# მუხლი 404. საქმის მასალების გაცნობის გადადება
1. თუ დამცველი ან კანონიერი წარმომადგენელი დანიშნულ ვადაში არ გამოცხადდება საქმის მასალების გასაცნობად, ბრალდებულს, დაზარალებულს, სამოქალაქო მოსარჩელეს და სამოქალაქო მოპასუხეს ეძლევა შესაძლებლობა მომდევნო 2 დღის განმავლობაში მოიწვიონ სხვა დამცველი ან კანონიერი წარმომადგენელი, ანდა მოითხოვონ მათი სახელმწიფოს ხარჯზე დანიშვნა. ამ კოდექსით გათვალისწინებული სავალდებულო დაცვის შემთხვევაში გამომძიებელი დადგენილი წესით უნიშნავს ბრალდებულს ახალ დამცველს.
2. თუ ამ მუხლის პირველ ნაწილში მითითებული პროცესის მონაწილეები უარს იტყვიან დანიშნულ დამცველზე, გამომძიებელი პირადად მათ წარუდგენს საქმის მასალებს გასაცნობად. პროცესის მონაწილეთა მიერ საქმის მასალების გაცნობაზე უარის თქმის შემთხვევაში გამომძიებელი ადგენს ოქმს საქმის მასალების გაცნობაზე უარის თქმის შესახებ, რომელზედაც ხელს აწერს პროცესის შესაბამისი მონაწილე. ამის შემდეგ გამომძიებელი უფლებამოსილია შეადგინოს საბრალდებო დასკვნა.

- საქართველოს 2004 წლის 16 სექტემბრის კანონი №430 - სსმ I, №26, 24.09.2004 წ., მუხ.126
