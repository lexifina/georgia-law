# მუხლი 680³. საქმის მასალების გაცნობის ვადის განსაზღვრის დროებითი წესი
ამ კოდექსის 401-ე მუხლის 1¹, 406-ე მუხლის 4² და 407-ე მუხლის 2¹ ნაწილების ამოქმედებამდე პატიმრობაში მყოფ ბრალდებულს, სამოქალაქო მოსარჩელეს, სამოქალაქო მოპასუხეს, მათ დამცველებს ან კანონიერ წარმომადგენლებს, მიმალვაში მყოფი თანამდებობის პირის ან რეკეტირის დამცველებს (კანონიერ წარმომადგენლებს) გამომძიებელი წინასწარი გამოძიების დამთავრების შემდეგ საქმის მასალების გაცნობისათვის განუსაზღვრავს გონივრულ ვადას, მაგრამ არანაკლებ 10 დღისა.
