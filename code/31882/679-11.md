# მუხლი 679¹¹. კოდექსის ნორმების მოქმედება იურიდიული პირის მიმართ
1. იურიდიული პირისთვის სისხლისსამართლებრივი პასუხისმგებლობის დასაკისრებლად საქმის წარმოება მიმდინარეობს ამ კოდექსით დადგენილი საერთო წესებისა და LXIV² თავის შესაბამისად. ამ კოდექსის ნორმები ვრცელდება იურიდიულ პირებზე მათი შინაარსის გათვალისწინებით.
2. ამ თავის მიზნებისათვის, იურიდიული პირი ნიშნავს სამეწარმეო (კომერციულ) ან არასამეწარმეო (არაკომერციულ) იურიდიულ პირს (მის უფლებამონაცვლეს).
