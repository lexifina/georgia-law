# მუხლი 528. სააპელაციო ინსტანციაში საქმის განხილვის ვადები
1. საქმე, საჩივარი და მისი შესაგებელი რაიონული (საქალაქო) სასამართლოდან სააპელაციო სასამართლოში უნდა გაიგზავნოს განაჩენის გამოტანიდან არა უგვიანეს ერთი თვისა.
