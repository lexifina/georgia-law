# მუხლი 421. სასამართლო შემადგენლობა განმწესრიგებელ სხდომაზე. პროკურორის მონაწილეობა განმწესრიგებელ სხდომაში
1. სისხლის სამართლის საქმე განმწესრიგებელ სხდომაზე განიხილება მოსამართლის ან სასამართლოს მიერ.
