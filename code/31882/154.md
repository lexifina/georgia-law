# მუხლი 154. პირი, რომლის მიმართაც შეიძლება აღკვეთის ღონისძიების გამოყენება
ბრალდებულის, განსასჯელის ან მსჯავრდებულის მიმართ აღკვეთის ღონისძიება შეიძლება გამოყენებულ იქნეს მხოლოდ იმ შემთხვევაში, თუ არსებობს 151-ე მუხლით გათვალისწინებული საფუძვლები. სამედიცინო ხასიათის იძულებითი ღონისძიების გამოყენებისას აღკვეთის ღონისძიების გამოყენება დაიშვება სასამართლო განჩინების აღსრულების უზრუნველსაყოფად. ეს პირი უნდა მოთავსდეს სპეციალურ განყოფილებაში ან პალატაში, რომელიც განკუთვნილია ფსიქიკურად დაავადებული ავადმყოფისათვის.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
