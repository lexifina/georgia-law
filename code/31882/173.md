## თავი XXI
## მოყვანა
# მუხლი 173. გამოცხადების სავალდებულოობა
1. პირები, რომლებსაც კანონით დადგენილი წესით იძახებენ მომკვლევი, გამომძიებელი, პროკურორი, მოსამართლე სისხლის სამართლის საქმის წარმოებასთან დაკავშირებით, ვალდებულნი არიან გამოცხადნენ ზუსტად დანიშნულ დროს. არასაპატიო მიზეზით გამოუცხადებლობის შემთხვევაში პროცესის მონაწილენი შეიძლება იძულებით მოიყვანონ.
2. ეჭვმიტანილის, ბრალდებულის, განსასჯელის იძულებით მოყვანა დაიშვება მხოლოდ პროცესის მწარმოებელი ორგანოს მოტივირებული დადგენილებით (განჩინებით).
- საქართველოს 1999 წლის 23 ივლისის კანონი №2354 - სსმ I, №36(43), 29.07.1999 წ., მუხ.178
