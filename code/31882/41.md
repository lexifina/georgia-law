# მუხლი 41. სამოქალაქო სარჩელის დაკმაყოფილება და უარყოფა
1. სასამართლოს უფლება აქვს მთლიანად ან ნაწილობრივ დააკმაყოფილოს ან უარყოს სამოქალაქო სარჩელი გამამტყუნებელ განაჩენში, აგრეთვე 28-ე მუხლის პირველი ნაწილის "ვ", "ზ", "თ", "ი" და "პ" ქვეპუნქტებში აღნიშნული საფუძვლით საქმის შეწყვეტის შესახებ განჩინებაში (დადგენილებაში), ან სამედიცინო ხასიათის იძულებითი ღონისძიების გამოყენებისა თუ მის გამოყენებაზე უარის თქმის შესახებ განჩინებაში (დადგენილებაში).
2. სასამართლო ვალდებულია უარყოს სარჩელი 28-ე მუხლის პირველი ნაწილის "ა", "ბ", "გ", "დ", "ე", "კ", "ნ", "ო", "ჟ" და "რ" ქვეპუნქტებში და იმავე მუხლის მე-2-3 ნაწილებში აღნიშნული საფუძვლით საქმის შეწყვეტისას.
3. სასამართლო ვალდებულია არ განიხილოს სარჩელი 28-ე მუხლის პირველი ნაწილის "ლ" და "მ" ქვეპუნქტებში აღნიშნული საფუძვლით საქმის შეწყვეტისას, აგრეთვე თუ სამოქალაქო მოსარჩელე ან მისი წარმომადგენელი არ გამოცხადდება სასამართლო სხდომაზე არასაპატიო მიზეზით.

- საქართველოს 1999 წლის 23 ივლისის კანონი №2354 - სსმ I, №36(43), 29.07.1999 წ., მუხ.178
