# მუხლი 558. საკასაციო ინსტანციის სასამართლოში განხილვის მონაწილენი
1. საკასაციო ინსტანციის სასამართლოში განხილვაში მონაწილეობენ 531-ე მუხლის პირველ ოთხ ნაწილში მითითებული პირები.
