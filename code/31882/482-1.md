# მუხლი 482¹. საფინანსო-საბუღალტრო ექსპერტის დაკითხვა
თუ მხარე შუამდგომლობს საქმეში მონაწილე საფინანსო-საბუღალტრო ექსპერტის დაკითხვას, საფინანსო-საბუღალტრო ექსპერტი სასამართლოში გამოიძახება და დაიკითხება მოწმის სახით წერილობით დასკვნაში მოყვანილი საკითხების თაობაზე.
- საქართველოს 2005 წლის 27 დეკემბრის კანონი №2543 - სსმ I, № 1, 04.01.2006წ., მუხ.9
