# მუხლი 519. სააპელაციო გასაჩივრების საგანი
სააპელაციო წესით შეიძლება გასაჩივრდეს რაიონული (საქალაქო) სასამართლოს განაჩენი და სხვა გადაწყვეტილება, რომელიც კანონიერ ძალაში არ შესულა და, აპელანტის აზრით, უსაფუძვლოა. განაჩენის, სხვა სასამართლო გადაწყვეტილების უსაფუძვლობაში იგულისხმება ის, რომ არ არის დამტკიცებული საქმის ფაქტობრივი გარემოებები. სააპელაციო საჩივარი შეიძლება შეტანილ იქნეს და იგი უნდა განიხილოს სააპელაციო ინსტანციის სასამართლომ, თუ განაჩენის საფუძვლიანობასთან ერთად სადავო ხდება მისი კანონიერებაც.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
