# მუხლი 569. საკასაციო ინსტანციის სასამართლოს განჩინება
განაჩენის გაუქმებისას ან საქმის შეწყვეტისას დანაშაულის შემთხვევის ან შემადგენლობის არარსებობისას, აგრეთვე მაშინ, როდესაც მსჯავრდებული არ მონაწილეობდა დანაშაულში, დაუშვებელია განაჩენის გაუქმების ან საქმის შეწყვეტის შესახებ განჩინებაში ისეთ ფორმულირებათა შეტანა, რომლებიც ეჭვქვეშ აყენებენ იმ პირის უდანაშაულობას, რომლის მიმართაც წყდება საქმე.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
