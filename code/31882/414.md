# მუხლი 414. პროკურორის მიერ ახალი საბრალდებო დასკვნის შედგენა
თუ პროკურორი ან მისი მოადგილე საბრალდებო დასკვნას არ ეთანხმება, იგი ადგენს ახალ საბრალდებო დასკვნას, ხოლო ადრე შედგენილი საბრალდებო დასკვნა ამოიღება საქმიდან.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
