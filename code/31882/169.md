# მუხლი 169. ხელწერილი გაუსვლელობისა და სათანადო ქცევის შესახებ
ხელწერილი გაუსვლელობისა და სათანადო ქცევის შესახებ არის ბრალდებულის წერილობითი ვალდებულება, რომელსაც იგი აძლევს სასამართლოს იმის შესახებ, რომ არ დაემალება გამოძიებასა და სასამართლოს, არ აწარმოებს დანაშაულებრივ საქმიანობას, ხელს არ შეუშლის საქმეზე ჭეშმარიტების დადგენას, გამოცხადდება მომკვლევის, გამომძიებლის, პროკურორის, სასამართლოს გამოძახებით. ხელწერილის მიმცემი კისრულობს ვალდებულებას არ გავიდეს აღნიშნული დასახლებული პუნქტიდან მომკვლევის, გამომძიებლის, პროკურორის, მოსამართლის ნებართვის გარეშე და შეატყობინოს მათ, თუ შეიცვალა საცხოვრებელი ადგილი მითითებული დასახლებული პუნქტის ფარგლებში.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
