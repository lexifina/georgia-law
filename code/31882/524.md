# მუხლი 524. სააპელაციო საჩივრის შეტანა
განაჩენის გამომტან სასამართლოში შეაქვთ სააპელაციო საჩივრის იმდენი ეგზემპლარი, რამდენიც საჭიროა იმისათვის, რომ იგი ამ სასამართლომ გადასცეს პროცესის ყოველ მონაწილეს, რომელსაც მხარის საპროცესო მდგომარეობა უკავია.
- საქართველოს 1999 წლის 28 მაისის კანონი №2048 - სსმ I, №18(25), 01.06.1999 წ., მუხ.75
