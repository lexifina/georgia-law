## თავი XLIV
## ექსპერტიზა
# მუხლი 356. ექსპერტიზის დანიშვნის საფუძველი
ექსპერტიზა ტარდება მომკვლევის, გამომძიებლის ან პროკურორის დადგენილებით, თუ საქმისათვის მნიშვნელობის მქონე ფაქტობრივ გარემოებათა დასადგენად საჭიროა მეცნიერების, ტექნიკის, ხელოვნების სათანადო დარგის ან ამა თუ იმ ხელობის სპეციალისტთა დასკვნა. თუ მომკვლევს, გამომძიებელს, პროკურორს, სპეციალისტსა და დამსწრეს აქვთ სპეციალური ცოდნა, ეს არ გამორიცხავს ექსპერტიზის დანიშვნის აუცილებლობას.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
