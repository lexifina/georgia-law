# მუხლი 570. საკასაციო ინსტანციის სასამართლოს მითითებანი
1. დამატებითი გამოძიებისათვის ან ხელახალი სასამართლო განხილვისათვის საქმის დაბრუნებისას საკასაციო ინსტანციის სასამართლოს უფლება აქვს მისცეს გამომძიებელსა და პროკურორს პირველი და სააპელაციო ინსტანციის სასამართლოს სავალდებულო მითითებები, რომელთა მიზანიცაა წინასწარი გამოძიებისა და სასამართლო განხილვის დროს დაშვებული ხარვეზების შევსება და სამართლებრივი შეცდომის გამოსწორება.
2. მითითებათა შესრულების შემდეგ გამომძიებელი ან პროკურორი პირველი ინსტანციის სასამართლო გადაწყვეტილებას იღებენ თავისი შინაგანი რწმენით და სამართალგაგებით.
- საქართველოს 1999 წლის 13 მაისის კანონი №1958 - სსმ I, №16(23), 14.05.1999 წ., მუხ.65
