# მუხლი 106. საქმეში ექსპერტის, სპეციალისტის, თარჯიმნისა და დამსწრის მონაწილეობის გამომრიცხავი გარემოებანი
1. ექსპერტს (გარდა 361-ე მუხლის პირველი ნაწილით გათვალისწინებული შემთხვევისა), სპეციალისტს, თარჯიმანს ან დამსწრეს უფლება არა აქვს მონაწილეობა მიიღოს სისხლის სამართლის საქმის წარმოებაში 105-ე მუხლის პირველი ნაწილის "დ" ქვეპუნქტში აღნიშნულ გარემოებათა არსებობისას, აგრეთვე როცა სამსახურებრივად ან სხვაგვარად დამოკიდებულია საქმეში მონაწილე ამა თუ იმ პირზე, ანდა ნათესაური ურთიერთობა აქვს მასთან.
2. ექსპერტი, სპეციალისტი, თარჯიმანი აცილებულ უნდა იქნენ იმ შემთხვევაშიც, თუ გამოვლინდება მათი პროფესიული არაკომპეტენტურობა, ხოლო დამსწრენი, - თუ ისინი არიან პოლიციის, სახელმწიფო უშიშროების ორგანოების, ფინანსთა სამინისტროს საგამოძიებო დეპარტამენტის, საგადასახადო ან საბაჟო დეპარტამენტის მოკვლევის ორგანოებისა და ქვედანაყოფების, დაზვერვის სახელმწიფო დეპარტამენტის, სახელმწიფო დაცვის სპეციალური სამსახურის, სახელმწიფო საზღვრის დაცვის სახელმწიფო დეპარტამენტის, პროკურატურის, სხვა სამართალდამცავი ორგანოების, იუსტიციის ორგანოების ან სასამართლოს მუშაკები.
3. ექსპერტად ან სპეციალისტად საქმეში მონაწილეობის უფლება არა აქვს პირს, რომელიც ატარებდა რევიზიას ან სხვა უწყებრივ შემოწმებას, რომლის საფუძველზედაც აღიძრა ეს საქმე.
