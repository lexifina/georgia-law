# მუხლი 106. საქმეში ექსპერტის, სპეციალისტის, თარჯიმნისა და დამსწრის მონაწილეობის გამომრიცხავი გარემოებანი
1. ექსპერტს (გარდა 361-ე მუხლის პირველი ნაწილით გათვალისწინებული შემთხვევისა), სპეციალისტს ან დამსწრეს უფლება არა აქვთ მონაწილეობა მიიღონ სისხლის სამართლის საქმის წარმოებაში, როცა სამსახურებრივად ან სხვაგვარად დამოკიდებულნი არიან საქმეში მონაწილე ამა თუ იმ პირზე ანდა ნათესაური ურთიერთობა აქვთ მასთან.
2. ექსპერტი, სპეციალისტი, თარჯიმანი აცილებულ უნდა იქნენ იმ შემთხვევაშიც, თუ გამოვლინდება მათი პროფესიული არაკომპეტენტურობა, ხოლო დამსწრენი, - თუ ისინი არიან პოლიციის, საქართველოს ფინანსთა სამინისტროს ფინანსური პოლიციის, საგარეო დაზვერვის სპეციალური სამსახურისა და სახელმწიფო დაცვის სპეციალური სამსახურის, პროკურატურის, სხვა სამართალდამცავი ორგანოების, იუსტიციის ორგანოების ან სასამართლოს მუშაკები.
3. ექსპერტად ან სპეციალისტად საქმეში მონაწილეობის უფლება არა აქვს პირს, რომელიც ატარებდა რევიზიას ან სხვა უწყებრივ შემოწმებას, რომლის საფუძველზედაც აღიძრა ეს საქმე.
