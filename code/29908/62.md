# მუხლი 62
მეზღვაურთა დასაქმების პროცედურები, მათი უფლებები და მოვალეობები, აგრეთვე მეზღვაურთა სოციალური დაცვის შესახებ დებულებები განისაზღვრება საქართველოს შრომის კანონმდებლობით, "მეზღვაურთა შრომის შესახებ" საქართველოს კანონით, საზღვაო დისციპლინური წესდებითა და მეზღვაურის შრომითი ხელშეკრულებით.
- საქართველოს 2007 წლის 30 მარტის კანონი №4598-სსმI, №11, 10.04.2007წ., მუხ.102
- საქართველოს 2011 წლის 22 თებერვლის კანონი №4222 - ვებგვერდი, 10.03.2011წ.
- საქართველოს 2023 წლის 31 მაისის კანონი №3043 - ვებგვერდი, 13.06.2023წ.
