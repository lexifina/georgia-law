# მუხლი 62
1. სააგენტო ზღვაოსნობის უსაფრთხოების, გარემოს დაბინძურების თავიდან აცილებისა და შრომის დაცვის მიზნით განსაზღვრავს ეკიპაჟის მინიმალურ დასაშვებ შემადგენლობას, რომლითაც შეიძლება გემის ზღვაში გასვლა.
