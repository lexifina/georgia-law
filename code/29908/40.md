# მუხლი 40
1. საქართველოს სახელმწიფო დროშით ნაოსნობის უფლების მოწმობას, გემის ბილეთს, გემის საკუთრების მოწმობას და რადიოსადგურის სერტიფიკატს გასცემს ადმინისტრაცია თავის მიერ სახელმწიფო ინტერესების გათვალისწინებით დადგენილი წესით.
2. (ამოღებულია).
3. განზომილებათა მოწმობას, სამგზავრო მოწმობას, მოწმობას სატვირთო მარკის შესახებ, აგრეთვე გემის სხვა საბუთებს, რომლებიც გათვალისწინებულია იმ საერთაშორისო კონვენციებით, რომელთა მონაწილეც არის საქართველო, გასცემს საკლასიფიკაციო საზოგადოება.
4. საკლასიფიკაციო საზოგადოების ნებართვით და ადმინისტრაციასთან შეთანხმებით, ზოგიერთი კატეგორიის გემს შეიძლება არ ჰქონდეს განზომილებათა მოწმობა ან მოწმობა სატვირთო მარკის შესახებ.
