# მუხლი 180
1. კრუიზის მონაწილეს უფლება აქვს კრუიზის დაწყებამდე ერთი კვირით ადრე მაინც უარი თქვას საზღვაო კრუიზის ხელშეკრულებაზე და ამ ხელშეკრულებით დადგენილი წესით და ვადაში დაიბრუნოს კრუიზის საფასური.
