# მუხლი 48
1. მთელი რეისის განმავლობაში გემის კაპიტანს ევალება:
ა) გემის ზღვაოსნობაუნარიანობის უზრუნველყოფა;
ბ) ადამიანის, გემისა და ტვირთის დაზიანების თავიდან აცილება;
გ) ნაოსნობის უსაფრთხოება;
დ) გემის მართვა;
ე) გემის მმართველობა;
ვ) ტექნიკური მდგომარეობის უზრუნველყოფა;
ზ) გემზე წესრიგის უზრუნველყოფა;
თ) ზღვის დაბინძურების თავიდან აცილება;
ი) ადამიანებისათვის სამედიცინო დახმარების აღმოჩენა;
კ) საჭიროების შემთხვევაში ნავსადგურში შესვლა.
2. გემის კაპიტნის განკარგულებები მისი უფლებამოსილების ფარგლებში უსიტყვოდ უნდა შეასრულოს გემზე მყოფმა ყველა პირმა. წინააღმდეგ შემთხვევაში ამ პირთა მიმართ კაპიტანი იღებს სათანადო ზომებს.
3. თუ გემზე მყოფი პირის მოქმედება საშიშროებას უქმნის გემის უსაფრთხოებას ან გემზე მყოფ პირებსა და ქონებას, კაპიტანს უფლება აქვს მოათავსოს ეს პირი განსაკუთრებულ სადგომში და გააჩეროს იქ რეპატრიაციისათვის მოხერხებულ პირველსავე ნავსადგურში შესვლამდე.
4. განსაკუთრებულ სადგომში ვისიმე უკანონოდ მოთავსებისათვის გემის კაპიტანი პასუხს აგებს საქართველოს კანონმდებლობით დადგენილი წესით.
[მუხლი 48
1. გემის კაპიტნის ბრძანება მისი კომპეტენციის ფარგლებში ზედმიწევნით უნდა შეასრულოს გემზე მყოფმა ყველა პირმა. თუ გემზე მყოფი რომელიმე პირი კაპიტნის ბრძანებას არ შეასრულებს, კაპიტანი ვალდებულია მის მიმართ შესაბამისი ზომები მიიღოს.
2. გემის კაპიტნის უფლებამოსილება მოიცავს (მაგრამ არ შემოიფარგლება) იმ უფლებას, რომ მან უარი თქვას გემის სანაოსნოდ გაყვანაზე, როდესაც გემი უსაფრთხოდ არ მიაჩნია, გემზე ასვლაზე უარი განუცხადოს ნებისმიერ პირს, გარდა სახელმწიფოს მიერ უფლებამოსილი პირისა, რომელიც ასრულებს მოვალეობას "ზღვაზე ადამიანის სიცოცხლის დაცვის შესახებ" 1974 წლის საერთაშორისო კონვენციის შესაბამისად, ასევე უარი თქვას ნებისმიერი სახის ტვირთის დატვირთვაზე.
3. თუ გემის კაპიტანი პროფესიული განსჯის საფუძველზე მიიჩნევს, რომ არსებობს კონფლიქტი გემის მიმართ წაყენებულ საზღვაო უშიშროების მოთხოვნასა და საზღვაო უსაფრთხოების მოთხოვნას შორის, იგი უპირატესობას ანიჭებს საზღვაო უსაფრთხოების მოთხოვნას, საჭიროების შემთხვევაში იღებს დროებით ზომებს საზღვაო უშიშროებისთვის და ამის შესახებ დაუყოვნებლივ აცნობებს სააგენტოს.
