# მუხლი 271
"საქართველოს საზღვაო სივრცის შესახებ" საქართველოს კანონით დადგენილ საქართველოს შიდა საზღვაო წყლებსა და საქართველოს ტერიტორიულ ზღვაში ყველა სახეობის მცურავ ობიექტზე აზარტული ან/და მომგებიანი თამაშობების მოწყობა რეგულირდება "ლატარიების, აზარტული და მომგებიანი თამაშობების მოწყობის შესახებ" საქართველოს კანონით.
- საქართველოს 2023 წლის 9 თებერვლის კანონი №2591 - ვებგვერდი, 24.02.2023წ.
