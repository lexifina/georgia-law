# მუხლი 47
1. გემის კაპიტნის, კაპიტნის თანაშემწეების, გემის მექანიკოსების, ელექტრომექანიკოსების და რადიოსპეციალისტების თანამდებობებზე სამუშაოდ დაიშვებიან შესაბამისი წოდების მქონე საზღვაო საქმის სპეციალისტები "საქართველოს საზღვაო გემების მეთაურთა შემადგენლობისათვის წოდების მინიჭების შესახებ " დებულების შესაბამისად.
2. წოდების მინიჭება ხდება სააგენტოში გამოცდების ჩაბარების შემდეგ, რაც დასტურდება სათანადო დიპლომითა და საკვალიფიკაციო მოწმობით.
3. წოდებების ჩამორთმევა ხდება სასამართლოს მიერ.
4. საქართველოს სახელმწიფო ალმით მცურავი სამგზავრო გემის კაპიტნის თანამდებობის დაკავება შეუძლია კაპიტნის წოდების მქონე პირს სპეციალური გამოცდების ჩაბარებისა და სააგენტოს მუდმივმოქმედი სახელმწიფო საზღვაო საკვალიფიკაციო კომისიის მიერ დამტკიცების შემდეგ.
- საქართველოს 2007 წლის 30 მარტის კანონი №4598-სსმI, №11, 10.04.2007წ., მუხ.102
- საქართველოს 2011 წლის 22 თებერვლის კანონი №4222 - ვებგვერდი, 10.03.2011წ.
