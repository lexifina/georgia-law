# მუხლი 47
1. გემის კაპიტნის, კაპიტნის თანაშემწეების, გემის მექანიკოსების, ელექტრომექანიკოსების და რადიოსპეციალისტების თანამდებობებზე სამუშაოდ დაიშვებიან შესაბამისი წოდების მქონე საზღვაო საქმის სპეციალისტები "საქართველოს საზღვაო გემების მეთაურთა შემადგენლობისათვის წოდების მინიჭების შესახებ " დებულების შესაბამისად.
2. წოდებების მინიჭება ხდება ადმინისტრაციაში გამოცდების ჩაბარების შემდეგ, რაც დასტურდება სათანადო დიპლომითა და საკვალიფიკაციო მოწმობით.
3. წოდებების ჩამორთმევა ხდება სასამართლოს მიერ.
4. საქართველოს სახელმწიფო ალმით მცურავი სამგზავრო გემის კაპიტნის თანამდებობის დაკავება შეუძლია კაპიტნის წოდების მქონე პირს სპეციალური გამოცდების ჩაბარებისა და ადმინისტრაციის სპეციალური კოლეგიის მიერ დამტკიცების შემდეგ.
