# მუხლი 52
გემზე ბავშვის დაბადების შემთხვევაში გემის კაპიტანი ამ ფაქტს გემის საბორტო ჟურნალში აღრიცხავს და მიუთითებს ბავშვის დედისა და მამის სახელებს, დაბადების თარიღებსა და მოქალაქეობას, აგრეთვე ბავშვის დაბადების თარიღსა და სქესს და ინფორმაციას იმის შესახებ, ბავშვი ცოცხალი დაიბადა თუ არა. გემის საბორტო ჟურნალში კაპიტნის მიერ გაკეთებულ ჩანაწერს ორი მოწმე აწერს ხელს. აღნიშნული ჩანაწერის ასლი, რომელზედაც მითითებულია ორი მოწმის ხელმოწერები, გადაეცემა ბავშვის მშობელს შესაბამის სამოქალაქო ორგანოში დაბადების რეგისტრაციისთვის.
- საქართველოს 2023 წლის 31 მაისის კანონი №3043 - ვებგვერდი, 13.06.2023წ.
