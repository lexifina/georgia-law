# მუხლი 44¹⁵
წერილობით შეთანხმებას საქართველოს სახელით ხელს აწერს სააგენტო, ხოლო აღიარებული ორგანიზაციის სახელით − მისი უფლებამოსილი წარმომადგენელი. ეს შეთანხმება სრულად უნდა ეფუძნებოდეს IMO-ს A.739 (18) რეზოლუციის მე-2 დანართის, MSC/Circ. 710 და MEPC/Circ. 307 ცირკულარებით გათვალისწინებული მოდელური ხელშეკრულების დებულებებს.
- საქართველოს 2012 წლის 5 ივნისის კანონი №6386 - ვებგვერდი, 19.06.2012წ.
