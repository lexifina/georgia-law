# მუხლი 3. ფშავ-ხევსურეთის დაცული ტერიტორიების კატეგორიები
1. ფშავ-ხევსურეთის დაცული ტერიტორიების ტერიტორიულ-ფუნქციური ორგანიზება ემყარება "დაცული ტერიტორიების სისტემის შესახებ" საქართველოს კანონით დადგენილ საფუძვლებს.
2. ფშავ-ხევსურეთის დაცული ტერიტორიები იქმნება ეროვნული მნიშვნელობისა და დიდი გარემოსდაცვითი და ესთეტიკური ღირებულების მქონე ბუნებრივი ტერიტორიების, აგრეთვე ადამიანისა და ბუნებრივი გარემოს ჰარმონიული ურთიერთობის შედეგად ჩამოყალიბებული ბუნებრივ-კულტურული ძეგლების დაცვისა და სასიცოცხლო გარემოს შენარჩუნებისათვის, რეკრეაციულ-ტურისტული საქმიანობისა და ტრადიციული სამეურნეო საქმიანობისათვის.
3. ფშავ-ხევსურეთის დაცული ტერიტორიები საქართველოს დაცული ტერიტორიების ნაწილია და მოიცავს დაცული ტერიტორიების შემდეგ კატეგორიებს:
ა) ფშავ-ხევსურეთის ეროვნული პარკი;
ბ) როშკის ბუნების ძეგლი;
გ) ასის აღკვეთილი;
დ) ფშავ-ხევსურეთის მრავალმხრივი გამოყენების ტერიტორია (დამხმარე ზონა).
4. ამ კანონით განსაზღვრული დაცული ტერიტორიების კატეგორიების ზონირება და ზონებში დაშვებული საქმიანობა, "დაცული ტერიტორიების სისტემის შესახებ" საქართველოს კანონის თანახმად, დგინდება შესაბამისი დაცული ტერიტორიის მენეჯმენტის გეგმით.
