# მუხლი 19 . შემოქმედებითი კავშირის წესდება
1 . შემოქმედებითი კავშირის საქმიანობის წესი და მისი ძირითადი მიმართულებები განსაზღვრულია წესდებით .
2 . წესდება უნდა შეიცავდეს :
ა ) შემოქმედებითი კავშირის სრულ სახელწოდებას , შემოკლებულ სახელწოდებას ( მისი არსებობის შემთხვევაში );
ბ ) შემოქმედებითი კავშირის საქმიანობის მიზნებსა და ამოცანებს ;
გ ) შემოქმედებით კავშირში გაწევრიანებისა და წევრობიდან გასვლის წესს ;
დ ) შემოქმედებითი კავშირის წევრთა უფლებებსა და მოვალეობებს ;
ე ) შემოქმედებითი კავშირის მართვის ორგანოთა შექმნისა და საქმიანობის საფუძვლებს , მათ უფლებამოსილებებს ;
ვ ) შემოქმედებითი კავშირის მიერ გაწეულ საქმიანობაზე კონტროლის წესს ;
ზ ) შემოქმედებითი კავშირის ლიკვიდაციისა და რეორგანიზაციის წესს ;
თ ) მასში ცვლილებისა და დამატების შეტანის წესს .
3 . შემოქმედებითი კავშირის წესდებით შეიძლება გათვალისწინებულ იქნეს სხვა საკითხებიც , რომლებიც არ ეწინააღმდეგება საქართველოს კანონმდებლობას .
[ მუხლი 19. შემოქმედებითი კავშირის წესდება
1. შემოქმედებითი კავშირის საქმიანობის წესი და ძირითადი მიმართულებები განსაზღვრულია კავშირის წესდებით.
2. შემოქმედებითი კავშირის წესდება უნდა შეიცავდეს:
ა) შემოქმედებითი კავშირის სრულ სახელწოდებას, ასევე შემოკლებულ სახელწოდებას (მისი არსებობის შემთხვევაში);
ბ) შემოქმედებითი კავშირის საქმიანობის მიზნებსა და ამოცანებს;
გ) შემოქმედებით კავშირში გაწევრების, კავშირიდან გასვლისა და გარიცხვის წეს ებ ს;
დ) შემოქმედებითი კავშირის წევრთა უფლებებსა და მოვალეობებს;
ე) შემოქმედებითი კავშირის მართვის ორგანოთა შექმნისა და საქმიანობის საფუძვლებს, მათ უფლებამოსილებებს და მათი გადაწყვეტილებ ებ ის მიღების წესს;
ვ) შემოქმედებითი კავშირის საქმიანობ ის კონტროლის წესს;
ზ) შემოქმედებითი კავშირის რეორგანიზაციის ა ნ ლიკვიდაცი ი ს შესახებ გადაწყვეტილების მიღებაზე უფლებამოსილი ორგანოს/პირის დასახელებას და ამ გადაწყვეტილების მიღების წესს, თუ იგი განსხვავდება ამ პუნქტის " ე " ქვეპუნქტით დადგენილი წესისაგან ;
თ) ხელმძღვანელობაზე/წარმომადგენლობაზე უფლებამოსილი პირის შესახებ მონაცემებს (სახელი, გვარი, პირადი ნომერი). თუ შემოქმედებით კავშირს წარმომადგენლობაზე უფლებამოსილი ორი ან მეტი პირი ჰ ყავს, სადამფუძნებლო დოკუმენტაციაში უნდა მიეთითოს , როგორ არის მათ შორის უფლებამოსილება ნი გადანაწილებული ;
ი) მასში ცვლილებისა და დამატების შეტანის წესს.
3. შემოქმედებითი კავშირის წესდებით შეიძლება გათვალისწინებულ იქნეს სხვა საკითხებიც, რომლებიც არ ეწინააღმდეგება საქართველოს კანონმდებლობას. (ამოქმედდეს 2011 წლის 28 ივლისიდან)]
- საქართველოს 2011 წლის 1 ივლისის კანონი №501 5 - ვებგვერდი, 14.07.2011წ.
