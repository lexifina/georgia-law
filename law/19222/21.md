# მუხლი 21 . შემოქმედებითი კავშირის გამგეობა
1. შემოქმედებითი კავშირის გამგეობა არის მართვის უმაღლესი ორგანო ყრილობებს ( საერთო კრებებს) შორის პერიოდში, რომელიც წარმართავს კავშირის საქმიანობას საქართველოს კანონმდებლობის, წესდებისა და ყრილობის ( საერთო კრების) გადაწყვეტილებათა საფუძველზე. გამგეობას ირჩევს ყრილობა ( საერთო კრება) 5 წლის ვადით, თუ წესდებით სხვა რამ არ არის გათვალისწინებული. გამგეობის უფლებამოსილება გრძელდება ამ ვადის გასვლის შემდეგაც, ახალი გამგეობის არჩევამდე.
2. გამგეობა:
ა) წარმართავს შემოქმედებითი კავშირის საქმიანობას;
ბ) ამტკიცებს შემოქმედებითი კავშირის წლიურ ანგარიშს, ადგენს სამუშაო გეგმებსა და აწარმოებს ხარჯთაღრიცხვას;
გ) ამზადებს ყრილობისათვის ( საერთო კრებისათვის) მასალებს, იწვევს ყრილობას ( საერთო კრებას) და ორგანიზაციას უწევს მის ჩატარებას;
დ) ახორციელებს ამ კანონითა და წესდებით გათვალისწინებულ სხვა ფუნქციებს.
3. გამგეობა უფლებამოსილია მიიღოს გადაწყვეტილება, თუ სხდომას ესწრება გამგეობის წევრთა ნახევარი მაინც. გადაწყვეტილება მიიღება დამსწრეთა ხმების უმრავლესობით. გამგეობის წევრს, რომელიც არ ესწრება სხდომას, უფლება აქვს წერილობით მიიღოს კენჭისყრაში მონაწილეობა.
4. შემოქმედებითი კავშირის თავმჯდომარე გამგეობის საქმიანობაში აღმოჩენილი მნიშვნელოვანი დარღვევებისას ერთპიროვნულად ან სარევიზიო კომისიის დასაბუთებული მოთხოვნის საფუძველზე იწვევს კავშირის რიგგარეშე ყრილობას ( საერთო კრებას), რომელზედაც შეიძლება განხილულ იქნეს გამგეობის ვადამდე გადარჩევის საკითხი. საკითხის განხილვა წესდებით შეიძლება დაკავშირებული იყოს მხოლოდ მნიშვნელოვანი საფუძვლის არსებობასთან.
