# მუხლი 2. არქივის მიერ გაწეული მომსახურება
1. არქივის მიერ გაწეული მომსახურებაა:
ა ) არქივში დაცული დოკუმენტებ ით სარგებლობა ;
ბ) საინფორმაციო მომსახურება ;
გ) ხელშეკრულების საფუძველზე დოკუმენტების სამეცნიერო-ტექნიკური დამუშავებისა და შემფასებელი ექსპერტიზის ჩატარებისათვის გაწეული მომსახურება.
2. დაინტერესებული პირის მოთხოვნის საფუძველზე არქივი მას მომსახურებას უწევს დაჩქარებული წესით.
