# მუხლი 4. კერძო სამართლის არასამეწარმეო (არაკომერციული) იურიდიული პირების რეესტრი
1. კერძო სამართლის არასამეწარმეო (არაკომერციული) იურიდიული პირების რეესტრი არის კავშირებისა და ფონდების შესახებ მონაცემთა სისტემური ერთობლიობა.
2. კერძო სამართლის არასამეწარმეო (არაკომერციული) იურიდიული პირების რეესტრში შედის:
ა) კავშირების რეესტრი;
ბ) ფონდების რეესტრი.
