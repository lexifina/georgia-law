# მუხლი 4. ლიცენზიის გამცემი ორგანო
"სამეწარმეო საქმიანობის ლიცენზიისა და ნებართვის გაცემის საფუძვლების შესახებ" საქართველოს კანონის მე-6 მუხლის "ჟ.ბ" ქვეპუნქტის შესაბამისად ლიცენზიის გაცემის უფლებამოსილების მქონე ადმინისტრაციული ორგანოა საქართველოს სოფლის მეურნეობისა და სურსათის სამინისტროს სახელმწიფო საქვეუწყებო დაწესებულება - მცენარეთა დაცვის სამსახური.
