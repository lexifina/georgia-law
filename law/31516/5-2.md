# მუხლი 5². დევნილის ვალდებულებები
დევნილი ვალდებულია :
ა ) ერთი თვის განმავლობაში აცნობოს სამინისტროს დროებითი საცხოვრებელი ადგილის შეცვლის შესახებ ;
ბ ) გაიაროს რეგისტრაცია სამინისტროს მიერ წინასწარ გამოცხადებულ ვადაში ;
გ ) ორ თვეზე მეტი ვადით საქართველოს ფარგლებს გარეთ გასვლის შემთხვევაში წინასწარ აცნობოს სამინისტროს ამის შესახებ ;
დ ) ათი დღის ვადაში აცნობოს სამინისტროს შრომითი დასაქმების შესახებ .
