# მუხლი 10. პარლამენტის წევრის სიცოცხლისა და ჯანმრთელობის სავალდებულო დაზღვევის ხელშეკრულება
1. პარლამენტის წევრის სიცოცხლისა და ჯანმრთელობის სავალდებულო დაზღვევა ხორციელდება ამ კანონით , აგრეთვე საქართველოს პარლამენტსა და მზღვეველ იურიდიულ პირს შორის დადებული დაზღვევის ხელშეკრულებით გათვალისწინებული პირობების საფუძველზე .
2. დაზღვევის ხელშეკრულებაში განისაზღვრება :
ა ) ხელშეკრულების მხარეების ვინაობა და მათი ადგილსამყოფელი ( იურიდიული მისამართი );
ბ ) დაზღვევის ობიექტი ;
გ ) სადაზღვევო რისკი , ხოლო ჯანმრთელობის დაზღვევისას - სამედიცინო მომსახურების სახეების ჩამონათვალი ;
დ ) სადაზღვევო შესატანის ( პრემიის ) მოცულობა , მისი გადახდის წესი და ვადა ;
ე ) სადაზღვევო თანხის ოდენობა ;
ვ ) ხელშეკრულების მოქმედების ვადა ;
ზ ) ხელშეკრულების შეცვლის ან მოშლის წესი ;
თ ) დაზღვევის პოლისის მოქმედების სფერო .
3. მხარეთა შეთანხმებით , ხელშეკრულებაში შეიძლება განისაზღვროს სხვა პირობებიც .
4. მზღვეველი მატერიალურად პასუხისმგებელია დამზღვევის წინაშე შესაბამისი დაზღვევის ხელშეკრულებით ნაკისრი ვალდებულებების შესრულებისათვის . მატერიალური პასუხისმგებლობის ზომა გათვალისწინებული უნდა იქნეს დაზღვევის ხელშეკრულებაში .
