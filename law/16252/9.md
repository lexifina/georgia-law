# მუხლი 9. პარლამენტის წევრის ჯანმრთელობის დაზღვევა
1. პარლამენტის წევრის ჯანმრთელობის დაზღვევა ითვალისწინებს :
ა ) ყოველწლიური სავალდებულო სამედიცინო გამოკვლევის ხარჯებს ;
ბ ) სასწრაფო გადაუდებელი სამედიცინო დახმარების ხარჯებს ;
გ ) სამედიცინო კონსულტაციების მიღების ხარჯებს ;
დ ) ამბულატორიული მკურნალობის ( ყველა ტიპის ლაბორატორიული გამოკვლევა , ფუნქციური დიაგნოსტიკა ), მკურნალი ექიმისა და სპეციალისტების ხარჯებს ;
ე ) ჰოსპიტალური მკურნალობის ხარჯებს , რომლებიც საჭიროების შე - მთხვევაში მოიცავს საოპერაციო ხარჯებსაც ;
ვ ) სამედიცინო დაწესებულების რეცეპტით შეძენილი მედიკამენტების ღირებულების 80 პროცენტით დაფარვის ხარჯებს .
2. სამედიცინო მომსახურების სრული ნუსხა დგება საქართველოს პარლამენტსა და მზღვეველ იურიდიულ პირს შორის ამ კანონის შესაბამისად დადებული ხელშეკრულებით .
3. პარლამენტის წევრის ჯანმრთელობის დაზღვევა არ ითვალისწინებს :
ა ) სახელმწიფო და მუნიციპალური პროგრამებით გათვალისწინებული ხარჯების დაფარვას ;
ბ ) კანონსაწინააღმდეგო ქმედებების ან თვითდაშავებით მიღებული დაზიანებების მკურნალობის ხარჯების დაფარვას ;
გ ) ნარკოტიკული ან ალკოჰოლური ნივთიერებების ზემოქმედებისას მიღებული დაზიანებების მკურნალობის ხარჯების დაფარვას ;
დ ) კოსმეტიკური ან არასამედიცინო მიზნით მკურნალობის ჩატარების ხარჯების დაფარვას .
4. პარლამენტის წევრი , რომლის ჯანმრთელობა დაზღვეულია , იღებს ჯანმრთელობის დაზღვევის დამადასტურებელ დოკუმენტს - ჯანმრთელობის დაზღვევის პოლისს . ჯანმრთელობის დაზღვევის პოლისის მოქმედება განისაზღვრება პარლამენტსა და მზღვეველ იურიდიულ პირს შორის ამ კანონის შესაბამისად დადებული ხელშეკრულებით .
5. მზღვეველს უფლება აქვს შესთავაზოს დამზღვევს ამ კანონით დადგენილზე უფრო ხელსაყრელი ან დამატებითი პირობები .
