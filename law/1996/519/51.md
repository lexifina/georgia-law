# მუხლი 51. კლიმატის დაცვა გლობალური ცვლილებებისაგან
1. გლობალური ცვლილებებისაგან დედამიწის კლიმატის დაცვის მიზნით საქმიანობის სუბიექტი ვალდებულია დაიცვას ატმოსფეროში სათბურის ეფექტის გამომწვევი გაზების გამოყოფის (ემისიის) ნორმები და განახორციელოს მათი შემცირების ღონისძიებანი.
2. სათბურის ეფექტის გამომწვევი გაზების გამოყოფა რეგულირდება გარემოს დაბინძურების ინტეგრირებული კონტროლის სისტემის საფუძველზე.
3. საქართველოს იურისდიქციის ფარგლებში გლობალური ცვლილებებისაგან კლიმატის დაცვის სამართლებრივ რეჟიმს აწესებს საქართველოს კანონმდებლობა.
[ მუხლი 51 1 . სათბურის აირების ემისიების ავტორიზაცია
1. საქართველოს მთავრობის დადგენილებით განსაზღვრული საქმიანობებისთვის აუცილებელია სათბურის აირების ემისიების ავტორიზაცია.
2. სათბურის აირების ემისიების ავტორიზაციას საქართველოს მთავრობის დადგენილებით განსაზღვრული საქმიანობებისთვის, გარდა საავიაციო საქმიანობებისა, გასცემს სამინისტროს სისტემაში შემავალი საჯარო სამართლის იურიდიული პირი − გარემოს ეროვნული სააგენტო, ხოლო საქართველოს მთავრობის დადგენილებით განსაზღვრული საავიაციო საქმიანობებისთვის − საქართველოს ეკონომიკისა და მდგრადი განვითარების სამინისტროს სისტემაში შემავალი საჯარო სამართლის იურიდიული პირი − სამოქალაქო ავიაციის სააგენტო.
3. ავტორიზაციის მისაღებად წარდგენილი განცხადება, საქართველოს ზოგადი ადმინისტრაციული კოდექსის 78-ე მუხლით გათვალისწინებული ინფორმაციის გარდა, უნდა შეიცავდეს:
ა) იმ დანადგარებისა და საქმიანობების, მათ შორის, ტექნოლოგიების, აღწერას, რომლებმაც შესაძლოა გამოიწვიოს სათბურის აირების ემისიები;
ბ) იმ ნედლი და დამხმარე მასალების შესახებ ინფორმაციას, რომელთა გამოყენებამაც შესაძლოა გამოიწვიოს სათბურის აირების ემისიები;
გ) საქართველოს მთავრობის დადგენილებით განსაზღვრული სათბურის აირების ემისიების წყაროების შესახებ ინფორმაციას;
დ) სათბურის აირების ემისიების მონიტორინგისა და ანგარიშგების გეგმის პროექტს;
ე) ამ პუნქტის "ა"-"დ" ქვეპუნქტებით გათვალისწინებული ინფორმაციის მოკლე, არატექნიკურ რეზიუმეს. არატექნიკური რეზიუმე შეიცავს სათბურის აირების ემისიების ავტორიზაციის მისაღებად წარდგენილი განცხადებისთვის დართული დოკუმენტების შესახებ მოკლე ინფორმაციას და შესრულებულია არატექნიკურ ენაზე. საჭიროების შემთხვევაში მას ერთვის გრაფიკული ან/და საილუსტრაციო მასალები.
4. სათბურის აირების ემისიების ავტორიზაცია ინდივიდუალური ადმინისტრაციულ-სამართლებრივი აქტია. იგი უნდა შეესაბამებოდეს საქართველოს ზოგადი ადმინისტრაციული კოდექსით დადგენილ მოთხოვნებს. სათბურის აირების ემისიების ავტორიზაცია, გარდა საქართველოს ზოგადი ადმინისტრაციული კოდექსის 53-ე მუხლით დადგენილი მოთხოვნების დაკმაყოფილებისა, უნდა შეიცავდეს:
ა) საქმიანობის განმახორციელებელი პირის დასახელებას, საიდენტიფიკაციო ნომერს ან/და პირად ნომერს და მისამართს;
ბ) საქმიანობისა და სათბურის აირების ემისიების აღწერას;
გ) სათბურის აირების ემისიების მონიტორინგის გეგმას. ეს გეგმა უნდა აკმაყოფილებდეს საქართველოს მთავრობის დადგენილებით განსაზღვრულ მოთხოვნებს. იგი მტკიცდება ავტორიზაციის შესახებ გადაწყვეტილებასთან ერთად;
დ) სათბურის აირების ემისიების ანგარიშგებასთან დაკავშირებულ ვალდებულებებს.
5. სათბურის აირების ემისიების ავტორიზაცია უვადოდ გაიცემა.
6. სათბურის აირების ემისიების ავტორიზაციის ძალადაკარგულად გამოცხადების საფუძველი, საქართველოს ზოგადი ადმინისტრაციული კოდექსის 61-ე მუხლით გათვალისწინებული საფუძვლების გარდა, შეიძლება იყოს:
ა) საქმიანობის განმახორციელებელი პირის მოთხოვნა;
ბ) საქმიანობის განმახორციელებელი პირის მიერ სათბურის აირების ემისიების ავტორიზაციის მიღებიდან 5 წლის ვადაში ამ ავტორიზაციით გათვალისწინებული საქმიანობის დაუწყებლობა;
გ) საქმიანობის განმახორციელებელი პირის მიერ სათბურის აირების ემისიების ავტორიზაციით გათვალისწინებული საქმიანობის 2 კალენდარული წლის განმავლობაში შეჩერება, თუ იგი ვერ დაასაბუთებს, რომ აღნიშნულ პერიოდში ჩატარდა სარემონტო ან განახლებითი სამუშაოები.
7. სათბურის აირების ემისიების ავტორიზაციის გამცემი ორგანო უფლებამოსილია სათბურის აირების ემისიების მონიტორინგის გეგმის დამტკიცებამდე შექმნას საექსპერტო კომისია ან მოიწვიოს ექსპერტი. საექსპერტო კომისია ან ექსპერტი განიხილავს ამ გეგმას და შესაბამის დასკვნას წარუდგენს სათბურის აირების ემისიების ავტორიზაციის გამცემ ორგანოს.
8. საქმიანობის განმახორციელებელი პირი ვალდებულია სათბურის აირების ემისიების ავტორიზაციის გამცემ ორგანოს დაუყოვნებლივ აცნობოს საქმიანობასთან დაკავშირებული ექსპლუატაციის პირობის ნებისმიერი დაგეგმილი ცვლილების შესახებ, რომელმაც შესაძლოა გავლენა მოახდინოს სათბურის აირების ემისიებზე. აღნიშნული პირობის ცვლილებისა და მის მიერ შესაბამისი გავლენის მოხდენის ფაქტის დადგენის შემთხვევაში სათბურის აირების ემისიების ავტორიზაციაში სათანადო ცვლილება უნდა იქნეს შეტანილი.
9. საქმიანობის განმახორციელებელი პირი ვალდებულია ამ მუხლის მე-8 პუნქტით გათვალისწინებულ ავტორიზაციაში ცვლილების შეტანის საჭიროების შემთხვევაში ან/და საქართველოს მთავრობის დადგენილებით განსაზღვრულ სხვა შემთხვევაში სათბურის აირების ემისიების ავტორიზაციის გამცემ ორგანოს არაუგვიანეს შესაბამისი წლის 31 დეკემბრისა წარუდგინოს სათბურის აირების ემისიების მონიტორინგის გეგმაში ცვლილების შეტანის შესახებ წინადადება. ამ წინადადების განხილვის შედეგად სათბურის აირების ემისიების ავტორიზაციაში სათანადო ცვლილება იქნება შეტანილი.
10. საქმიანობის განმახორციელებელ პირს უფლება აქვს, სათბურის აირების ემისიების ავტორიზაცია სრულად ან ნაწილობრივ გადასცეს სხვა პირს, თუ ეს არ ეწინააღმდეგება ამ ავტორიზაციით გათვალისწინებული საქმიანობის არსს ან/და საქართველოს კანონმდებლობით დადგენილ მოთხოვნებს. სათბურის აირების ემისიების ავტორიზაციის გადაცემა გულისხმობს როგორც უფლებების, ისე შესაბამისი ვალდებულებების გადაცემას.
11. სათბურის აირების ემისიების ავტორიზაციის გადაცემის შესახებ ინდივიდუალური ადმინისტრაციულ-სამართლებრივი აქტის გამოცემის საფუძველია ამ ავტორიზაციის მფლობელისა და მიმღების ერთობლივი განცხადება, ხელშეკრულება ან საქართველოს კანონმდებლობით გათვალისწინებული სხვა დოკუმენტი, რომელიც ადასტურებს აღნიშნული ავტორიზაციის გადაცემის ფაქტს.
12. სათბურის აირების ემისიების ავტორიზაციის გამცემი ორგანო სათბურის აირების ემისიების ავტორიზაციის გადაცემის თაობაზე განცხადებას იხილავს და გადაწყვეტილებას იღებს საქართველოს ზოგადი ადმინისტრაციული კოდექსით დადგენილი მარტივი ადმინისტრაციული წარმოების წესით.
13. პირი, რომელსაც სათბურის აირების ემისიების ავტორიზაცია გადაეცა, ვალდებულია შესაბამისი საქმიანობა განახორციელოს მხოლოდ ამ მუხლის მე-11 და მე-12 პუნქტებით გათვალისწინებული აქტის გამოცემის/გადაწყვეტილების მიღების შემდეგ.
14. სათბურის აირების ემისიების ავტორიზაციის გამცემი ორგანო ამ მუხლის მე-11 და მე-12 პუნქტებით გათვალისწინებული გადაწყვეტილების მიღებიდან 3 სამუშაო დღის ვადაში უზრუნველყოფს შესაბამისი სამართლებრივი აქტის გარემოსდაცვით საინფორმაციო პორტალზე განთავსებას.

1. საქმიანობის განმახორციელებელი პირი ვალდებულია აწარმოოს სათბურის აირების ემისიების მონიტორინგი სათბურის აირების ემისიების მონიტორინგის გეგმის საფუძველზე, დანადგარების კატეგორიზაციის, ემისიების წყაროების ნაკადებისა და ემისიების წყაროების შესაბამისი მეთოდოლოგიის თანახმად.
2. საქმიანობის განმახორციელებელი პირი ვალდებულია სათბურის აირების ემისიების ავტორიზაციის გამცემ ორგანოს ყოველწლიურად, არაუგვიანეს შესაბამისი წლის 31 მარტისა წარუდგინოს სათბურის აირების წლიური ემისიების შესახებ ანგარიში. ეს ანგარიში დამმოწმებლის მიერ შესაბამისი ფორმით უნდა იყოს დამოწმებული.
3. ამ მუხლის მე-2 პუნქტით გათვალისწინებული ანგარიშის სათბურის აირების ემისიების ავტორიზაციის გამცემი ორგანოსთვის წარდგენით საქმიანობის განმახორციელებელი პირის ანგარიშგების ვალდებულება შესრულებულად მიიჩნევა.
4. დამმოწმებელი სათბურის აირების წლიური ემისიების შესახებ ანგარიშს დაამოწმებს სათბურის აირების ემისიების მონაცემთა დამოწმების წესის შესაბამისად.
5. სათბურის აირების ემისიების ავტორიზაციის გამცემი ორგანო სათბურის აირების წლიური ემისიების შესახებ დამოწმებული ანგარიშის მიღებიდან 5 სამუშაო დღის ვადაში უზრუნველყოფს მის გარემოსდაცვით საინფორმაციო პორტალზე განთავსებას.
6. საერთაშორისო ავიაციისთვის ნახშირორჟანგის კომპენსაციისა და შემცირების სქემის (CORSIA) ფარგლებში ნახშირორჟანგის გამონაბოლქვის მონიტორინგის, ანგარიშგებისა და შესაბამისი ანგარიშების დამოწმების მიმართ მოთხოვნები დგინდება "საერთაშორისო ავიაციისთვის ნახშირორჟანგის გამონაბოლქვის შემცირებისა და კომპენსაციის წესის დამტკიცების შესახებ" სსიპ − სამოქალაქო ავიაციის სააგენტოს დირექტორის ბრძანებით.
