# მუხლი 151 . კოლხეთის ეროვნული პარკის ტრადიციული გამოყენების ზონა
1. კოლხეთის ეროვნული პარკის ტრადიციული გამოყენების ზონა (შემდგომ ამ მუხლში − ტრადიციული გამოყენების ზონა ) " დაცული ტერიტორიების სისტემის შესახებ " საქართველოს კანონის შესაბამისად ეწყობა ტრადიციული სამეურნეო საქმიანობის დაცვისა და თვითმყოფადი გარემოს შენარჩუნებისათვის .
2. ტრადიციული გამოყენების ზონის ძირითადი მიზანია განახლებადი ბუნებრივი რესურსების კონტროლირებადი და მდგრადი გამოყენება ეკოსისტემების დაცვისა და მონიტორინგის აუცილებელი განხორციელებით .
3. ტრადიციული გამოყენების ზონაში დაშვებულია მხოლოდ :
ა ) ადგილობრივი მოსახლეობის მოთხოვნილებისა და ბუნებრივი პროდუქტიულობის გათვალისწინებით ლიმიტირებული ძოვება , თიბვა , თევზჭერა და საშეშე მერქნის დამზადება ;
ბ ) არამანიპულაციური და მანიპულაციური სამეცნიერო კვლევები ;
გ ) საგანმანათლებლო საქმიანობა ;
დ) ეკოტურიზმი, მათ შორის, ტურისტული ინფრასტრუქტურის მოწყობა;
ე ) ვიზიტორთა გადაადგილება განსაზღვრული წესით დადგენილ საზღვრებში (ქვეითად , ცხენით , ნიჩბიანი ან ელექტროძრავიანი ნავით );
ვ ) აღდგენითი ღონისძიებების განხორციელება ;
ზ ) მონიტორინგის სამუშაოების წარმოება ;
თ ) საკადასტრო სამუშაოების განხორციელება ;
ი) სამსახურებრივი მოვალეობების შესრულების მიზნით ავტომოტო-, საჰაერო და სანაოსნო სატრანსპორტო საშუალებებით გადაადგილება;
კ ) ტრადიციული გამოყენების ზონის ფიზიკური დაცვის მიზნით აუცილებელი ღონისძიებების განხორციელება.
4. ტრადიციული გამოყენების ზონის ზუსტი მდებარეობა , ფართობი და საზღვრები " დაცული ტერიტორიების სისტემის შესახებ " საქართველოს კანონის შესაბამისად დგინდება ამავე დაცული ტერიტორიის სა მენეჯმენტო გეგმის მიხედვით .
