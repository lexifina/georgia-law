# მუხლი 23. დაბადების რეგისტრაციის ადგილი
1. დაბადების რეგისტრაცია წარმოებს ბავშვის დაბადების ადგილის ან ერთ-ერთი მშობლის რეგისტრაციის ადგილის მიხედვით, აგრეთვე დაბადების იურიდიული მნიშვნელობის მქონე ფაქტის დადგენის შესახებ გადაწყვეტილების გამოტანის ადგილის მიხედვით.
2. ბავშვის დაბადების ადგილად მიიჩნევა ის ადმინისტრაციული ტერიტორია, სადაც დაიბადა ბავშვი.
3. თუ ბავშვი მგზავრობისას დაიბადა, მისი დაბადების რეგისტრაცია წარმოებს ერთ-ერთი მშობლის რეგისტრაციის ადგილის მიხედვით.
4. დაბადების აქტის ჩანაწერში და დაბადების მოწმობაში მიეთითება ბავშვის დაბადების ადგილი. მშობლების სურვილისამებრ დაბადების ადგილად შეიძლება მითითებულ იქნეს დაბადების რეგისტრაციის ადგილი.
