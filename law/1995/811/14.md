# მუხლი 14. იმ შეზღუდული შესაძლებლობის მქონე პირების სოციალური დაცვა, რომლებსაც შესაძლებლობა მეორე მსოფლიო ომის შედეგად, სხვა სახელმწიფოთა ტერიტორიებზე მიმდინარე საბრძოლო მოქმედებების შედეგად და საქართველოს ტერიტორიული მთლიანობისთვის, თავისუფლებისა და დამოუკიდებლობისთვის მიმდინარე საბრძოლო მოქმედებების შედეგად შეეზღუდათ
1. ამ კანონის მე-11 და მე-12 მუხლებით გათვალისწინებული შეზღუდული შესაძლებლობის მქონე პირების სოციალური დაცვა ითვალისწინებს:
ა ) საპენსიო უზრუნველყოფას "სახელმწიფო პენსიის შესახებ" საქართველოს კანონის შესაბამისად;
ბ ) დაკავებული სასამსახურო საცხოვრებელი სახლებიდან სამაგიეროს მიუცემლად გამოსახლების დაუშვებლობას;
გ ) საყოფაცხოვრებო-კომუნალური მომსახურების (წყლის, საყოფაცხოვრებო და სხვა ნარჩენების გატანის, გაზის, ელექტროენერგიის, ტელეფონის) სააბონენტო გადასახადების გადახდისგან გათავისუფლებას, აგრეთვე ქალაქში საქალაქო ტრანსპორტით (გარდა ტაქსისა) სარგებლობას, ხოლო სოფლად - საგარეუბნო და საქალაქთაშორისო ტრანსპორტით სარგებლობას საქართველოს კანონმდებლობის შესაბამისად;
დ ) სოციალური დაცვის სხვა გარანტიებს საქართველოს კანონმდებლობის შესაბამისად.
2. ომის ვეტერანთა ჰოსპიტლების დახურვა დაიშვება მხოლოდ საქართველოს მთავრობის დადგენილებით.
