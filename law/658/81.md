# მუხლი 81
1. საქართველოს კონტროლის პალატა ძირითადად კომპლექტდება ეკონომიკური და იურიდიული განათლების მქონე პირებით. საქართველოს კონტროლის პალატის საკონტროლო-სარევიზიო საქმიანობით დაკავებულ მოხელეს უნდა ჰქონდეს უმაღლესი განათლება, სპეციალობით მუშაობის არანაკლებ სამი წლის სტაჟი და გავლილი - საკვალიფიკაციო-საატესტაციო გამოცდა.
2. საკვალიფიკაციო-საატესტაციო გამოცდის ჩატარების წესი განისაზღვრება ცალკე დებულებით, რომელსაც საქართველოს კონტროლის პალატის თავმჯდომარის წარდგინებით ამტკიცებს საქართველოს პრეზიდენტი.
3. საქართველოს კონტროლის პალატის საკონტროლო-სარევიზიო საქმიანობით დაკავებული მოხელე საკვალიფიკაციო-საატესტაციო გამოცდის ჩაუბარებლობის შემთხვევაში თავისუფლდება თანამდებობიდან.
- საქართველოს 2000 წლის 8 დეკემბრის კანონი №672 - სსმ I, №50, 27.12.2000 წ., მუხ.142
