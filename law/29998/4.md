# მუხლი 4. შეთანხმების სახეები
1. შრომითი და სოციალურ-ეკონომიკური ურთიერთობების სფეროდან გამომდინარე შეიძლება დაიდოს გენერალური, დარგობრივი (დარგთაშორისი, პროფესიული) და ტერიტორიული შეთანხმება.
2. გენერალური შეთანხმება ადგენს შრომითი და სოციალურ-ეკონომიკური ურთიერთობების მოწესრიგების ზოგად პრინციპებს სახელმწიფო დონეზე.
3. დარგობრივი (დარგთაშორისი, პროფესიული) შეთანხმება ადგენს შრომით და სოციალურ-ეკონომიკურ ურთიერთობებს ერთი ან რამდენიმე დარგისათვის ან პროფესიისათვის.
4. ტერიტორიული შეთანხმება ადგენს შრომით და სოციალურ-ეკონომიკურ ურთიერთობებს ქალაქის, რაიონის და სხვა ადმინისტრაციულ-ტერიტორიული ერთეულისათვის, მისი თავისებურებების გათვალისწინებით.
5. შეთანხმება შეიძლება იყოს ორმხრივი ან სამმხრივი.
