# მუხლი 4. მექანიკური სატრანსპორტო საშუალების პირველად რეგისტრაციაზე უარის თქმის საფუძველი
დაინტერესებული პირის მიერ შეძენილი, სახელმწიფო (საბაჟო) კონტროლის გვერდის ავლით ან მისგან მალულად საქართველოს ეკონომიკურ ტერიტორიაზე შემოტანილი მექანიკური სატრანსპორტო საშუალების პირველადი რეგისტრაცია არ განხორციელდება:
ა) თუ მექანიკურ სატრანსპორტო საშუალებაზე აღრიცხულია უფლებრივი შეზღუდვა;
ბ) თუ მექანიკური სატრანსპორტო საშუალება ან მისი პირველადი რეგისტრაციის მიზნით წარდგენილი დოკუმენტაცია ვერ აკმაყოფილებს საქართველოს კანონმდებლობით დადგენილ მოთხოვნებს;
გ) თუ დაინტერესებულ პირს მექანიკური სატრანსპორტო საშუალება შეძენილი აქვს არაკეთილსინდისიერად ან არ დასტურდება მექანიკური სატრანსპორტო საშუალების კეთილსინდისიერად შეძენის ფაქტი;
დ) თუ დაინტერესებულმა პირმა მექანიკური სატრანსპორტო საშუალება შეიძინა 2006 წლის 1 ივლისის შემდეგ;
ე) თუ მექანიკური სატრანსპორტო საშუალება ან დაინტერესებული პირი ვერ აკმაყოფილებს ამ კანონით დადგენილ მოთხოვნებს;
ვ ) საქართველოს კანონმდებლობით გათვალისწინებულ სხვა შემთხვევებში.
