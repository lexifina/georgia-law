# მუხლი 3. ტერმინთა განმარტება
ამ კანონში გამოყენებულ ტერმინებს აქვს შემდეგი მნიშვნელობა:
ა) სააგენტო - საჯარო სამართლის იურიდიული პირი - საქართველოს შინაგან საქმეთა სამინისტროს მომსახურების სააგენტო (შემდგომ − სააგენტო) ;
ბ ) მექანიკური სატრანსპორტო საშუალება - 50სმ3 -ზე მეტი ძრავის მუშა მოცულობის მქონე სატრანსპორტო საშუალება (მოპედის გარდა), აგრეთვე ყველა სახის სასოფლო-სამეურნეო ტექნიკა, მათი მისაბმელები, ნომრიანი აგრეგატები და დამხმარე ტექნიკური საშუალებები, რომელთა დადგენილი წესით რეგისტრაციასაც ახორციელებს სააგენტო;
გ ) კეთილსინდისიერად შეძენილი მექანიკური სატრანსპორტო საშუალება - საქართველოს მოქალაქის ან საქართველოში რეგისტრირებული იურიდიული პირის მიერ 2006 წლის 1 ივლისამდე კეთილსინდისიერად შეძენილი, სახელმწიფო (საბაჟო) კონტროლის გვერდის ავლით ან მისგან მალულად საქართველოს ეკონომიკურ ტერიტორიაზე 2006 წლის 1 ივლისამდე შემოტანილი მექანიკური სატრანსპორტო საშუალება;
დ ) დაინტერესებული პირი - ამ მუხლის "გ " ქვეპუნქტით განსაზღვრული სატრანსპორტო საშუალების შემძენი, რომელსაც ამ კანონით დადგენილი წესით სურს მექანიკური სატრანსპორტო საშუალების პირველადი რეგისტრაციის განხორციელება ;
ე ) პირველადი რეგისტრაცია − დაინტერესებული პირის მიერ მექანიკური სატრანსპორტო საშუალების სააგენტოში დადგენილი წესით პირველადი დარეგისტრირება (აღრიცხვაზე აყვანა), მისთვის სარეგისტრაციო ნიშნების მინიჭება და საგზაო მოძრაობაში მონაწილეობისათვის მის ი დაშვება.
