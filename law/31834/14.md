# მუხლი 14. იმ პირის უფლებები და მოვალეობები, რომელიც დახმარებას უწევს სახელმწიფო უშიშროების სამსახურს
1. სახელმწიფოს უშიშროების დაცვის მიზნით პირს უფლება აქვს ნებაყოფილობით ითანამშრომლოს და დახმარება აღმოუჩინოს სახელმწიფო უშიშროების სამსახურს.
2. პირს, რომელიც დახმარებას უწევს სახელმწიფო უშიშროების სამსახურს, უფლება აქვს:
ა) სახელმწიფო უშიშროების სამსახურთან დადოს კონტრაქტი კონფიდენციალური თანამშრომლობის შესახებ;
ბ) სახელმწიფო უშიშროების სამსახურის თანამშრომლებისაგან მიიღოს განმარტებები თავისი ამოცანების, უფლებებისა და მოვალეობების თაობაზე;
გ) კონსპირაციის მიზნით გამოიყენოს პირადობის დამადასტურებელი დაშიფრული დოკუმენტები;
დ) მიიღოს ანაზღაურება კონტრაქტით გათვალისწინებულ შემთხვევაში, აგრეთვე იმ ზიანის კომპენსაცია, რაც მიადგა მის ჯანმრთელობას ან ქონებას სახელმწიფო უშიშროების სამსახურისათვის დახმარების გაწევისას.
3. პირი, რომელიც სპეციალური კონტრაქტის საფუძველზე დახმარებას უწევს სახელმწიფო უშიშროების სამსახურს, ვალდებულია:
ა) შეასრულოს სახელმწიფო უშიშროების სამსახურის დავალებები მის წინაშე მდგომი ამოცანების გადასაწყვეტად;
ბ) დაიცვას სახელმწიფო უშიშროების სამსახურთან დადებული კონტრაქტის პირობები;
გ) განზრახ არ მიაწოდოს სახელმწიფო უშიშროების სამსახურს ყალბი ან ცილისმწამებლური ინფორმაცია.
4. პირი, რომელიც დახმარებას უწევს სახელმწიფო უშიშროების სამსახურს, ამ სამსახურისათვის განზრახ ყალბი ან ცილისმწამებლური ინფორმაციის მიწოდებისათვის, ან კანონით დაცული იმ ინფორმაციის გამჟღავნებისათვის, რომელიც მისთვის ცნობილი გახდა სახელმწიფო უშიშროების სამსახურთან თანამშრომლობის დროს, პასუხს აგებს საქართველოს კანონმდებლობით.
5. იმ პირის სოციალური უფლებების დაცვას, რომელიც დახმარებას უწევს სახელმწიფო უშიშროების სამსახურს, განსაზღვრავს საქართველოს კანონმდებლობა.
6. პირი, რომელიც დახმარებას უწევს სახელმწიფო უშიშროების სამსახურს, საქართველოს კანონმდებლობისა და სახელმწიფო უშიშროების სამინისტროში დადგენილი წესის შესაბამისად შეიძლება ჩაირიცხოს სახელმწიფო უშიშროების სამსახურში.
